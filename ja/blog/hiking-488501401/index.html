概要

写真:韓国観光公社 観光写真ギャラリー(江原特別自治道 麟蹄郡)・公共ヌリ

黄腸山(ファンジャンサン、荒場山)は、慶尚北道聞慶市東魯面と忠清北道丹陽郡の境界をなす白頭大幹の稜線上にある山です。山頂の標高は約1,076mとして登録されていますが、実測GPXで見ると山頂部の最高地点は1,085mまで上がることが確認されています。聞慶セジェの南側、道楽山・黄庭山・水利峰へと連なる白頭大幹の一角に位置し、岩稜と奇岩が入り混じった「骨山(コルサン)」的な性格の強い山として知られています。公式の登山路データでは難易度は「やさしい」と分類されていますが、実際に山頂まで登る代表コースは距離と高低差を考えると体力的に決して軽い山行ではありません。とはいえ、日帰りの往復でも十分にこなせる山です。

山容と地形

写真: 韓国観光公社 観光写真ギャラリー (慶尚北道聞慶市東魯面アンセンダル路279) · 公共ヌリ

黄腸山は典型的な岩峰型の山で、山頂部から稜線のあちこちに、垂直に近い岩壁と幅の狭い岩稜が発達しています。山容の核となるのは白頭大幹の稜線筋をたどるラインで、山頂付近ではデッキ階段や展望台が設けられるほどの急傾斜の岩場が続きます。代表的なピークは黄腸山（1,076m）の山頂で、その近くにはカムトゥ峰と呼ばれる岩峰、そしてヌウンの滝周辺の岩盤地帯が、特徴的な地形として挙げられます。山頂部の稜線には「天国の階段」と呼ばれる急傾斜のデッキ区間があり、岩稜と人工物が同居する地形的な個性を見せています。全体としては土の山というより岩と絶壁が主役の骨山（コルサン）型の山容で、谷筋（ヌウンの滝の周辺）には水の流れがあるものの、年間を通して水量豊かな沢というわけではなさそうです。

山登りの雰囲気

写真: 韓国観光公社 観光写真ギャラリー（慶尚北道聞慶市東魯面ヨウモク路2371-5）· 公共누리(KOGL)

登山口から前半は森の道が中心に続き、中盤を過ぎて分岐点を通ると、だんだん岩や岩稜が姿を見せる区間へと表情が変わっていく——これがこの山行のいわば定番の流れです。ヌウン滝を過ぎて山頂エリアに入ると、岩盤とロープ・デッキの区間が続き、体感の難易度が一気に跳ね上がります。山頂近くの日陰の休憩所と山頂休憩所を過ぎて黄腸山の頂に立てば、道楽山の展望ポイントとデッキ展望台から白頭大幹の稜線と周囲の山並みが気持ちよく広がる眺めを楽しめます。春は新緑と野の花、秋は紅葉が稜線と溶け合って、季節感がはっきり出る山として知られています。夏は森の区間の日陰が暑さをある程度やわらげてくれますが、岩稜の区間は照りつける日差しにさらされがちです。冬は岩稜とデッキ階段の区間が凍結して山行の雰囲気がまるで別物になり、静かで穏やかな雪景色どころか、かなりの緊張感を求められる区間へと変わります。

コース1 — センダル公営駐車場 → 山頂付近の日陰休憩所

📏 5.65km ⛰️ 582m 獲得標高 ⏱️ 2:23 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由: 月岳山（ウォラクサン）黄腸山（ファンジャンサン）センダル公営駐車場 → センダル2里 村会館トイレ → 分岐点 → 黄腸山公園管理所 → ヌウンの滝 → 山頂付近の日陰休憩所 → 山頂休憩所 → 黄腸山山頂 → 道楽山（トラクサン）展望ポイント → デッキ展望台 → 山頂部デッキ道 → 天国の階段 → アンセンダル展望ポイント → ウェイポイント22 → ウェイポイント23

登山口へのアクセス: センダル公営駐車場は聞慶（ムンギョン）市東魯（トンノ）面センダル里一帯にあり、鉄道駅や地下鉄で近づくのは難しい山間部です。近くの公共交通はアンセンダル橋、センダル2里の停留所を行き来する地域バスを使うのが一般的ですが、本数がかなり少なめなので、事前に時刻表を確認しておくのがおすすめです。「公営駐車場」という名前とは裏腹に、公共データ上では駐車場施設の登録が確認できませんでした。実際に停められるかどうか、どのくらいの規模なのかは、現地で確かめたほうがよさそうです。

特徴・おすすめの方: 序盤は集落の道と森の道を進み、公園管理所を過ぎたあたりから本格的な山道が始まります。ヌウンの滝の区間からは、岩と水の流れが織りなす渓谷の雰囲気を味わえます。その先、山頂圏に近づくにつれて岩稜とデッキ階段が続き、体力の消耗が大きくなる区間なので、白頭大幹（ペクトゥデガン）縦走をされる方や、岩稜歩きに慣れた登山者に向いたコースです。山頂近くの道楽山展望ポイントとデッキ展望台からは、視界の開けた稜線の眺めが得られるので、展望重視の登山者にも満足度は高めだと思います。ただ、初心者には急勾配のデッキや岩稜区間がしんどく感じられるかもしれません。ある程度の山歩き経験がある方にこそおすすめしたいコースです。

難易度・路面・注意点

写真: 韓国観光公社 観光写真ギャラリー（慶尚北道 聞慶市 東魯面 生達里）· 公共ヌリ

市内の登山道空間情報では最高難易度が「やさしい」として登録されているのですが、これはあくまで市内の登山道の総延長（3.1km）を基準にした分類です。実際に山頂まで登る代表コース（5.65km、純高度差582m）は、100名山のGPX実測値をもとにすると★★★★☆評価。なかなか手強い山行になります。路面についての詳細な属性は公共データに登録がありませんが、山の姿からして、山頂に近づくほど岩盤・岩場の区間が増えていくと見てよさそうです。展望地点、危険地域、避難小屋、登山口・下山口といった施設は、公共データの地点ベースではすべて0か所。案内設備や避難できる場所はあてにできない区間だと思っておいたほうがいいでしょう。こうした岩稜地形ですから、雨の日は岩が滑りやすくなること、とくに冬場の凍結時はデッキ階段と岩稜区間での転落・転倒リスクが跳ね上がることに、くれぐれも注意してください。

距離と所要時間

管内の登山道全区間を積み上げた公共データ上では、登り55分・下り38分という数字が出ており、そこから割り出される平均の登りペースは約18分/kmになります。ただしこれは管内の全区間を合計した値なので、実際に山頂まで登る代表コース（センダル公営駐車場 → 山頂付近の木陰休憩所、5.65km）の所要時間と取り違えてはいけません。このコースの実測ベースの推定所要時間は、片道でおよそ2時間23分です。下山まで含めれば往復4〜5時間前後が一般的な範囲と見てよく、日帰り登山で十分にこなせる山だと言えます。避難小屋の登録がないことを考えると、あえて1泊で計画する理由はあまりありませんが、近くのトラクサン（道楽山）やファンジョンサン（黄井山）と繋げた縦走を狙うなら、1泊の行程に広がることもあります。

アクセス（公共交通機関・駐車場）

黄腸山（ファンジャンサン）のセンダル登山口の近くまでは、公共交通機関だとアンセンダル橋、センダル2里の停留所があるようで、聞慶（ムンギョン）方面か丹陽（タニャン）方面から地域バスで向かうのが一般的なようです。ただ、山間部ということもあってバスの本数はかなり少なく、路線自体もちょくちょく変わるので、出かける前にKakaoMapかNaver Mapでリアルタイムの路線と時刻をしっかり確認しておくのが無難です。車で行く場合は「センダル公営駐車場」で検索できるのですが、公共データ上では登録された駐車施設が見つからないので、現地の路肩に停めるなど別の手も頭に入れておくと安心です。なお、Googleマップは韓国の山間部だと登山道や細い道の情報が当てにならないことが多いので、KakaoMapかNaver Mapのアプリを使うことをおすすめします。

シーズン・天候・装備

登山に無理のないシーズンは春（4〜5月）と秋（9〜11月）で、新緑と紅葉のどちらも楽しめる時期です。夏場は森林区間には日陰がありますが、岩稜区間では直射日光と猛暑をまともに受けることになるので、水分と休憩はたっぷり確保してください。冬場は山頂周辺のデッキ階段や岩稜区間が凍りつくことが多く、アイゼンやスパッツといった冬用装備は事実上必須。初心者の方なら、そもそも冬の登山を選ぶかどうかから慎重に考えたほうがいいと思います。季節を問わず用意しておきたいのは、足首を守ってくれる登山靴、トレッキングポール、着替え、ヘッドランプ（非常用）、そして十分な量の飲み水です。山中の水飲み場は公開データ上では確認できませんでしたから、登山前に自分で水を多めに持っていくことが何より大事になります。

外国人旅行者向けのヒント

黄鳥山（ファンジャンサン）はローマ字で Hwangjangsan と表記し、山頂の標高は1,076〜1,085mです。代表的な登山口は Saengdal Public Parking Lot（センダル公営駐車場）の近くにあります。入山許可や入場料は特に確認されておらず、国立公園のような事前予約の手続きなしにアクセスできるようですが、現地の案内板で最新情報を確かめておくと安心です。トイレは登山口近くのセンダル2里村会館のトイレ（Saengdal 2-ri Village Hall Restroom）が使えます。ただし登山中はトイレも水飲み場も、データ上は確認できませんでした。出発前に必ずトイレを済ませ、飲み水は多めに持っていってください。地図アプリはGoogleマップよりも、KakaoMap（カカオマップ）かNaver Map（ネイバーマップ）のほうが韓国の山間部の登山道情報にはるかに正確なので、ぜひ併用をおすすめします。岩稜が中心の山容で、避難小屋や安全設備も特に整っていません。単独よりは誰かと一緒に歩くこと、そして天候が崩れそうなとき（特に冬の凍結時）は思い切って延期することをおすすめします。
