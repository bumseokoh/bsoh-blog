概要

写真: 韓国観光公社 観光写真ギャラリー（慶尚南道泗川市昆明面）· 公共누리

智異山（チリサン、Jirisan）は、慶尚南道から全羅南道・全羅北道にまたがる韓国屈指の国立公園の山です。最高峰の天王峰（チョンワンボン、Cheonwangbong）は、資料や測定地点によって1,938m〜1,945mと記録が分かれています。尾根が非常に長く、いくつもの峰が連なる大型の山体で、ちょっとした散策程度の区間から山頂を目指すロングトレイル縦走コースまで、難易度の幅がかなり広いのが特徴です。公園内に登録されている登山道の総延長は13.93km（複数区間を合計した数値で、単一コースの距離ではありません）、データ上の最高難易度は「中級」に分類されています。ただし、山頂を狙う実際のコースは片道7〜15km、累積標高差1,300m以上と体力の消耗が大きく、準備なしの日帰りで山頂を往復しようとするよりも、時間にゆとりを持って体調を整えて臨むべき山だと思います。

山の姿と地形

写真: 韓国観光公社 観光写真ギャラリー（全南光州統合特別市 求礼郡 土旨面）· 公共누리（KOGL）

智異山（チリサン）は花崗岩と片麻岩が入り混じった「土山（つちやま）」の性格が強い山ですが、稜線の頂上付近には岩場がところどころ混じっていて、なだらかな稜線と荒々しい岩稜が同居する地形になっています。代表的なピークは最高峰の天王峰（チョンワンボン）と、その西へ続く中峰（1,889m）。この二つを結ぶ稜線は、智異山縦走の象徴的な区間としてよく知られています。実測コース上には帝釈峰（チェソクボン）という名のピークも登場しますが、ここは古くから枯れ木（枯死木）の広がる一帯として有名な場所です。稜線全体がとにかく長いので、山全体の姿を一望するのは難しく、谷筋は深くて水量も豊かだと言われています。

山歩きの感触

写真: 韓国観光公社 観光写真ギャラリー（全南光州統合特別市 求礼郡 土旨面）· 公共누리

歩き始めの渓谷沿いは、うっそうとした森の中の道。それが標高を上げていくにつれて木が低くなり、視界がすっと開ける亜高山帯の地形へ変わっていく——ここが智異山登山のいちばん体で感じる部分だと思います。山頂近くの帝釈峰あたりは、枯れ木とススキが混ざり合った独特の風景で知られていて、空がぱっと開けたような開放感がある区間として挙げられています。季節感がとてもはっきりした山でもあって、春は新緑と山野草、秋は紅葉とススキ、そして冬は山頂部に樹氷と雪が積もって、まるで別の山かと思うほど雪景色が印象的だとか。全体としては、前半はゆるやかに進み、後半の山頂直前で一気に傾斜がきつくなる——そんな流れが実測の標高データからもちゃんと読み取れます。

コース1 — 智異山（中山里）→ 帝釈峰

📏 15.13km ⛰️ 1304m 獲得標高 ⏱️ 5:57 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由: 智異山（登山口）→ トイレ → 中山里探訪センター → 分岐 → カルバウィ → 石段 → デッキ階段 → 距離標 → マンバウィ → 展望ポイント → 避難小屋 → 法界寺 → 展望所 → 休憩所 → 開仙門

登山口へのアクセス: 道標に「中山里探訪センター」が含まれているので、智異山国立公園の中山里地区を登山口とするコースだと思われます。中山里地区は慶尚南道山清郡矢川面にあり、一般的には晋州市外バスターミナルや近隣の街から中山里行きの市外バス・農漁村バスで向かうルートがよく知られています。マイカーの場合は、中山里探訪支援センター近くの公営駐車場を使うのが一般的です。ただし今回の公共データの地点基準では、管内のバス停・駐車場がいずれも0か所と集計されているため、実際に訪れる前に自治体や国立公園の公式案内で最新の交通・駐車情報を必ず確認しておきたいところです。

特徴・おすすめの人: 序盤は渓谷沿いの森の道を登り、その後カルバウィ・石段・デッキ階段といった人工の設備が続く整備区間になるのが特徴です。法界寺を過ぎると一気に標高が上がり、視界が開けてきます。帝釈峰付近の枯れ木帯はこのコースでしか出会えない独特の景観。距離も標高差もかなりのものなので、体力に自信のある登山者や、智異山の縦走を計画している人に向いたロングコースです。

コース2 — チャムセム → 山頂

📏 7.18km ⛰️ 1410m 獲得標高 ⏱️ 4:09 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由: チャムセム（登山口付近の地点以外、追加の道標データはありません）

登山口へのアクセス: 「チャムセム（참샘）」という地名は、智異山（チリサン）のふもとの湧き水や渓谷の周辺でよく使われる名前で、正確な行政区域や公共交通機関の状況は今回の資料では特定できませんでした。智異山の南・西斜面にある渓谷登山口のひとつとして使われているようです。訪れる前に、KakaoMap や Naver Map で「참샘」と検索して、実際の進入路と周辺の公共交通・駐車事情を必ず事前に確認しておくことをおすすめします。

特徴・おすすめの方: 距離は7.18kmでコース1より短いのですが、純高度差はむしろ1,410mと大きく、短い距離のうちに一気に標高を稼ぐ急勾配型のコースだと言えます。序盤から登りが続く体感が強いので、のんびりした散策よりも本格的な登りを味わいたい方、あるいは短時間で山頂域の標高を体験したい経験者に向いています。道標データがチャムセム地点以外では確認できないため、実際に歩くときは国立公園の公式地図や現地の道標も併せて参考にすると安心です。

難易度・路面・注意点

写真：韓国観光公社 観光写真ギャラリー（全北特別自治道 南原市 朱川面）・公共누리（KOGL）

データ上、管内の登山路の最高難易度は「中級」に分類されていますが、山頂方面へ向かう実測コース2本はいずれも難易度が最高ランク（★★★★★）と算定されており、体力の消耗がかなり大きい区間だという点に注意が必要です。路面の材質については今回の資料に個別の記録がありませんが、コース1の道標に「石段・デッキ階段・カルバウィ（刀岩）」が登場することから、整備された階段区間と岩盤・ガレ場が入り混じっているものと思われます。こうした区間は雨天時に滑りやすくなり、冬場は凍結も珍しくないため、くれぐれも慎重に。施設に関する公共データを見ると、今回の資料では危険箇所・展望ポイント・水飲み場がいずれも0か所と集計されており、コース内に公式登録された便益施設はほとんどないようです。ただし現地には法界寺（ポッケサ）や避難小屋など、道標に記載された地点が実際に存在しますので、給水や休憩は事前にしっかり計画を立ててから入るのが得策です。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（全羅北道特別自治道 南原市 朱川面）· 公共누리（KOGL）

管内の全区間を累積した数字では、登り293分・下り202分と記録されています。これを総延長13.93kmに当てはめると、登りの平均ペースはおよそ21分/kmという計算になります。ただしこれは管内のいくつもの区間を足し合わせた累積値なので、特定の単一コースの所要時間だと勘違いしてはいけません。山頂周辺の実測コースを基準にすると、智異山（中山里）→帝釈峰コースが片道約5時間57分、チャムセム→山頂コースが片道約4時間9分。往復ならそれぞれ12時間、8時間前後かかることになり、日帰り登山としてはかなり長い行程です。データ上は避難小屋が0か所と集計されていて、形式的には日帰り可能に分類されるのですが、実際のところは早朝出発と余裕のある下山時間の確保が絶対条件。体力や時間に不安があるなら、無理に往復を狙わずコースの一部だけを歩く、あるいは宿泊・野営を前提にした計画を立てる、という手もあります。

アクセス（公共交通機関・駐車場）

写真：韓国観光公社 観光写真ギャラリー（全北特別自治道 南原市 朱川面）・公共누리（KOGL）

智異山（チリサン）の中山里（チュンサンリ）地区を起点にする場合、一般的には晋州（チンジュ）などの近隣拠点都市から中山里行きのバスに乗り換えてアクセスする方法が広く知られています。ソウルなど首都圏からなら、KTXか高速バスで晋州まで移動し、そこから現地のバスに乗り換えるルートが定番です。チャムセム（参샘）登山口については、今回の資料では正確な公共交通の路線が確認できませんでしたので、出かける前に KakaoMap または Naver Map で実際の道路とバス路線を必ず確認してください。Google マップは韓国国内の徒歩・公共交通の経路案内が正確でないことが多いので、現地ではカカオマップかネイバー地図のアプリを使うのがおすすめです。マイカーの場合は国立公園の公式駐車場か、近隣集落の公営駐車場を利用するのが一般的ですが、繁忙期や週末は満車になりがちなので、公共交通の利用か早めの到着をおすすめします。

シーズン・天候・装備

写真：韓国観光公社 観光写真ギャラリー（全北特別自治道 南原市 朱川面）・公共ヌリ

智異山（チリサン）は、春（4〜5月）と秋（10〜11月）が気温も視界も一番穏やかなシーズンとされています。夏は雨季・梅雨と気温の上昇で体力の消耗が激しく、落雷や集中豪雨の危険もあるので、事前の気象チェックが欠かせません。冬は山頂付近の凍結と強風、体感温度の急降下がよくあることなので、アイゼン・スパッツ・ウインドブレーカーといった冬季装備が必須で、初心者にとって冬の山頂までの登山はとりわけ手強いと言われています。季節に関係なく、登山靴、着替え、十分な飲み水と行動食、ヘッドランプ、防風・防水ジャケットは基本として持っていきたいところ。データ上、水場が0か所と集計されているだけに、飲み水は必ず事前に用意しておく必要があります。

外国人旅行者向けのヒント

写真: 韓国観光公社 観光写真ギャラリー（全羅北道特別自治道 南原市 朱川面）· 公共누리（KOGL）

智異山（チリサン）はローマ字で Jirisan、最高峰の天王峰は Cheonwangbong、中峰は Jungbong、帝釈峰は Jeseokbong と表記します。国立公園区域内の登山路そのものには入場料がかからないケースが一般的ですが、探訪予約制など時期ごとの規制がかかることもあるので、出かける前に韓国国立公園公団の公式サイトで最新の案内を確認しておくと安心です。トイレについては、コース1の道標に「トイレ」の表示があるので入口付近にはあるようですが、それ以外の区間では給水所・トイレのデータが確認できませんでした。飲み水と衛生用品は必ず事前に用意しておいてください。道案内は Google マップよりも KakaoMap か Naver Map を使うほうが圧倒的に正確で、英語インターフェースにも対応しています。智異山は稜線がとても長く天候の変化も激しい山なので、単独行より誰かと一緒に歩くこと、そして下山時刻に余裕をもたせて夜間の行動を避けることが安全につながります。
