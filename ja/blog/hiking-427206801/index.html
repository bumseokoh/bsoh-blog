概要

写真:韓国観光公社観光写真ギャラリー(江原特別自治道平昌郡龍坪面雲頭嶺路1243)・公共ヌリ

桂芳山(ケバンサン)は江原道の平昌郡と洪川郡の境界に位置する山で、頂上部の標高は資料によって1,572〜1,601mとまちまちに記録されていますが、韓国南部でも指折りの高峰の一つとしてよく知られています。山容はなだらかで稜線も柔らかい、いわゆる土山に近いため、標高のわりに登山の難易度はそれほど高くなく、代表的なコースなら日帰りで往復するのも十分可能です。公共データ上でも管内の登山道の最高難易度は「易しい」に分類されていて、初心者でも装備さえきちんと整えれば無理なく挑戦できる山として紹介されています。

山容と地形

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道平昌郡龍平面イスンボク生家路160）・公共누리

鶏芳山（ケバンサン）は、尖った岩峰が目立つタイプの山というより、幅広くどっしりとした稜線が続く、いかにも土の山らしい表情を持っています。頂上付近はほとんど草原と言っていいほどなだらかな地形が広がっていて、そのおかげで四方に遮るもののない眺めが楽しめるのだそうです。公共データに登録されている主な峰としては、鶏芳山頂上（1580m）と鶏芳山（1572m）の二つがあり、この山の頂上部分が一点の鋭い山頂ではなく、なだらかに続くいくつかの地点として捉えられていることがうかがえます。山全体としても、切り立った岩稜帯というよりは土の道と草地が中心で、ナラやモミ、イチイといった針葉樹・広葉樹が入り混じる森の道が主だと言われています。

登山の雰囲気

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 평창군 용평면 운두령로 728-3) · 공공누리

桂芳山(ケバンサン)は、登り口から頂上まで、とにかく鬱蒼とした森の中をひたすら歩き続けるタイプの山です。夏場は深い緑が空を覆って日陰が多く、ひんやり涼しいのがありがたいところ。秋には紅葉と一緒に落ち葉を踏みしめる感触が印象的な区間としても知られています。頂上に近づくにつれて木の背丈がだんだん低くなり視界が開けてくるのですが、これがまたたまらなくて、頂上に立つと四方に広がる山並みと空の稜線を一望できる開放感が待っています。切り立った岩稜をスリリングに攻めるタイプの山というより、黙々と登り続ける体力勝負の山という印象が強く、季節ごとに新緑・深緑・紅葉・雪景色とはっきり表情を変えるのも、この山の魅力の一つに挙げられます。

コース1 — 簡易休憩所 → 頂上

📏 4.71km ⛰️ 819m 獲得標高 ⏱️ 2:33 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地: 簡易休憩所 → イノシシの足跡 → ミヤマキリシマ → クィデガム岩 → 分岐点 → 休憩所 → 登山路案内板

登山口までのアクセス: 簡易休憩所の登山口は、桂芳山の南西斜面から登っていくポイントで、公共交通機関よりも自家用車でのアクセスが一般的に便利とされています。近隣の村(平昌郡龍平面一帯)から入るルートが一般的で、公共交通機関を使う場合は平昌市外バスターミナルや珍富駅から村営バス・タクシーに乗り換える方法がよく利用されています。公共データ上、管内に登録されているバス停・駐車場の数は確認できなかったため、訪問前に実際の道路状況や駐車の可否を地図アプリで再確認することをお勧めします。

特徴・おすすめの対象: このコースは純登高差が819mに達し、管内の2コースの中では比較的、上り坂が急でかつ長く続くほうなので、体力に自信のある登山者向けです。稜線沿いに登っていく中で、ミヤマキリシマの群落や岩場地形(クィデガム岩)を通過する区間があり、林間の道と岩場地形が交互に現れる変化があるのが特徴で、頂上への登頂そのものを目的とする登山者におすすめのコースです。

コース2 — 入口案内 → 展望台

📏 4.06km ⛰️ 460m 獲得標高 ⏱️ 1:47 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

経由地: 桂芳山ウンドゥリョン → トイレ → ウンドゥリョン林特産物広報館 → ウンドゥリョン休憩所 → 入口案内 → 休憩所 → トネリコの木 → 分岐点 → 立入禁止 → 案内板 → 立入禁止案内 → 低木帯 → 禁止行為案内 → 禁止案内 → 展望台

登山口へのアクセス: このコースの起点となるウンドゥリョン(雲頭嶺)は、国内の舗装道路の中でも標高の高い峠として広く知られており、6号国道沿いにあるため自家用車でも比較的アクセスしやすいと言われています。近くにはトイレや林産物広報館、休憩所などの施設がすでに整備されているので、公共交通機関よりもマイカーや貸切バスで訪れる人が多いようです。公共交通機関を使う場合は、チンブ駅や付近のバスターミナルからタクシーに乗り継ぐのが現実的な方法とされています。

特徴・おすすめの人: 純標高差460mとコース1より緩やかで、トネリコの群落やいくつもの案内板・立入禁止区間を通ることから見て、自然保護のための規制区間が多く含まれるコースのようです。山頂までは続かず展望台で終わる構成なので、短時間で眺望を楽しみたい旅行者や家族連れの訪問者、野生の花や植生の観察に関心のある人に向いているコースと言えそうです。

難易度・路面・注意点

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道平昌郡龍坪面雲頭嶺路714-52）・公共누리

山林庁の公共データによると、桂芳山（ケバンサン）管内の登山道の最高難易度は「易しい」として登録されていて、路面情報については特に記録がありません（登山道の総延長13.93km）。ただ、100大名山のGPX実測ベースで見ると、簡易休憩所から頂上までのコースは純高低差819mで難易度★★★★☆に相当していて、公共データ上の「易しい」という評価とは別に、実際の頂上登頂コースはかなり体力を使うコースだということも頭に入れておいたほうがいいです。コース内の施設としては展望ポイントが1カ所確認されていて、水場（泉）も1カ所あるので、給水できるスポットとして覚えておくと便利です。危険地域は公共データ上には特に登録されていませんが、頂上部の草地・尾根区間は強風や霧にさらされやすいので、雨天時や冬場の凍結区間ではとくに注意が必要です。特に冬は積雪や凍結で体感難易度がぐっと上がることで知られていて、アイゼンなどの補助装備なしで下山すると滑落の危険があります。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（江原特別自治道平昌郡珍富面パンアダリ路1011-26）· 公共누리

桂芳山には管内に登録された2つの区間（노동리区間9.99km、자운리区間3.94km）があって、合わせると総延長13.93kmの登山道になります。避難小屋は別途登録されていないので、日帰り登山で十分こなせる山と言っていいでしょう。実測GPXベースの代表的なコースを見ると、簡易休憩所→山頂は片道およそ2時間33分、入口案内所→展望台は片道およそ1時間47分と推定され、往復だとそれぞれ5時間前後、3時間30分前後で計画するのが一般的です。公共データ上では管内全区間を積算した数値として上り414分・下り289分という記録がありますが、これは個々のコースの所要時間ではなく、管内の登山道全体を合計した際の参考値である点に注意が必要です。これを換算すると、平均の上りペースはだいたい1kmあたり30分程度になります。このペースを目安にしつつ、自分の体力レベルに合わせてコースごとの所要時間を見積もってみるのが実用的だと思います。

行き方(公共交通・駐車)

写真:韓国観光公社観光写真ギャラリー(江原特別自治道平昌郡蓉坪面雲頭嶺路601-4)・公共ヌリ

桂芳山(ケバンサン)の近くまで行くには、KTXでチンブ(五台山)駅まで乗って、そこからタクシーか村営バスに乗り換えるのが一般的なルートです。ソウルなど首都圏からなら、市外バスで平昌(ピョンチャン)・チンブ方面のターミナルまで行き、現地の交通手段に乗り継ぐという手もあります。雲頭嶺(ウンドゥリョン)方面(入口案内→展望台コース)は6号国道沿いにあるので、マイカーでも比較的アクセスしやすいのですが、簡易休憩所の登山口(コース1)は村の中の道を通る必要があるので、事前にルートを確認しておいたほうが安心です。公共データ上、管内に登録されているバス停や駐車場は確認できなかったので、実際のバスの時刻表や駐車できるかどうかは、必ずKakaoMap(カカオマップ)やNaver Map(ネイバー地図)でリアルタイムに確認してから訪問の計画を立てることをおすすめします。

季節・天気・装備

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道平昌郡龍坪面雲頭嶺路767-17）・公共누리

桂芳山(ケバンサン)は春の新緑と秋の紅葉が美しい山として知られていて、夏場もうっそうとした木陰のおかげで比較的涼しく登れるコースだと紹介されています。ただ、冬場は積雪量が多いうえ、山頂付近の稜線では強風が吹き荒れることもあり、一気に難易度が上がる季節とされているので、アイゼン・スパッツ・防風ジャケットなど防寒・滑り止め装備は必ず揃えておく必要があります。基本的には一年を通して登山靴・着替え・十分な飲料水・ヘッドランプ・非常食を用意しておくのが望ましく、山頂付近は気温差が大きいので、夏場でも薄手の防風ウェアを一枚持っていくことをおすすめします。

外国人旅行者へのアドバイス

写真提供：韓国観光公社 観光写真ギャラリー（江原特別自治道平昌郡龍坪面雲頭嶺路767-17）・公共누리

鶏芳山（ケバンサン）の山頂はローマ字で「Gyebangsan(-jeongsang)」、主要な登山口である雲頭嶺（ウンドゥリョン）は「Undureong」と表記されます。特別な入山許可や入場料は確認されていませんが、国立公園に隣接するエリアなので、訪れる前には現地の標識や通行規制区間（コース2には「立入禁止」の表示が多数）を必ず確認してください。トイレは雲頭嶺付近（コース2の登山口）にあることが確認できましたが、飲み水については登山道内に湧き水（水飲み場）が1か所あるものの、山行中の飲み水をそこだけに頼るのは心配なので、事前にしっかり準備しておくのが安心です。地図アプリはGoogleマップだと韓国国内の登山道情報が不正確なことが多いので、実際のルートや公共交通の情報を確認するにはKakaoMapかNaver Mapを使うのを強くおすすめします。安全のためにも、冬場は単独登山を避けて誰かと一緒に行動し、日没時間も考慮して余裕を持った下山計画を立てるようにしましょう。
