概要

写真: 韓国観光公社 観光写真ギャラリー(江原特別自治道寧越郡武陵桃源面百年渓谷路158) · 公共누리

白徳山（ペクトクサン）は、江原道寧越郡水周面と平昌郡放林面の境界にまたがる山で、頂上部の標高は地理情報によって1,327m〜1,345mの間で若干のばらつきがあり、登山道の実測ベースでは最高1,364m地点まで登ることが確認されています。隣接する獅子山（1,183m）と稜線でつながっているため、二つの峰を一緒に歩く縦走登山がよく知られています。全体的には土の斜面が多い、いわゆる「土山」に近い性格を持ちながらも、頂上付近には岩場が混じっており、後半に進むほど体感的な難易度が上がる山です。管内に登録されている登山道の総延長（複数区間を合算した数値）は16.42kmとそれほど長くはなく、代表的なコースは片道4〜11km程度で、日帰り登山でも十分こなせます。ただし、頂上圏コースの累積高低差が700〜860mにも達するため、距離のわりに体力を消耗する山に分類されます。

山容と地形

写真：韓国観光公社観光写真ギャラリー（江原特別自治道寧越郡武陵桃源面百年渓谷道142）・公共누리

ペクトクサンは江原道嶺西地域の山稜らしさがよく出ている山で、全体的には土の道が多い土山なんですが、山頂直前の区間だけは岩稜とガレ場が入り混じって現れます。公共データに登録されている峰の情報を見ると、獅子山山頂（1,183m）、ペクトクサン山頂（1,327m・1,337m・1,345mなど調査地点によって表記が違います）、九峰台山（907m）と九峰台山山頂（922m）が一本の稜線軸を成していて、ペクトクサン－獅子山－九峰台山とつながる山稜全体が縦走の対象になるくらいのスケールを持っています。実測コース上には雪筒岩、駱駝岩、龍岩といった名前の付いた岩塊が登場するんですが、これはペクトクサンの山頂部が単なる土の峰ではなく、大小の岩場地形を含んでいることを物語っています。山頂付近には駱駝岩展望台と呼ばれる眺望ポイントがあって、稜線と渓谷を一緒に見渡せる場所だそうです。渓谷方面にはピネソゴルという地名が出てくるんですが、この区間は土砂崩れ脆弱地域に指定されていて、渓谷地形特有の斜面の不安定さを抱えた場所と見ていいと思います。

登山の雰囲気

写真: 韓国観光公社 観光写真ギャラリー（江原特別自治道寧越郡無陵桃源面百年渓谷路88-3）· 公共누리

白徳山は、序盤の穏やかな森歩きと、山頂が近づくにつれてぐっと増してくる急勾配・岩稜帯とのコントラストがはっきり味わえる山です。興元寺(フンウォンサ)方面から取り付くと、まずお寺の森のしんとした空気の中を歩き始めることになります。古木が倒れてトンネルのようになった区間(モッコルコース)があったり、ツツジの群生地の案内板が立っていたりと、季節ごとに見どころが変わるのもこのコースの面白いところ。山頂圏に近づくとラクダ岩の展望台や龍岩といった岩場を越えていくのですが、「墜落注意」の標識が現れるあたりから、手を使ってよじ登る岩稜登山らしい緊張感が漂ってきます。一方、文峙(ムンジェ)の登山口から獅子山へ登るコースはヘリポートを経由する比較的なだらかな稜線歩きで、同じ山でもどちらの登山口を選ぶかで山行の性格がまるで変わってくるのが興味深いところです。秋は稜線の紅葉、初夏はツツジの群生地が季節感を添えてくれる山だと言えるでしょう。

コース1 — フンウォン寺 → 展望台

📏 7.72km ⛰️ 691m 獲得標高 ⏱️ 3:05 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 寧越（ヨンウォル）公営「幸せバス」停留所 → 簡易トイレ → フンウォン寺 → 白徳山（ペクトクサン）登山路入口、フンウォン寺 → 雪桶岩（ソルトンバウィ） → 分岐点 → 祭壇跡 → 展望台 → ラクダ岩展望台 → 落下注意区間 → 龍岩（ヨンバウィ） → 白徳山頂上手前の岩場

登山口へのアクセス: フンウォン寺方面は寧越郡水周（スジュ）面側から入るコースで、地域の公営バス（幸せバス）の停留所が登山路入口の近くにあるようです。ただ、農漁村バスらしく本数が少ないので、事前に時刻表を確認しておくのは必須だと思います。車で行く場合はフンウォン寺付近の空き地に停めるのが一般的で、専用の登山者用駐車場は特に見当たりませんでした。

特徴・おすすめしたい人: お寺の森の中を歩き出し、後半には雪桶岩・ラクダ岩・龍岩といった名物の岩塊地帯を次々と通過していくコースです。白徳山の頂上付近にある岩稜の魅力を一番味わえる、いわば代表コースと言えるでしょう。ラクダ岩展望台からの眺めは抜群ですが、「落下注意」の区間もはっきり明記されているので、岩稜歩きに慣れている登山者向きかなと思います。

コース2 — モッコル → 頂上

📏 4.51km ⛰️ 427m 獲得標高 ⏱️ 1:50 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

経由地: 白徳山駐車場トイレ → 白徳山登山道入口 → モッコル → 倒木がトンネルのように連なる区間 → 分岐点 → 道標脇の小さな休憩スペース → ツツジ群落地の案内板 → 登山道閉鎖区間 → 道端の小さな空き地 → 空き地の丸椅子 → 倒木地点 → 傾斜が急で土道のため要注意 → 白徳山登山道入口 → ウンギョ(雲橋)バス停 → ウンギョ1里村会館前トイレ

登山口へのアクセス: モッコル登山口は平昌郡芳林面ウンギョ里方面にあり、近くにウンギョ(雲橋)バス停があるので市外バスや農漁村バスも使えそうですが、便数がかなり少ないので事前に時刻を確認しておいたほうが安心です。村の会館前にトイレがあるので、登山前後に立ち寄れます。

特徴・おすすめの人：4つのコースの中で最も長い11.19kmの区間で、倒木がトンネル状になった区間やツツジの群落地を通るなど、森の原生的な雰囲気が色濃く残るコースです。ただ、登山道の閉鎖表示があちこちで確認できるうえ、急斜面の土道で注意が必要な区間もあるので、体力と時間にしっかり余裕のある登山者向けです。出かける前に最新の通行止め情報をチェックしておくことをおすすめします。

コース3 — 白徳山への道 → 山頂手前の小さな広場

経由地: 白徳山への道 → 分岐点 → 山頂手前の小さな広場 → 山頂手前 → 山頂手前の木 → 白徳山山頂 → 文峠・白徳山・ビネソゴル分岐点 → ビネソゴル下山路 → 注意案内板 → 渓谷 → 山崩れ脆弱地域 → ビネソゴル

取付き（入山口）へのアクセス：このコースには特にはっきりした村の入山口名がなく、「白徳山への道」という表示だけになっています。なので実際には、他のコースと稜線上でつながる縦走ルートの一部として使われることが多いようです。公共交通機関よりも、車で近くまで行ってそこから歩いて入るのが現実的なやり方です。

特徴・おすすめのタイプ：白徳山の山頂を実際に越えて、ビネソゴルの渓谷方面へ下っていく区間です。山頂を通過したあと、文峠・白徳山・ビネソゴルの分岐点でどちらに進むか選べるのがポイント。下山路には山崩れの脆弱地域が明記されているので、雨の日や梅雨時は避けたほうが無難です。渓谷の地形も一緒に楽しみたいという登山者にぴったりのコースです。

コース4 ― 文峙(ムンジェ)登山口 → 獅子山山頂

経由地: 文峙休憩所 → 文峙登山口 → 登山道閉鎖区間 → 分岐点 → ヘリポート → 倒木地点 → 道を塞ぐ倒れた古木 → 登山道閉鎖 → 古木の倒壊箇所 → 獅子山山頂 → 急斜面すぐ横の道 → 白徳山まで2km地点

登山口へのアクセス: 文峙は寧越（ヨンウォル）と平昌（ピョンチャン）を結ぶ峠道で、峠の頂上部に文峙休憩所があるため、車でのアクセスは比較的しやすいほうです。公共交通機関の路線は確認できなかったので、自家用車かタクシーを使うのが一般的でしょう。

特徴・おすすめの人: 4つのコースの中で距離が一番短く、累積標高差も一番小さいので、体力的な負担が比較的軽いコースです。ヘリポートを通る緩やかな尾根道が中心とはいえ、登山道の閉鎖区間や倒れた古木の地点が何か所か確認されているので、最新情報のチェックは欠かせません。短時間でサッと獅子山山頂まで行って戻ってきたい人や、白徳山縦走の登山口・下山口として使いたい人に向いているコースです。

難易度・路面・注意点

写真：韓国観光公社観光写真ギャラリー（江原特別自治道寧越郡無陵桃源面百年渓谷道15-5）・公共누리

管内に登録されている登山道のデータ上の最高難易度は「やさしい」に分類されていますが、これはあくまで行政洞単位の登山道区間データであって、実際の頂上圏コース（興元寺・モクコル・白徳山への道）はGPS実測ベースで最高難易度（★★★★★）に相当し、体感としてはかなりの差があることに注意が必要です。路面情報は別途登録されていませんが、道標の名称から土の道と岩場が入り混じっていることが確認できます。特にソルトン岩・ラクダ岩・龍岩の区間は岩稜特有の滑りやすさがあり、モクコルコースとムンジェコースにはそれぞれ「傾斜が急で土の道のため注意」という標識が確認できるので、雨天時の滑落には気をつけたいところです。公共データ上、別途指定された危険地域の数は0件となっていますが、実測GPSでは滑落注意（コース1）、地すべり脆弱地域（コース3のビネソコル方面）という表示が確認できるため、該当区間ではとりわけ慎重に歩く必要があります。展望ポイントは1か所（ラクダ岩展望台）確認されており、ここが白徳山山行における最も代表的な眺めのスポットといえるでしょう。また、モクコル・ムンジェの両コースでは共通して「登山道閉鎖」の標識が複数箇所確認されているので、山行前に自治体や国立公園関連の告知で最新の通行規制状況を確認しておくのが賢明です。

距離と所要時間

写真:韓国観光公社 観光写真ギャラリー(江原特別自治道平昌郡平昌邑元堂里261)·公共ヌリ

白徳山は、管内すべての登山道を合算した登りの所要時間が419分、下りが293分と記録されていますが、これはあちこちの区間をすべて足し合わせた累積値なので、特定の一コースの所要時間だと勘違いしないよう注意が必要です。この累積データから割り出した平均登りペースは1kmあたり約26分で、他の山と比べるとやや遅めの部類に入ります。これは白徳山の登山道に急斜面や岩場の区間が少なくないことと符合しています。コース別に見ると、興元寺コースが約3時間29分、モクコルコースが約4時間10分、白徳山へ向かうコースが約3時間5分、文峠(ムンジェ)-獅子山コースが約1時間50分(いずれも片道)と算出されますが、これは距離と標高差をもとにした推定値なので、実際にかかる時間は体力や休憩の取り方によって変わってきます。往復で歩く場合、興元寺コースやモクコルコースは1日で合計7~8時間以上かかることもあるので、朝早めに出発するのがおすすめです。どのコースを選ぶにしても避難小屋の存在は確認されていないので、泊まりがけではなく日帰り登山として計画するのが一般的です。

行き方(公共交通・駐車)

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 평창군 방림면 들모고개길 47-1) · 공공누리

白徳山は江原道の寧越郡と平昌郡の境にあるせいで、正直公共交通ではちょっとアクセスしづらい山です。ソウルなど首都圏から行くなら、KTXや市外バスで平昌(方林)や寧越の市内まで出て、そこから農漁村バスかタクシーに乗り換えて各登山口へ向かうのが基本パターンになります。モクゴル(먹골)コース近くには雲橋(ウンギョ)停留所があって路線バスも使えますが、興元寺(フンウォンサ)コース周辺は寧越公営「幸福バス」の停留所があるものの本数が少ないので、事前に時刻表を確認しておくのは必須です。文材(ムンジェ)登山口は峠道という性質上、公共交通よりは車かタクシーを使うのが現実的でしょう。公共データ上では正式な駐車場は見当たらないので、登山口付近の空き地や村へ入る道の路肩に停めるケースが多いのですが、私有地や農地に入り込んでしまわないよう気をつけたいところです。実際の道路状況や最新のルートは、必ずカカオマップ(KakaoMap)かネイバー地図(Naver Map)アプリで確認することをおすすめします。グーグルマップは韓国内の徒歩・公共交通ルート案内が弱いので、この山行にはあまり向いていません。

シーズン・天候・装備

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道 寧越郡 武陵桃源面 百年渓谷路 66-16）・公共누리

白徳山は、春はツツジ類の花が咲く頃、秋は紅葉シーズンに登るのがおすすめの山として知られています。夏場は渓谷方面（ビネソゴル）に山崩れの弱いエリアがあるので、集中豪雨のときは登山を避けたほうが無難ですし、湿度が高くて体力の消耗も普段より激しくなりがちです。冬場は山頂付近の岩稜区間（ソルトンバウィ・ナクタバウィ・ヨンバウィ）や急斜面の土道区間が凍結することがあるので、アイゼンやスパッツといった冬装備は必須と考えてください。共通で用意しておきたい装備としては、登山靴、着替え、防風・防水ジャケット、十分な飲料水（水場の有無がはっきりしないので最低1.5〜2Lは持参するのがおすすめです）、ヘッドランタン（長距離コースに備えて）、トレッキングポール（急斜面区間に備えて）などが挙げられます。トイレは興元寺付近の簡易トイレ、白徳山駐車場のトイレ、雲橋1里の村会館前のトイレなどが確認されているので、登山の前後に利用できます。

外国人旅行者向けのヒント

白徳山のローマ字表記は「Baekdeoksan」、山頂は「Baekdeoksan Summit」、隣接する獅子山は「Sajasan」と表記されます。特に入山規制時間や入場料は確認されていない山なので、国立公園のような事前予約や入場料なしで訪れることができますが、登山道が閉鎖されている区間がいくつか確認されているので、現地の案内板は必ず確認してください。トイレは興院寺の簡易トイレ、白徳山駐車場のトイレ、雲橋1里村会館のトイレなど限られた場所でしか確認できないので、登山前に済ませておくのが安全です。また、登山道の途中には水飲み場が確認されていないので、水は必ず持参してください（Bring your own drinking water — no water fountains are confirmed along the trail）。地図アプリはGoogleマップよりもカカオマップ（KakaoMap)やネイバーマップ（Naver Map)を使うことを強くおすすめします。どちらのアプリも英語インターフェースに対応しているので、外国人旅行者でも登山道検索や公共交通機関での経路案内に活用できます。公共交通機関が限られている地域なので、タクシー配車アプリ（カカオTなど）も一緒に用意しておくと便利です。携帯電話の電波が弱い区間もあるので、オフライン地図を事前にダウンロードしておき、単独登山よりは同行者と一緒に登山計画や下山予定時刻を事前に共有しておくと安心です。
