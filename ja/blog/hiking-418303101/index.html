概要

写真：韓国観光公社 観光写真ギャラリー（京畿道楊平） · 公共누리

龍門山（ヨンムンサン)は京畿道楊平郡にある山で、頂上部の最高標高はおよそ1,176mに達する、京畿東部エリアを代表する高山です。頂上まで続く各コースは、だいたい片道8~11km台の距離に800m以上の累積標高差があり、実測データで見ると頂上を目指すコースのほとんどが最高難度に分類されるほど体力を使う山です。ただし、管内に登録されている登山道区間そのものの公共データ上の難易度は「易しい」と表示されており、短い区間だけを歩く人にとっては比較的取っつきやすい山でもあります。登山口から頂上まで一気に歩く場合でも日帰りで十分で、1泊が必要になるような規模の山ではありません。

山容と地形

写真:韓国観光公社観光写真ギャラリー(京畿道楊平)・公共누리

龍門山は土山と岩稜が入り混じった山容が特徴です。全体としては太い稜線に沿っていくつものピークが連なる構造になっていて、代表的なところでは頂上の龍門山(1,161m)、そのすぐ近くにも別途1,152mと表記される龍門山頂上、将軍峰(1,025mと1,113mの二通りの表記あり)、白雲峰(940m)、中元山上峰(782m)、龍門山神仙峰(645m)、龍門山龍鳥峰(612m)などが挙げられます。頂上付近は資料によって標高の表記に若干のばらつきが見られますが、これはGPS計測地点や調査時期の違いから来るよくある現象で、実測GPXベースでは頂上圏の最高標高は1,176mと確認されています。頂上部は岩と稜線が入り混じっていて視界が開ける地点が多く、下部は鬱蒼とした森に覆われた土山らしい雰囲気が強くなっています。龍門山の裾野には千年の歴史を誇る古刹・龍門寺があり、境内のイチョウの木は国内で最も古く大きいイチョウの一つとして知られていて、登山のついでに立ち寄る価値のある名所です。

登山の感じ

사진: 한국관광공사 관광사진 갤러리 (경기도 양평) · 공공누리

龍門山の登山は、入口付近のなだらかな森の道から始まり、登るほどに傾斜がはっきりしてくる、いかにもこの山らしい流れです。下部は広葉樹と針葉樹が混ざった森の道で木陰が濃く、夏場でも比較的涼しく歩けるのですが、上部に近づくにつれて岩稜や岩場が交じるようになり、体感的な難易度がぐっと上がります。山頂付近では稜線沿いに視界が開ける地点がいくつかあり、京畿道東部の山並みを広く見渡せます。季節ごとの表情もはっきりしていて、春には新緑と谷川の流れが調和し、秋には稜線に沿って紅葉が華やかに染まることでよく知られています。全体としては長距離・高低差の大きい本格的な登山にあたるので、ちょっとした散策気分ではなく、一日をしっかり充てるつもりで臨むのが向いていると思います。

コース1 — ヨンムンボン登山口 → ヨンムンボン

📏 8.92km ⛰️ 953m 獲得標高 ⏱️ 3:49 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地: ヨンムンボン登山口 → ヨンムンボン → 分岐点 → マダンバウィ

登山口へのアクセス: ヨンムンボン登山口は、ヨンムンサンのメイン登山口とは別方向にある入口で、公共交通機関よりもマイカーやタクシーを使うほうが何かと便利です。正確な進入路はカカオマップやネイバーマップで事前にチェックしておくのをおすすめします。

特徴・おすすめの人: このコースはヨンムンボンを経て頂上方向へ取り付く尾根型のルートで、序盤からずっと高度を上げていく区間が続きます。そのぶん、マダンバウィ付近で視界が開ける地点があり、岩稜の眺めを楽しめます。静かな尾根歩きと岩場の地形が好きな経験者向きで、初心者にはちょっとハードなコースと言えます。

コース2 — 分岐点 → 龍門山山頂

📏 8.2km ⛰️ 903m 獲得標高 ⏱️ 3:33 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由: 分岐点 → 平床（ベンチ休憩地） → 龍門山山頂

登山口へのアクセス: このコースは中腹の分岐点から山頂まで一直線に詰めていく区間で、単独で使うよりも他のコースと組み合わせて歩くことが多いです。下部の登山口へは龍門山観光地・龍門寺方面からアプローチするのが一般的で、その場合は中央線電車の龍門駅（Yongmun Station）からバスかタクシーで移動して取り付くルートがよく使われています。

特徴・おすすめの人: 「平床」と呼ばれる休憩ポイントを通過してそのまま山頂へ詰め上げる、比較的まっすぐな流れのコースです。とにかく山頂を目指したい登山者にとっては効率のいい選択肢だと思います。山頂近くでは稜線の展望が開ける区間もあり、体力に自信のある人向けのコースといえます。

コース3 — 分岐点 → 山頂

📏 9.54km ⛰️ 838m 獲得標高 ⏱️ 3:47 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 分岐点 → 休憩所 → 百年薬水（ペンニョンヤクス）

登山口へのアクセス: 龍門寺方面から登ってくるメイン登山道と合流する区間で、龍門山観光地の入口までバスやタクシーで行き、そこから徒歩で入るのが一般的です。龍門山観光地の近くには大きな駐車スペースが整備されていて、マイカーで来る人も多いようです。

特徴・おすすめの人: 百年薬水を経由するこのコースは、龍門山でいちばんメジャーな、昔ながらの登頂ルートといっていいでしょう。長く続く樹林帯を抜けたところで、上部になると岩稜や岩場が出てくるという、いかにもな流れになっていて、とにかく山頂を踏みたいという人にはまず候補に挙がるコースです。

コース4 — 龍門寺入口→将軍峰

📏 11.54km ⛰️ 845m 獲得標高 ⏱️ 4:18 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 龍門山観光地→チケット売り場→ファミリートイレ→エコ農業博物館→韓国民族独立運動発祥地→龍門寺入口→龍遊亭→龍門寺四天王門→龍門寺テンプルステイ→龍門寺のイチョウの木→龍門寺→分岐点→ベンチ

登山口へのアクセス: 龍門寺入口は龍門山観光地の入り口部分にあたり、チケット売り場を通り抜けてから入っていく構造になっています。公共交通機関の場合、中央線電鉄の龍門駅からバスに乗り換えてアクセスするのが一般的で、観光地ということもあって駐車スペースもしっかり整備されているため、アクセスのしやすさは比較的良好です。

特徴・おすすめの対象: このコース最大の特徴は、龍門寺のイチョウの木や四天王門といった文化財・観光施設を経由できる点で、ただの登山にとどまらず寺院巡りも一緒に楽しめるところにあります。ただ、全体の距離は5つのコースの中で一番長く、体力の消耗もそれなりに大きいので、文化財巡りと山頂アタックを両方楽しみたい人向けと言えそうです。時間には余裕を持たせて計画するのがおすすめです。

コース5 — 京畿・楊平駅 → リギダマツ植栽地帯

📏 8.83km ⛰️ 902m 獲得標高 ⏱️ 3:43 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 京畿・楊平駅 → 分岐点3 → 分岐点4 → 休憩所 → 松林群落地 → 分岐点7 → 展望ポイント → 分岐点10 → 栗の木植栽地 → リギダマツ植栽区域 → リギダマツ植栽地帯 → 休憩所・運動施設 → 分岐点16 → 分岐点24 → 兄弟井戸薬水

取り付き口へのアクセス: 楊平駅（Yangpyeong Station）から歩いてそのまま入っていけるコースで、5コースの中では公共交通機関でのアクセスが群を抜いて良いのが魅力です。中央線の電車で楊平駅まで来てしまえば、バスに乗り換える手間もなく、そのまま山行をスタートできます。

特徴・おすすめの人: 松林群落地、栗の木植栽地、リギダマツ植栽地帯など、植林地を数多く通り抜けていくコースで、人工林と自然林が入り混じった、なかなか味のある森の景観が楽しめます。都心からのアクセスの良さもあって、公共交通機関だけで山行を組み立てたい人には特に重宝するコースだと思います。後半に出てくる兄弟井戸薬水は、喉の渇きを癒してくれるポイントとしても知られています。

管内に登録されている登山道の区間別の難易度と距離は以下の通りです。

上の表の区間はあくまで行政洞を基準に分けた管内登山道の区分であって、実際の登山コース名ではない点に注意してください。一方で、山頂圏まで登る実際の登頂コースは、これまで見てきた通り、純高度差800m以上のハードなコースがほとんどです。路面は下部の森の道では土の道と落ち葉が混じった区間が続きますが、上部の稜線や山頂付近では岩盤や岩がむき出しになった区間が現れるため、雨天時や冬場の凍結時は特に滑りやすいので注意が必要です。コース内には展望ポイントが3か所確認されており、稜線を登っていく途中で視界が開ける場所に出会えますが、危険地域や避難所は特に確認されていません。

距離と所要時間

写真:韓国観光公社観光写真ギャラリー(京畿道楊平)・公共누리

龍門山の登頂は日帰りで十分こなせる山で、宿泊はとくに必要ありません。管内の登山道全体を合算した上りの累積所要時間は約370分、下りは約257分となっていますが、これはあくまで管内の複数コースをすべて足した数字なので、「ある一つのコースの所要時間」だと勘違いしないよう注意してください。この累積値を距離換算すると、上りの平均ペースはおおよそ1kmあたり22分ほど。これを実際の登頂コースに当てはめてみると、8〜11kmクラスのコースで3時間30分から4時間20分ほどかかるというGPXベースの推定値と、だいたい辻褄が合う感じです。とはいえこれはあくまで平均的なペースの話で、実際にかかる時間は体力や休憩の取り方によって当然変わってきます。往復で計画するなら、片道時間の2倍以上を余裕を持って見積もり、下山が遅い午後にならないよう出発時刻も早めに設定しておくのがおすすめです。

行き方(公共交通機関・駐車)

사진: 한국관광공사 관광사진 갤러리 (경기도 양평) · 공공누리

龍門山(ヨンムンサン)周辺では、中央線の龍門(ヨンムン)駅と楊平(ヤンピョン)駅が主な玄関口になります。龍門山観光地・龍門寺方面のコースは龍門駅からバスかタクシーに乗り換えて向かうのが一般的で、リギダマツの植栽地帯コースのように楊平駅から徒歩でそのまま入れるコースもあります。登山口付近の実際のバス停としては龍門山、安息館入口、楊平駅、楊平市場入口などが確認されているので、目的のコースに応じて適切な停留所を選んで下車すれば大丈夫です。ただ、バスの路線や運行間隔は時期によって変わることがあるので、出発前にKakaoMapやNaver Mapで最新のルートと停留所の位置を必ず確認しておくのをおすすめします。車で行く場合、観光地方面には駐車スペースが用意されていますが、登山道自体に専用の駐車場があるという情報は確認できなかったので、観光地の駐車場を利用するのが現実的です。

シーズン・天気・装備

사진: 한국관광공사 관광사진 갤러리 (경기도 양평) · 공공누리

龍門山(ヨンムンサン)は、新緑がぐっと濃くなる春と、紅葉が見事な秋が特におすすめの時期です。夏場は谷の水量が増えて湿度も高くなるぶん体感的にきつく感じるので、早めの出発とこまめな水分補給を心がけたいところ。冬は山頂付近の稜線や岩稜帯が凍結することがあるので、アイゼンやスパッツといった防寒・滑り止め装備は必須になります。共通で欠かせない装備としては登山靴、たっぷりめの水（水場がほとんどないので多めに準備）、防水・防風ジャケット、トレッキングポール、着替えなどが挙げられ、季節を問わずヘッドランプを持っていくと下山が長引いた場合にも安心です。

外国人旅行者向けのちょっとしたヒント

사진: 한국관광공사 관광사진 갤러리 (경기도 양평) · 공공누리

龍門山のローマ字表記は「Yongmunsan」、山頂は「Yongmunsan Summit」、麓の主要な寺院は「Yongmun Temple（龍門寺）」と表記されます。国立公園ではなく一般の山なので入山許可のようなものは不要ですが、龍門山観光地・龍門寺エリアは入場料がかかることがあるので、訪れる前に確認しておくと安心です。トイレは龍門山観光地の入口付近やチケット売り場周辺にありますが、登山道沿いにはほぼ水飲み場が見当たらないので、水は多めに用意してから登り始めるのが鉄則です。地図アプリはGoogleマップだと登山道の情報がいまいち怪しいことが多いので、韓国で実際によく使われているKakaoMapかNaver Mapを入れておいて、実際のルートや公共交通の情報を確認するのをおすすめします。安全第一で、日が暮れる前に下山を終えられるよう計画を立て、スマホのバッテリーと緊急連絡先の準備も忘れずに。
