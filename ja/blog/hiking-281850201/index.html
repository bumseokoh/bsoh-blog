概要

写真：韓国観光公社観光写真ギャラリー（慶尚北道奉化郡）・公共누리

清凉山（청량산、チョンリャンサン）は慶尚北道奉化郡にある山で、最高峰の丈人峰は標高869m、公共データの登山道GPXによる最高高度は882mと記録されています。洛東江の上流を抱くように岩峰が屏風のように連なっていて、規模のわりに山容がくっきりしているのが特徴で、道立公園として指定・管理されています。全体の難易度は「中級」に分類され、頂上圏を巡る主要コースは片道2時間前後なので、たいていは日帰り登山で十分まわれる山です。ただ、急斜面の岩稜区間があちこちにあるので、初心者よりはある程度登山経験のある方向きだと思います。

山容と地形

사진: 한국관광공사 관광사진 갤러리 (경북) · 공공누리

清凉山は土の山ではなく、岩峰が主体となる骨山（コルサン）タイプの地形が特徴です。頂上の丈人峰（869m）をはじめ、祝融峰（表記845.2m、データ上875m）、紫霄峰（別名・菩薩峰、表記840m・850m）、硯滴峰（表記846m・852m）、卓筆峰（836m）など、名の知れた峰が五つ以上、稜線沿いに連なっています。卓筆峰（筆先）、硯滴峰（硯の水差し）、紫霄峰（菩薩）といった具合に、こうした名前を持つ峰が多いのは、昔からこの山が儒生たちの学問修行の場として知られてきたためで、一般には「清凉山十二峰」という呼び名でも知られています。稜線のあちこちが切り立った岩壁になっているため見晴らしの利く区間が多く、中腹には清凉寺や応真殿といった寺院施設が岩の地形と溶け合い、独特の景観を作り出しています。谷間は比較的なだらかですが、頂上に近づくにつれ岩の稜線と急斜面が現れる、典型的な岩山地形です。

登山の雰囲気

사진: 한국관광공사 관광사진 갤러리 (경상북도 봉화군) · 공공누리

清凉山の登山は、入口の森の道から始まって、だんだん岩場と展望が開けてくる尾根道へとつながっていく構成が一般的です。序盤は渓谷やお寺の周りの鬱蒼とした森の道を歩き、中盤以降になると岩稜やロープ・階段区間が現れて、体感的な難易度がぐっと上がってきます。中でもハヌルダリ（空の橋）区間は、渓谷を横切る吊り橋になっていて、けっこう高度感があるので、渡っている間はスリル満点。それでいて足元の谷を見下ろす開放感も同時に味わえる、なかなか贅沢な区間です。春は新緑とお寺周辺の静かで落ち着いた雰囲気が、秋は岩峰と紅葉が織りなす景色が特に印象的だと言われています。全体としては森の道・渓谷沿いの道・岩稜からの展望道がバランスよく混ざっていて、飽きずに歩けるコースだと評価されています。

コース1 — 天空の橋入口→丈人峰

📏 4.94km ⛰️ 647m 獲得標高 ⏱️ 2:19 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地: 清凉寺の眺め → ソッテ（鳥竿の民間信仰塔）と詩人 → 奉化清凉精舎 → ベンチ → お手洗い → 湧水場（清凉寺お手洗い） → 清凉寺 → 分岐点 → 清凉寺湧水場 → 清凉寺の庭 → 清凉寺五層石塔 → 峰の眺望 → 天空の橋入口 → 清凉山天空の橋 → 天空の橋の眺め

登山口へのアクセス: 天空の橋入口へは清凉山道立公園の入口側から入るのが一般的です。地下鉄が通っていないエリアなので、奉化・安東の市内から市外バスや路線バスで移動し、そこから徒歩かタクシーで向かうのが定番のルートになります。マイカー利用の場合は道立公園近くの駐車スペースを使うことが多いのですが、シーズン中や週末は混み合うことがあるので、時間に余裕を持って早めに到着することをおすすめします。

特徴・おすすめの人: このコースは清凉寺を抜けて天空の橋を渡り、丈人峰の頂上まで登る、清凉山でいちばん象徴的な区間です。お寺の境内を歩きながら文化的な見どころを楽しみ、続いて渓谷をまたぐ天空の橋でスリル満点の眺望を味わったあと、頂上まで岩稜を登っていく流れなので、登山と観光を両方楽しみたい方にぴったりです。ただし天空の橋を渡ったあと頂上までは標高差が大きく岩場が続くので、ある程度の基礎体力は必要になります。

コース2 — 山城入口 → 北門址展望台

📏 6.72km ⛰️ 458m 獲得標高 ⏱️ 2:27 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由地：山城入口 → 山城入口トイレ → 登山口・山城入口 → 山城入口休憩所 → 分岐点 → ミルソンデ眺望 → 清凉寺・応真殿眺望 → 北門址展望台 → 位置情報 → 祝融峰 標高845.2m → 下山口・山城入口 → 金湯峰・蓮花峰 → 立石休憩所 → 清凉山休憩所・売店

登山口へのアクセス：山城入口も、公共交通よりマイカーでのアクセスが基本になる登山口として知られています。近くに休憩所・売店があるので、山行の前後にちょっと腹ごしらえをしたり情報収集したりするのに便利ですし、トイレも登山口の入り口付近にあることが確認できます。ただ公共交通のルートは地域のバス事情によって変わることもあるので、訪れる前に地図アプリで最新情報をチェックしておくのが安心です。

特徴・おすすめの人：3つのコースの中で最も距離が長く、ミルソンデ・北門址展望台など見どころの多い展望ポイントをいくつも経ながら、祝融峰まで尾根を縦走するように歩くコースです。清凉寺と応真殿を尾根の上から見下ろせる眺望地点があり、清凉山全体の山容を眺めるにはぴったりのコースなので、山頂だけ踏んでさっと下山するより、尾根縦走の醍醐味をじっくり味わいたいという方におすすめです。距離が長い分、体力配分は要注意です。

コース3 — 紫霄峰入口の位置情報 → 応真殿登山道展望台

📏 4.68km ⛰️ 564m 獲得標高 ⏱️ 2:07 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

経由地：転落注意 → 分岐点 → 応真殿登山道展望台 → 転落危険 → 応真殿 → 経由台（応真殿法堂前）→ 風穴台 → 登山道展望台 → 風穴台展望台 → 聡明水 → 御風台 → 転落危険につき立入禁止 → 金生窟 → 金生滝 → 蓮花峰の眺め

登山口へのアクセス：紫霄峰方面の登山口も、清凉山道立公園のエリア内からのアプローチになります。他の2コースに比べると人が少なめで、わりと静かなコースとして知られているようです。公共交通機関よりは自家用車かタクシーで向かうのが一般的です。

特徴・おすすめの人：このコース最大の特徴は、応真殿・風穴台・金生窟・金生滝といった名だたる見どころを次々と通ることで、3コースの中でも文化的・自然的な見応えは群を抜いています。ただ、道標に「転落注意」「転落危険につき立入禁止」の表示が何度も出てくることからもわかるように、崖に近い区間があるので気は抜けません。写真を撮るのに夢中になって足を踏み外さないよう、くれぐれもご注意を。名所めぐりと登山を両方楽しみたい方、それでいて標高差は比較的なだらかなコースを望む方に向いていると思います。

距離と所要時間

写真:韓国観光公社観光写真ギャラリー(慶尚北道奉化郡)・公共누리

清凉山の管内登山道の総延長(17.17km、5区間合算)で見ると、登りが約400分、下りが約168分かかるというのがデータの示すところです。これはあくまで管内の全区間を合算した累積数値なので、特定の一つのコースの所要時間と勘違いしないよう注意が必要ですが、これを距離換算すると平均の登りペースはだいたい1kmあたり23分といったところです。実際のコース別片道所要時間を見てみると、空中歩道入口→丈人峰が約2時間19分、山城入口→北門址展望台が約2時間27分、紫霄峰入口→応真殿登山道展望台が約2時間7分という計算になり、どのコースも往復4~5時間もあれば十分歩ける距離です。避難小屋も特になく、総延長も17km程度なので、清凉山は泊まりがけにしなくても日帰りで十分楽しめる山だと言えます。ただ、複数のコースをつなげて縦走したり、寺や見どころをゆっくり回りたいという場合は、移動時間に余裕を持たせておいたほうがいいでしょう。

行き方(公共交通機関・駐車場)

사진: 한국관광공사 관광사진 갤러리 (경상북도 봉화군) · 공공누리

清凉山は地下鉄が通っていないエリアにあるので、ソウルなど首都圏からだとKTXや市外バスで安東(アンドン)か奉化(ポンファ)まで出て、そこから市内バス・農漁村バスに乗り換えて登山口を目指すのが一般的なルートとされています。車で行く場合は中央高速道路などを経由して道立公園の進入路に入るのが定番のようです。ただ公共データ上では周辺のバス停や駐車場までは細かく拾えていないので、実際のバス停の位置や駐車できるかどうかは、必ずカカオマップかネイバー地図で最新のルートと施設情報を確認することをおすすめします。グーグルマップは韓国国内の道路・公共交通情報が不正確なことが結構あるので、国内の地図アプリと併用するのが無難です。

シーズン・天気・装備

写真：韓国観光公社観光写真ギャラリー（慶尚北道奉化郡）・公共누리

清凉山は春（新緑）と秋（紅葉）のシーズンに訪れるのが特におすすめです。夏場は蒸し暑さに加えて水飲み場がほとんどないため脱水に気をつける必要がありますし、冬場は岩稜区間の凍結で体感的な難易度がぐっと上がるので、アイゼンやスパッツといった冬装備が欠かせません。基本装備としては足首をしっかり支えてくれる登山靴、最低でも1〜1.5リットル以上の飲み水（園内に水飲み場が実質ないとのことなので必須です）、雨対策のレインウェア、トレッキングポール、日焼け対策グッズなどを揃えておくとよいでしょう。ハヌルダリ（空中橋）や応真殿など崖に近い区間を通る際は、滑り止め機能のある靴と手袋を着用しておくと安全面で安心です。

外国人旅行者へのちょっとしたヒント

写真：韓国観光公社 観光写真ギャラリー（慶尚北道奉化郡）・公共누리

清涼山のローマ字表記は「Cheongnyangsan」、頂上の将人峰は「Jangingbong」、名物スポットである空中歩道は「Cheongnyangsan Sky Bridge」、清涼寺は「Cheongnyangsa Temple」と表記されます。入山許可や入場料に関する情報は今回のデータには含まれていないので、訪問前に清涼山道立公園管理事務所や公式チャンネルで最新の料金・開放時間を確認しておくのがおすすめです。トイレは山城入口の登山口付近にあることが確認できていますが、水飲み場（薬水場）については公共データ上では特に該当地点が見当たらないため、登山前に水を十分に用意しておいたほうが安心です。地図アプリはグーグルマップではなく、カカオマップ（KakaoMap)かネイバー地図（Naver Map）の使用を強くおすすめします。また、この辺りは公共交通が密ではないエリアなので、タクシー配車アプリ（カカオTなど）も一緒に準備しておくと移動がぐっと楽になります。安全面では、崖に近い区間にある「転落危険」の標識は必ず守ってください。日が短い季節は下山時間に余裕を持たせて計算し、夜間登山にならないよう気をつけるのがいいと思います。
