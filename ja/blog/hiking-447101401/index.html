概要

写真: 韓国観光公社 観光写真ギャラリー (충청남도 금산군 추부면 개덕사길 83) · KOGL

瑞台山（ソデサン、931m）は忠清南道錦山郡にある山で、忠南地域の山の中でも屈指の高さを誇ります。山頂部は岩峰地形が目立ち、山全体としては土山と岩山の特徴が入り混じっているため、登山コースによってまったく違った雰囲気を味わえます。難易度は中級程度ですが、山頂付近では急斜面や岩稜帯が現れるので、体力と注意力が必要です。代表的なコースは往復でも日帰りで回れる山行先ですが、管内の登山道をすべて縦走しようと思うなら1泊以上を考えておいたほうがいいでしょう。

山容と地形

写真: 韓国観光公社 観光写真ギャラリー (충청북도 옥천군 장령산로 519) · KOGL

ソデ山は頂上部が尖った岩峰の形をしていて、名前が示す通り西側から眺めるとその雄大な山容がひときわ目を引きます。公共データに登録されている主な峰々を見てみると、ジェビボン頂上（539m・546mの2地点で登録）、チャングンバウィ（将軍岩）頂上（902m）、ソデ山頂上（931m、904m・930mとしても登録あり）、ボンウリ頂上（550m）、テソン山頂上（724m）、ジェビボン頂上（575m）など、名前のついた峰や岩場が山全体にわたって点在しています。将軍岩・龍岩・仙女岩・神仙岩といった名前からも察しがつく通り、あちこちに奇岩が控えていて、稜線を歩いていると大小さまざまな岩の展望スポットに次々と出会うことになります。谷筋は比較的なだらかな一方、山頂に近づくにつれて傾斜がきつくなり岩場が増えていく、いかにも忠清道エリアらしい岩峰型の山容を見せてくれます。

登山の雰囲気

西大山の登山道は、入口ではうっそうとした森の中を歩く穏やかな雰囲気から始まり、興国寺・孝心寺といった寺院を通り抜ける区間では、どこか懐かしい山寺の空気も味わえます。中腹を越えたあたりから岩肌が目立つようになり、傾斜も一気にきつくなってきて、龍岩・仙女岩・神仙岩といった奇岩を通過する際には、思わず手をついてよじ登るような場面も出てきます。頂上付近まで来ると視界が一気に開け、特に眺望岩の周辺では周囲の山並みと錦山郡一帯の景色が気持ちよく広がります。春は新緑と山野草、秋は紅葉が尾根を彩り、夏は谷筋の湿った空気も相まって体力の消耗がかなり大きく、冬は岩場の凍結によって山歩きの雰囲気ががらりと変わる、そんな山です。

コース1 — ソデサンドリームリゾート → チェビ峰山頂

📏 4.65km ⛰️ 662m 獲得標高 ⏱️ 2:16 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地：ソデサンドリームリゾート → ドリームリゾート → リゾート案内所 → リゾート敷地内 → 分岐点 → 案内看板 → リゾート案内板 → サッカー場 → ソデサン雨量観測所 → 自然景観（龍岩） → ソデサン1-2 → ソデサン1-3 → チェビ峰山頂 → 自然景観（チェビ峰） → 登山路休憩所

登山口へのアクセス：ソデサンドリームリゾートがある錦山郡秋富面一帯は公共交通機関がやや限られているため、近くのバス停で下車してそこから徒歩で向かうのが一般的です。車で行く場合はドリームリゾート周辺の空き地に停めている方が多いのですが、正式な登山用の駐車場としては登録されていないので、事前に地図アプリで確認しておくのがおすすめです。

特徴・おすすめの方：リゾートの敷地内を通り、サッカー場や雨量観測所といった人工的な施設を抜けたあと、龍岩のような自然景観のポイントを経て稜線へと登っていくコースです。3つのコースの中では距離も高低差も一番小さく、日帰り往復がしやすいのが魅力です。とはいえ山頂付近には急坂がまだ残っているので、初心者よりはある程度山歩きに慣れている方に向いています。短時間でパッと山頂を踏みたい、という方にはぴったりのコースだと思います。

山꽃路(ボグァン橋)から一不寺入口を経て頂上へ向かうコース2の翻訳です。

コース2 — 一不寺入口 → 頂上

📏 7.16km ⛰️ 715m 獲得標高 ⏱️ 2:59 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 山꽃路(ポグァン橋) → バス停 → 分岐点 → アンポグァンリ孝心亭 → ウェイポイント5 → 孝心寺トックンスクール → 孝心寺トックンスクール駐車場 → トイレ → 孝心寺 → 瑞台山登山案内図 → 緊急救難標識 → 緊急救助地標 → 緊急救難地標 → 仙女岩 → 眺望岩

登山口へのアクセス: 山꽃路のポグァン橋付近にバス停があるので、公共交通機関でも比較的アクセスしやすいコースです。経由地に孝心寺トックンスクールの駐車場が含まれているので、車で来る場合はここを利用するとよいでしょう。

特徴・おすすめの人: 3つのコースの中で距離・累積標高差ともに最大で、難易度も一番高いコースです。序盤は孝心寺を通る寺院巡礼路のような雰囲気で始まり、後半になると仙女岩・眺望岩といった岩場が続くのが特徴。経由地にトイレの表示があるので序盤の入口付近では助かりますが、全体としては体力をかなり使うコースなので、山歩きに慣れた人向けだと思います。

コース3 — 黄鳥木道（フングクサ入口）→ 頂上

📏 6.31km ⛰️ 698m 獲得標高 ⏱️ 2:44 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地：桜並木道・サンゴク橋 → 分岐点 → ウェイポイント4 → ソンムンサ → 黄鳥木道左側（食用植物群落地）→ ウェイポイント6 → フングクサ路の赤松林 → 黄鳥木道（フングクサ入口）→ 黄鳥木道（フングクサへ上る登山道）→ フングクサ → シンソン岩 → 岩の休憩スポット → マダン岩 → ソデサン戦跡碑 → ドリームリゾート駐車場

登り口へのアクセス：サンゴク橋の近くから山行をスタートするコースで、下山口がドリームリゾート駐車場につながっているため、コース1と組み合わせて周回コースを組みたい方にも都合がいいルートです。公共交通機関よりは、マイカーでのアクセスの方が多少便利な区間になります。

特徴・おすすめの人：桜並木道や食用植物群落地といった自然の要素が楽しめる区間を抜け、フングクサ・ソンムンサといったお寺を経由しながら、後半にはシンソン岩・マダン岩など広々とした岩の休憩スポットが続いていくのがこのコースの特徴です。マダン岩のような広い岩場でひと息つきやすいので、景色を眺めながらのんびり登りたいという方にぴったりのコースだと思います。

難易度・路面・注意点

山林庁の登山路空間情報によると、瑞石山エリアの登山路の難易度はデータ上「中間」となっており、路面についての詳しい情報は特に登録されていません。とはいえ「100대명산」の実測コースデータを見ると、頂上圏まで登る3コースはいずれも純標高差660m以上、難易度は星4〜5とけっこうな数字が出ていて、体感的にはデータ表記より歯応えがありそうです。公共データ上、展望ポイント・危険地域・待避所・登山口や下山口の施設はすべて「0件」と登録されており、正直なところ安全施設や避難スペースを当てにせず自分で計画を立てる必要があります。頂上部や龍岩・仙女岩・神仙岩などの岩場区間は雨の日に滑りやすさが一気に増し、冬場は凍結でさらに危険度が跳ね上がるので、このあたりは油断せずしっかり気を配ってください。

距離と所要時間

西大山エリア内に登録されている登山道の総延長(複数区間を合算した数値)は46.19kmにもなります。ただこれは特定の一本のコースの距離ではなく、山全体の登山道網をぜんぶ足し合わせた数字なので、そこは勘違いしないようにご注意を。エリア内全区間を基準にした累積所要時間は登り914分・下り633分で、ここから逆算すると平均登坂ペースはだいたい20分/kmといったところです。

とはいえこのペースはあくまで山全体の登山道の平均的な登り速度を示す参考値であって、特定コースの所要時間ではありません。実際にどのコースを歩くか決めるときは、先ほど紹介したコース別の詳細タイム(片道約2時間16分〜2時間59分)を基準にするのが正解です。主要コースはどれも片道2時間前後なので、往復しても日帰りで十分こなせる山行コースといえます。ただし、複数区間をつなげて縦走のように歩く場合は総延長が46kmを超えてくるので、その時は1泊以上の日程を組むことをおすすめします。

行き方(公共交通機関・駐車場)

瑞台山は忠清南道錦山郡にあるので、大田や近隣都市から市外バスや市内バスを使ってアクセスするのが一般的です。公共データ(TAGO)に登録されている登山口付近の実際のバス停としては、瑞台山ドリームリゾート停留所と聖堂2里停留所が確認できて、コース1(瑞台山ドリームリゾート→チェビ峰頂上)を利用する場合はこれらの停留所が使えます。ただ、都心部に比べて運行間隔が広いことがあるので、事前に時刻表をチェックしておくのが大事です。正式な登山口駐車場は公共データ上では特に登録がなく、車で行く場合はドリームリゾート周辺やお寺近くの空き地を使うケースが多いようです。公共交通機関にせよ徒歩ルートにせよ、出発前にKakaoMapやNaver Mapでリアルタイムの経路と運行情報を確認しておくことをおすすめします。

シーズン・天候・装備

ソデ山登山におすすめのシーズンは春（4〜5月)と秋（9〜11月)。新緑と紅葉をどちらも楽しめて、気温も登山にちょうど良い時期です。夏場は谷筋の湿気と暑さで体力を消耗しやすいので、飲み水をしっかり持って休憩もこまめに取る計画が必要ですし、冬場は山頂付近や岩場が凍結するため、アイゼンやスパッツといった冬山装備が欠かせません。基本装備としては足首を守る登山靴、飲み水(この山には湧き水がほぼないので必ず自分で持参すること)、トレッキングポール、雨対策のレインウェア、着替えなどを用意しておくといいでしょう。岩場が多い山なので、手袋も一緒に準備することをおすすめします。

外国人旅行者へのアドバイス

写真: 韓国観光公社 観光写真ギャラリー (충청남도 금산군 홍골1길 142) · KOGL

西大山は英語表記だとSeodaesan(931m)、主な登山口となる西大山ドリームリゾートはSeodaesan Dream Resort、山頂付近のピーク・제비봉はJebibongと表記できます。特別な入山許可や入場料があるという情報は今のところ見当たりませんが、念のため訪問前に管理事務所や自治体の告知を確認しておくと安心です。トイレについては、コース2（イルブルサ入口→山頂）の経由地のうち、ヒョシムサ・トクブンスクール駐車場付近に設置場所の表示がありますが、それ以外の区間にはトイレも水飲み場もほぼないと考えたほうがよく、登山前に水分補給とトイレは済ませておくのがおすすめです。登山道の案内はGoogleマップよりKakaoMapやNaverマップのほうが断然正確なので、この2つのアプリを使うことを強くおすすめします。オフライン地図を事前にダウンロードしておくと、電波が届きにくい区間でも安心です。安全面では、単独登山よりも同行者を見つけたほうがよく、特に岩場が多いコースなので、雨天時や冬場の登山は慎重に判断してください。
