概要

写真：韓国観光公社観光写真ギャラリー（江原特別自治道洪川郡東面）・公共누리

孔雀山(コンジャクサン)は、江原特別自治道洪川郡花村面一帯にある山です。頂上の標高は、昔からある頂上標識石の表記だと886mとされていますが、実測GPXデータで見るとコース内の最高地点は923mまで出ています。全体としてゴツゴツした岩峰型の山というわけではないものの、頂上に近づくにつれて高低差がけっこう広がっていくタイプで、登山口によっては頂上まで片道8~14kmにもなるコースがいくつもあります。なので、ちょっと寄って帰るというより、丸一日空けて臨む山という感覚に近いです。アクセスのいい短いコースを選べば日帰り往復も十分可能ですが、頂上付近のいくつものピークをまとめてつなぐ縦走系のコースを選ぶと、歩く距離も時間もぐっと増えるので、そこは事前に頭に入れておいたほうがいいと思います。

山の姿と地形

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道洪川郡東面）・公共ヌリ

孔雀山は、鋭い岩峰が連なるいわゆる「骨山」というより、尾根がなだらかに続く「肉山」に近い山なんですが、それでいて山頂付近には大小いくつものピークが折り重なるように立っていて、思っていたより一筋縄ではいかない山容をしています。公共データに登録されている主なピークだけでも、薬水峰頂上（557m）、薬水峰558（537m）、スリボン(820m)（789m）、スリボン(755m)（773m）、孔雀山スリボン頂上（780m）、640峰（652m）、コサリボン（466m）、そしてかつて山頂標識が立っていた孔雀山頂上（886m）と、標高の異なるピークが尾根沿いにずらりと並んでいます。これだけピークの名前と標高が細かく分かれているというのは、孔雀山が一つの尖った頂を持つタイプの山ではなく、複数のピークが肩を並べながら連なる、いわゆる連峰型の山だということを物語っています。コース途中には老松の群生地、チョウセンゴヨウの植林地、カラマツの植栽地、ナラの群生地など、針葉樹と広葉樹が入り混じった森が広く広がっていて、尾根を歩いていると樹種がどんどん変わっていくのを肌で感じられるのも、この山を歩く楽しみのひとつです。

登山の感覚

公作山の山行は、序盤こそなだらかな森の道が続きますが、中盤を過ぎると老松の群生地やチョウセンゴヨウの林といった針葉樹の密集区間に入り、一気に木陰が濃くなるのが特徴です。コースによっては公作滝や屈雲貯水池、砂防ダムなど水にまつわる地形も通るので、渓谷歩きのような趣も味わえます。頂上付近の展望ポイントでは視界が開ける区間もありますが、全体としては鬱蒼とした森の割合が大きく、真夏でも日陰を選んで歩けるコースだと言えます。ただ、片道の距離が長いコースが多いせいか、後半になるほど体力の消耗がじわじわ効いてくる感じがしますし、特に縦走タイプのコースでは「墜落注意」「墜落危険」の表示がある区間を通過しなければならず、気が抜けない瞬間もあります。秋にはカラマツやナラの群生地の紅葉が、春には新緑がコース全体の雰囲気をやわらげてくれます。

私が公作山を初めて訪れたとき、コース選びで結構悩んだ記憶があるので、その辺の実感も交えて訳してみます。

コース1 — 公作橋 → 頂上

📏 8.19km ⛰️ 601m 獲得標高 ⏱️ 3:03 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地: 公作橋 → 東屋休憩所 → 分岐点 → 老松群落地 → 老松群落地の終わり → 落葉松植栽地域

登山口へのアクセス: 公作橋は洪川郡花村面一帯にあるとされていて、洪川市内から車で20〜30分ほどの距離だと把握しています。公共交通を使う場合は洪川バスターミナルから花村面方面の郡内バスに乗り、そこから徒歩で向かうのが一般的なようです。ただ、きちんと区画された登山用駐車場があるという情報は確認できなかったので、自家用車で行く方は路肩や小さな空き地を利用しているケースが多いようです。

特徴・おすすめの人: 全6コースの中では距離が短めな部類に入るので、比較的気軽に取り付けるコースです。入口から東屋休憩所までは緩やかな林道が続き、老松群落地の区間では年月を重ねた松林ならではの雰囲気を味わえます。公作山に初めて訪れる方や、日帰りでさくっと往復したいという方に向いていると思います。

コース2 — 孔雀山入口駐車場・トイレ → 頂上

📏 12.86km ⛰️ 714m 獲得標高 ⏱️ 4:24 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 孔雀橋 → ケヤキ休憩所 → フォトゾーン → 分岐点4 → 孔雀山入口駐車場・トイレ → カラマツ群生地 → 転落注意 → 展望ポイント → 頂上 → チョウセンゴヨウ → コナラ群生地 → 640峰 → チョウセンゴヨウ群生地 → 老松群生地 → 老松群生地

登山口へのアクセス: 名前の通りトイレを備えたスペースから出発できる地点で、6コースの中では初めての人でも登山口を見つけやすいほうです。ただ、正式に登山路駐車場として登録されている場所ではないため規模はそれほど大きくなく、繁忙期には満車になることも頭に入れておいたほうがいいでしょう。洪川市内から車で約20〜30分、公共交通なら和村面方面行きのバスに乗ってから徒歩で向かいます。

特徴・おすすめの人: 距離も高低差も6コースの中で最大で、難易度は最高ランク（★★★★★）です。ケヤキ休憩所やフォトゾーンなど休める場所がいくつも用意されていて、頂上付近の展望ポイントでは景色を楽しめますが、「転落注意」区間が実測の道標にはっきり示されているので、そこは気を引き締めて歩く必要があります。体力に自信のある登山者や、丸一日をこの山行のために空けられる人向けのコースです。

코스 3 — 屈雲貯水池バス停 → 頂上

経由地：屈雲貯水池バス停 → 分岐点 → 陽だまりペンションガーデン → 転落注意区間 → 松林エリア → 老松群生地 → 잣나무（チョウセンゴヨウ）林 → 私設・公雀山自然休養林

登山口へのアクセス：屈雲貯水池バス停は近隣に登録されているバス停のひとつで、公共交通機関でそのまま降りて登山を始められる便利な登山口です。マイカー利用の場合も、貯水池周辺の空き地に停めている人をよく見かけます。

特徴・おすすめの人：屈雲貯水池を回り込むように始まる序盤の眺めがなかなか印象的で、陽だまりペンションガーデンなどの宿泊施設を通り過ぎると、松や잣나무（チョウセンゴヨウ）の群生地へと続いていきます。「転落注意」の標識が立つ区間もあるので、雨の日や路面が凍る時期は特に気を引き締めて歩きたいところです。私設の公雀山自然休養林のそばを通るルートなので、自然休養林らしい雰囲気も一緒に味わいたいという方に向いています。

초めまして、と言いたいところですが、今日は登山コースの紹介です。

コース4 ― グルンチョ貯水池バス停 → カラマツ地帯

📏 12.82km ⛰️ 718m 獲得標高 ⏱️ 4:24 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：グルンチョ貯水池バス停 → 分岐点 → カラマツ地帯 → コンジャク滝 → ナブンドゥル停留所（グノプ2里）

登山口へのアクセス：コース3と同じくグルンチョ貯水池バス停からスタートしますが、終点はナブンドゥル停留所（グノプ2里）付近。公共交通機関を使えば、登山口と下山口を別にする山行も組めます。

特徴・おすすめの人：必ずしも頂上を踏まずに、カラマツ地帯とコンジャク滝を抜けて反対側へ抜ける縦走タイプのコースで、6コースの中では距離が最長の13.91kmです。コンジャク滝をはじめとした渓谷の景色を楽しめるので、滝や渓谷の風景が好きな人、あるいは登山口と下山口を分けて縦走したい人にぴったりです。

私、実は先週、公津山(コンジャクサン)の全6コースを一気に踏破してやろうと勢い込んで、地図とにらめっこしていたんですが、コース5だけは何度見ても「一番ラクそう」という印象が変わらなくて。今回はそのコース5をご紹介します。

コース5 — ノヒョンドゥル → 頂上

📏 13.91km ⛰️ 706m 獲得標高 ⏱️ 4:39 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：ノヒョンドゥル → 墓地 → 分岐10 → 老松群落地 → 分岐13 → 松（チョウセンゴヨウ）植林地 → カラマツ植林地

登山口へのアクセス：ノヒョンドゥルは集落の地名で、近くまで自家用車で入ってから徒歩で登山口へ向かうのが一般的なやり方です。公共交通を使う場合は、洪川(ホンチョン)の郡内バスの路線とバス停の位置を、事前にしっかり確認しておいたほうがいいと思います。

特徴・おすすめの人：距離8.54km、標高差543mと、6コースの中では割と緩やかな部類に入るので、体への負担が少なめなコースです。墓地や松の植林地などを抜けていく道中では、集落近くならではの素朴な風景も楽しめるので、公津山を短く手軽に登ってみたいという初〜中級の登山者にちょうどいいコースだと思います。

코ース6 — クルンジョー貯水池 → カラマツ生息地帯

経由地: クルンジョー貯水池 → ホタル生息地域 → プンギョンファペンション → 分岐点7 → 砂防ダム → カラマツ生息地帯 → チョウセンゴヨウ生息地 → 分岐点20 → 分岐点21 → 分岐点11 → 分岐点12 → 老松群落地 → 分岐点14 → スリボン(820m) → 分岐点16

登山口へのアクセス: クルンジョー貯水池付近からスタートします。公共交通機関を使う場合はクルンジョー貯水池停留所で降りて徒歩で向かい、自家用車の場合は貯水池周辺の空き地に停めればOKです。

特徴・おすすめの人: 全6コースの中で道標の経由地点が最も多く、ホタル生息地域・砂防ダム・スリボン(820m)など、生態や地形のさまざまな見どころを一通り巡る縦走型のロングコースです。孔雀山のいくつもの峰を一緒に眺めながら山の懐深さをじっくり味わいたいベテランハイカー向きで、それなりの距離があるぶん時間には余裕を持たせておくのが吉です。

難易度・路面・注意点

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道洪川郡東面）・公共누리

公作山エリアの登山道は行政区域（行政洞）単位で4区間が登録されており、データ上の難易度はいずれも「やさしい」となっています。ただこれは個々の登頂ルートというより、エリア内の登山道全体を行政洞ごとに区切った総延長区間だという点に気をつけたいところです。

行政洞基準のデータでは最高難易度が「やさしい」と登録されているものの、100대名山GPX基準の山頂周辺コースは片道の距離も標高差もそれなりにあるため、実際に歩いた体感の難易度はデータ表記より高く感じられることがあります。路面情報は別途登録されておらず、舗装・未舗装の詳細までは確認できません。また実測の道標には「転落注意」「転落危険」の表示が出てくる区間もあり、雨上がり直後や冬場の凍結時には滑りやすさに特に気をつける必要があります。展望ポイント・水飲み場・避難小屋・危険地域といった施設のPOIは公式には登録がなく、山行中に別途の給水や避難施設を期待するのは難しい状況です。

距離と所要時間

写真:韓国観光公社 観光写真ギャラリー(江原特別自治道 洪川郡 東面)・公共ヌリ

管内の登山道を全区間つなげて合計してみると、上り622分・下り435分かかる計算になります。総延長29.81kmで割ると、平均の上りペースはだいたい1kmあたり21分ってところでしょうか。

ただ、これはあくまで管内の登山道を全部つなげた場合の累積時間なので、「どれか一つのコースを登るのにこれだけかかる」と勘違いしないよう注意が必要です。実際に個々のコースでどれくらいかかるかは、上の表にある片道約3時間〜4時間40分という数字を見てもらうのが正確です。

公 直橋や 老峴들登山口みたいな短めのコースなら、往復でも余裕で日帰りできます。一方で片道12〜14kmクラスのコースだと、往復で8〜9時間以上かかることもあるので、朝は早めに出発するのがおすすめです。

山頂付近のいくつかのピークをつなぐ縦走系のコースを考えているなら、管内登山道の総延長(29.81km)と、避難施設が一切ないという点を頭に入れて、1泊以上の余裕あるスケジュールで組んだほうが安全です。

行き方（公共交通機関・駐車）

写真:韓国観光公社観光写真ギャラリー(江原特別自治道洪川郡東面)・公共ヌリ

孔雀山の周辺には孔雀洞、屈雲貯水池、瓦洞ソニ峠などのバス停が確認できます。ソウルなど首都圏からだと、東ソウル総合ターミナルや上鳳ターミナルから洪川行きの市外バスに乗って洪川バスターミナルに到着し、そこから化村面方面の郡内バスに乗り換えて、孔雀洞・屈雲貯水池・瓦洞ソニ峠など目指す登山口近くの停留所で降りる、というのが一般的なルートです。ただ、郡内バスは運行間隔がわりと広めなので、事前に時刻表を確認しておいたほうが安心です。車で行く場合は、公式に登録された登山専用駐車場は特に見当たらず、コース2の「孔雀山入口駐車場」のような、名前だけ知られた小さめのスペースや、屈雲貯水池周辺の空き地を使うケースが多いようです。実際のルートや最新の公共交通情報については、必ずKakaoMapやNaver Mapで「孔雀山」または各登山口の地名(孔雀橋、屈雲貯水池、老懸ドゥルなど)を検索して確認することをおすすめします。

季節・天気・装備

こんにちは。今日は公共写真の紹介文をひとつ訳してみます。訳文はこちらです。

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 홍천군 동면) · 공공누리

公작산は春と秋がいちばん歩きやすい時期で、新緑と紅葉の両方を楽しめる山です。夏場は木々が茂って木陰を拾いながら歩けるものの、登録された水場がないので、うっかりすると脱水になりかねません。飲み水は多めに持っていくことを忘れずに。冬になると、老松の群落地やチョウセンゴヨウの林など日陰になりやすい区間、それから「落下注意」「落下危険」の標識が立っている場所で凍結が起きやすくなるので、アイゼンやスパッツといった防寒・滑り止め装備は必須です。基本装備としては登山靴、着替え、ストック、ヘッドランプ(コースが長くなる場合に備えて)、そして十分な水と間食を用意しておくと安心です。避難施設が整っていない山なので、天候が悪くなってきたら無理せず早めに下山するのが賢明です。

公作山のローマ字表記はGongjaksan(Mt. Gongjak)で、主な地名は公作橋(Gongjak-gyo)、屈雲貯水池(Guluun Reservoir)、老懸坪(Nohyeondeul)などとなっています。入山許可や入場料は特に確認されておらず、国立・道立公園のように매표소(チケット売り場)を通さずに入れる山として知られていますが、現地の案内板で最新情報を再確認しておくと安心です。トイレはコース2の登山口（「公作山入口駐車場・トイレ」）でしか確認できず、それ以外の区間には専用トイレや水飲み場の記載がないので、登る前にあらかじめ準備しておく必要があります。GoogleMapsは韓国内の登山道情報が不正確なことが多いので、事前にKakaoMapかNaver Mapのアプリを入れておいて、公共交通機関のルートや実際の登山道を確認しておくのがおすすめです。山行中は携帯の電波が弱くなる区間もあるので、オフライン地図をあらかじめダウンロードしておき、避難施設がないことも踏まえて日没前の下山を目標にスケジュールを組むと安全です。
