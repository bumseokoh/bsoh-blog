概要

写真：韓国観光公社 観光写真ギャラリー（慶尚北道金泉市恒渓面）・公共누리

黄岳山（ファンアクサン、Hwangaksan）は、慶尚北道金泉市と忠清北道永同郡の境界にまたがる山で、白頭大幹の稜線の一部を成しています。頂上部の標高は登山道資料によると1,132m~1,142mの間とされていて、山のふもとには新羅時代の古刹・直指寺（チクジサ）があるため、登山とお寺めぐりを一緒に楽しめる山として広く知られています。全体としては土山に近い穏やかな山容で、登山道の空間情報上の最高難度は「易しい」に分類されていますが、実際に頂上まで続く登山コースは距離も標高差もそれなりにあり、体力を使う長丁場のコースがほとんどです。短めのコースを選べば日帰り往復も十分可能ですが、白頭大幹の稜線を長く縦走するコースを選ぶと一日で終えるにはなかなかタイトになるので、コース選びには注意が必要です。

山容と地形

写真：韓国観光公社 観光写真ギャラリー（慶尚北道金泉市項道面）・公共누리

黄岳山は尖った岩峰が目立つタイプというより、なだらかな稜線と柔らかな斜面が続く土山（土がちな山）タイプの地形です。周辺には黄岳山（1132m）をはじめ、黄岳山兄弟峰（1082m・1065mの二地点として記録）、余情峰（1055m）、坤天山（1058m）、雲水峰（674m）、黄岳山望峰（596m）など複数のピークが白頭大幹の稜線沿いに連なっており、単独の山というより稜線全体で山容を成しているタイプに近いです。山頂の標高は資料によって1125m〜1142mと若干のばらつきがありますが、これは測量地点や調査時期の違いによるもののようで、山頂自体が稜線上のなだらかな高まりという形をしていることとも無関係ではないでしょう。コース別の詳しい道標を見ると、白蓮庵・雲水庵・明寂庵といった付属の庵や砂防ダム、国有林境界石などが登場し、渓谷部と寺院林を併せて通る、白頭大幹の裾野らしい典型的な登山道の特徴がうかがえます。

登山の雰园

写真：韓国観光公社 観光写真ギャラリー（慶尚北道金泉市項洞面）・公共누리

低地部分では直指寺一帯の鬱蒼とした森の道と谷沿いのなだらかな土の道が続き、高度が上がるにつれて稜線特有の爽快な眺望が開ける区間が現れます。各コースの道標に「眺望点」「黄岳山展望台」「三聖山眺望点」といった表示が繰り返し登場することから、稜線に上がると白頭大幹の山並みを望める地点があちこちに点在していることがわかります。春には新緑と山桜、夏には谷筋の涼やかな木陰、秋には紅葉に染まる稜線歩き、冬には雪をまとった白頭大幹の稜線の趣を味わえるなど、季節ごとに違った表情を見せてくれる山だと言えるでしょう。ただ、急斜面や落石・落ち葉注意の標識がある区間も含まれているため、後半に差し掛かるほど登りの体感的なきつさが増していく傾向があります。

コース1 — 分岐点4 → 山頂付近の展望ポイント

📏 10.88km ⛰️ 950m 獲得標高 ⏱️ 4:18 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 分岐点4 → 分岐点5 → 休憩所 → 東屋 → 分岐点17 → 分岐点19 → 分岐点20 → 分岐点21 → 分岐点23 → 山頂付近の展望ポイント → 黒ヤギのつがい → 分岐点33 → 展望ポイント → 分岐点51 → 分岐点56

入山口へのアクセス: 分岐点タイプの入山口で、専用のバス停名は確認できませんでした。近隣のコミュニティバスやタクシーを利用し、そこから徒歩でアプローチする形になりそうです。マイカーの場合は、近くの空き地や路肩に停めている人が多いようです。

特徴・おすすめの人: いくつもの分岐点や休憩所、東屋を次々と通過していく区間が多く、道がやや複雑に感じられるかもしれません。途中には「黒ヤギのつがい」というなんとも珍しい道標表記まであるほどで、野生動物にひょっこり出くわすこともある静かな尾根道です。道標自体は細かく整備されている一方、その分こまめに確認する必要があるので、地図アプリと照らし合わせながら歩くのがおすすめ。人の少ない静かな山道が好きな、ある程度経験を積んだ登山者向けのコースだと思います。

コース2 — 極楽殿駐車場 → 頂上部展望ポイント

📏 10.15km ⛰️ 945m 獲得標高 ⏱️ 4:07 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：極楽殿駐車場 → 案内図 → 入山統制所 → 道標 → 分岐点 → 白蓮庵の休憩所（トイレ） → 白蓮庵 → 雲水庵駐車場 → 雲水庵の休憩所（トイレ） → 雲水庵・黄岳山分岐点 → 休憩スポット → 黄岳山道標 → 国家地点番号 → 立入禁止区域 → 立入禁止エリア

取り付き点へのアクセス：極楽殿駐車場は寺への参道につながる駐車スペースで、市内バスで直指寺方面まで行き、そこから歩いて向かうのが一般的なルートです。マイカーの場合も駐車場が用意されているので、比較的アクセスは良いほうだと思います。

コースの特徴・おすすめしたい人：白蓮庵、雲水庵といった付属の庵を順番に巡っていく、いかにも寺巡礼らしい伝統的な登山道です。入り口に入山統制所と案内図があるので、初めて歩く人でも道に迷いにくいのがありがたいところ。後半には立入禁止区域の表示が出てくるので、決められた登山道を外れないよう気をつけたいところです。お寺の文化を味わいながら山歩きも楽しみたい、という方にぴったりのコースだと思います。

コース3 — オクルクチョン（ヘピョン）→ コンチョンサン頂上休憩所

📏 12.4km ⛰️ 851m 獲得標高 ⏱️ 4:31 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地：オクルクチョン（ヘピョン）→ 多目的倉庫の空き地 → 渓流を渡る → 分岐点 → 急斜面の登り → 道標 → 陸軍の標石 → 軍の鉄柵と哨所 → 急斜面 → 展望スポット → 道標 → 標識 → 松の木 → 黄岳山展望スポット → 落ち葉注意

登山口へのアクセス：オクルクチョン（ヘピョン）の集落から始まる登山口ですが、公共交通の便があまりよくないので、自家用車かコールタクシーを使うのが現実的です。専用の駐車場という表記は特になく、集落の道路脇のスペースを利用することになるかもしれません。

特徴・おすすめの方：六つのコースの中でもっとも距離が長く（12.4km）、渓流を渡り、急斜面を登り、軍の鉄柵や哨所まで現れるなど、軍事施設のすぐそばを通る山道です。最後に「落ち葉注意」の標識が出てくるあたり、秋から初冬にかけては落ち葉に覆われて道が滑りやすく、道筋がわかりにくくなることもありそうなので、体力と経験のある登山者向けのコースと言えます。

コース4 — 駐車場 → サムソンサン山頂休憩所

📏 7.2km ⛰️ 376m 獲得標高 ⏱️ 2:26 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

経由地：駐車場 → ウドゥリョン（牛頭嶺） → ウドゥリョン案内板 → 道標 → 稜線休憩所 → サムソンサン山頂休憩所 → サムソンサン（三聖山） → ヨジョンボン（余程峰） → 白頭大幹損傷地復元事業区間 → 自然石の階段 → 休憩所 → 国家地点番号

登山口へのアクセス：ウドゥリョン峠付近の駐車場から出発するコースです。白頭大幹の稜線が通る峠だけあってマイカーでのアクセスが一般的で、駐車スペースも用意されています。公共交通機関を使う場合は、近くの町からウドゥリョン方面行きのバス便を事前に確認しておく必要があります。

特徴・おすすめの人：六つのコースの中でも距離（7.2km）と累積標高差（376m）が最も短く緩やかで、初中級者に最も取り組みやすいコースです。白頭大幹損傷地復元事業の区間や自然石の階段など、整備された設備を通り抜けながらヨジョンボンまで稜線をつないで歩けるので、短時間で白頭大幹の稜線の雰囲気を味わいたい登山者におすすめです。

コース5 — 風才(パラムジェ)休憩所(登山口)〜山頂

登山口へのアクセス: 登山口の近くに「風才(パラムジェ)」バス停があるので、6つのコースの中では公共交通機関で行きやすいほうだと思います。道路沿いに駐車・転回スペースが何ヶ所か示されているので、マイカーで行っても特に問題はありません。

特徴・おすすめの人: 案内所と展望ポイントが何度も続くので、視界の開けた区間が多いのが魅力です。ただ、砂防ダムや土砂災害警戒区域の案内板があることからもわかるように、雨の日は谷筋の安全に気をつけたいコースでもあります。落石注意の標識も出ているので、梅雨時や雪解けの時期は特に慎重に進んだほうがいいでしょう。公共交通機関で日帰り登山を計画している人にはぴったりのコースです。

コース6 — 極楽殿駐車場 → 望月峰

管内の登山道の空間情報上では最高難易度が「易しい」に分類されていますが、実際に頂上まで続く「100대名山」のGPXベースのコースはほとんどが累積高低差700m以上、距離10km前後と、体感的にはかなり難易度が高くなっています。これは、管内の登山道データが低地帯の区間を中心に登録されているのに対し、頂上圏のコースは白頭大幹の稜線に沿って長距離で続いているためだと考えられます。危険地域は登録件数が0件となっていますが、コースごとの道標には急斜面・落石注意・落葉注意・土砂崩れ脆弱地域といった表示が実際に確認できるため、雨上がり直後や凍結期にはこうした区間で特に気をつける必要があります。展望地点も公式な登録数では0件ですが、コース詳細を見ると「頂上付近の展望点」「頂上部展望点」「黄嶽山展望台」「三聖山展望点」など、実質的な展望ポイントが複数確認できるので、稜線区間では眺望が期待できそうです。飲み水場（湧き水場）は登録地点がなく、山中で飲み水を確保するのが難しいため、必ず十分な水を用意しておくべきです。避難所も登録されている場所がなく、天候が急変した際に避難できる施設が特にない点も覚えておいたほうがいいでしょう。登山口・下山口は3地点が登録されており、同じ場所を往復するより、登山口と下山口を別々に設定する縦走型の山行が多い山だと言えそうです。

距離と所要時間

写真：韓国観光公社観光写真ギャラリー（慶尚北道金泉市アハン面）・公共ヌリ

管内の登山道総延長5.34km区間における上り96分・下り66分のデータをもとに計算すると、平均の上りペースはおよそ18分/kmとなります。この数値はあくまで管内の複数区間を積み上げた通行所要時間であり、特定の単一コースの往復所要時間と誤解してはいけません。実際に頂上圏の登山を計画する際に参考になるのは、100大名山GPXに基づくコース別の推定所要時間で、短いものではコース4(駐車場→三成山頂上休憩所、片道約2時間26分)、長いものではコース3(オクルク村(海坪)→崑千山頂上休憩所、片道約4時間31分)と、かなり幅があります。往復登山の場合、片道所要時間の1.8~2倍程度を見込むのが一般的で、これを踏まえると短いコースなら午前から午後にかけて日帰り往復が十分可能ですが、長いコース(コース1、2、3、5)を往復で計画する場合は8~9時間前後かかることもあるので、朝早めの出発と余裕を持ったスケジュール確保が必要です。全体として黄岳山は管内の登山道総延長が5kmほどしかなく、避難小屋もないことを考えると、泊まりがけの縦走よりも日帰り登山として計画するのが一般的で、複数のコースをつないで白頭大幹区間縦走に挑戦する場合に限り、山小屋や近隣の宿泊施設を利用した一泊日程を検討することになります。

行き方(公共交通機関・駐車場)

写真: 韓国観光公社 観光写真ギャラリー(慶尚北道金泉市抱項面) · 公共누리

黄岳山の登山口付近には「パラムジェ(風峠)」「ファゴク」の各バス停があり、なかでもパラムジェ休憩所(登山口)へ続くコース5は、パラムジェ停留所を使えば比較的公共交通機関でアクセスしやすいルートです。金泉市内から直指寺方面、あるいは牛頭嶺方面行きの市内バスに乗り、停留所で降りたら徒歩で登山口まで向かうのが一般的なパターン。KTXや一般列車を利用する場合は金泉亀尾駅か金泉駅で市内バスに乗り換える必要があり、正確な路線・運行間隔は変更されることもあるので、カカオマップ(KakaoMap)やネイバーマップ(Naver Map)で「直指寺」または「牛頭嶺」を目的地に検索し、リアルタイムの公共交通ルートを確認しておくのがおすすめです。管内の登山道データ上では正式に登録された駐車場は見当たらないものの、コースの詳細な道標には極楽殿駐車場、雲水庵駐車場、明寂庵駐車場、牛頭嶺付近の駐車場など実際に利用できる駐車スペースが複数確認できるので、車で向かう場合はこうしたポイントを目的地に設定するのが現実的です。ただし駐車スペースにあまり余裕がないこともあるため、繁忙期の週末は早めの到着をおすすめします。

シーズン・天候・装備

사진: 한국관광공사 관광사진 갤러리 (경상북도 김천시 대항면) · 공공누리

黄岳山（ファンアクサン）に登るなら、やっぱり気候が穏やかで紅葉や新緑も一緒に楽しめる春（4〜5月）と秋（10〜11月)が一番無難だと思います。夏場は谷筋のひんやりした涼しさが魅力なんですが、雨が降ると砂防ダムや山崩れ危険区域の標識がある区間で急流や落石のリスクが一気に高まるので、天気予報のチェックだけは絶対に怠らないでください。冬場は稜線や急斜面が凍結しやすく、アイゼンやスパッツといった冬装備は必須です。季節ごとの体感難易度も、正直言って冬が一番きついですね。

共通して持っていきたい必須装備を挙げると、足首をしっかり守ってくれる登山靴、山の中に水場がない点を踏まえた十分な飲み水（コースにもよりますが1.5〜2リットル以上）、トレッキングポール、防風・防水ジャケット、行動食や非常食、下山が遅れた時のためのヘッドランプ（特に長距離コースでは必須級）、それに地図アプリを入れたスマホあたりでしょうか。

外国人旅行者向けのヒント

写真: 韓国観光公社観光写真ギャラリー（慶尚北道金泉市項道面）· 公共누리

黄嶽山は英語表記で「Hwangaksan」、代表的な寺院である直指寺は「Jikjisa Temple」と表記されます。山頂は「Hwangaksan Summit」、主要な登山口のひとつである牛頭嶺は案内板で「Udu-ryeong Pass」と併記されていることが多いです。入山そのものに特別な許可や入場料は必要ないのが一般的ですが、直指寺の境内を通るコースを利用する場合は、寺院の文化財観覧料が別途かかることがあるので、現地の案内を確認しておくと安心です。トイレは極楽殿駐車場や雲水庵駐車場など、寺院近くの施設で利用できますが、中腹より上の区間にはトイレが設置されていないため、出発前に済ませておくことをおすすめします。登山道沿いに登録された水場(薬水)はないので、出発前に飲料水を十分な量買って持参する必要があります。地図アプリはGoogleマップだと韓国国内の徒歩・公共交通の経路案内が不正確なことが多いので、事前にカカオマップやネイバーマップをインストールして、実際の登山道や公共交通の路線を確認しておいたほうが安全です。安全面では、この区域には避難所や危険地域として登録された地点がないこと、そして実際には急斜面・落石・落ち葉の区間が存在することも踏まえて、単独登山よりも同行者と一緒に登ることをおすすめします。また下山時間には余裕を持たせ、日が暮れる前に下山を終えられるよう計画するのが望ましいでしょう。
