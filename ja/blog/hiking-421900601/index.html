デックハンサン(徳項山、Deokhangsan)は江原特別自治道・三陟市にそびえる山で、頂上の標高は1059mとされています。すぐ隣の芝覚山・幻仙峰(1056m)とは稜線続きでつながっていて、白頭大幹の一部を成す山でもあります。頂上付近は岩稜とカルスト(石灰岩)地形が発達していて、山のふもとには天然記念物に指定されている幻仙窟・大金窟などの鍾乳洞が集まる大耳里洞窟地帯が広がっています。全体的な山の姿は比較的なだらかな土山寄りですが、頂上へ向かう区間は標高差が大きく、なかなか体力を使わされます。コースによって難易度の差がかなりあるのもこの山の特徴で、たいていのコースは日帰りで十分歩き通せます。

山の地形と特徴

덕항산은 全体的になだらかな稜線を持つ土山タイプの山ですが、頂上付近だけはカルスト地形の影響で奇岩や石灰岩の絶壁があちこちに顔を出しているのが面白いところです。代表的なピークとしては덕항산の頂上（1059m）と、お隣の지각산 환선봉（1056m）があり、この二つは稜線でつながっているので、縦走スタイルの登山も楽しめます。麓の대이리一帯は国内でも有数の石灰洞窟の密集地帯で、환선굴をはじめとする洞窟群が、まさにこの山の地質的な個性を物語っています。実測したコースデータを見ると、登山ルートが到達する最高標高は1111mまで記録されていて、これはおそらく덕항산頂上付近の稜線にある展望ポイントか、환선봉方面へ続く区間で出た数値だと思われます。

山登りの感想

덕항산 登山は、序盤の渓谷歩きから始まって、だんだん傾斜のきつい山道へと変わっていくのが基本パターンです。大耳渓谷(대이계곡)沿いを登っていく区間では、水音と鬱蒼とした森が相まって涼しげな気分にさせてくれますが、標高が上がるにつれて稜線歩きと岩稜地帯が交互に現れ、なかなか骨の折れる登りが続きます。頂上付近まで来ると視界が開け、周囲の稜線や山並みを見渡せるポイントがいくつか登場します。季節感で言うと、夏は渓谷のひんやりした空気と生い茂る緑が、秋は稜線の紅葉が、そして冬は山頂付近の樹氷や霧氷が見どころとして知られている山です。ただし山頂圏コースは純粋な標高差が大きく急斜面の区間も含まれているため、体力の消耗がかなり激しいコースだという点は覚悟しておいたほうがいいでしょう。

コース1 — 登山口トイレ → 展望台

経由地：渓谷沿いの食堂街 → ウェイポイント1 → デイ渓谷 → ファンソングル乗り場 → 小さな広場 → ベンチ4基 → 登山口手前のトイレ → ソニョ滝 → 保護樹 → ファンソングル手前の休憩所 → コルマル → モノレール乗降場横のトイレ → ファンソングル → 分岐点 → 展望台

登山口へのアクセス：このコースの登山口はデイリのファンソングル観光地の近くにあり、三陟市内からデイリ方面へ向かう市内バスか自家用車を使うのが一般的です。観光地だけあってアクセス路はよく整備されていますが、近くのバス停はデータ上確認できなかったので、公共交通機関を使う場合は事前にダイヤをしっかり確認しておくと安心です。駐車場はエリア内に1か所確認でき、ファンソングルの観光客と登山客が共用する形になっています。

特徴・おすすめの対象：序盤はデイ渓谷やソニョ滝、ファンソングルなど見どころが続く観光型の探訪路に近く、登山と名所めぐりを一度に楽しめます。ただしファンソングルから展望台までの区間は純高度差749mとなかなかの体力勝負で、コース全体の難易度も最高ランクに位置づけられているため、ある程度登山経験を積んだ人向けと言えるでしょう。渓谷・鍾乳洞・眺望を一度に味わいたい登山好きにはうってつけのコースです。

コース2 — 徳項山登山口・ウェナムゴル → 徳項山山頂

📏 5.15km ⛰️ 366m 獲得標高 ⏱️ 1:54 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

経由地：イエス院バス停 → 徳項山登山口(ウェナムゴル) → 分岐点 → ウェイポイント10 → ウェイポイント13 → 眺めのいい場所 → 徳項山山頂 → 休憩所手前 → 断崖 → 倒木 → 木橋中間地点 → トイレ

登山口までのアクセス：ウェナムゴル登山口には「イエス院バス停」という道標が確認できることから、近くに小さなバス停はあるようです。とはいえ本数の少ないローカル路線である可能性が高く、正直マイカーで行った方が気楽だと思います。三陟市内から向かう場合は、事前にKakaoMapやNaver Mapで実際の道路状況と最新の公共交通情報をチェックしておくことをおすすめします。

特徴・おすすめの人：このコースは累積標高差366mと、コース1に比べるとかなり緩やかで、徳項山山頂まで比較的まっすぐ続く稜線タイプの登山道です。経由地に「断崖」「眺めのいい場所」といった地名が出てくる通り、岩稜や崖地形を慎重に通過する区間も含まれていて、山頂に着いたあとの眺望を楽しむにはうってつけのコースです。とにかく山頂を踏みたい人や、余計なことを考えずに純粋な山歩きに集中したい人に向いていると思います。

難易度・路面・注意点

区内に登録されている登山道区間をもとにした公共データ上の最高難易度は「やさしい」となっていますが、これはあくまで区内全区間(周遊路・散策路的な区間も含む)をひっくるめた数値でして、実際の頂上圏コースは上の表を見てもわかる通り、最高★★★★★まで振れ幅が大きくなっています。路面情報については個別の記載がないものの、頂上部のカルスト地形と岩稜という性格上、岩がむき出しになっている区間は少なくないだろうと見ておいたほうがよく、特に雨天時の滑りやすさには気をつけたいところです。施設POIベースでは危険地域・眺望ポイントがそれぞれ0か所と集計されていて、危険区間の表示や展望案内の施設は特に確認されていませんが、実際のコース沿いには「眺めの良い場所」「崖っぷち」といった地形の特徴を知らせる道標が立っているので、現地では道標の案内をよく見ておく必要があります。水飲み場は3か所確認されていて、詳細名はいずれも「薬水(ヤクス)場」となっており、長距離コースであるコース1ではここを給水ポイントとして使えます。駐車場は1か所、登山口・下山口は6か所登録されていてコース選びの幅はあるものの、アクセス施設そのものはそれほど多くない印象です。

距離と所要時間について

管内の登山道は全コースを合わせて総延長15.09km。どのコースを選んでも日帰りで無理なく完登できる山です。代表的な山頂ルートで見ると、コース1(登山口トイレ→展望台)は片道で約2時間48分、コース2(외나무골→徳項山山頂)は片道で約1時間54分というのが計算上の目安です。往復する場合は、これより余裕をもって時間を見ておいたほうが安心でしょう。

ちなみに、管内全区間を積算したデータでは登り269分・下り186分という記録があり、そこから割り出した平均登りペースはおよそ18分/kmになります。ただしこれは特定の1コースの所要時間ではなく、登山道全体をならした平均値にすぎないので、実際にコースごとの計画を立てる際は、上の表にある片道時間を基準にするのがおすすめです。

アクセス(公共交通機関・駐車場)

徳項山は江原特別自治道・三陟市にあるので、ソウルなど首都圏からだとKTXか市外バスでまず三陟か東海方面まで行って、そこから三陟総合バスターミナルで大耳里・道渓方面行きの市内バスに乗り換えるのが一般的なルートになります。ただ公共データを見る限り、コース周辺に登録されているバス停は見当たらず、公共交通機関だけで登山口まで辿り着くのは正直しんどそうなので、車で行くことをおすすめします。管内の駐車場は1ヶ所確認できて、幻仙窟観光地近くの駐車場を登山客と鍾乳洞見学者が一緒に使っているようです。リアルタイムの経路や最新の交通情報は、KakaoMapかNaver Mapで調べるのが一番確実です。Googleマップは国内の山間部だと徒歩ルートの情報が怪しいことが多いので、あまりおすすめしません。

山も気持ちよく登れて、景色もいい——덕항산に行くなら春か秋がベストシーズンです。夏場は大이계곡沿いのコースなので涼しく歩けるのが魅力ですが、雨が降ると渓谷の水量が急に増えたり岩稜帯が滑りやすくなったりするので、そのあたりは油断せず気をつけてください。冬は山頂付近が凍結・積雪でグッと難易度が上がるので、アイゼンと防寒装備はもう「必須」と思っておいたほうがいいです。

季節を問わず共通して用意しておきたい装備は、登山靴、トレッキングポール、十分な飲み水（湧き水スポットはあるものの、安全のためにも事前に水を準備しておくのが安心です）、雨具または防水ジャケット、そして長距離コース（コース1）を歩く予定なら念のためのヘッドランプ、といったところです。

外国人旅行者へのヒント

徳項山はローマ字で「Deokhangsan」と表記し、近隣の見どころである環仙窟は「Hwanseon Cave」と表記されます。登山道自体は特別な入山許可や入場料は不要ですが、コース1で立ち寄る環仙窟を見学する場合は別途入場料がかかるので、現地で確認しておいたほうがいいでしょう。トイレはコース上に「登山道手前のトイレ」「モノレール乗り場横のトイレ」、コース2の「トイレ」など複数箇所に設置されているので、その点はあまり心配しなくて大丈夫そうです。飲料水は園内3か所の薬水（湧き水）が使えますが、正確な位置は地図アプリで再確認しておくと安心です。地図アプリはGoogleマップよりも、KakaoMapかNaver Mapを使うほうが韓国の山間部では断然正確です。安全面では、登山前に天気と季節ごとの凍結状況をチェックしておくこと、そしてコース1のように累積標高差が大きく所要時間の長いコースを選ぶ場合は、下山時刻に余裕を持たせたスケジュールを組むことをおすすめします。
