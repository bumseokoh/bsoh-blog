천台山（チョンテサン）

写真：韓国観光公社 観光写真ギャラリー・公共누리

天台山は忠清北道永同郡にある山で、山頂の標高は資料によって734m・720m・743mとまちまちに記載されていますが、GPS実測ベースでの最高地点は746mとなっています。山全体の規模はそれほど大きくないものの、山頂部にごつごつした奇岩と岩稜をまとっていて、土の山と岩稜が同居するような山容を見せてくれます。登山道自体の難易度はデータ上「易しい」に分類されていますが、これはあくまで管内の登山道全区間を総合した数値であって、実際に山頂圏まで登るコースは純粋な高度差が大きいため、体感的な難易度はそれよりも高く感じられることがあります。日帰りで十分歩ける山で、山頂部には由緒あるお寺・寧国寺があるため、登山と合わせて文化財巡りも楽しめる山として知られています。

山容と地形

写真: 韓国観光公社 観光写真ギャラリー・公共누리

天台山は全体的に土山らしい緩やかな尾根を基本の骨格としつつ、山頂付近には亀岩(コブクパウィ)・三神ハルモニ岩といった名前の付いた奇岩がところどころに顔を出しているのが特徴です。山頂稜線から続く独立した峰として望塔峰があり、この一帯は岩稜区間を含んでいて、視界が大きく開ける展望ポイントとして知られています。山頂部については先ほど触れた通り、複数の標高値(734m・720m・743m、GPS実測746m)が入り混じって表記されていますが、これは山頂標識石の設置位置や測定時期・方法の違いによるものと見られ、どの数値を採っても700m台半ばから後半のこぢんまりとした山であることに変わりはありません。中腹には寧国寺が佇んでおり、山そのものが信仰的・歴史的な空間と自然に溶け合った趣を見せています。

私はこの投稿を日本人ブロガーの語り口で自然に翻訳する仕事だけをこなせばいいので、そのまま進めます。

登山の雰囲気

登山口から頂上へと向かう区間は、序盤こそすっかり森の中を歩く道が続くんですが、中盤を過ぎたあたりから祈祷スポットや亀岩といった岩場を通過するようになり、次第に岩稜っぽさが増していく、そんな流れになっています。夏場は鬱蒼とした木陰のおかげでコース全体がひんやり涼しく感じられるそうですし、秋には紅葉が稜線と岩場の間を染め上げて、眺めが一段と華やかになるといわれています。霊国寺を経由するコースだと、一柱門やイチョウの木、湧き水といった寺院境内の風情も一緒に味わえるので、純粋な山歩きというより、山寺巡りに近いのんびりした雰囲気が加わってくる感じです。頂上付近や岩稜区間では視界が開けて周囲の山並みを見渡せるので、登っている間の森の中の体感と、頂上での開放感とがいいコントラストを成しているコースだと言えそうです。

コース1 — 登山口 → 天台山山頂

📏 3.1km ⛰️ 486m 獲得標高 ⏱️ 1:35 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

経由地：新安里(シナムリ)村会館 → 分岐点 → 登山口 → 東屋 → 道標 → 祈祷所 → 亀岩(コブクバウィ) → 天台山山頂 → 花園洞(ファウォンドン)下山案内板 → シヌム滝

登山口へのアクセス：新安里（花園洞）方面の登山口からアプローチするコースです。近くに新安里（花園洞）バス停があり、公共交通機関でも行けるようです。車で向かう場合は、村の入り口周辺に数台分の小さな駐車スペースが確保されていることが多いので、出かける前にKakaoMapやNaverマップで最新の道路状況と駐車の可否を確認しておくのがおすすめです。

特徴・おすすめの人：村会館からスタートし、東屋と祈祷所を経て亀岩エリアを抜け、山頂を目指すコースです。序盤は歩きやすい森の道がしばらく続きますが、後半の亀岩周辺で岩場が現れ、そこから急に難易度が上がるのが特徴です。下山は花園洞方面に向かい、途中でシヌム滝を通るので、渓谷のせせらぎを聞きながら締めくくれるのもポイント。距離が比較的短いので、日帰り登山の中でも「半日コース」で計画したい人や、とにかく手早く山頂まで登ってしまいたいという人に向いています。

천태산 들머리から望塔峰まで、コース2の翻訳です。

コース2 — チョンテサン(天台山)入口 → マンタプボン(望塔峰)

📏 5.89km ⛰️ 528m 獲得標高 ⏱️ 2:21 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由地: チョンテサン入口 → ヨングクサ(寧国寺)駐車場 → チョンテサン休憩所 → 案内標識板 → 食堂 → サムシンハルモムバウィ(三神婆岩) → ヨングクサ一柱門 → 券売所 → ヨングクサ湧き水 → ヨングクサ銀杏の木 → ヨングクサ → 仮設トイレ → 登山口 → 分岐点 → 岩稜上ヨングクサ展望地

入口へのアクセス: ヨングクサ方面の入口で、近くにヨングクサバス停があるので公共交通機関でもアクセス可能です。コースの経由地にヨングクサ駐車場が含まれているので、車で行く場合はこの駐車場を目印にするといいでしょう。ただ、正確な位置や進入路はKakaoMapやNaver Mapで事前に確認しておくのがおすすめです。

特徴・おすすめの人: ヨングクサの境内を通り抜けるコースで、一柱門・湧き水・銀杏の木・券売所といった寺院の施設を順に通っていくので、登山とお寺めぐりを一緒に楽しみたい方には特にぴったりです。サムシンハルモムバウィのような奇岩を過ぎたあとは後半で岩稜地帯が続き、経由地名に「岩稜上ヨングクサ展望地」とあるとおり、登りの終盤ではヨングクサの全景を見下ろせる展望ポイントを通過します。距離と累積標高差はコース1より大きく、難易度もひとつ上がるので、体力に余裕があって山行時間をたっぷり確保できる登山者、お寺めぐりと岩稜からの眺めの両方を楽しみたい方におすすめのコースです。

難易度・路面・注意点

写真：韓国観光公社観光写真ギャラリー（忠清北道永同郡陽山面英国洞キル225-35）・公共누리

管内の登山道データ上では最高難易度が「易しい」と記録されていますが、これは孝橋里（ヒョギョリ）区間（3.38km）を基準にした表記であり、100大名山GPX実測データを見ると、頂上圏コースの難易度は★★★☆☆（コース1）から★★★★☆（コース2）まで幅があり、体感的な難易度差があります。主な路面情報については個別に記録されていないものの、コースの経由地に亀岩（コブクバウィ）・三神ハルモム岩・岩稜上の展望地点など、岩場に関連するスポットが複数含まれていることから、実際には岩の区間を通過する箇所があると見られます。こうした岩場・岩稜区間は、雨上がりや朝露が降りた時間帯には滑りやすいので注意が必要ですし、冬場は凍結によって体感難易度が大きく上がるため、アイゼンなどの補助装備が欠かせません。公共データ上では危険区域・展望ポイント・独立した登山口・下山口の標識がいずれも0件と集計されており、山の規模の割には細かい安全設備や展望案内のインフラはまだ十分とは言えない状況のようです。

距離と所要時間

管内の登山道の総延長(複数コースを合算した数値)は3.38kmで、これは単一コースの距離ではなく、ヒョギョリ区間を含む管内登録区間すべてを合算したものです。管内全区間の累計でみると、上り59分・下り41分という記録が残っており、そこから計算した平均上りペースはおよそ17分/kmとなります。ただしこれはあくまで管内の登山道全体をならした平均値であって、コース一本あたりの所要時間ではないので、実際にコースごとの目安を知りたいときは、100大名山のGPXデータに基づくコース別推定所要時間(コース1が片道約1時間35分、コース2が片道約2時間21分)を参考にするほうが確実です。どちらのコースも片道2時間30分以内で収まる規模なので、往復しても十分に日帰りで歩き切れる山として楽しめます。宿泊や山小屋の予約は特に必要ありません。

行き方(公共交通機関・駐車場)

사진: 한국관광공사 관광사진 갤러리 (충청남도 금산군 제원면 길곡길 8) · 공공누리

公共交通機関で向かう場合、登山口の近くに新安里(花園洞)バス停と寧国寺バス停があって、それぞれコース1とコース2の出発地点の近くで降りられるようです。ただ、どちらの停留所も市外バス・郡内バスが走っているエリアなので、便数がかなり少ないことも多く、行く前に永同郡または該当バス会社の最新時刻表を必ず確認しておくことをおすすめします。乗り換えルートや停留所の正確な位置については、Googleマップよりも国内の地図アプリ(KakaoMapやNaver Map)で調べたほうが、実際の道路・停留所情報と合っていて確実です。車で行く場合は、コース2の経由地に寧国寺の駐車場が含まれているのでそこを目印にできますが、公共データ上では登録されている駐車場の数が0件となっていて、大きな公営駐車場は特に用意されていないようです。お寺の境内の駐車スペースや、村の入り口付近の空き地を利用することになる可能性が高いと思います。現地に着く前に、KakaoMapやNaver Mapでリアルタイムの道路状況と駐車できそうな場所をもう一度確認しておくと安心です。

シーズン・天気・装備

사진: 한국관광공사 관광사진 갤러리 (충청북도 영동군 양산면 누교리) · 공공누리

登山に向いているのはやっぱり春と秋ですね。春は新緑が芽吹く森の道を、秋は紅葉に染まった岩稜からの眺めを、それぞれ堪能できます。夏場は湿気と草木の茂りでちょっと体感的にキツくなりますし、虫や蛇への備えも欠かせません。逆に冬は山頂付近や岩稜区間が凍結してスリップ事故のリスクが高まるので、アイゼンと防寒装備は必ず用意しておきたいところです。必須装備としては、足首をしっかり守ってくれる登山靴、そして水分補給用の飲み水（コース内に水場はほとんど無いようなので、事前にしっかり準備しておくのが安全です）、トレッキングポール、雨天用の防水ジャケット、冬なら加えてアイゼンと防寒帽といったところでしょうか。コース2のようにお寺の境内を通る区間もあるので、そのあたりは服装もある程度きちんとしたものを選ぶのがマナーとしておすすめです。

外国人旅行者向けのヒント

天台山はローマ字表記だと “Cheontaesan”、山頂は “Cheontaesan Summit”、代表的なお寺は “Yeongguksa Temple” と表記されます。国立公園ではなく郡（グン）管理の山なので、入山許可や入場料といったものは特に確認されていませんが、霊国寺の境内に入る際は文化財見学に関する簡単な案内や手続きがある場合もあるので、現地の案内板は一応チェックしておくと安心です。トイレはコース2の経由地に仮設トイレがあるので利用できますが、それ以外の区間には基本的にトイレがないと考えたほうがよく、登山口で済ませておくのが無難です。水場（薬水場）は公共データ上ゼロと集計されていて、山中で水を調達するのはほぼ期待できません。コース2の経由地にある「霊国寺の湧き水」が唯一知られた水源ではあるものの、お寺側の管理状況次第で使えたり使えなかったりするので、飲み水はあらかじめしっかり用意しておくのが安全です。道案内については、韓国国内だとGoogleマップが不正確なことが多いので、KakaoMapかNaverMapのアプリを入れて実際の登山道やバス路線を確認することをおすすめします。また、どちらのコースも後半に岩場・岩稜帯があるので、雨の日や凍結時は無理せず日を改めるか、慎重に行動するようにしてください。
