登山初心者のための準備物まとめ｜夏冬の服装と持ち物

キャンプ · 公開日 2022/12/24 ·

翻訳します。

登山を始めようという方に向けて、準備しておきたいものをまとめてみます。

しっかり備えて、楽しい山歩きになりますように。

夏の服装

夏の登山では、服装はとにかく汗を吸って早く乾くこと、ここに重点が置かれます。

動きやすい短パンやレギンス、それに機能性のあるトップス、強い日差しを防ぐ帽子、サングラスやゴーグル。

そして山頂で休むときにサッと風をしのげる軽めのジャケットがあれば十分です。

手袋、汗を拭ける機能性のハンカチ、あるいはスイムタオルなどが加わると、ぐっと快適な登山になります。

別に登山ブランドでなくても構いませんし、機能性のウェアでさえあれば問題ないと思っています。

歩く距離にもよりますが、私はストックはわりとおすすめする派です。上半身も下半身も筋肉をまんべんなく使えますし、

膝や足首への負担を減らしてくれる大事な道具なんですよね。

冬の服装

冬は、歩いている間の保温を担うジャケット、休憩時に羽織るダウン、冬用の登山ズボンあたりを基本に、ベースレイヤーは夏と同じく汗を吸って乾くタイプで構いません。ただし歩いているとかなり汗をかくので、ダウンなどを着たまま歩くのはNGです。

歩くときは防風ジャケット、休むときにダウンを取り出して着て休む。これが全部ザックに収まることが前提になります。

ザックの中の持ち物

Previous image Next image

水筒

プラスチックのボトルもあれば、シリコン製のボトルもあります。

大容量だと以前はプラスチックをよく使っていましたが、最近はシリコンボトルでも2リットルのものが出ています。

用途に合わせて選べばいいと思います。たいていシリコンボトルのほうがお値段は高めです。

ヘッドランプ

国立公園クラスの山行は、たいてい夜明け前からのスタートになることが多いです。

登りでも下りでも使うヘッドランプ、それに予備の電池は必須。いつもザックに入れておく習慣をつけましょう。

たまにスマホのライトをヘッドランプ代わりにするという方がいますが、片手がふさがると一気に危ない場面がやってきます。ヘッドランプは安いものでも構わないので、ひとつは用意しておいてください。

救急セット

登山中、なぜか体の調子が悪くなることがあります。特に胃薬と痛み止めは、ちょくちょく出番があります。

私は胃薬、湿布、虫除け、日焼け止め、ウェットティッシュなどをまとめてパッキングして、ザックに入れて持ち歩いています。

行動食

行動食というのは、腰を据えて食事をするのではなく、歩きながらこまめにカロリーを補給する食べ物のことです。

おすすめの行動食は、ようかん、あめ、ポカリスエットあたりの製品です。

逆におすすめしないのは、いわゆるチョコ系のお菓子（韓国でいう「자유시간」みたいなもの）です。理由は、消化に思ったより時間がかかって、

すぐにエネルギーとして使えている感じがしないから。それならパワージェルのほうがおすすめです。

短いと3〜4時間、長いと14時間も歩くことがあります。

長くても短くても、行動食は2,000kcal以上を用意して、ポーチに入れてザックに忍ばせています。

バックパッキング

もしバックパッキングまで考えているなら、次のものが加わります。

テント

Previous image Next image

寒さも暑さも、雨風も防いでくれるテントが要りますよね。

テントはとても大事な生存道具です。場合によっては他のもので代用できることもあります。ただし、それは慣れた人に限った話ですが。

マット

Previous image Next image

マットは地面からの冷気を遮り、背中のゴツゴツを解消してくれる大事な道具で、しっかり休むには欠かせません。

シュラフ（寝袋）

マットと並んでとても重要な保温道具で、冬でも夏でも、季節に合ったシュラフが必要です。

調理道具

国立公園を除けば、キャンプ場やその他の場所で火を使って調理ができるところがあります。

一泊以上のバックパッキングをするなら食事をとる必要があるので、それなりの道具が要ります。

スプーン、フォーク、バーナー、コッヘルなどがこれにあたります。

食料

簡単に食べられるもの、お弁当、食料。

休む場所にたどり着いたら、食事をとります。

屋外で何時間も登山やトレッキングをしたあとは、体力の消耗は普段の何倍にもなっています。

しっかり食べてしっかり休まないと、翌日また歩くことはできません。

ですから、十分なカロリーの食料やインスタント食品などを用意して、食事をとり休息します。

選択と集中

ここまで並べたものを全部背負って担いでいくのかと思うと、もう今から疲れてきます。

だからこそ、私たちは選択と集中をしなければいけません。

もちろん、山の上で食べるキンパと熱々のカップラーメンは本当に最高においしい食べ物ですが、

下山してから食べるサムギョプサルにソジュ（焼酎）ほどではないでしょう。

身軽に、本当に必要なものだけ小さなザックに詰めて、ゆったり登って、下山後においしいものを楽しむ。

これもまた、とてもいい登山のかたちです。

軽いからこそ、よく行く

小さなザックに基本的な登山用品を入れておいて、こまめに背負って出かける。これが登山の基本だと思います。

通っているうちに自分のスタイルが見えてきて、軽量登山が好きなのか、それとも重いザックを背負っての縦走が好きなのか、だんだんわかってきます。

登山やトレッキングは、思っているよりハードなスポーツです。その分、得られるものも多いんですよね。

近場の低い山からゆっくり始めて、いずれは国立公園の縦走に挑戦してみると、本当に楽しいということがわかってきます。

以上、登山の準備物についてまとめてみました。

ありがとうございました。
