概要

写真：韓国観光公社 観光写真ギャラリー（忠清北道永同郡上村面古子里）・公共ヌリ

民主之山（ミンジュジサン、標高1,242m前後として広く知られています）は、忠清北道永同郡上村面物閑里一帯を中心に、全羅北道茂朱郡と慶尚北道金泉市の境界にまたがってそびえる山です。近くの石器峰・三道峰・角虎山と稜線でつながり、ひとつの山群を形成していて、白頭大幹の稜線（マルギム）の一部としてもよく知られています。登山道の空間情報では、山頂付近の複数の測定地点が1,207〜1,275mの範囲で記録されており、コースデータ上の最高地点は1,275mとなっています。全体としては中級レベルの山なのですが、山頂付近のコースはほとんどが片道9〜12kmにもなるほど距離が長く、なかなか体力を削られます。短いコースを選べば日帰りも可能ですが、石器峰・三道峰・角虎山をつなぐ縦走コースを狙うなら、1泊してじっくり歩くことをおすすめします。

山の様相と地形

写真：韓国観光公社 観光写真ギャラリー（忠清北道永同郡上村面物閑渓谷路1212）· 公共누리

民主之山は全体としてなだらかな土山の稜線が続いていますが、頂上付近には大小の岩稜が入り混じった地形になっています。登山道の空間情報に記録されている峰の地点を見ると、石器峰（1,255m・1,274mの2地点で記録）、三道峰（1,207m）、角虎山（1,227m）、民主之山（1,271m・1,233m・1,243mと複数地点で記録）、頂上石（1,217m）などが確認できます。これは頂上部が一つの尖った峰ではなく、稜線沿いにいくつもの峰や標識地点が連なっている構造であることを示しています。特に三道峰は、忠清北道・全羅北道・慶尚北道の三つの道の境界が交わる地点として広く知られており、角虎山側は比較的岩稜の占める割合が高く、視界が開ける区間が多いとされています。渓谷部にあたる物閑渓谷方面は典型的な土山の渓谷地形で、鬱蒼とした森と澄んだ渓流が織りなす景観を見せてくれます。

登山の雰囲気

写真：韓国観光公社観光写真ギャラリー（忠清北道永同郡上村面）・公共누리

登山の序盤は物閑渓谷や道馬嶺方面からスタートし、林道を伝ってなだらかに高度を稼いでいく区間が多いです。渓谷沿いの区間では、広葉樹林の木陰と水音が重なり合い、真夏でも比較的ひんやりとした山歩きの雰囲気を味わえます。稜線に近づくにつれて角虎山・石器峰周辺の岩場が現れ、視界が一気に開けて、白頭大幹の稜線沿いに連なる幾重にも重なった山並みの眺めを楽しめます。秋にはこの稜線一帯に紅葉が広く色づくことで知られ、冬には山頂付近の稜線に雪や樹氷が積もり、雪山さながらの景色を見せてくれることが多いです。全体的に登山道が長く続くタイプなので、短時間でパッと山頂を踏んで下山するというより、一日をまるまる空けて稜線歩きの流れをじっくり楽しむ山行に向いています。

表・見出し・区切り線・画像行はそのまま、本文だけ自然な日本語にしました。

コース1 — 分岐点 → 頂上

📏 9.96km ⛰️ 724m 獲得標高 ⏱️ 3:42 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

登山口へのアクセス：このコースの登山口となる「分岐点」は、他の登山道と合流する分岐地点で、ムルハンゲゴク(物閑渓谷)方面から入って到達するケースが多いようです。公共交通機関の便が頻繁にあるエリアではないため、ヨンドン(永同)またはムジュ(茂朱)方面からマイカーでアクセスするのが一般的におすすめです。正確な進入路は地図アプリで事前に確認しておくのがよいでしょう。

特徴・おすすめの対象：3つのコースの中では相対的に一番短く、頂上まで一直線に続く区間で、途中の経由地の道しるべの記録がないほどシンプルな動線になっています。序盤からずっと登りが続く感じなので体力配分が重要で、稜線縦走というより頂上だけを目標に効率よく往復したい登山者に向いています。

コース2 — トマリョン登山口 → カッコサン(角虎山)山頂

📏 8.78km ⛰️ 734m 獲得標高 ⏱️ 3:25 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：トマリョン登山口 → トマリョン入口駐車場 → 登山道スタート地点 → トマリョン入口 → 登山口 → サンヨンジョン(上龍亭) → 角虎山 → 角虎山山頂 → 分岐点 → 避難小屋 → 休憩所 → 民主之山(ミンジュジサン) → トイレ → 名品林道総合下 → ファンリョンサ(黄龍寺)

取り付きへのアクセス：トマリョンは地方道が通る峠として知られているスポットで、道標の経由地にトマリョン入口駐車場が含まれているので、車で行くにはわりと楽な部類だと思います。公共交通機関を使う場合は、永同（ヨンドン）や茂朱（ムジュ）の市外バスターミナルから近くの面（面所在地）までバスで移動し、そこからさらにトマリョン方面への足を確保する必要が出てくることがあるので、事前にルートをよく確認しておくのがおすすめです。

特徴・おすすめのタイプ：角虎山の山頂を先に踏んでから、避難小屋・休憩所・民主之山・トイレなど複数のポイントを経由しつつ、尾根をずっとたどっていく縦走系のコースです。角虎山ならではの岩稜から広がる眺望と、民主之山山頂部の景色を一度に楽しめるので、尾根歩きが好きで、変化に富んだ景色を求める登山好きの方には特におすすめできるコースです。

コース3 — 分岐点 → ソッキボン

📏 11.58km ⛰️ 718m 獲得標高 ⏱️ 4:06 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：分岐点 → 休憩所 → ミンジュジサン → サムシンサン休憩所 → ソッキボン → ヘリポート兼休憩所 → サムドボン → ウムジュアム滝 → トイレ → 3番目のトイレ → 2番目のトイレ

登山口へのアクセス：ムルハンゲゴク方面から入るのが一般的なようで、これまでの2コースと同じく、公共交通よりも自家用車で来たほうが何かと楽だと思います。

特徴・おすすめの人：3コースの中では距離が最も長く、ミンジュジサン・ソッキボン・サムドボンを一気につなぎながら白頭大幹（ペクドゥデガン）の稜線をたどるルートです。ウムジュアム滝のような渓谷の景色も途中で楽しめますし、トイレがあちこちに配置されているので、長丁場の山行中でも設備面で困りにくいのがありがたいところ。体力と時間にゆとりのある、山慣れした人向けのコースだと言えます。

この表は行政洞単位で集計された管内登山路の総延長（41.09km）を示したもので、ひとつのコースの距離ではなく、複数区間を合算した数字です。データ上の最高難易度は「中級」となっていて、路面の素材については特に区分がありません。ただ、先ほど紹介した頂上圏コースは、GPX実測ベースで累積標高差700m以上、片道9〜12kmに達していて、体感的な難易度はかなり高めです。カクホ山・ソッキボン周辺の稜線には岩場が混じっているので、雨の日や落ち葉が積もる秋には滑りやすく注意が必要です。登山路の空間情報を見ると、危険地域・展望ポイント・登山口/下山口として別途集計された施設は0件となっていて、標識や案内施設をあてにするより、地図アプリとGPXトラックを併用するほうが安全です。

距離と所要時間

管内すべての登山道を合わせると総延長は41.09kmで、これをもとに算出すると上りの累積所要時間は855分、下りは599分になります。距離換算すると上りの平均ペースはおよそ21分/kmですが、これはあくまで管内の全区間を歩き通した場合の積算値であって、ひとつのコースの所要時間ではないので混同しないようにしてください。実際に個々のコースを片道で歩いた場合の推定所要時間は約3時間25分〜4時間6分で、往復となると7〜8時間以上かかることもある長丁場の山行です。短めのコースを往復するだけなら日帰りでも十分いけますが、各湖山・民主之山・石器峰・三道峰をすべてつなぐ縦走を計画しているなら、物閑渓谷付近で1泊するスケジュールを組んだほうがいいと思います。

민주지산 권역は交通の便が決して良いとは言えない山あいのエリアなので、正直なところ車で行くのが無難だと思います。KTXや一般列車で永同駅まで出て、そこから永同市外バスターミナルで上村面・物閑里方面のバスに乗り換える、というルートは一応考えられます。無住方面からなら、無住市外バスターミナルを経由して雪川面・道馬嶺方向へ向かうルートもあるらしいです。とはいえ、このあたりはバスの本数がかなり少ないこともあるので、行く前に時刻表は必ずチェックしておいたほうがいいでしょう。

車の場合は道馬嶺入口の駐車場や物閑渓谷付近の駐車スペースが使えるらしいのですが、登山路の空間情報データ上では駐車場・バス停の集計がどちらも0件と出ていて、正直このデータだけでは心もとないのが本音です。なので現地の実際の状況については、出発前にKakaoMapやNaver Mapで最新のルートと駐車の可否をもう一度確認しておくのが安心だと思います。

シーズン・天候・装備

山に登るのに一番無難な時期はやっぱり春と秋でして、特に秋は紅葉と一緒に、比較的天候も安定していて稜線からの眺めを楽しむにはもってこいです。夏場は谷筋の日陰のおかげで多少は暑さが和らぐんですが、コースのほとんどが長距離な上に、登山道の空間情報を見ても給水所が確認できないので、飲み水はしっかり多めに持っていくようにしてください。梅雨時は谷の水量が増えることがあるので、ムルハン渓谷（물한계곡）付近を歩くときは注意が必要です。冬場は山頂付近の稜線に雪や凍結が出やすいので、アイゼン・スパッツ・防寒装備は必須ですし、日が短くなる時期なのを踏まえて、早めの出発と余裕を持った下山時間の計画も欠かせません。共通の必須装備としては、登山靴、十分な飲み水と非常食、地図アプリ、ヘッドランプ、レインウェアあたりを揃えておくことをおすすめします。

外国人旅行者向けのヒント

民主之山は英語表記だと「Mt. Minjujisan」となりますが、主要なピークである石奇峰（Seokgibong）、三道峰（Samdobong）、角乎山（Gakhosan）の名前も一緒に覚えておくと、道標を確認するときに役立ちます。国立公園や道立公園のように別途入山許可や入場料が必要な山ではないようですが、物閑渓谷付近の自然休養林の施設を利用する場合は別料金が発生することがあるので、現地で確認しておくのが無難です。トイレは道馬嶺登山コースと石奇峰コース沿いに複数箇所表示されているものの、飲料水の補給スポット（薬水場）は登山道の空間情報上では確認できないため、登山前に十分な水を用意しておくことが必須です。Googleマップは韓国の山間部の登山道情報が不正確なことが多いので、代わりにKakaoMapやNaver Mapのアプリを使って、実際のルートや公共交通機関・駐車場の情報を確認することをおすすめします。コースの距離が長く、人通りの少ない区間も多いので、単独行動よりも同行者と一緒に動き、登山計画を事前に共有しておくと安心です。
