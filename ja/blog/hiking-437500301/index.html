개要

写真:韓国観光公社観光写真ギャラリー(江原特別自治道東海市三和洞)・公共ヌリ

頭陀山(トゥタサン)は、江原道の東海市と三陟市の境界にまたがる山で、山頂部の標高はおよそ1,380m前後、実測GPXによると山頂アプローチ地点の最高標高は1,428mに達します。武陵渓谷(ムルン渓谷)を抱く代表的な名山として知られ、渓谷美と岩稜美を兼ね備えた山容から、江原道東海岸エリアでも屈指の登山スポットとして名高い山です。山頂圏まで続くコースは距離・標高差ともにかなりのもので体力の消耗は大きめですが、未明か早朝に出発すれば日帰り往復も十分可能な山です。ただ、公共交通でのアクセスがやや不便なうえ、登山中に水を調達できる場所もほとんどないため、事前準備が特に肝心な山と言えます。

山容と地形

写真提供：韓国観光公社観光写真ギャラリー（江原特別自治道東海市三和洞）・公共누리

頭陀山は、いわゆる「土の山」と「岩の山」両方の顔を併せ持つ山として知られています。麓のあたりは鬱蒼とした森に覆われたなだらかな尾根が続いているのですが、頂上付近や一部の稜線区間では岩稜や絶壁がむき出しになっていて、そこがこの山の面白いところです。公共データに登録されている主な峰としては、ヘッテドゥン(988m)、頭陀山の山頂付近の峰(1,382mと1,371mの2地点が別々に登録されています)、シヌムサン(689m)があり、これらが稜線でつながって山全体の骨格を作っています。頭陀山の裾野といえば武陵渓谷が真っ先に思い浮かびますが、そのほかにもペトゥル岩や頭陀山城など、岩盤と渓谷が織りなす地形が広く知られていて、渓谷の下流部は広い一枚岩と淵(沼)が発達していることで有名です。頂上に近づくにつれて急斜面や絶壁の区間が現れてくるので、体力だけでなく注意力も求められる、変化に富んだ地形と言えるでしょう。

두타산の登山は、麓の谷道や森の小道から始まり、登るにつれて岩稜や急斜面へと様相を変えていく、変化のはっきりした山だと感じています。序盤は広葉樹と松が混じった木陰が続くので、夏でも比較的涼しく感じる区間が多く、谷川のせせらぎを聞きながら歩けるので気分的にもゆったり登れると言われています。中盤を過ぎて高度が上がってくると視界が開ける区間が現れ、頂上付近に近づくほど急斜面や崖地形が続いて、体感的な難易度がぐっと上がっていく傾向があります。春には新緑と野の花、秋には紅葉が谷の景色と溶け合って季節感がはっきり出る山として知られており、冬になると日陰の急斜面で凍結しやすく、山行の雰囲気がなかなか気の抜けないものになる山です。

コース1 — 国家地点番号 → 山頂

📏 13.74km ⛰️ 1267m 獲得標高 ⏱️ 5:33 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：国家地点番号 → 分岐点 → 展望ポイント → ヘリポート → 河川氾濫コース → 保護樹木 → フォトゾーン → 断崖 → 簡易休憩所 → 武陵渓谷名勝地案内図 → 将軍岩 → オルレジ（カタクリ）休憩所

登山口へのアクセス：このコースの登山口は、武陵渓谷の名勝地エリア付近から始まるとみられ、東海市や三陟方面から武陵渓谷方面へバスかタクシーで向かうルートが一般的に知られています。専用駐車場のデータは確認できていないので、武陵渓谷観光地の駐車エリアを利用するのが無難でしょう。

特徴・おすすめの方：3つのコースの中で距離・所要時間ともに最も長く、累積標高差も大きいため、体力に自信のある登山者向けのコースとされています。序盤の河川氾濫コースと保護樹木の区間では渓谷らしい雰囲気をたっぷり味わうことができ、後半の断崖・簡易休憩所・将軍岩の区間では岩稜の眺めが続くと伝えられています。公共交通機関ではアクセスの起点を特定しづらいコースなので、マイカーやタクシー利用者のほうが動きやすいコースと言えそうです。

コース2 — テジェ駐車場 → テジェ展望台

📏 6.24km ⛰️ 538m 獲得標高 ⏱️ 2:27 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地: テジェ駐車場 → テジェ展望台 → テジェ造形物 → テジェ休憩所 → テジェトイレ → 分岐点 → 簡易休憩所 → ヘッテドゥン → 急斜面区間 → 展望ポイント → 三角点

取り付き（登山口）へのアクセス: テジェは三陟（サムチョク）と太白（テベク）を結ぶ白頭大幹（ペクトゥデガン）の峠道に位置しているのが一般的に知られていて、道路沿いに駐車スペースと休憩施設が整っているので、マイカーで一番楽に入れる登山口です。公共交通は路線が限られているので、三陟の市内からタクシーで向かうのが現実的な手だと思います。

特徴・おすすめの人: 3つのコースの中では距離も高低差も一番小さくて、比較的気楽に歩けるコースです。入り口にテジェ造形物・休憩所・トイレといった基本的な設備がまとまっているので山行の準備がしやすく、ヘッテドゥンを過ぎたあたりから展望が開ける区間が続くと言われています。急斜面区間さえ気をつければ、日帰りの半日山行でも白頭大幹の稜線（マルンクム）の雰囲気を味わいたい人にぴったりのコースです。

コース3 — 天恩寺駐車場トイレ → 頂上

📏 9.17km ⛰️ 1151m 獲得標高 ⏱️ 4:13 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 天恩寺駐車場トイレ → 天恩寺駐車場 → 東安寺 → 保護樹 → 簡易駐車場 → 小型トイレ → 天恩寺 → 分岐点 → フォトスポット → 展望ポイント → 急斜面地 → シヌムサン → オシプチョン

登山口へのアクセス: 天恩寺（チョヌンサ）は三陟（サムチョク）エリアの寺院として一般的に知られていて、三陟市内から車やタクシーでアクセスするルートがよく使われています。登山口に駐車場とトイレが整っているので、3つのコースの中でも入口の便利さはいちばんだと思います。

特徴・おすすめの人: 天恩寺や東安寺など、寺院の境内を通り抜ける序盤があるので、文化的な趣も一緒に味わえるコースとして知られています。シヌムサンを越えてオシプチョン薬水（湧き水）付近を経て頂上へ向かう区間が続き、距離も高低差もそれなりにあるので、体力配分を考えておく必要があります。寺院巡りと頂上登頂を一緒に計画している登山者や、武陵渓谷とは反対側からアクセスしたい人に向いているコースです。

距離と所要時間

写真：韓国観光公社観光写真ギャラリー（江原特別自治道東海市三和洞）・公共누리

頭陀山は管内の登山道の総延長が22.26kmとされていますが、これは複数区間を合算した数値で、単一コースの距離と勘違いしないよう注意が必要です。実測GPXベースで見ると、頂上圏コースの片道距離は6.24km（デッチェコース）から13.74km（国家地点番号コース）までかなり幅があり、片道の推定所要時間もおよそ2時間27分から5時間33分までコースによってばらつきます。管内全区間を積算したデータでは上り508分・下り353分となっており、これを換算すると平均の上りペースは約23分/kmです。ただしこのペースはあくまで管内全区間を積算した平均値であって、個々のコースの所要時間ではありません。実際にどのコースがどれくらいかかるかは、必ず上記のコース別表を基準に判断してください。往復山行を考えると、一番短いデッチェコースでも半日以上、一番長いコースだと丸一日かかることもあるので、早朝出発と余裕を持った日程の計画が欠かせません。避難小屋は登録されていないので、1泊山行というよりは日帰り往復山行として計画するのが一般的です。

今日は두타산への行き方について、公共交通機関の実情も含めて訳しますね。

行き方(公共交通機関・駐車)

写真:韓国観光公社観光写真ギャラリー(江原特別自治道東海市三和洞)・公共누리

頭陀山(トゥタサン)は江原道の東海市と三陟市の境にあるので、ソウルなど首都圏から向かう場合は、KTXや市外バスで東海駅か三陟バスターミナルまで出て、そこから市内バスやタクシーで各登山口へ、というのが定番のアクセスルートとして知られています。武陵渓谷(ムルンゲゴク)方面の登山口は東海・三陟市内から地域バスが出ているようですが、댓재(テッチェ)や天恩寺(チョヌンサ)方面は本数がかなり限られていて、タクシーを使うのが現実的なケースが多いようです。公共データ上ではこのあたりのバス停・駐車場の登録件数がゼロと出ているので、実際の停留所の位置や駐車できるかどうかは、出発前にKakaoMapかNaver Mapで最新情報を確認しておくのがおすすめです。自家用車の場合は武陵渓谷観光地の駐車場や댓재の路肩スペースなどが使えますが、シーズン中や週末は混み合うこともあるので、余裕を持って早めに到着するのが良さそうです。

시즌・天候・装備

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 동해시 삼화동) · 공공누리

頭陀山は、新緑と紅葉を一度に楽しめる春（4~5月）と秋（9月末~11月初め）が一番人気のシーズンとして知られています。夏は渓谷区間のひんやりした涼しさが魅力なんですが、雨が降ると急斜面や岩稜地帯が滑りやすくなるので油断は禁物です。梅雨時は渓谷の水量が増えるため、川を渡るコースなど一部区間の通行には特に気をつけたいところ。冬場は日陰や山頂付近の急斜面で凍結がよく起きて難易度がぐっと上がるので、アイゼンやスパッツといった冬山装備は必須と考えてください。季節を問わず共通して、登山靴、トレッキングポール、余裕を持った飲料水（湧き水場がないので最低1.5~2リットル以上は持っていくのがおすすめ）、防風・防水ジャケット、ヘッドランプ（長時間コースに備えて）、非常食と救急用品はしっかり準備しておきましょう。

外国人旅行者へのヒント

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 동해시 삼화동) · 공공누리

頭陀山（トゥタサン）は英語表記だと「Duta Mountain」または「Dutasan」と書かれ、무릉계곡（ムルンゲゴク渓谷／Mureung Valley）、천은사（チョヌンサ／Cheoneunsa Temple）、댓재（テッチェ峠／Daetjae Pass)、쉰음산（シヌムサン／Ssaeneumsan）といった主要な地名もローマ字併記されています。入山そのものに特別な許可や入場料は基本的に不要とされていますが、무릉계곡渓谷など一部の観光エリアは独自の入場料がかかることもあるので、現地の案内板は一応チェックしておいたほうが安心です。トイレについては、コース3の천은사주차장（駐車場トイレ）と小型トイレ、コース2の댓재トイレなど、登山口付近にいくつか確認できますが、登山中のコース上にはトイレも水場もないようなので、出発前に済ませておき、飲み水も多めに用意しておくのが鉄則です。グーグルマップは韓国国内の登山道表記が怪しいことが結構あるので、KakaoMapかNaver Mapを必ずインストールして、実際の登山道と公共交通のルートを確認しておくことを強くおすすめします。電波は稜線部でもだいたい問題なくつながりますが、山頂付近の岩稜区間は単独より仲間と一緒に歩くほうが安全です。下山時間には余裕を持たせて、日没前に下山を終えるようにしましょう。
