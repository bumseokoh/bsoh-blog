概要

道楽山(トラクサン、道樂山)は忠清北道丹陽郡にある山で、山頂部の最高標高は985m前後とされています(公共データ上は山頂標高987mと登録されていますが、一般的には964m前後として紹介されることも多く、資料によって多少差があります)。丹陽八景や仙岩渓谷(上仙岩・中仙岩・下仙岩)一帯を見渡せる山として広く知られています。全体としては岩稜が発達した険しい山容を持ちながらも、公共データ上の登山道難易度は最高でも「易しい」に分類されており、アプローチ自体の道は比較的なだらかです。ただし実際の山頂圏コースは純標高差が大きいため体感的な難易度は決して低くなく、公共交通機関を使って日帰りで往復できる山でもあります。

山の姿と地形

道楽山（トラクサン）は、大小の岩峰が稜線に沿って連なる骨山（ゴルサン）型の地形を持つ山です。公共データに登録されている峰としては、兄峰（911m）、道楽山（987m）、神仙峰（938m）、彩雲峰（892m）、剣峰（848m）、道楽山964m峰（932m）、上仙岩峰（659m）、諸峰（843m）があり、これらの峰が一本の稜線上に連続して並んでいるため、縦走スタイルの岩稜歩きが楽しめる構造になっています。頂上部に近づくほど花崗岩・石灰岩系の岩場が目立つようになり、一方で下部の谷筋には仙岩渓谷の澄んだ渓流と淵（ふち）が形成されていて、上部の岩峰地形と下部の渓谷地形の対比がくっきりと際立っているのが、この山の特徴と言えます。

登山の雰囲気

登山口はまず上仙岩渓谷沿いのなだらかな森の道からスタートで、渓流の音を聞きながら登っていく区間がしばらく続きます。中腹を過ぎたあたりから徐々に岩場が姿を見せ始め、上仙岩峰の付近まで来ると尾根の眺望が開けて、丹陽一帯の山並みが目に飛び込んできます。兄峰と弟峰をつなぐ区間は岩稜特有の緊張感がある区間で、手を使わなければならない岩場も含まれているため、体感的な難易度が一気に上がります。頂上の道楽山に立つと四方に尾根が広がる開放感があり、秋には紅葉が岩峰と溶け合って、この山を代表する絶景区間として名前が挙がります。

コース1 — カサン2里バス停 → サンソナムボン（道楽山山頂）

📏 6.62km ⛰️ 692m 獲得標高 ⏱️ 2:49 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由地：バス カサン2里 → サンソナム駐車場 → 分岐点 → サンソナム（上仙巌） → ソナムガーデン食堂 → 展望ポイント → サンソナムボン → 景観地 → 岩場 → チェボン → ヒョンボン → フォトゾーン → 道楽山 → 落雷危険地帯 → シンソンボン

登山口へのアクセス：カサン2里バス停が登山口付近にあるため、丹陽（タニャン）邑内から出発する市内バスを利用してアクセスするのが一般的です。正確な運行間隔や路線は変更されることがあるので、KakaoMapやNaver Mapで事前に確認しておくことをおすすめします。公共データ上ではこの区間付近に登録済みの駐車場は確認できなかったので、車で行く場合はサンソナム渓谷の入り口付近の空き地や案内標識を頼りに、現地で駐車できるかどうかを確認する必要があります。

特徴・おすすめの人：サンソナム渓谷沿いを登っていく序盤は、森と渓流が織りなすなだらかな道で、いわばウォーミングアップ的な区間です。そこからサンソナムボンを過ぎたあたりから岩稜区間と展望区間が交互に現れ、特にヒョンボン〜チェボン間の岩場は初心者にはやや手強く感じられるかもしれないので、ある程度岩稜歩きの経験がある人向けです。山頂の道楽山まで登ったあとシンソンボン方面まで続く縦走型コースなので、展望と岩稜歩きを一度に楽しみたい人にはうってつけのコースと言えるでしょう。

難易度・路面状況・注意点

写真: 韓国観光公社観光写真ギャラリー（忠清北道丹陽郡江面仙岩渓谷路148）・公共누리

公共データ上、道楽山エリアの登山道の最高難易度は「易しい」に分類されていますが、これはエリア内の登録区間全体（行政洞単位）を基準にした分類であり、頂上圏へとつながる実際のコース(カサン2里→上仙岩峰)の純粋な高低差や岩場地形を考慮すると、体感難易度はこれより高く感じられることがあります。路面の詳細情報は別途登録されていませんが、先の山容の説明で触れた通り、頂上部に近づくほど岩盤・岩場地帯が増えるため、雨天時や朝露が降りた早朝には岩が滑りやすくなるので注意が必要です。冬場は凍結した岩場での転倒事故リスクが高まるため、アイゼンなどの補助装備を用意することをお勧めします。

公共データの登山道施設POIリストでは、展望地点・水飲み場・避難所・危険地域がいずれも0件と集計されており、地図上に別途登録された案内施設はないようです。ただ、実際のGPXトラック記録には上仙岩峰付近の展望ポイントと、道楽山〜神仙峰区間の間にある落雷危険地域が経由地として示されているため、施設物が特に無い区間であっても、天候の変化(特に夏場の雷雨)には気をつける必要があります。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（忠清北道丹陽郡仙岩渓谷路790 上仙岩）・公共누리

頂上圏につながるコース（ガサン2里バス停→上仙岩峰）は片道6.62km、純標高差692mで、推定所要時間は片道約2時間49分です。往復だとおおよそ5時間前後を見ておけばよく、このコース自体は日帰り登山で十分こなせます。ただ、道楽山エリアに登録されている登山道の総延長は7区間を合わせて32.53kmにもなりますが、これは複数の区間をすべて合算した数値であり、単一コースの距離ではありません。公共データにあるエリア全区間の累積所要時間は上り585分・下り401分と集計されていますが、これも単一コースの所要時間ではなく、エリア全体の区間を積み上げた数値なので混同しないよう注意が必要です。この累積値を距離換算すると、平均の上りペースはおよそ18分/kmとなり、道楽山の登山道全体としてはなだらかな部類に入るという参考指標として使えます。もし複数区間をつないで縦走するような山行を計画するなら、1日では終わらせにくい可能性があるため、1泊以上の日程を検討しておく必要があります。

行き方（公共交通機関・駐車場）

写真：韓国観光公社 観光写真ギャラリー（忠清北道丹陽郡丹城面佳山里）・公共누리

頂上コースの登山口の近くには佳山2里バス停があるので、丹陽市内から出る市内バスでアクセスできます。丹陽の市街地までは、ソウルの東ソウル総合ターミナルや清凉里などから出る市外・高速バス、あるいはKTXやムグンファ号といった鉄道で丹陽駅・丹陽ターミナルまで移動し、そこから市内バスに乗り換えるのが一般的なルートです。バスの路線や運行間隔は時期によって変わることがあるので、出発前に必ずKakaoMapやNaver Mapアプリでリアルタイムの公共交通機関のルートを確認しておくことをおすすめします。マイカーで行く場合は、公共データ上に登録された駐車場が見当たらないため、上仙巌渓谷の入り口付近の駐車スペースを事前に地図アプリで調べておくか、近くの飲食店や施設の案内に従って駐車する必要があります。

季節・天候・装備

写真：韓国観光公社 観光写真ギャラリー（忠清北道丹陽郡大崗面舎人巌2キル42）・公共ヌリ

道楽山は春と秋の山行に向いた山ですが、なかでもおすすめなのは秋。岩峰と紅葉が織りなす眺望が抜群で、この時期がいちばんです。夏場は蒸し暑さに加えて午後に雷雨が発生することがあるので、特に前述した道楽山〜神仙峰間の落雷危険地帯を通過する際は天候の変化に十分注意してください。冬場は岩場が凍結して滑りやすくなるため、アイゼンやスパッツといった冬山装備を用意しておくのが安心です。共通して欠かせない基本装備としては、足首をしっかり支えてくれる登山靴、トレッキングポール、着替え用の衣類、そして十分な飲み水が挙げられます。特にこの山には湧き水や給水場が見当たらないため、登る前に飲み水をたっぷり準備しておくことが大切です。

外国人旅行者へのヒント

写真:韓国観光公社観光写真ギャラリー・公共누리

道楽山の頂上はローマ字表記だと「Doraksan」、頂上コースの登山口となる加山2里は「Gasan 2-ri」と書けます。途中で通る上仙庵は「Sangseonam」、道楽山の近くにあるピークの神仙峰は「Sinseonbong」、兄峰は「Hyeongbong」、弟峰は「Jebong」とローマ字化できます。入山許可や入場料が必要という情報は見当たりませんが、現地の案内看板で最新情報を確認しておくのが安心です。トイレや給水施設については、公共データ上は登山道沿いに個別登録がないため、登山口の加山2里や近くの上仙庵駐車場周辺の食堂・商業施設を利用するか、事前に水を十分持っていくようにしましょう。Googleマップは韓国国内の登山道情報が不正確なことが多いので、KakaoMapやNaver Mapを入れておいて、実際の登山道ルートや公共交通の情報を確認することを強くおすすめします。岩稜(암릉)区間があるため、雨の日や凍結時は滑落・転倒のリスクがあります。事前に天気を確認し、無理な登山は避けるようにしてください。
