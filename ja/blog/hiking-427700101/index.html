概要

写真:韓国観光公社 観光写真ギャラリー(江原特別自治道旌善郡旌善邑)・公共누리

加里旺山(Gariwangsan、迦利王山)は、江原道の旌善郡と平昌郡の境に位置する山で、頂上部の最高標高は約1,597mに達します。太白山脈の系譜を引く、懐の深い高山らしい山容を持ち、2018年平昌冬季オリンピックの滑降競技が行われた加里旺山アルパイン競技場がすぐ近くに整備されていることから、その名が広く知られるようになりました。登山道は概ね緩やかな土の道が中心で、路面そのものの難易度は低めですが、山頂圏までの距離が長く累積標高差も大きいため、体力的には決して侮れない山です。アクセスがあまり良くないうえコースも長いので、日帰り登山も可能とはいえ、縦走したり余裕を持った日程を組んだりする場合は1泊を検討する人が多いです。

山容と地形

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道旌善郡旌善邑）・公共누리

カリワン山は、尖った岩峰よりもどっしりとした稜線と深い谷が織りなす、いかにも土山らしい高山です。頂上付近は、カリワン山山頂（1,556m）と山頂標識のあたり（1,569m）、それよりもう少し高いカリワンサ峰（1,593m）が互いに近接していて、山全体が広くなだらかに広がっているのが特徴です。稜線の途中にはセムト峰（1,252m）があり、その名の通り水が湧く場所として知られています。山全体がほぼ原生林に近い樹林帯をなしていて、特に「苔谷」と呼ばれる渓谷部には長い年月をかけて積もった苔と滝・淵の地形が発達していて、江原道の山ならではの原始的な雰囲気を漂わせています。

登山のリアルな感じ

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道旌善郡旌善邑）・公共ヌリ

カリワン山（加里旺山）の登山道は、序盤から山頂直前まで鬱蒼とした針葉樹・広葉樹の混交林に覆われた土の道がほとんどで、足裏に伝わる感触が柔らかく、木陰も濃いので夏でも比較的涼しく登れます。ただ、谷沿いを登っていく区間では苔むした岩や湿った地面のせいで足を滑らせやすい瞬間が何度もあるので、そこは気を抜かない方がいいです。山頂が近づくにつれて標高が一気に上がり、息も上がってきますが、山頂付近まで来ると視界がぱっと開け、江原道の山並みが幾重にも連なる眺めに出会えます。秋にはナラやカエデが色づいて紅葉が見頃を迎え、冬は高山らしくどっさり雪が積もるので、雪山登山の趣をしっかり味わえる山です。

コース1 — チャングモギ → 頂上道標

📏 9.79km ⛰️ 1161m 獲得標高 ⏱️ 4:23 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 登山口チャングモギ → 苔の谷1爆(滝) → 道標 → 苔の谷6爆 → 苔の谷9爆 → 簡易休憩所 → 分岐点 → 苔岩 → イチイの木 → 頂上道標 → 頂上 → オウンゴル → オウンゴルの滝 → オウンゴル滝筋 → チョニルクル(千日窟)の姿

登山口へのアクセス: チャングモギは旌善(チョンソン)郡の山間部にある登山口で、正直言って公共交通はかなり心もとないです。旌善市外バスターミナルから山あいの村へ向かう路線バスかタクシーを使うのが一般的なんですが、本数が少ないので事前に時刻表を調べておいたほうが無難です。専用の公営駐車場は見当たらず、車で行く場合は路肩や村の空き地に停めることになるケースが多いようです。

特徴・おすすめの人: 苔の谷沿いにいくつもの滝(1爆・6爆・9爆)を連続で通過していく渓谷タイプのコースで、水音と深い苔むした岩壁がなかなか印象的です。累積標高差が1,161mとかなりきついので、後半の登りはかなりの急坂に感じるはず。渓谷トレッキングと原生林の雰囲気を両方味わいたい、体力に自信のある登山者向けと言えそうです。

コース2 — 発心寺入口 → 頂上

📏 10.84km ⛰️ 690m 獲得標高 ⏱️ 3:52 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 発心寺入口 → 苔の谷 → シダ群落 → 分岐点 → ナラの木 → 倒れた古木 → ヘリポート → カエデ地帯 → 簡易休憩所 → チョウセンゴヨウの森 → 穴の空いた古木 → 旌善・江陵府三山棒標

登山口へのアクセス: 発心寺入口も旌善郡花岩面近くの山間部にあり、旌善の市街地から村営バスかタクシーで向かうのが一般的です。マイカーの場合、発心寺への進入路付近の空き地に停めている人が多いのですが、正式な駐車場があるという情報は見当たらないので、余裕を持って早めに着いて場所を確保しておくのが無難だと思います。

特徴・おすすめしたい人: 距離はそこそこありますが、累積標高差が690mと比較的なだらかで、体力の消耗が最後まで均等に分散されるコースです。ヘリポートや、旌善と江陵の境界を示していた昔の三山棒標など、歴史の名残に出会えるのも魅力のひとつ。急な登りより長距離を歩き通す持久力がものを言うコースなので、長時間じっくり歩くのが好きな人にぴったりだと思います。

難易度・路面・注意点

写真：韓国観光公社観光写真ギャラリー（江原特別自治道旌善郡旌善邑）・公共누리

加里旺山エリアの登山道のうち、登録区間（行政洞基準）5カ所はすべてデータ上「やさしい」に分類されていますが、これはあくまで各区間ごとの傾斜度による評価です。実際には頂上まで通しで歩く縦走型コース（チャングモギ・パルシムサコース）は累積標高差が大きく、体感的な難易度はかなり高くなります。路面はほとんどが土の道ですが、苔渓谷区間は水気と苔で滑りやすく、雨上がりや結氷期は特に気をつけたいところです。冬場は山頂付近の積雪・結氷がひどく、アイゼンなしでの通行は危険を伴うことがあります。公共データ上確認できる設備としては湧き水（水飲み場）が1カ所登録されているのみで、展望ポイントや避難小屋、危険区域として明記された場所は見当たりません。飲み水や非常用装備は自分で用意して登るのが安全です。登山口・下山口は合わせて6カ所確認されており、コース選びの自由度はそれなりにある方だと思います。

距離と所要時間

写真:韓国観光公社観光写真ギャラリー(江原特別自治道旌善郡旌善邑)・公共누리

カリワン山(加里旺山)エリアの登山道は、いくつかの区間を全部足すと総延長29.3kmにもなります。データを見ると、登りの累積所要時間は576分、下りは404分となっていて、平均すると登りのペースはだいたい1kmあたり20分ちょっと。ただしこれはエリア内の全区間を合算した数字なので、「1つのコースの所要時間」だと勘違いしないよう注意が必要です。実際に頂上を目指す代表的なコース、チャングモギ(장구목이)コース(9.79km、約4時間23分)や発心寺(パルシムサ)コース(10.84km、約3時間52分)は、片道だけでも4時間前後かかる本格派。往復となると8~9時間クラスの長丁場になります。体力に自信があれば日帰り往復も不可能ではありませんが、無理に強行日程を組んだり夜間山行になったりするのを避けたいなら、近隣で前泊して早朝から歩き始めるプランをおすすめします。

行き方(公共交通機関・駐車場)

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 정선군 정선읍) · 공공누리

首都圏からガリワン山(가리왕산)を公共交通機関で目指すなら、KTX江陵線の珍富(チンブ)駅か、旌善(ジョンソン)行きの市外バスで旌善市外バスターミナルまで行き、そこから山間の集落に向かう緩行バスかタクシーに乗り継ぐのが一般的なルートです。運行間隔が長いうえに路線が変わることもよくあるので、出発前に必ずリアルタイムのバス情報をチェックしておくのが賢明です。マイカーで行く場合も、各登山口付近にちゃんとした大型駐車場があるわけではなく、村の空き地や路肩に停めるしかないケースが多いので、時間に余裕を持って早めに到着したほうが安心です。実際のルートや最新の交通事情については、カカオマップやNaverマップで必ず再確認することをおすすめします。

シーズン・天気・装備

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 정선군 정선읍) · 공공누리

カリワン山登山に一番おすすめのシーズンは、新緑がまぶしい晩春から初夏にかけて、そして紅葉が見頃を迎える秋です。夏場は谷筋の区間が湿って滑りやすくなるので足元に気をつけたいところですし、冬場は高山ならではの積雪と凍結でぐっと難易度が上がるため、アイゼン・スパッツ・防寒装備は必須になります。基本装備としては登山靴、予備の水（水場が1か所しかないので飲み水は多めに持参する必要があります）、防水ジャケット、ヘッドランプ、トレッキングポールがあると安心です。コースが長く、人とすれ違うことが少ない区間も多いので、スマホのバッテリーと非常食もしっかり用意しておくといいですよ。

外国人旅行者向けのヒント

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 정선군 정선읍) · 공공누리

山頂は英語表記でGariwangsan Summit、代表的な登山口はJanggumogi TrailheadとBalsimsa Temple Entranceと書けます。特別な入山許可や入場料があるという情報は確認できませんでしたが、お寺（発心寺）の近くを通るときはそれなりのマナーを心がけたほうがいいでしょう。トイレや水飲み場は登山道内にほとんどないので（確認できた給水スポットは1か所のみ）、出発前に村で済ませておくのをおすすめします。グーグルマップは韓国国内の登山道情報が不正確なことが多いので、カカオマップやネイバーマップを使って実際のルートや公共交通機関を確認したほうがずっと安心です。山奥の地域なので通信が不安定な区間もあり得ますから、できれば同行者と一緒に登り、下山時刻にも余裕を持ってスケジュールを組むことをおすすめします。
