희양산は、慶尚北道聞慶市加恩邑と忠清北道槐山郡延豊面の境界にまたがる山で、山頂部の標高はだいたい996m前後とされています。白頭大幹の稜線が通る山並みの上にあり、山頂付近に真っ白な花崗岩の岩峰がまるごとそびえ立っているのが最大の見どころです。山の麓には曹渓宗の由緒あるお寺・鳳巌寺があり、山の姿とお寺の持つ宗教的な重みが合わさった山としても広く知られています。登山の難易度はコース次第でかなり差があり、短くて緩やかな区間なら初心者でも歩けるのですが、山頂付近の岩稜を通るコースは体力と経験が求められる上級コース扱いになります。とはいえ、ほとんどのコースは日帰りで十分歩き切れます。

사진: 한국관광공사 관광사진 갤러리 (경상북도 문경시) · 공공누리

山容と地形

写真:韓国観光公社観光写真ギャラリー(慶尚北道聞慶市)・公共누리

ヒヤンサンは典型的な岩山で、山頂部全体がひとつの巨大な花崗岩の塊のように見える独特な地形を持っています。遠くから眺めると、山頂が白い岩でまるく覆われたような姿をしていて、他の山とはひと目で見分けがつきます。山頂部には표지地点が2か所あり、それぞれ995m、997mと表記されているので、実際の高さはだいたい996〜997m前後と考えていただければと思います。GPS実測では992m地点が最高高度として確認されていますが、山頂石の表記と多少ズレがあるのは、測定時期や機器によるいつもの誤差の範囲と理解しておけば十分でしょう。

周辺の稜線にはいくつもの峰が連なっています。クワンボンへとつながる白頭大幹の主稜線上にはシルボンがありますが、こちらも山頂石の表記が911mと919mの二つに分かれていて、だいたい915m前後だろうと推測できます。このほか、チュチボン(約703〜722mと表記)、トゥグボン(663m)、そして近くの稜線につながるアクフィボンとマクジャンボン(888m)も、この登山道エリアに含まれています。渓谷区間には岩盤の上を流れる渓流や小さな滝(ヒヤン滝)も見られ、荒々しい岩の稜線と渓谷の水の流れが対照をなす山容となっています。

登山の雰囲気

사진: 한국관광공사 관광사진 갤러리 (충청북도 괴산군 연풍면 적석2길 42) · 공공누리

希陽山の登山は、区間ごとに雰囲気がガラッと変わるのが面白いところです。登り始めは広葉樹の森が続き、木陰が深くて落ち着いた雰囲気なのですが、稜線に近づくにつれて岩肌が顔を出し始め、山頂付近ではすっかり岩稜地帯に様変わりします。特に山頂近くで巨大な白い岩峰と対面する瞬間の開放感は、この山を訪れた人たちが口を揃えて話すポイントです。稜線眺望点や希陽山眺望といった地点からは白頭大幹の稜線が幾重にも連なる景色を望むことができ、眺望の良さで評価の高い山となっています。ただ、岩稜区間が多いぶん手を使わないと登れない箇所もあり、クマザサ(篠竹)の群生地や赤松林を通る区間では野生動物(イノシシなど)の痕跡が確認されているという表示もあるので、季節や時間帯によっては注意が必要です。春は新緑と渓谷の水音、秋は岩峰と紅葉のコントラストが印象的だという声が多く、冬場は岩場が凍りついて、雰囲気は荘厳になる一方で体感的な難易度はぐっと上がります。

コース1 — 簡易休憩所 → 白頭大幹クワンボン(九王峰)

📏 8.54km ⛰️ 681m 獲得標高 ⏱️ 3:16 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 簡易休憩所 → 分岐点 → ウェイポイント16 → 白頭大幹クワンボン(九王峰) → ヒヤンサン(希陽山)展望地点 → ウェイポイント19 → チルムティ峠分岐点 → ウェイポイント21 → 老松 → ウェイポイント24 → 稜線展望地点 → ヒヤンサン(希陽山)山頂 → 岩山頂上の簡易展望地点 → 山城跡 → ヒヤンポクト(希陽滝)

登山口へのアクセス: このコースは白頭大幹の主稜線をそのままたどる区間で、聞慶(ムンギョン)加恩邑(カウンウプ)ウンティ村方面から入山するケースが多いようです。最寄りの地下鉄駅はなく、聞慶・槐山(コェサン)方面への市内・市外バスでアクセスした後、村営バスかタクシーで登山口まで移動するのが一般的です。公式データ上、付近に指定駐車場は確認されていないため、事前に村の空き地や路肩に駐車できるかどうかを確認しておくことをおすすめします。

特徴・おすすめの方: 白頭大幹縦走者がよく訪れる定番の主稜線コースで、クワンボン(九王峰)を越えてヒヤンサン(希陽山)山頂まで続く道中、ヒヤンサン展望地点や稜線展望地点などから巨大な岩峰をさまざまな角度から眺めることができます。老松が点在する稜線や山城跡の痕跡も通過し、下山路ではヒヤンポクト(希陽滝)にも出会えます。距離・標高差ともにかなりあり体力の消耗が激しいコースなので、登山経験が豊富な方向けです。

コース2 — 分岐点 → シルボン(甑峰)山頂

📏 8.39km ⛰️ 663m 獲得標高 ⏱️ 3:12 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地: 分岐点 → 簡易休憩所 → ヘッコルバウィ(骸骨岩) → サンジュナム(篠竹)群生地 → 野生イノシシ出没エリア → シルボン山頂 → シルボン休憩所

登山口へのアクセス: シルボン方面のコースも、聞慶(ムンギョン)・槐山(クェサン)の境にある山間の村を経由して入るのが一般的です。公共交通機関を使う場合は、最寄りの邑（ウプ）中心部までバスで行き、そこから徒歩かタクシーで登山口まで向かうのが無難でしょう。

特徴・おすすめの人: ヘッコルバウィと呼ばれる骸骨のような形の奇岩を通り過ぎ、サンジュナム（篠竹）が密生する森を抜けていく区間が印象的です。野生イノシシの出没を示す標識もあるので、特に早朝や夕方の時間帯は、あえて音を立てながら進むのがおすすめです。他のコースに比べて利用者が少ないので、静かに山を楽しみたい方にはぴったりの一本です。

코ース3 — 登山口→山頂

登山口へのアクセス：6コースの中で距離が最も長く（14.24km）、実質的には稜線をひと続きに縦走するタイプのコースなので、特定の登山口ひとつだけを使って短時間で往復するというより、近隣の複数の村をつなぐ長丁場の山行に使われることが多いです。

特徴・おすすめの人：累積標高差は580mとそこまで急ではないものの、距離が長いぶん総所要時間は4時間30分以上とみておいたほうがいいでしょう。稜線をずっとたどっていく中でいくつもの峰々の眺めを存分に楽しめるので、一日まるごと山で過ごすつもりの体力に自信のある方向きのコースです。日帰りも可能ですが、朝早めの出発が必須になります。

코ース4 — 取付口 → 山頂

経由地: 取付口 → 日本統治時代に地脈を断ち切ったとされる跡 → 分岐点 → 下山口 → オジャッキョ岩（烏鵲橋岩）

取付口へのアクセス: 比較的短めの5.89kmコースで、集落のすぐ近くから取付口に入れる区間のようです。公共交通機関を使う場合は、近くの邑（ウプ）にあるバスターミナルまで行き、そこから徒歩でアプローチするのが一般的なパターンになります。

特徴・おすすめしたい人: 日本統治時代にこの山の地脈を断ち切ったと伝わる跡地を通るのがこのコースの特徴で、歴史にまつわる話が残る区間です。オジャッキョ岩という、ちょっと変わった名前の岩場も見どころのひとつ。標高差(650m)に対して距離が短いぶん体感的な傾斜はなかなかきつめなので、「短時間でもガツンと歩きたい」というタイプの方に向いているコースだと思います。

コース5 — 登山口 → 岳輝峰(アクフィボン)頂上

📏 14.24km ⛰️ 580m 獲得標高 ⏱️ 4:32 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：立石村駐車場 → 簡易売店 → 駐車場トイレ → 分岐点 → 村の簡易休憩所 → 登山口 → チッパウィ(集岩) → 隈笹群落 → 岩石景観 → 岩盤渓流 → 立石岩 → 展望岩 → 立ち岩 → 岳輝峰頂上 → 頂上展望地

登山口へのアクセス：立石村駐車場を起点とするコースで、この村の近くに立石バス停があるため、6コースの中では公共交通機関でのアクセスが比較的楽な方です。駐車場付近には簡易売店とトイレがあることも確認できていて、登り始め周辺の施設という点では6コース中いちばん充実しています。

特徴・おすすめしたい人：チッパウィ・立石岩・立ち岩といった名前の付いた奇岩を次々と通り過ぎていくコースで、隈笹の群落や岩盤の上を流れる渓流（岩盤渓流）も見られるので、変化に富んでいて飽きません。頂上部の岳輝峰頂上には展望地点が別途設けられていて、見晴らしもなかなかのものです。登り始めの施設と公共交通のアクセスのしやすさを合わせて考えると、この山に初めて来る方が出発点として選ぶにはちょうどいいコースだと思います。

コース6 — 登山口 → チュチボン

📏 5.89km ⛰️ 650m 獲得標高 ⏱️ 2:33 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地: 分岐点 → チュチボン → 赤松群落 → サンサンジェ(山神祭)跡地 → 山林遺伝資源保護区域案内板 → 展望岩 → マブンボン(馬糞峰)を望む地点 → イノシシの出没痕跡 → 簡易休憩所 → 下山口 → 登山口

登山口へのアクセス: 村の分岐点から始まる、ほぼ周回コースになっているルートです。近くの村のバス停まで行き、そこから徒歩で登山口へ向かうのが一般的なアクセス方法になります。

特徴・おすすめの人: 赤松が群生する赤松群落と、山林遺伝資源保護区域の案内板がある、生態的に保護された森を通り抜けるのがこのコースの見どころです。マブンボンを背景に眺められる展望ポイントもあり、景観にも変化があって飽きません。ただ、イノシシの出没痕跡を示す表示があるので、単独で歩くときは物音を立てたり、熊鈴（というかイノシシ除け）を持っていくと安心です。累積標高差は508mと6コースの中では一番なだらかなので、中級者以上ならそれほど無理なく登れるはずです。

この登録区間の難易度は「易しい」に分類されていますが、これまで整理してきた実測GPXコースはほとんどが★★★★☆~★★★★★となっており、実際に頂上を目指すコースは体感的にはるかにハードです。これは、登録区間データが山全体の登山道のうち一部(取り付き区間など)しかカバーしていない可能性を示しているので、頂上まで行くコースを計画するなら実測GPXコースの表を基準にする方が安全です。

安全施設データを見ると、展望ポイント0カ所、湧き水(薬水)0カ所、避難所0カ所、危険区域指定0カ所として登録されており、登山口・下山口は2カ所確認できます。ただ、実際のコースの道標データには稀陽山展望・稜線展望点・頂上展望・展望岩など、眺めの良いポイントが別途表示されていて、公式の登録施設の数字とは別に、現地で展望を楽しめる場所はいくつも存在します。路面は頂上付近に近づくほど花崗岩の岩盤がむき出しになっている区間が多く、雨の日は非常に滑りやすくなり、冬場は凍結のリスクも高まります。岩稜区間では手を使って登る箇所もあるので、雨上がりや凍結期にはコース選びに特に慎重を期してください。

距離と所要時間

写真:韓国観光公社観光写真ギャラリー(忠清北道槐山郡延豊面郷校路40-2)・公共누리

希陽山の頂上圏の登山はほとんど日帰りで十分こなせるコースで、避難小屋も特に登録されていないので、1泊がかりの計画までは要らないと思います。ただ、管内データにある上り140分・下り98分という数字は、管内の複数区間を積み上げた値なので、うっかり「特定の1コースの所要時間」だと勘違いしないよう気をつけたいところです。この積算値を距離で割ってみると、上りの平均ペースはだいたい1kmあたり25分という計算になります。これは前に整理した実測GPXコース(だいたい1kmあたり22~26分に換算される水準)ともほぼ近い数字なので、コースごとの所要時間を大まかに見積もる際の物差しとしてなかなか使えます。例えば一番短いコース4(5.89km)なら往復5時間前後、一番長いコース3(14.24km)だと往復9時間以上かかることもあるので、こちらは朝早めの出発が必須です。

行き方(公共交通機関・駐車)

写真: 韓国観光公社 観光写真ギャラリー(忠清北道槐山郡延豊面中央路44)・公共누리

希陽山は、公共交通機関だけで向かうにはちょっと骨が折れる山の一つです。山を貫くような地下鉄はもちろんなく、聞慶(ムンギョン)か槐山(グェサン)方面の市外バスターミナルまで行ってから、そこから地元の農漁村バスや村営バスに乗り換えて登山口付近まで近づくのが基本パターンになります。公共データを見る限り、登山口周辺には陳村(チンチョン)停留所と立石(イプソク)停留所という二つのバス停が確認できて、なかでも立石停留所は岳輝峰(アクフィボン)頂上コース(コース5)の立石村駐車場に近いので、公共交通機関利用の際の目印として結構使えます。とはいえ、停留所ごとの実際の運行間隔や路線は、出発前に必ず自分でチェックしておいてください。

駐車場については、公共データ上に正式登録された指定駐車場が見当たりません(立石村駐車場のようにコース内表記は存在するものの、公式の駐車場統計には反映されていない状態です)。なので車で向かう場合は、村の空き地や路肩など、現地の案内に従って駐車するのが無難だと思います。実際のルートについては、KakaoMapやNaver Mapで「希陽山」、あるいは近くの集落名(ウンティ村、立石村など)を検索して、徒歩・車それぞれのルートを最終確認しておくことをおすすめします。

季節・天気・装備

希陽山(ヒヤンサン)登山に一番向いているのは、新緑がまぶしい春と、紅葉が色づく秋です。夏場は谷川のせせらぎと木陰のおかげで登り口あたりは気持ちよく歩けますが、岩稜帯は日差しをさえぎるものがほとんどないので、真昼どきの山行は避けたほうが無難です。冬は山頂付近の花崗岩の岩盤が凍りつき、体感的な難易度がぐっと上がるので、アイゼンやスパッツといった防寒・滑り止め装備は必須になります。

必携品としては、岩稜帯が多いのでグリップ力のある登山靴、水場が一切ないので必要な分をすべて背負っていく飲み水、岩をつかむ場面に備えた手袋、トレッキングポール、防風・防水ジャケット、それに簡単な救急用品あたりをおすすめします。避難小屋のない山なので日帰り日程は必ず守り、日の短い季節は午後遅い時間の下山は避けるようにしてください。

海外からの旅行者向けヒント

戲陽山（ヒヤンサン、Huiyangsan）は、韓国人登山者の間でも岩峰の景観で名高い山なんですが、海外からいらっしゃる旅行者にとってはあまり馴染みのない山かもしれません。山頂はローマ字で Huiyangsan Peak、主稜線上のピークは Guwangbong（グァンボン）、Sirubong（シルボン）、Akhwibong（アクィボン）、Juchibong（チュチボン）、Makjangbong（マクチャンボン）などと表記されます。入山にあたって特別な許可や入場料は必要ないようですが、山麓の鳳巌寺（ポンアムサ）の境内は基本的に立入りが制限されていて、お釈迦様の誕生日など特定の日を除くと拝観が難しいことが多いので、その点は頭に入れておいてください。トイレはコース5（アクィボン頂上コース）の立石（イプソク）村駐車場付近にしか見当たらず、他のコースには設置されていないので、出発前に済ませておくのが無難です。飲み水が汲める場所（薬水場）も山全体を通じて確認できないので、水は必ず十分な量を持参してください。地図アプリについては、Googleマップだと韓国の山間部の登山道情報が正確に表示されないことが多いので、現地で広く使われているKakaoMapかNaver Mapを入れておいて、実際の登山道と公共交通のルートを確認することをおすすめします。岩稜帯の多い山なので、安全のためにも単独行より同行者と一緒に、そして天候が悪ければ無理せず日を改めるのが賢明です。
