概要

写真: 韓国観光公社 観光写真ギャラリー（慶尚南道梁山市下北面）· 公共누리(Public Nuri)

千聖山（천성산、Cheonseongsan）は慶尚南道梁山市にある山で、釜山・梁山の市民には近郊の登山スポットとしてすっかりおなじみの存在です。登山路データによると山頂部の最高標高は882mで、山の姿は険しい岩稜というより、なだらかな土の尾根が広々と続くタイプ。山頂まで片道3時間台かかるコースもあるほど懐が広く深いので、初めて登る方には中級以上に感じられるかもしれません。代表的なコースを選べば日帰りで十分楽しめますし、わざわざ一泊の準備をする必要はありません。

山容と地形

写真：韓国観光公社 観光写真ギャラリー（慶尚南道梁山市下北面）· 公共누리（KOGL）

天聖山（チョンソンサン）は、尖ったひとつのピークがそびえる山ではなく、複数の峰と広い高原状の稜線が連なっていくタイプの山です。頂上部は切り立った岩峰ではなく、なだらかに続く土の稜線が主体として知られていて、そのあちこちに大小の岩場が混ざっています。登山道データの峰情報には標高550m地点に「山頂」という名前の峰が登録されているのですが、これは実際の頂上部より低い中腹の峰と見られ、GPX実測ベースの頂上圏最高標高（882m）とは分けて考える必要があります。山全体は広い裾野を成し、いくつもの谷（代表的なのは内院寺（ネウォンサ）渓谷方面）と湿地性の地形をあわせて抱えているので、単純なピーク型の山ではなく、広がりのある山岳地形だという点が特徴です。

山歩きの雰囲気

写真：韓国観光公社 観光写真ギャラリー（慶尚南道 梁山市 下北面）· 公共누리（KOGL）

千聖山（チョンソンサン）の山行は、全体として鬱蒼とした森の道をひたすら歩き続ける印象が強いコースです。入口付近は渓流沿いの森の道が続き、稜線に近づくにつれて視界が開ける場所が現れ、遠くの景色を楽しめます。岩稜を越えるようなスリルというよりは、土の道やガレ場をコツコツ登っていく、体力勝負型の山歩きだと考えていただければいいかと思います。春は新緑と山菜、秋は紅葉が彩る稜線歩きが印象的で、夏は渓流の水音とともに日陰の多い森の道が暑さをいくぶん和らげてくれます。ただ、コース自体が長いので、季節に関係なく後半に向かうほど疲れが体にたまってくる傾向があります。

コース1 — 展望ポイント → 山頂

📏 8.88km ⛰️ 847m 獲得標高 ⏱️ 3:38 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由: 展望ポイント → 龍骨山（ヨンゴルサン） → 分岐9 → 分岐10 → 分岐11 → トゴク → 分岐13 → 分岐14 → 福泉精舎（ポクチョンジョンサ）

登山口へのアクセス: 最寄り駅からの正確な連絡情報は確認が難しいのですが、梁山（ヤンサン）市内バスの路線を使って登山口の近くまで向かうのが一般的なようです。専用駐車場についても情報が見つからなかったので、公共交通機関を第一に考えつつ、出かける前にKakaoMapなどで実際の道路状況をチェックしておくのがおすすめです。

特徴・おすすめの人: 純標高差が847mということで、全コースの中でも体力の消耗がいちばん大きいグループに入ります。経由地の名前からも分かるとおり、龍骨山を越えて山頂域へ取り付く長距離の尾根コース。途中、トゴク付近で視界が開ける場所をいくつか通り、遠くの山並みを見渡すことができます。距離も標高差もなかなかのものなので、体力と登山経験がある程度ある方に向いています。初心者の方なら、時間をたっぷり確保して臨むのが良いでしょう。

コース2 — 分岐1 → 山頂

📏 7.7km ⛰️ 490m 獲得標高 ⏱️ 2:45 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由: 分岐1 → 分岐2 → 分岐3 → 分岐4 → 分岐5 → 休憩所 → 展望ポイント → 分岐9 → 分岐10 → イムギョンサ（臨鏡寺） → 分岐12 → 分岐15 → 分岐16 → 分岐17 → 分岐19

登山口へのアクセス: このコースも専用駐車場がデータ上で確認できないため、市内バスで登山口の近くまで向かうのが現実的です。正確なバス停の位置は、KakaoMap や Naver Map で「천성산（千聖山）」と検索して、実際のルートを事前にご確認ください。

特徴・おすすめの方: 分岐と休憩所が細かく続く区間で、コース1よりも累積標高差（490m）がゆるやかなので、体感的な負担はやや軽めです。途中で休憩所と展望ポイントの両方を通るため、ひと休みしながら景色も楽しめるのがいいところ。ただし分岐がいくつも出てくるので、道標の確認はこまめにしながら歩くのが大事です。コース1に比べると比較的アクセスしやすいので、日帰り登山の経験がある一般の登山者に向いています。

難易度・路面・注意点

写真: 韓国観光公社 観光写真ギャラリー（慶尚南道梁山市下北面）· 公共누리(KOGL)

登山路データによると、この地域に登録されている区間の最高難易度は「中間」で、路面の情報は登録されていません。ただしGPXの実測値で見ると山頂周辺のコースは★★★★☆〜★★★★★となっていて、地域全体の平均よりも山頂への取り付き区間はかなりキツいということになります。公共データ上、危険箇所・展望ポイント・避難小屋はいずれも0件。つまり安全設備や逃げ込める場所は期待できません。路面が明記されていないので、たとえ土の道が主体だとしても、雨の日のぬかるみや冬場の凍結は自分で備えるしかありません。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（慶尚南道 梁山市 下北面）· 公共ヌリ

管内に登録されている区間の総延長は179.13km。これは天聖山エリアにある複数の区間をすべて足し合わせた数字なので、ひとつのコースの距離だと勘違いしないようご注意を。実際の上りが3,319分、下りが2,315分という所要時間データも、同じく管内の全区間を積み上げた値です。これをコース数で割ってみると、上りの平均ペースはだいたい19分/kmくらいになります。このペースで計算すると、山頂に向かうコース（8.88km・7.7km）は3〜4時間台という結果に。実測GPXをもとにした推定所要時間（およそ2時間45分〜3時間38分）とも、おおむね近い範囲に収まっています。山頂だけを目指す山行なら日帰り往復で十分ですし、179kmに及ぶ全区間を縦走しようというのでもない限り、泊まりの準備をする必要はありません。

アクセス方法（公共交通・駐車場）

写真: 韓国観光公社 観光写真ギャラリー（慶尚南道梁山市下北面）· 公共누리（KOGL）

千聖山（チョンソンサン）の登山口周辺には、スチョン村（水清마을）、マダンモルリ、コーロン・ハヌルチェ、ムルグム・ハンシン・ザヒュといったバス停があります。梁山ムルグム地区のマンション団地を経由する路線なので、釜山・梁山の市内バスでこれらのバス停付近まで行き、そこから歩いて登山口を目指すのが一般的なパターンです。公共データ上、登山口周辺に専用駐車場の登録はないため、マイカーで訪れる場合は近隣の公営駐車場や集落の駐車スペースを事前に調べておくのがおすすめです。正確なリアルタイム経路やバス停の位置は、KakaoMapまたはNaver Mapで「천성산（千聖山）」と検索し、徒歩・公共交通の経路検索で改めて確認してください（Googleマップは韓国の山道情報が不正確なことが多いので要注意です）。

シーズン・天候・装備

写真：韓国観光公社 観光写真ギャラリー（慶尚南道 梁山市 下北面）・公共ヌリ（KOGL）

登山に一番向いているのは、やはり春と秋。夏は湿気と暑さで体力の消耗が激しいので、水は多めに用意しておきましょう。冬は稜線での凍結と強風に備えて、アイゼンと防風装備が欲しくなります。必携品としては、足首を守ってくれる登山靴、余裕をもった飲み水（コース内に水飲み場はほぼないようなので、個人でたっぷり持っていくのが必須です）、トレッキングポール、そして雨風をしのげる防水・防風ジャケット。コースが長めなので、日の短い晩秋から冬にかけては早めに出発し、ヘッドランプも一緒に忍ばせておくと安心です。

外国人旅行者へのヒント

写真: 韓国観光公社 観光写真ギャラリー（慶尚南道梁山市下北面）· 公共누리（KOGL）

天聖山（チョンソンサン）のローマ字表記は Cheonseongsan です。コース上の主な地名は、道標にハングルのみで書かれていることが多いので、あらかじめハングルの地名をスクリーンショットで保存しておくと役に立ちます。入山許可や入山料については確認できなかったので、自由に入山できるようですが、訪問前に現地の案内板で最新情報をもう一度確かめておいてください。トイレや水飲み場といった設備もデータ上は確認できないため、登山口近くの集落（勿禁（ムルグム）一帯）で先にトイレを済ませ、飲み水を十分に用意してから入山するのがおすすめです。道案内はGoogleマップよりKakaoMapかNaver Mapのほうが圧倒的に正確なので、必ずこの2つのアプリを使ってください。コースが長く分岐も多い山なので、登山アプリのGPXトラック機能やオフライン地図も併せて準備しておくと、道に迷うリスクを下げられます。人けの少ない区間もあるため、できれば単独ではなく誰かと一緒に歩き、下山の時間には余裕をもたせて、日没前に下り終えるようにすると安心です。
