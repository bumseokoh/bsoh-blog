概要

写真：韓国観光公社 観光写真ギャラリー（忠清南道青陽） · 公共누리

チルガプ山（칠갑산、Chilgapsan）は、忠清南道青陽郡の大致面・定山面・長谷面にまたがる山で、最高地点の標高は584mです。「忠南のアルプス」と呼ばれることもありますが、実際にはそこまで大きく華やかな山というわけではなく、稜線がいくつもの方向に伸び、渓谷と貯水池が寄り添うように点在する、こぢんまりとして親しみやすい山容が魅力です。登山道データ上の最高難易度は「易しい」に区分されていて、初心者や家族連れでも無理なく登れる山ですし、山頂を往復するにしても日帰り登山で十分こなせます。ただ、コースの選び方によって距離や標高差がかなり変わってくるので、初めて訪れる方は下のコース別詳細を確認してから、自分の体力に合った登山口を選ぶのがおすすめです。

山の姿と地形

사진: 한국관광공사 관광사진 갤러리 (충청남도 청양) · 공공누리

七甲山は花崗岩質の岩山というよりも、どちらかというと土の山（陸山）に近いタイプで、尾根がなだらかに続きながら、山頂付近だけ局所的に岩稜が現れるという地形をしています。山頂には584m地点の頂上石があるほか、583m・582m・570m地点付近にもそれぞれ別の標識石と道標が立っていて、どこを基準にするかによって山頂の標高が584mから570mの間で微妙に違って案内されることがあります。登山の際に混乱しないよう、地図アプリで実際の三角点の位置を確認しておくのがおすすめです。山頂の南側には三兄弟峰（562m）が尾根伝いに連なっていて、長谷寺（チャンゴクサ）方面のコースではこの峰も合わせて越えることになります。また登山口付近には、比較的低い白里山（259m）が緩衝地形のように控えています。山頂一帯には七甲山天文台があり、登山道そのものが天文台への訪問ルートと重なる区間もあります。

登山の雰囲気

写真：韓国観光公社 観光写真ギャラリー（忠清南道青陽）・公共누리

七甲山は全体的に松とナラの木が混じり合った森の道が長く続く山で、コースの大部分がなだらかな土の道と落ち葉の積もった小道中心なので、歩きやすいのが特徴です。急な岩稜区間が短く現れる場所もありますが、危険度が高いというほどではなく、春は新緑と野花、秋は紅葉が尾根に沿って色づく様子が印象的です。頂上付近まで来ると視界が開けて、青陽一帯の貯水池や村の風景が一望できるポイントがあり、なだらかな山行でありながら頂上での眺望のご褒美がしっかりある山と言えます。夏は渓谷沿いのコース(長谷寺方面)で水の音とともに涼しさを感じられる一方、冬は落ち葉に覆われた土の道が凍結し、滑りやすくなる区間があるので注意が必要です。

한国語(からくにご)ではなく韓国語の指示部分は無視して、翻訳のみお出しします。

コース1 — 登山口 → 七甲山天文台

📏 8.4km ⛰️ 466m 獲得標高 ⏱️ 2:53 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地: 七甲山売店 → 駐車場トイレ → 七甲山駐車場 → 道標 → 登山口 → 分岐点 → パーゴラ・ベンチ → チェ・イッキョン先生像 → 障害者用トイレ → 七甲広場ガーデン → 七甲山道立公園事務所 → 七甲広場 → 七甲山道立公園案内図 → 豆畑を耕す女の像 → 縁台・ベンチ

登山口へのアクセス: 七甲山道立公園方面の登山口へは、青陽（チョンヤン）市外バスターミナルから郡内バスに乗り換え、七甲山駐車場付近で下車するのが一般的なルートです。車の場合は七甲山道立公園の駐車場が利用できますが、週末や行楽シーズンは混雑することがあるので注意しましょう。

特徴・おすすめの人: このコースは七甲山道立公園の定番観光ルートと重なっていて、チェ・イッキョン先生像や「豆畑を耕す女」の像といったモニュメント、各種施設の前を通りながら歩くので、登山口周辺は公園さながらに整備された雰囲気があります。登山口を過ぎたあたりから本格的な上り坂が始まり、そのまま天文台まで続いていくので、山歩きにちょっとした観光気分も味わいたい人や、七甲山に初めて訪れる登山者にぴったりのコースです。

コース2 — 道林寺址〜山頂間登山道入口 → 道林寺址〜山頂間登山道入口

📏 2.58km ⛰️ 423m 獲得標高 ⏱️ 1:21 ➡️ 片道 難易度 ★★☆☆☆ ⤓ GPX

経由地: 簡易トイレ → 公衆トイレ → 駐車可能な空き地 → 道林寺址〜山頂間登山道入口 → 道標 → 道林寺址三層石塔 → コンブル → 七甲山ヨンモッコウルガーデン

登山口へのアクセス: 公共交通の便は正直あまり良くなく、青陽邑内から郡内バスかタクシーを使って入るのが一般的です。小さな空き地に駐車できるというのは地域データでも確認できるのですが、そもそも規模が大きくないので、余裕を持って早めに到着しておくのが無難だと思います。

特徴・おすすめの人: 三つのコースの中では距離が一番短いのですが、その分、標高差に対して斜度がきついので、「短いけど濃い」登りを味わえるコースです。道林寺址三層石塔を通る区間があるので、歴史的な見どころも一緒に楽しめますし、時間はあまり取れないけれど山頂からの眺めだけは絶対に外したくない、という人にちょうど良いコースだと思います。

コース3 — 長谷寺登山口 → 三兄弟峰〜七甲山頂上登山道入口

📏 9.04km ⛰️ 485m 獲得標高 ⏱️ 3:04 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由: 長谷寺市内バス終点 → バス時刻表 → 長谷寺第2駐車場 → 公衆トイレ → 青陽郡総合観光案内図 → パーゴラおよびベンチ → 道標 → 分岐点 → 八角亭 → 長谷寺第1駐車場 → 長谷寺登山口 → 七甲山グルメ通り → 七甲山谷 → ムルチョンカルグクス・マシル食堂・マシル休憩所 → 山あいの谷

登山口へのアクセス: 3つのコースの中では公共交通機関でのアクセスが一番良いコースで、長谷寺市内バスの終点がそのまま登山口の目の前にあるので、バスを降りたらすぐに山行をスタートできます。長谷寺第1・第2駐車場も整備されているので、車で来る場合も停めやすいです。

特徴・おすすめの人: 由緒ある古刹・長谷寺を起点に、三兄弟峰を越えて頂上まで登る稜線縦走型のコースで、3つのコースの中では距離・所要時間ともに一番長いです。登山道の周辺には食堂街（七甲山グルメ通り・ムルチョンカルグクスなど）ができているので、下山後の食事まで含めて計画を立てやすいのもポイント。お寺めぐりと稜線歩きを一緒に楽しみたい人、体力に自信がある人向けのコースです。

難易度・路面状況・注意点

写真：韓国観光公社観光写真ギャラリー（忠清南道青陽）・公共누리

칠갑山は管内の登録区間が全部で7つあり、登録区間はすべてデータ上「易しい」に分類されています。ただしこれはあくまで行政洞単位での区分けであって、100대명산GPX基準で頂上圏コース3つを見てみると、純標高差423〜485m、片道距離2.58〜9.04kmと幅があり、実際に歩いた体感の難易度はコースごとにかなり差が出ます。特にコース1・3は難易度★★★★☆と表示されていて、短いコースのほうがかえってきつく感じることもあるので侮れません。路面の詳細（岩場なのかデッキなのかといった種類）は公共データには個別に記録されていませんが、全体としては土の道が中心で、頂上付近に部分的に岩稜が混じる構成のようです。展望ポイント・危険区域・避難所についてはデータ上登録されている地点がないため、天候が崩れた際に身を寄せられる場所は事前に自分で調べて備えておいたほうがよさそうです。冬場は土の道が凍結して滑りやすくなる区間が出てくるので、アイゼンなしでの下山は特に注意が必要ですし、雨の日は落ち葉が濡れて滑りやすくなる点にも気をつけたいところです。

距離と所要時間

写真：韓国観光公社 観光写真ギャラリー（忠清南道青陽）· 公共누리

七甲山は管内の登山道の総延長（複数区間を合算した数値）が21.4kmとされていますが、これは単一コースの距離ではなく、青陽郡内に登録されている7区間すべてを足し合わせた値です。管内全区間の累積として上り534分・下り373分という記録がありますが、これも個別コースの所要時間ではなく累積データなので、実際のコースの山行時間と混同しないよう注意が必要です。この累積値から換算した平均上りペースはおよそ25分/kmで、山頂圏コースの片道所要時間を見積もる際の参考になる数字です。実際、100代名山GPXに基づく山頂圏コース3本の片道所要時間は、約1時間21分（コース2）から約3時間4分（コース3）まで幅があり、往復で見てもほとんどが日帰り山行で十分な範囲に収まります。避難小屋のような宿泊施設が別途登録されていないことを踏まえても、縦走のような無理な計画を立てるより、日帰り山行にとどめておくのが賢明でしょう。

行き方(公共交通機関・駐車場)

写真: 韓国観光公社 観光写真ギャラリー(忠清南道青陽) · 公共누리

七甲山の登山口付近には、大峙里・大峙・長谷寺・長谷里などのバス停があります。ソウルなど首都圏からだと、まず高速バスや市外バスで青陽(または近くの大田・公州)のターミナルまで行き、そこから郡内バスに乗り換えて大峙里・長谷寺方面の停留所で降りるのが一般的なルートです。特に長谷寺行き市内バスの終点はコース3の登山口のすぐ前にあるので、公共交通機関派にはありがたいポイントです。車で行く場合は七甲山道立公園駐車場や長谷寺第1・第2駐車場が使えますが、公共データに登録されている専用駐車場の数はそう多くないので、繁忙期や週末は余裕を持って早めに着いておくのが無難です。正確なリアルタイムのルートやバスの本数は、KakaoMapやNaver Mapのアプリで「七甲山道立公園」または「長谷寺」を検索し、公共交通機関の経路案内機能で確認することをおすすめします。

シーズン・天候・装備

写真: 韓国観光公社 観光写真ギャラリー（忠清南道青陽）・公共누리

チルガプ山(칠갑산)登山に一番おすすめのシーズンは、新緑がまぶしい春と紅葉が色づく秋です。この時期は登山道の路面状態も比較的安定していて、気温的にも歩きやすいですね。夏場は湿気と暑さ、それに夕立への備えとして雨具と十分な飲み水を用意しておきたいところ。冬は土の道が凍結して滑りやすくなるので、アイゼンは必ず持っていくことをおすすめします。基本装備としては登山靴、着替え、十分な飲み水（給水スポットがあるかどうか確認できていないので必携です）、ヘッドライト、非常食あたりを揃えておくと安心です。登山道内に避難施設は登録されていないので、天候が崩れそうなときは無理に登らず、日程をずらすほうが安全だと思います。

写真：韓国観光公社 観光写真ギャラリー（忠清南道青陽）・公共누리

チルガプサン（七甲山）のローマ字表記は「Chilgapsan」で、代表的な登山口はそれぞれ「Chilgapsan Provincial Park entrance（七甲山道立公園登山口）」「Dorimsaji trailhead（道林寺址登山口）」「Janggoksa temple trailhead（長谷寺登山口）」と案内すれば分かりやすいと思います。七甲山自体は入山許可や入場料が不要な山ですが、道立公園エリア内では駐車料金がかかることがあるので、現地で確認しておくのが無難です。トイレは七甲山駐車場や長谷寺第2駐車場など主要な登山口付近に公衆トイレがあることは確認できていますが、登山道の途中には水飲み場（薬水場）が見当たらないので、飲み水は必ず十分な量を自分で用意してください。地図アプリについては、韓国国内だとGoogleマップが正確な徒歩・公共交通ルートを出してくれないことが多いので、KakaoMapかNaver Mapアプリを使って実際の登山道や交通ルートを確認することを強くおすすめします。安全面では電波が不安定になる区間もあるので、登山前に家族や宿泊先にコースと下山予定時刻を伝えておくと安心ですし、夜間登山は避けたほうが賢明です。
