概要

写真：韓国観光公社 観光写真ギャラリー（慶尚北道亀尾市南通洞、薬師庵）・公共ヌリ

金烏山（クモサン、Geumosan／Mt. Geumo）は、慶尚北道亀尾市にある道立公園級の名山です。頂上部にあたる玄月峰（ヒョヌォルボン）は、資料によると標高984m前後とされていますが（同じ資料群の中には981mと記載されているものもあり、標高は調査時点によって若干のズレがあるようなので、あくまで目安として捉えていただければと思います）、稜線沿いには切り立った岩壁や奇岩があちこちに発達していて、昔から景観の美しさで知られてきた山です。頂上圏まで登る実測コースは短いもので6km台、長いものだと11kmにもなり、片道おおよそ3時間前後かかるので、たいていは日帰り登山で十分こなせます。ただ、累積標高差は750〜860mとかなりあるので、のんびり散策気分で臨むというよりは、体力とそれなりの準備が必要な中〜上級レベルの登山地として捉えておいたほうがよさそうです。

行政区域（亀尾市）ベースで登録されている市内の登山道は全部で4区間あり、これらを合算した総延長は3.43kmとなっています。これは頂上まで一気に登る一本のコースの距離ではなく、行政洞単位で区切られた複数の登山道区間を足し合わせた数値なので、下記の「主要コース」で紹介する実測コースの距離（6〜11km台）とは性質の異なる数字だということをあらかじめお断りしておきます。

山勢と地形

사진: 한国観光公社 観光写真ギャラリー（慶尚北道亀尾市 金烏山）・公共누리

金烏山は、なだらかな土の山というより、岩峰や岩稜が際立つ山容を持っています。頂上の玄月峰を中心に、城安全危峰（855m）、칼다峰（734m）、孝子峰（515m）、할딱峰（538m）といった峰々が稜線沿いに連なり、山の下の方には감은山（241m）、虎嶺峰（268m）のような低い峰が山裾を形成しています。特に頂上付近や西峰・南峰方面では、展望岩や岩塊、展望台のような岩盤地帯がよく現れ、登山中にロープや手すりを使わなければならない急斜面の岩稜区間も含まれています。金烏山城が山の稜線に沿って残っているのも、この山の特徴のひとつで、城壁と岩稜が織り合わさった風景は、あちこちのコースの道標にも描かれています。全体としては道立公園に指定されているだけあって、大惠瀑布や道詵窟のような有名な見どころが山の入口付近にあるため、頂上を目指す登山だけでなく、短い散策コースとしても多くの人が訪れる山です。

登山の雰囲気

写真：韓国観光公社 観光写真ギャラリー（慶尚北道亀尾市）・公共누리

登山口を抜けて尾根に上がるまでは、松林と渓谷沿いを歩く区間が続くため比較的日陰が濃くて湿り気があり、夏場は渓谷の水音を聞きながら登れるのが特徴です。中腹を過ぎたあたりから岩場や展望岩が目立つようになり、山頂付近では岩稜を伝って登りながら四方に開けた眺めを楽しめます。いくつものコースで共通して「滑落・スリップ注意区間」という標識が出てくることからもわかるように、山頂圏の岩稜は足場に気を配らねばならない区間が少なくありません。秋は尾根の紅葉と岩稜からの眺望が相まって特に人気が高く、春は入口の渓谷や森の道で新緑を楽しむのに適しています。冬は岩稜区間が凍結することが多く、体感的な難易度がぐんと上がる山だということも頭に入れておいてください。

登山道の入口や見どころが一目で分かるように整えてみました。

コース1 — 富尚里登山口 → 頂上

📏 10.93km ⛰️ 754m 獲得標高 ⏱️ 3:59 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地: 分岐点 → 富尚里登山口 → 頂上標識 → 展望岩 → ベンチ休憩所 → 石塔 → 岩上の松 → 岩上フォトスポット → 展望台の岩壁 → 第1展望台 → 第1展望台デッキ → 岩塊 → 展望岩の上 → 第2展望台 → 葛項寺

登山口へのアクセス: 富尚里方面へは亀尾（クミ）市内バスで行くのが一般的で、近くに富尚1里・富尚バス停があるので、公共交通機関でも登山口付近まで行くことができます。専用駐車場があるかどうかは確認できていないので、車で行く場合は路肩か村の近くの空き地に停めることになりそうです。

特徴・おすすめの人: 8コースの中で距離が一番長く、第1・第2展望台をはじめとする見晴らしポイントが途切れなく続くのが魅力です。尾根伝いに長く歩く分、体力はそれなりに使いますが、その代わり景色を楽しみながらペース配分できるので、体力に自信のある登山者向けのコースです。

コース2 — ウジャンコゲ入口 → クモサン(金烏山)山頂

📏 7.4km ⛰️ 763m 獲得標高 ⏱️ 3:07 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地：ウジャンコゲ入口 → 木製ベンチ休憩所 → 山頂道標 → 分岐点 → 転落・滑落注意区間 → 国家地点番号標識 → 眺望岩 → 展望岩 → クモサン西峰 → 松林 → 岩場休憩所 → 平床休憩所 → クモサン山頂道標

登山口へのアクセス：ウジャンコゲは亀尾(グミ)市街地の外れにあり、市内バスを乗り継がないとたどり着けないことが多いので、事前に地図アプリでバス停の位置を確認しておくと安心です。

コースの特徴・おすすめの人：西峰を経由して山頂まで登る稜線コースで、途中に「転落・滑落注意」の標識が立っている区間があるため、雨天時や冬場は特に気をつけたいところ。西峰からの眺めも一緒に楽しみたいという方にぴったりのコースです。

コース3 — 上部公営駐車場 → カルダボン

📏 9.25km ⛰️ 863m 獲得標高 ⏱️ 3:45 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地: 上部公営駐車場 → 探訪案内所 → ケーブルカー乗り場下 → トイレ → 分岐点 → ヘウンサ（海雲寺） → デヘ滝 → 休憩所 → クモサン（金烏山・城内展望峰） → カルダボン

登山口へのアクセス: 金烏山道立公園の顔ともいえる入口で、上部公営駐車場に探訪案内所とケーブルカー乗り場が揃っているので、いちばんアクセスしやすい登山口です。車で行くならこの駐車場を使うのが一番無難だと思います。

特徴・おすすめしたい人: デヘ滝やヘウンサ（海雲寺）といった道立公園を代表する見どころを通るコースで、入口に案内所とトイレがあるのも初心者や家族連れには地味にありがたいポイントです。ただ、山頂エリアのカルダボンまでは累積標高差がそこそこあるので、後半は体力配分を意識しておいたほうがいいでしょう。

コース4 — 木製ベンチの休憩所・運動器具設置エリア → 頂上

📏 6.63km ⛰️ 802m 獲得標高 ⏱️ 3:00 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地: 木製ベンチの休憩所・運動器具設置エリア → 分岐点 → 木製ベンチの休憩所 → 頂上への道標 → 岩場 → 金烏山自然観察路の案内板 → 谷 → 落石危険区域 → 金烏山頂上の道標 → 金烏山城 → 展望岩 → ヘリポート → 転落・滑落注意区間

登山口へのアクセス: 運動器具が設置された近隣の休憩所からスタートするコースで、亀尾（クミ）の市街地からわりと短時間でアクセスできるのが特徴です。

コースの特徴・おすすめの方: 8コースの中で距離は一番短いのに、累積標高差は800mを超えていて、距離あたりの傾斜で言えばトップクラスの急坂です。金烏山城やヘリポートも通るので、歴史の痕跡に興味がある方、そして「短いけどガツンと登りたい」というタイプの方にぴったりのコースだと思います。

コース5 — 霊梅寺入口 → 金烏山南峰

📏 10.26km ⛰️ 814m 獲得標高 ⏱️ 3:55 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 空き地駐車場 → 長山堤貯水池 → 霊梅寺 → 展望岩 → 分岐 → 岩壁 → 金烏山南峰 → 山神堂 → 奇岩 → 滑落注意区間 → 祈祷所 → 少林寺 → 石岩寺

取り付き: 長山堤貯水池と霊梅寺の脇を抜けていく静かな入口です。空き地状の駐車スペースはあるものの、きちんと舗装された正式な駐車場ではないので、時間に余裕を持って向かうのがおすすめです。

特徴・おすすめの人: 霊梅寺・少林寺・石岩寺と、いくつもの寺院の前を通り抜けていくのがこのコースの持ち味。静かな山道の雰囲気の中で、山神堂や奇岩といった土着信仰の名残にも出会えます。人混みを避けてのんびり歩きたい人にぴったりのコースです。

コース6 — ホテル金烏山入口 → 頂上方面案内板

経由地: 分岐点 → 渓谷 → 岩場 → 岩稜上の展望ポイント → 頂上方面案内板 → 展望岩 → 救急箱 → 展望岩と松の木 → 岩壁 → 木製ベンチの休憩所 → 金烏山城 → 石塔 → 四季食堂 → ホテル金烏山入口

登山口へのアクセス: ホテル金烏山の近くからスタートするコースで、道立公園の進入路にも近いので比較的アクセスしやすいのが嬉しいところ。入口には食堂街もあるので、山行の前後にサクッと食事を済ませられるのも便利です。

特徴・おすすめの人: 経由地に救急箱の表示があるのがちょっと目を引きます。岩稜上の展望ポイントを何度も通るので、道中こまめに景色を楽しめるコースでもあります。山を歩いた後、そのまま食事まで済ませてしまいたいという方にぴったりだと思います。

行政洞単位で登録されている管内登山道区間（総延長3.43km）の内訳は以下の通りです。

上の表は行政洞単位で分けた短い登山道区間で、礼山里区間のようにひとつの区間の中に易しいから難しいまで難易度が混在しているケースもあり、実際に歩いたときの体感難易度は区間内でもばらつきがあるかもしれません。管内の登山道全体を通して確認できる最高難易度は「難しい」で、路面の材質については特に記録がありません。

施設面では、登山道POIデータベース上に登録されている危険地域・展望地点・給水所・避難所・公式の登山口／下山口はすべて0件となっています。ただ、先ほど紹介した実測コースのGPX道標には「転落・滑落注意区間」「落石危険地域」「展望台」「眺望岩」といった標示がコースごとに何度も出てきます。つまり公式の施設登録統計と実際の現場の地形・安全標示との間には差がある可能性があるので、山行中は現地に設置された案内板や標示を必ず確認していただき、岩稜区間では特に雨天後や冬場の凍結時の通行に気をつけていただければと思います。

距離と所要時間

写真：韓国観光公社 観光写真ギャラリー（慶尚北道亀尾市）・公共누리

金烏山はコース別に6~11km台、片道で約3時間前後かかる山なので、往復であっても日帰りで山行を終えられます。管内の登山路データでは上り60分、下り43分という所要数値が確認できますが、これは先ほど説明した行政洞区間（総延長3.43km)を積算した数値であって、頂上まで登る一本の実コースの所要時間だと勘違いしないよう注意が必要です。この積算数値を距離に換算すると、平均の上りペースはおおよそ17分/kmという計算になり、これは山行計画を立てる際に自分のペースを見積もる目安として使えます。実際の頂上圏コースは純標高差が750~860mにも及ぶため、この平均ペースよりもう少し時間がかかることがあるので、往復山行の際は余裕を持って6~8時間程度を見込み、下山時刻をあらかじめ決めておくのがおすすめです。日帰りで頂上まで往復できるので泊まりが必要な山ではありませんが、日が短くなる晩秋~冬場は早めの出発が必要です。

금오山への行き方(公共交通・駐車)

사진: 한국관광공사 관광사진 갤러리 (경상북도 구미시) · 공공누리

金烏山は慶尚北道亀尾市にあるので、ソウルなど首都圏からだとKTXで金泉亀尾(キムチョングミ)駅か亀尾駅まで行き、そこから市内バスに乗り換えるのが一般的なルートです。道立公園の切符売り場・ケーブルカー方面(コース3の上側公営駐車場付近)へ向かう路線が最もメジャーで、扶桑里(プサンリ)方面の登山口(コース1)を目指す場合は、扶桑1里または扶桑バス停で降りて徒歩で向かうことになります。ただ亀尾市内バスの路線や運行本数はしょっちゅう変わるので、出発前に必ずKakaoMapかNaver Mapでリアルタイムの公共交通ルートを確認しておいてください。Googleマップは韓国国内の公共交通・徒歩ルート情報が限られていて、当てにならないことが多いです。駐車に関しては、道立公園切符売り場近くの上側公営駐車場を利用するのが一番無難で、それ以外の登山口(ウジャンコゲ、ヨンメサ、ホテル金烏山など)にはきちんとした大型駐車場があるとは確認できていないので、公共交通の利用を優先したほうがよいでしょう。

シーズン・天候・装備

사진: 한국관광공사 관광사진 갤러리 (경상북도 구미시) · 공공누리

登山に一番おすすめのシーズンは春(4〜5月)と秋(9〜11月)です。春は入り口の渓谷や森の新緑、秋は稜線の紅葉と岩稜からの眺望が楽しめます。夏場は渓谷の湿気と暑さで体力の消耗が激しく、局地的な豪雨の際は渓谷区間の通行に注意が必要です。冬場は岩稜や展望岩の区間が凍結しやすく、体感的な難易度がぐっと上がるので、アイゼンとスパッツ、防寒装備は必ず用意してください。山全体に給水スポットは特に見当たらないので、季節を問わず個人の飲み水(体感として1人1〜1.5L以上)をたっぷり準備し、登山靴・トレッキングポール・ヘッドランプ(非常用)・非常食など基本的な登山装備を整えてから出発するようにしましょう。

写真：韓国観光公社観光写真ギャラリー（慶尚北道亀尾市）・公共누리

金烏山のローマ字表記はGeumosan（山頂の懸月峰はHyeonwolbong）で、道立公園なので国立公園のような登山申告や高額な入場料制度は基本的にないことが多いのですが、公園区域への進入料や駐車料金が発生する場合もあるので、現地の案内所で確認しておくと安心です。トイレは上部公営駐車場・探訪案内所付近（コース3）にあることが確認できますが、それ以外の登山口には特にトイレの情報が見当たらないので、公共交通の乗り換え地点や出発前に市内で済ませておくのがおすすめです。前述の通り、この山には給水スポットが特に見当たらないので、水は必ず事前に購入して持参してください。地図アプリはGoogleマップよりKakaoMapかNaver Mapを使ったほうが、登山道や公共交通の情報がずっと正確に表示されます。山頂稜線には岩稜帯や「転落・滑落注意」区間が何度か出てくるので、登山経験の少ない旅行者なら、アクセスが良く設備も整ったコース3（上部公営駐車場→カルダ峰）の前半区間（探訪案内所〜テヘ滝）だけを歩いてみるのも良い選択肢になりそうです。携帯電話の電波状況はおおむね良好ですが、念のため下山予定時刻を同行者や宿泊先に事前に伝えておくことをおすすめします。
