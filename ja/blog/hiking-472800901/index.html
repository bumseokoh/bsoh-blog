概要

大耶山（テヤサン、Daeyasan）は、慶尚北道の聞慶市加恩邑と忠清北道の槐山郡の境に位置する山で、白頭大幹の鳥項山・曦陽山の稜線へとつながる岩稜の名山です。山頂の標高表記は資料によって多少ばらつきがあり、おおよそ930〜950m台とされていますが、実測のコースデータでは山頂周辺の最高地点が1,001mまで確認できます。龍湫渓谷の涼やかな渓谷美に、象岩・大門岩・農岩といった奇岩怪石が加わった岩稜の山歩きが楽しめる場所で、登山道自体の行政区分上の難易度は「やさしい」に分類されていますが、実際の山頂コースは距離と標高差を考えると体力も注意力もそれなりに求められる、という印象です。日帰りで十分に行ってこられる山で、縦走よりは往復か周回コースで楽しむのが一般的です。

山容と地形

写真：韓国観光公社 観光写真ギャラリー（慶尚北道 聞慶市 加恩邑 完章里）・公共ヌリ

テヤ山（大耶山）は、なだらかな土の山（陸山）らしさと鋭い岩峰が同居する山で、全体としては花崗岩・変成岩系の岩の地形が目を引きます。山容をつくる主な峰としては、テヤ山の山頂部（公共データの峰POIでは952m・942mとそれぞれ表記）、北へ連なるトゥンドク山（979m）、そして西の裾に位置するカルモ峰の山頂（585m）があります。山頂付近には、コッキリ岩（象岩）、ノン岩（箪笥岩）、テムン岩（門岩）といった名前そのままの形をした岩が尾根沿いに並び、歩いている間ずっと目を楽しませてくれます。谷筋のヨンチュ谷には、水が削り出した沼（소）や滝の地形、それに自然の冷気が吹き出すとされる風穴地帯があり、陸山と岩山、そして渓谷の魅力をひととおり兼ね備えた山として評価されています。

山歩きの感触

大也山（テヤサン）の山行は、登り始めの渓谷の森の道からスタートして、だんだん岩稜帯へ移っていく流れが面白いところです。龍湫谷（ヨンチュゴル）コースは水音を聞きながら歩く渓谷トレッキングの雰囲気が濃く、山頂に近づくほど、象岩・ノンバウィ・大門岩を越える岩稜帯では手を使って登り下りするスリリングな区間が続きます。ミルジェ付近の稜線からは白頭大幹の尾根と鳥項山（チョハンサン）方面の眺めが開け、山頂近くの展望地では俗離山（ソンニサン）一帯の山並みが幾重にも重なる景色を楽しめます。春は渓谷の新緑と野の花、秋は岩稜と溶け合う紅葉が特に評判のいい山として知られています。

コース1 — ヨンチュゴル入口トイレ → 風穴地帯

経由: ハクチョンジョン（学天亭） → ヨンチュゴル入口トイレ → ムダンソ → テヤ山自然休養林 → テヤ山自然休養林駐車場 → 分岐点 → テヤ山自然休養林内の休憩所 → ヘビ・毒虫注意の標識 → トゥンドク山登山案内図 → トゥンドク山道標 → 国家地点番号 → 救助標識 → トゥンドク山道標・国家地点標識 → トゥンドク山への道 → 山岳位置標識

登山口へのアクセス: ハクチョンジョンとヨンチュゴル入口へは、聞慶（ムンギョン）市加恩邑（カウンウプ）莞章里（ワンジャンリ）方面から入るのが一般的とされています。近くにテヤ山自然休養林があるので、車で行くなら休養林の駐車場を使うのが定番。公共交通なら、聞慶の市街地から莞章里方面の農漁村バスに乗って、そこから歩いてアプローチするかたちが基本です。

特徴・おすすめの人: 三つのコースのなかで最も長く、純標高差も大きいので、体力の消耗はなかなかのものです。序盤はヨンチュゴルの渓谷沿いに、ムダンソなどの淵を眺めながら進むので、渓谷トレッキングらしい趣を存分に味わえます。テヤ山自然休養林の区間では、木陰の下をゆるやかに歩く散策路のような雰囲気も。ただし後半のトゥンドク山方面の稜線は道標頼りに続いていくので、ある程度山歩きの経験がある方、長い距離を承知のうえで静かな山道を求める方に向いたコースだと思います。

経由: 救助表示柱 → 案内標識 → ミルジェ（밀재） → 分岐 → 象岩 → ノンバウィ（農岩） → 大耶山山頂付近の展望地 → 大門岩（手前） → 大門岩（奥） → 転落注意標識柱 → 転落注意 → 大耶山付近の展望地 → 大耶山山頂 → ウェイポイント40 → 中大峰展望地

登山口へのアクセス: ミルジェを経由することから、聞慶（ムンギョン）側の渓谷入口から尾根へ取り付く区間と見られます。公共交通機関や駐車場については公共データ上の登録が確認できなかったので、訪れる前にKakaoMapやNaver Mapで実際の進入路と駐車できるかどうかを下調べしておくのが安心です。

特徴・おすすめの人: 三つのコースのなかで、大耶山の象徴とも言える象岩・ノンバウィ・大門岩をすべて通る、もっとも代表的な山頂コースです。ミルジェを越えたあたりから岩稜帯が本格的に始まり、大門岩の手前と奥を通過する区間では、実際に「転落注意標識柱」と「転落注意」の表示が立て続けに確認できるほどで、手足をフルに使う急斜面・岩稜が続きます。山頂付近の展望地と中大峰展望地からの眺めが素晴らしく、写真を撮るのにも打ってつけのコース。岩稜歩きにある程度慣れた登山者におすすめです。

登山口へのアクセス: 大耶山探訪支援センターと大耶山龍湫駐車場が道標の経由地として実測されているので、3つのコースの中ではこのコースがいちばんアクセスしやすいほうです。探訪支援センターの近くにトイレがあることが確認できますし、車で行く場合は龍湫駐車場を起点にするのが一般的なようです。公共交通機関なら、聞慶市内バスで近くのバス停まで行き、そこから歩いてアクセスする方法が知られています。

特徴・おすすめの人: 探訪支援センターから出発して渓谷と尾根を行き来しながら、ソンニョマグィトンシ岩のような名の知れた奇岩を過ぎて月影台に至るコースです。展望地点が2か所（大耶山展望地点、展望地点）確認できるので、眺めを楽しみながら歩くのにぴったりですね。先の2コースに比べると序盤のアクセスが楽で、トイレなどの設備も整っているので、初めて大耶山を訪れる登山者にも、下山路として使うにも無理のないコースと言えそうです。

難易度・路面・注意点

写真: 韓国観光公社 観光写真ギャラリー（忠清北道槐山郡青川面三松キル205-182）· 公共누리

管内の登山道の総延長（莞荘里区間5.26km + 区間名不明4.85km、合計10.11km）を基準にすると、データ上の最高難易度は「やさしい」として登録されています。ただしこれは行政区単位で登山道全体をひとまとめに評価したもので、山頂周辺の実際のコース（構造表示木・龍湫谷・探訪支援センターの各コース）は、実測GPXをもとに計算するといずれも最高難易度（★★★★★）になります。路面についての情報は別途登録されていませんが、コースの経由地の名前（ゾウ岩・農岩・大門岩・孫娘マグィトンシ岩）からも察しがつくように、山頂周辺は岩稜・岩場の比率が高く、雨の日のスリップや冬場の凍結にはとくに注意が必要です。公共データ上、危険地域のPOIは0件、展望地点のPOIも0件として集計されていますが、実測した経由地では大門岩の区間で「転落注意標識木」と「転落注意」の表示がそれぞれ確認され、コース3では「大耶山展望点」と「展望点」の2か所が確認されています。つまり現場には、実際に展望ポイントと注意区間が存在するわけです。避難小屋は0か所、登山口・下山口は2か所という登録内容なので、非常時に逃げ込める施設がないまま歩くことになる点は頭に入れておきたいところです。

距離と所要時間

市内に登録されている区間（莞荘里区間・区間名不明の区間）をすべて足し合わせると、データ上の所要時間は上りが253分、下りが176分。これを距離に換算すると、上りの平均ペースはおよそ25分/kmになります。ただしこの数字は市内の複数区間を合算した累計値なので、特定の一コースの所要時間と取り違えないよう注意してください。実際の山頂コースごとの所要時間は、先ほどの実測コース表（片道で約3時間10分〜4時間30分）を基準に考えるのが正解です。3コースいずれも往復なら6〜9時間ほどかかるので、日帰りでも十分こなせる範囲ではありますが、早めの出発と、下山にゆとりを持たせた時間配分は必須です。市内に避難小屋は0か所なので、一泊前提の山行インフラはありません。日帰りを前提に計画を立てるのが一般的です。

アクセス（公共交通機関・駐車場）

写真: 韓国観光公社 観光写真ギャラリー（慶尚北道聞慶市加恩邑大也路1290）· 公共누리

大也山（テヤサン）は聞慶市の加恩邑あたりにあるので、鉄道でのアクセスはちょっと厳しめ。公共交通機関で行くなら、聞慶総合ターミナルか加恩市外バス停留所から莞蒼里（ワンジャンリ）方面の農漁村バスに乗り換えるルートが一般的です。ただ、この路線は運行間隔がかなり広いという話なので、時刻表は事前にしっかり確認しておいたほうが安心です。公共データ上では周辺のバス停や駐車場として登録されているPOIは見つからないのですが、実測コースには「大也山龍湫（ヨンチュ）駐車場」が登山口近くの地点として出てくるので、車で行く場合はここを目的地にする人が多いようです。正確な進入路やリアルタイムの交通情報は、韓国の地図サービスに強いKakaoMapかNaver Mapで確認するのがおすすめ（Googleマップは韓国国内の公共交通や細い道の情報が不正確なことが結構あります）。

シーズン・天候・装備

大耶山（テヤサン）は渓谷と岩稜が組み合わさった山だけに、春（4〜5月）の新緑と野草、そして秋（10〜11月）の紅葉シーズンが登山に向いた時期とされています。夏はヨンチュゴル渓谷の涼しさを楽しめますが、雨天時は渓谷の水量が急に増えたり岩稜区間が滑りやすくなったりするので注意が必要。冬は山頂周辺の岩稜が凍りつきやすいため、アイゼンやスパッツといった冬装備が欠かせません。登山の際は基本として登山靴、トレッキングポール、手袋（岩稜区間で手をかけるため）を用意しておくと安心です。園内に湧水場や給水所は特に確認できないので、飲み水は十分に持っていきましょう。

外国人旅行者向けのヒント

大耶山（テヤサン）はローマ字で Daeyasan と表記され、主な地名は龍湫渓谷（Yongchu Valley）、月影台（Wolyeongdae）、ミルジェ峠（Miljae Pass）、大門岩（Daemunbawi）などと併記されます。国立公園ではない一般の登山道なので、入山許可や入場料の制度は特に確認されていませんが、訪問時は現地の案内板や自治体のお知らせで最新情報をチェックしておくと安心です。トイレは龍湫谷の入口（コース1）と大耶山探訪支援センターの近く（コース3）にありますが、湧き水の水場や給水施設はデータ上存在しないので、飲み水は必ず事前に用意していってください。地図アプリは Google マップよりも KakaoMap か Naver Map のほうがおすすめです。どちらも英語インターフェースに対応しているので、外国人旅行者でも問題なく使えます。山頂周辺のコースには岩稜帯や落下注意の標識がある区間もあるため、単独よりも誰かと一緒に登るのが安心。携帯電話の電波が弱い区間もあるので、登山計画は事前に周囲の人に伝えておきましょう。
