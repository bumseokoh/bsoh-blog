概要

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道束草市）・公共누리

点鳳山（チョムボンサン、点鳳山）は江原道の麟蹄郡と襄陽郡の境界にそびえる山で、山頂の標高は1,424mに達しますが、今回のガイドで紹介する代表的なコースは、山頂圏の展望ポイント（標高1,131m）まで登るルートを中心にしています。稜線の鞍部にあたる部分は「コムベリョン(곰배령)」という名前でよく知られており、ユネスコ生物圏保護区に指定されるほど原生林と野生の花々の群落がそのまま残されている山として有名です。データ上の難易度は「易しい」に分類されていますが、実際には往復4時間前後かかる、傾斜のゆるやかな登山コースで、日帰りでも十分楽しめます。とはいえ、この山域の登山道の総延長はかなりのものなので、いくつかの区間を通して縦走するなら1泊以上を見込んでおいたほうがいいでしょう。

점봉산は、雪岳山国立公園に近い、いわゆる肉山系の山で、鋭い岩峰よりもなだらかな稜線と鬱蒼とした広葉樹林が特徴です。よく知られている地形といえば、なだらかな草原地帯が広がる곰배령一帯でしょう。ここは木のない広い草地の稜線が広がっていて、他の江原道の山々とは一線を画す風景を見せてくれます。谷筋には大小の滝や淵が点在し、入口から頂上付近へと続く区間は、緩やかな渓谷沿いの散策路から始まって、徐々に高度を上げていくかたちになっています。岩場や岩稜帯はあまり目立たず、全体としては穏やかな印象を与える山容です。

登山の雰囲気

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 인제군) · 공공누리

入口を出発してしばらくは、渓谷沿いに続く森の道を歩きます。夏でもひんやりとした木陰が心地よく、汗をかいてもすぐに涼しさを取り戻せる区間です。原生林に近い広葉樹林帯を抜けていくうちに、あちこちに顔を出す野生の花々や豊かな植生に出会えるのが、この山行いちばんの魅力だと思います。徐々に標高を上げていくと視界がぱっと開けてきて、コンベリョン（곰배령）山頂の展望ポイント付近では、四方に広がる稜線と草原地帯のすっきりとした眺めが待っています。急な坂道や危険な区間はほとんどなく体感的な難易度は低めですが、その分距離が短くないので、完歩するにはそれなりの体力が要ります。季節ごとの楽しみ方としては、春の野生の花、夏の新緑と渓流のせせらぎ、秋の紅葉が特におすすめだと言われています。

※出典：韓国登山・トレッキング支援センター「100大名山」GPXデータ（距離・標高・所要時間・難易度）・人気度は参考値です

코스1—入口→クムベリョン山頂

経由：民間有料駐車場 → 売店 → 駐車場トイレ → 外来種侵入防止エアガン → 入口 → チョムボンサン生態管理センター → 外来種侵入防止エアガン → 滝 → 分岐点 → 休憩所 → クムベリョン奥の一軒家 → 民間売店トイレ → クムベリョン山頂展望ポイント → クムベリョン山頂

登山口へのアクセス：チョムボンサン・クムベリョンの探訪路入口は、江原道인제郡キリン面ジンドンリ一帯にあります。公共交通機関だけで行くにはちょっと不便なところで、ソウルなど首都圏からだと、東ソウル総合バスターミナルから인제・ヒョンリ方面の市外バスに乗り、ヒョンリでさらに郡内バスかタクシーに乗り換えてジンドンリ（クムベリョン入口）まで向かうのが一般的なようです。バスの本数が少ないので、正直マイカーで行った方がずっと楽ですし、入口付近には民間の有料駐車場も用意されています。

特徴・おすすめの人：序盤の谷筋は勾配が緩くて木陰も多いので、家族連れや登山初心者でも無理なく登れる雰囲気です。チョムボンサン生態管理センターを過ぎたあたりからは原生林特有の植生を眺める楽しみが出てきて、クムベリョン山頂展望ポイント付近に広がる大草原の景色は、このコースいちばんの見どころと言っていいでしょう。急な坂道が少ないので体力的な負担もそれほど大きくなく、それでいて山頂級の展望が味わえるので、自然観察をしながらのんびり歩きたい人には特に向いているコースだと思います。

難易度・路面・注意点

写真:韓国観光公社観光写真ギャラリー(江原特別自治道麟蹄郡)・公共누리

山林庁の登山路空間情報によると、点鳳山のデータ上の最高難易度は「易しい」となっており、管内に登録されている区間は3つ、総延長は29.96kmに及びます。路面についての情報は別途提供されていませんが、全体的には土の道や緩やかな散策路として知られているため、岩場でのスリップの危険性はそれほど大きくないようです。ただ、公共データ上では危険地域・眺望ポイントともに0件となっており、特別な安全施設や展望案内設備は確認できません。また、登山口・下山口は合わせて9か所登録されていて、複数の方向からアプローチできる山であることがわかります。雨天時は谷筋の水量が増えることがあるので、滝や渓谷区間を通過する際は注意が必要ですし、冬場は凍結する区間も出てくるため、アイゼンなど冬山装備なしでの登りは厳しいかもしれません。

距離と所要時間

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 인제군) · 공공누리

点봉山エリアの登山道全区間(3区間の合計)を見ると、データ上では上りが合計543分、下りが合計381分となっており、これを換算すると上りの平均ペースはおよそ18分/kmです。これはエリア内の全区間を積み上げた数値なので、特定の一つのコースの所要時間と勘違いしないよう注意してください。代表的なコースである入口→곰배령(コムベリョン)山頂展望ポイントの区間は、実測GPXに基づく計算で片道およそ1時間59分。往復だと4時間前後になるので、日帰り登山でも十分こなせる距離感です。ただ、곰배령周辺の複数の登山道を縦走したり、隣接する雪嶽山(ソラクサン)方面の稜線まで足を延ばす場合は総距離がかなり伸びるので、1泊以上の日程を組んだほうが安全です。

行き方(公共交通機関・駐車)

写真:韓国観光公社観光写真ギャラリー(江原特別自治道麟蹄郡)・公共ヌリ

首都圏から向かう場合は、東ソウル総合ターミナルから麟蹄(インジェ)行き、または賢里(ヒョルリ)行きの市外バスに乗り、賢里市外バスターミナルで鎮洞里(コムベリョン)方面の郡内バスかタクシーに乗り換えるのが一般的なルートとして知られています。バスの本数が少なく乗り換えも必要になるので、出発前にKakaoMapやNaver Mapでリアルタイムの公共交通機関のルートと時刻表を必ず確認しておくことをおすすめします。車で行く場合は、ソウル襄陽高速道路などを使って麟蹄方面に入り、そこから鎮洞里方向へ向かうことになります。入口付近には民間の有料駐車場があるので、そちらを利用できます。ちなみに公共データ上では、この付近のバス停や公営駐車場は集計されていないので、民間施設への依存度が高い登山地だという点は頭に入れておいたほうがよさそうです。

シーズン・天気・装備

写真：韓国観光公社観光写真ギャラリー（江原特別自治道麟蹄郡）・公共누리

チョムボン山は春の山野草開花期（4~5月）と秋の紅葉シーズン（9月末~10月）が登山のベストシーズンとしてよく知られていて、夏場も鬱蒼とした木陰のおかげで比較的涼しく歩けます。ただ、夏の集中豪雨のときは渓谷の水量が増えたり落石の危険もあるので、事前に天気予報をチェックしておくのが大事です。冬は凍結や積雪で体感の難易度がぐっと上がるので、アイゼン・スパッツ・防寒装備は必須と考えてください。基本装備としては登山靴、着替え、十分な飲み水（湧き水スポットがはっきりしないので必ず自分で用意すること）、ヘッドランプ、非常食あたりを揃えておくと安心です。コンベリョン一帯は入山予約制が敷かれていることがあるので、訪れる前に予約が必要かどうか確認しておくと安全です。

外国人旅行者向けのヒント

写真：韓国観光公社 観光写真ギャラリー（江原特別自治道 麟蹄郡）・公共누리

占鳳山（チョンボンサン、Jeombongsan）を代表する名所であるコムベリョンは、ローマ字だと「Gombaeryeong」と表記され、頂上の展望ポイントは「Gombaeryeong Summit Viewpoint」といった案内になります。このエリアは生態系保護のため入場予約制や人数制限がかかっていることがあるので、出発前に必ず国立公園または管理事務所に予約の要不要を確認しておきましょう。トイレは駐車場と売店の近くに用意されていますが、登山道内の水飲み場については公共データ上確認が取れないので、飲み水は各自でしっかり持参する必要があります。グーグルマップは韓国国内の登山道情報が不正確なことが多いので、実際のルート検索や公共交通機関の確認にはKakaoMapかNaver Mapアプリを使うことを強くおすすめします。山行中は携帯電話の電波が弱くなる区間もあり得るので、出発前にオフライン地図をダウンロードしておく、同行者に山行プランを共有しておくといった、基本的な安全対策はきちんと押さえておくといいでしょう。
