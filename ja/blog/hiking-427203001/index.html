概要

写真：韓国観光公社観光写真ギャラリー（全羅南道光州統合特別市長城郡北下面、白羊寺）・公共누리

白巖山（ペガムサン）は、全羅南道長城郡と全羅北道淳昌郡・井邑市の境界にまたがってそびえる山で、内蔵山国立公園の北側エリアを形成しています。山頂部は上王峰で、登山道の空間情報に登録された数値では769mと772mの2つの値が併存していますが、この記事では山頂の標高を772mと表記します。山全体が国立公園区域に含まれ、千年の古刹・白羊寺（ペギャンサ）を抱いていることから、寺院巡りと登山を同時に楽しめる場所として広く知られています。登山道の空間情報上では登録区間の最高難易度は「易しい」となっていますが、実際に山頂圏を結ぶコースは距離8〜10km、累積標高差480〜620mに達し、往復するとなかなかの体力を要するため、日帰り登山自体は十分可能ですが、早めの出発をおすすめします。

山容と地形

写真：韓国観光公社観光写真ギャラリー（全羅南道・光州広域市チャンソン郡プッカ面、白羊寺）・公共누리

白岩山は、なだらかな尾根が続く土山と、鋭い岩稜が組み合わさった、なかなか懐の深い山容を見せてくれます。山頂部にあたる上王峰(769～772m)から南へ延びる稜線をたどると白鶴峰(669m・678mの二地点が登録されています)があり、鶴が翼を広げた姿に似ていることからその名がついたと伝えられる岩峰帯が、白羊寺の裏手を屏風のように取り囲んでいます。このほか獅子峰(748m)が尾根筋のもう一つの軸をなしていて、南側のカッパウィ(笠岩)区間には、笠(帽子)にそっくりな独特の形をしたカッパウィ山頂石(668m)があり、白岩山を代表する岩の名所の一つに数えられています。全体としては山頂部から稜線にかけて岩稜や展望岩が多く、一方で谷筋や斜面は広葉樹中心の土山地形になっているのが特徴です。

登山の空気感

写真：韓国観光公社 観光写真ギャラリー（全羅南道長城郡北下面）・公共ヌリ

登山口はだいたい森の道から始まります。白羊寺(ペギャンサ)方面はヒノキやコナラなどの広葉樹林が茂る、散歩コースのような穏やかな雰囲気からスタートし、標高が上がるにつれて白鶴峰(ペンハクボン)の岩稜の眺望が開けてくる区間へとつながっていきます。南倉渓谷方面はモンゲ滝を通る渓谷登山の色合いが強く、水音を聞きながら歩く区間が多いのが特徴です。杉の入口からカッパウィ(甲岩)へ登るコースは、後半に転落の危険がある区間を抜けて頂上の展望台へたどり着く、なかなか緊張感のある山行になります。季節ごとの表情としては、春は新緑と渓谷の水、夏は深い緑陰と渓谷めぐりが楽しめ、何より秋の紅葉がこの山を代表する景色として名高く、冬になると稜線の岩場が雪と氷に覆われ、まったく違う顔を見せてくれます。

コース1 — カイン民泊村入口 → 白鶴峰

📏 10.09km ⛰️ 617m 獲得標高 ⏱️ 3:33 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地: 白羊探訪支援センター → 案内板 → 一柱門トイレ → 分岐点 → 休憩所 → カイン民泊村入口 → カイントイレ → 白羊水辺の道 → 博物館トイレ → 白羊寺博物館 → 白羊寺駐車場 → 白岩谷自然観察路 → 救命ボックス → 自然観察路フォトゾーン → 自然観察路休憩所

登山口へのアクセス: 白羊寺方面はこの山の代表的な玄関口で、長城方面から市内バスでアクセスし、白羊寺駐車場を利用するのが一般的です。白羊寺自体が観光地としてもよく知られているので、アクセス路は比較的しっかり整備されているほうだと思います。

特徴・おすすめの人: 白羊探訪支援センターから白羊寺の境内、博物館、自然観察路を順に巡る構成で、序盤はお寺めぐりを兼ねたなだらかな森の道、後半に進むにつれて白鶴峰の岩稜に向けて標高を上げていく本格的な登山へと表情を変えていきます。3つのコースの中では距離も標高差も一番大きいので、体力に自信のある方、あるいは白羊寺の寺院風景と山頂からの眺望を両方楽しみたいという方に向いているコースです。

登山口へのアクセス: ナムチャン渓谷方面の登山口で、スンチャン方面から入るのが一般的。ナムチャン国立公園駐車場を起点にするケースが多いです。近くにペンションがいくつもあることからも分かるように、宿泊とセットにした山行も組みやすいエリアですね。

特徴・おすすめの人: 序盤からモンゲポクポ(夢渓滝)を通る渓谷歩きが長く続くのが特徴で、道標には滝周辺に「落石注意」「危険区域」の表示が出ているので、雨上がり直後は特に気をつけたいところです。水音を聴きながら歩く渓谷山行が好きな方にはぴったりのコースだと思います。

コース3 — 杉の木 → カッパウィ(甲岩)頂上

登山口へのアクセス: 杉の木林を抜けていく登山口で、入口には公園自然保存地区が指定されており、まず自然保護区間を通過することになります。他の2コースに比べるとアクセス情報があまり知られていないので、事前に地図アプリでルートを確認しておくのがおすすめです。

特徴・おすすめしたい人: 杉やリギダマツの林を抜けた後半でカッパウィ頂上へと登っていくコース構成で、道標に「転落危険」「転落注意」の表示が2回も出てくるほど、頂上付近の岩稜帯は緊張感があります。その分、カッパウィ手前からの眺めやカッパウィ展望台からの眺め、亀岩といった見どころがぎゅっと詰まっているので、岩場の展望や写真撮影が好きな登山者にはぴったりのコースだと思います。

距離と所要時間

写真：韓国観光公社観光写真ギャラリー（全南光州統合特別市長城郡北下面）・公共ヌリ

管内の登山道は総延長19.66kmですが、これは複数コースを合算した数字で、単独コースの距離ではありません。上り375分・下り264分というデータも管内全区間を積み上げた数値なので、一つのコースの所要時間だと勘違いしないよう注意が必要です。これを距離で割った平均の上りペースはおよそ19分/kmとなります。このペースを基準に考えると、山頂圏の3コースはそれぞれ距離8〜10km区間なので、片道約2時間53分〜3時間33分かかる計算になります。往復だと休憩時間を含めて6〜8時間前後を見ておくのが一般的で、3コースともに日帰り登山で十分行ける距離であり、1泊が必要な山ではありません。ただし片道3時間を超えるコース1（カイン民宿村入口→白鶴峰）は、往復するなら朝早めの出発をおすすめします。

行き方(公共交通機関・駐車場)

사진: 한국관광공사 관광사진 갤러리 (전남광주통합특별시 장성군 북하면) · 공공누리

白羊寺方面の登山口へは、KTXや無窮花号が停車する長城駅を起点に、長城市外バスターミナルや長城駅から白羊寺行きの市内バスに乗るのが一般的なアクセス方法です。光州広域市から市外バスで向かうという手も、よく使われています。南倉渓谷・夢渓の滝方面の登山口は淳昌郡側から入るのが基本で、杉の木登山口についても近くの集落を経由してアプローチすることになります。ただ、登山道の空間情報にはこの山域で登録済みのバス停・駐車場の地点データが見当たらないため、実際のバスの時刻表や停留所の場所、駐車場の有無については、出発前に必ずKakaoMapやNaver Mapで「白羊寺」「南倉国立公園駐車場」「夢渓の滝」などを検索し、実際のルートと駐車の可否をご自身で確認されることをおすすめします。

季節・天気・装備

写真: 韓国観光公社 観光写真ギャラリー（全羅南道光州統合特別市長城郡北下面）・公共누리

秋（だいたい10月末〜11月頭）は白羊寺の紅葉で特に有名で、この時期はどうしても人が集中しがちです。春（4月頃）は新緑がきれいで、渓谷の水量も増えて夢渓瀑布とあわせて楽しめる季節。夏は渓谷沿いの登山が涼しくて気持ちいいんですが、梅雨明け直後は夢渓瀑布付近で落石や危険区間が出やすいので、そこだけは油断せず気をつけてください。冬は山頂稜線とカッパ바위(甲岩)周辺の岩稜区間が凍結しやすく、体感の難易度がぐっと上がるので、アイゼン・スパッツといった防寒・防氷装備は必ず持っていきたいところです。共通で必須なのは登山靴、トレッキングポール、余裕を持った飲料水（登山道の空間情報上、給水所が確認できていないので全コース分の水を持参する必要があります)、非常食、レインウェアあたりが基本セットになります。

外国人旅行者へのアドバイス

写真:韓国観光公社観光写真ギャラリー（全南光州統合特別市長城郡北下面）・公共누리

主要な地名のローマ字表記は次のとおりです。白岩山 Baegamsan、上王峰 Sangwangbong、白鶴峰 Baekhakbong、갓바위(カッパウィ) Gatbawi、白羊寺 Baekyangsa Temple、夢渓の滝 Monggyepokpo Falls。この山は国立公園（内蔵山国立公園）のエリアに含まれていて、韓国では2023年5月から国立公園の入場料が全面的に廃止されているので、基本的には山の入場料なしで歩けます。ただ、白羊寺の境内見学については、細かい部分は現地の案内板で確認しておいたほうがいいでしょう。トイレは白羊探訪支援センター・一柱門・가인(カイン)・博物館の近くで確認できますが、水飲み場は登山道の空間情報上に登録された地点がないので、出発前に水は多めに用意しておくと安心です。地図アプリはGoogleマップだと韓国国内の徒歩ルート案内が不正確なことが多いので、KakaoMapかNaver Mapを使うのがおすすめです。安全面では、夢渓の滝付近の落石区間と갓바위(カッパウィ)付近の転落危険・転落注意区間が実測ルート上で確認されているので、雨上がり直後や凍結期にはこの区間でスピードを落とし、できれば単独ではなく誰かと一緒に歩くようにしてください。
