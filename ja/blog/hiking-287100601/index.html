概要

写真: 韓国観光公社 観光写真ギャラリー · 公共누리

摩尼山（マニサン、Manisan）は仁川広域市江華郡華道面にある山で、山頂には檀君の建国を祀る祭天施設「塹星壇（チャムソンダン）」が鎮座しており、江華島を代表する歴史散策の山として広く知られています。実測コースデータによると山頂の最高標高は491mで、山自体はさほど大きくないものの、稜線と岩稜が入り混じっているため、距離は短くても登り下りの体感的なアップダウンはなかなかのものです。データ上のコース難易度は最高でも「中級」レベルに分類されていて、各コースの片道距離は3〜7km程度なので、往復しても一日で十分に歩き切れる日帰り登山コースとなっています。

山の姿と地形

摩尼山は西海と江華島南端の干潟を見渡せる位置にそびえる山で、全体としては岩稜と土山が入り混じった地形をしています。頂上部は一つの尖った峰ではなく、複数地点に分かれて登録されているのが面白いところで、実測資料でも摩尼山頂上(491m)、摩尼山頂上(470m)、摩尼山頂上(488m)という3地点がそれぞれ確認できます。これは塹星壇周辺の頂上部が、なだらかに連なるいくつかの岩峰と祭壇跡で構成されているためで、測量地点によって標高表記が少しずつ変わってくると理解しておけばいいと思います。頂上への登り区間には花崗岩の岩盤があちこちに露出していて、特に分岐コース側には「滑落注意」「転落注意」「転落事故危険区間」といった道標が実際に設置されており、急勾配の岩稜区間が含まれていることがうかがえます。逆に含虚洞天渓谷側の低地は、森が生い茂った土山らしいなだらかな地形で、キャンプ場と渓谷が組み合わさった感じになっています。

登山の雰囲気

摩尼山の登山は、前半の渓谷・森林区間と後半の稜線・岩稜区間とで雰囲気がはっきり分かれるのが特徴です。函虚洞天方面から入ると、渓谷沿いに続く木陰の道がしばらく続き、夏場でも比較的ひんやりとしていますが、頂上に近づくにつれて木々が減り、花崗岩の岩肌が現れて視界が開けてきます。摩尼山入口コースは、塹星壇や頂上付近から西海と干潟を見下ろす開放的な眺望が得られるため、距離自体は短くても、頂上に着いたときの達成感と眺めを両方味わえる山として知られています。春・秋は稜線からの眺めが格別に澄み渡り、夏は渓谷区間の緑がいっそう濃くなり、冬は岩稜区間に雪や氷が積もるため、同じコースでも体感の難易度がかなり変わってきます。

コース1 — 入口トイレ → 頂上

📏 6.07km ⛰️ 463m 獲得標高 ⏱️ 2:17 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

経由地: ハムホドンチョン → ハムホドンチョン駐車場 → ハムホドンチョン第2・第3駐車場 → キャンプ場前マンナムスーパー → 入口トイレ → 第1駐車場 → イレガーデン → 雲渓谷スーパー → 休憩所 → 入口券売所 → 売店 → トイレ → 第2キャンプ場 → 分岐点 → ハムホジョン

登山口へのアクセス: ハムホドンチョン方面の登山口は江華郡花道面側からのアクセスになります。近くにハムホドンチョンのバス停があるので、江華市内(江華ターミナル)から郡内バスで入ることも可能です。ただ、正確な運行本数やバス停の場所は現地で確認したほうが確実だと思います。

特徴・おすすめタイプ: 序盤から渓谷やキャンプ場、売店、スーパーなどの施設が集中しているので、登山前後に一息ついたり物資を買い足したりするのが楽なコースです。緑濃い渓谷沿いの道からスタートして、なだらかに高度を上げていく構成になっているため、いきなり急な傾斜に放り込まれるより、じわじわ体をほぐしながら登りたいという人に向いています。分岐点を過ぎてハムホジョンに至る後半になると、雰囲気が尾根道らしいものに変わっていきます。

取り付き地点へのアクセス: マニ山入口バス停や華道ターミナルバス停を使ってアクセスでき、江華ターミナルで郡内バスに乗り換えてマニ山国民観光地入口まで入るのが一般的なルートです。経由地にマニ山観光地の無料駐車場があるのは確認できますが、繁忙期の週末は混雑しがちなので、公共交通機関の利用も合わせて検討しておくと安心です。

特徴・おすすめの人: マニ山国民観光地入口にはチケット売り場や食堂、コンビニなどが揃っていて、アクセスのしやすさと利便性では一番の代表コースと言えます。頂上直前には塹星壇を通過し、頂上部と展望ポイントの2箇所で西海と干潟方面の眺めを楽しめるので、マニ山に初めて訪れる人や塹星壇見学も兼ねたい登山者に一番おすすめのコースです。ただし経由地に「マニ山薬水場」という名前の地点はあるものの、実際に飲めるかどうかや管理状態は現地で確認する必要があるので、飲み水は別途用意しておくのが無難です。

登山口へのアクセス: コース1・2と合流する分岐点からスタートする区間なので、単独で公共交通機関を使って入るというより、ハムホドンチョンやマニ山入口方面から入山してから続けて歩くケースがほとんどです。

特徴・おすすめの人: 3つのコースの中で距離は一番短いんですが、「滑落注意」「転落注意」「転落事故危険区間」といった危険区間の道標が立て続けに出てくるのが最大の特徴です。短い距離に高低差がぎゅっと詰まっているので体感の傾斜がかなり急で、岩稜帯での注意も特に必要になるため、ある程度山慣れした人向けだと思います。初心者の方は、雨の日や冬場はこの区間を避けておくのが無難です。

距離と所要時間

摩尼山は片道3〜7km、往復しても半日から一日あれば十分に歩ける日帰りの山です。代表コースの摩尼山入口→頂上は片道約2時間27分(6.84km)、入口トイレ→頂上は片道約2時間17分(6.07km)、分岐点→頂上は片道約1時間33分(3.23km)というのが目安の数字で、往復だとだいたい3〜5時間くらいの幅に収まります。ちなみに管内の登山道を全部つなげると28.27km(複数区間の合計)になり、データ上は上りの累計が558分、下りの累計が386分となっていますが、これは特定コースの所要時間ではなく管内全区間を足し合わせた数字なので、「このコースにこんなにかかるのか」と勘違いしないよう注意してください。この数字を換算すると平均の上りペースはだいたい1kmあたり20分ほどになるので、上で挙げた各コースの片道タイムもこのペースを基準に、自分の体力に合わせて時間配分を考える際の参考にしてもらえればと思います。

行き方(公共交通機関・駐車場)

公共交通機関を使う場合は、江華(カンファ)ターミナルから郡内バスに乗ってマニ山方面へ向かい、ハムホドンチョン、テサ村、マニ山入口、華道(ファド)ターミナルなどのバス停で降りて登山口に入るルートになります。ソウル方面からだと、新村(シンチョン)や仁川(インチョン)あたりから江華行きのバスに乗って江華ターミナルまで行き、そこで乗り換えるのが一般的です。バスの本数はそれほど多くないので、事前にKakaoMapやNaver Mapでリアルタイムのルートと運行間隔を確認しておくのがおすすめです。マイカーで行く場合は、マニ山入口コースの経由地として出てくるマニ山観光地無料駐車場が使えますが、公共データ上で正式に登録された駐車場POIは見当たらないので、駐車スペースの広さや繁忙期の混雑具合については現地で改めて確認したほうが安心です。ハムホドンチョン方面から入る場合も、近くにハムホドンチョン駐車場や第2・第3駐車場などが経由地として表示されるので、参考にしてみてください。

シーズン・天気・装備

사진: 한국관광공사 관광사진 갤러리 (인천광역시 강화군 화도면 해안남로1114번길 6) · 공공누리

マニ山に登るなら、断然おすすめしたいのは春(4~5月)と秋(9~11月)です。この時期は稜線から山頂にかけての眺望がすっきり澄んでいて、気温も穏やかで歩きやすいんですよね。夏は谷筋の日陰にちょっと助けられて暑さを多少しのげるものの、湿気と虫対策はマストですし、岩稜区間では汗で足元が滑りやすくなるので油断は禁物です。冬になると山頂付近の岩稜や塹星壇周辺は凍結しやすく、アイゼンと防寒装備がないとかなり厳しい状況になります。特に分岐コースの滑落危険区間は、冬場の通行可否を慎重に見極めたいところです。基本装備としては足首をしっかり支える登山靴、着替え、十分な飲み水、季節に応じた防風・防寒ジャケットを揃え、冬はアイゼンとスパッツ、夏は虫よけスプレーを追加で持っていくと安心です。

外国人旅行者へのヒント

写真：韓国観光公社観光写真ギャラリー（仁川広域市江華郡吉祥面温水里）・公共누리

摩尼山（マニサン）のローマ字表記は「Manisan」で、頂上にある祭天遺跡は「Chamseongdan（塹星壇）」と表記されます。主な登山口は「Manisan-ipgu（摩尼山入口）」「Hamheodongcheon（涵虚洞天）」などの表記で見つけられるはずです。ここは国立公園ではなく道立・郡立の管理区域なので、入山許可自体は不要ですが、観光地エリアへの入場時に料金がかかることがあるので、現地の券売所（摩尼山入口券売所、入口券売所）で確認しておくと安心です。トイレは各コースの入口付近（入口トイレ、摩尼山国民観光地入口付近のトイレ、分岐点付近のトイレ）で利用できますが、中腹から上のエリアには給水スポットが見当たらないので、登る前に飲み水はしっかり持参してください。地図アプリはGoogleマップだと精度がいまひとつなことがあるので、KakaoMapかNaver Mapを使うのがおすすめです。バスの時刻や経路もこれらのアプリで確認するのが確実です。安全のため、分岐コースにある危険区間の標識（滑落注意、転落注意など）は必ず守り、日没時刻を考えると午後遅くの出発は避けたほうがいいでしょう。
