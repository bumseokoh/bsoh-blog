概要

写真：韓国観光公社観光写真ギャラリー（京畿道加平郡）・公共누리

明智山(ミョンジサン)は京畿道加平郡北面一帯にそびえる山で、山頂部の最高標高は1,280m前後、京畿道内でも指折りの高峰として知られています。土の稜線と岩稜が入り混じった山容を持ち、山頂まで続く主要コースは片道8~12km、累積標高差900m以上と、なかなか体力を削られるルートです。登山道の空間情報上の難易度は「中級」に分類されていますが、山頂圏まで登る代表的なコースは実測データ上では上級（★★★★★）に相当し、初心者よりも登山経験がある方向きと言えます。とはいえコース自体は長くても、日帰りで十分踏破できる山でもあります。

山の形と地形

写真:韓国観光公社観光写真ギャラリー(京畝道加平郡)・公共누리

明智山は、基本的には典型的な土山らしいなだらかな稜線を描きながらも、頂上部や峰のあちこちに岩場が混じっている、なんとも面白い構造をしています。頂上は明智1峰(頂上石には1,228mまたは1,247mと表記されていることもあります)と明智2峰(1,231m、近くの1,250峰は1,226mと別記されています)の二つに分かれていて、資料によって標高がちょこちょこ違うのもこの山らしいところです。これはおそらく頂上石・三角点の位置と、実測GPXの最高点(約1,281m)とのズレから来ているのでしょう。なので明智山は「頂上が一つ」というより、明智1峰と明智2峰が並んで立つ双耳峰として捉えるのが正確だと思います。しかも明智山は単独で存在しているわけではなく、西には恋人山(恋人山頂上1,110m)、姜氏峰(820m)、パルンゴル峰(814m)、南には松岳山(松花峰、724m)へと続く山稜の中心に位置していて、いわゆる「明智山〜恋人山縦走」としてセットで語られることが多い、稜線歩きの定番スポットでもあります。谷筋は明智渓谷(明智川)沿いに滝や淵が発達していて、夏場は水遊びスポットとしても知られています。稜線を登るにつれてチョウセンゴヨウの群落や広葉樹の森、頂上部の低木・草地が交互に現れるのも、この山の特徴のひとつです。

登山の雰囲気

사진: 한국관광공사 관광사진 갤러리 (경기도 가평군) · 공공누리

登山口から山頂まで、大きく分けて三つの区間で雰囲気ががらりと変わります。序盤はミョンジ渓谷沿いを歩く緩やかな森の道で、渓流の音と鬱蒼としたチョウセンゴヨウ・ナラの林が重なり合い、日陰が多くて比較的歩きやすい道のりです。中盤に差し掛かると傾斜が目に見えて急になり、石混じりの土道と岩場が交互に現れるので、体力の消耗がぐっと増える区間になります。山頂付近まで来ると視界が一気に開け、ミョンジ山とヨニン山方面の稜線がパノラマのように広がります。特に秋の紅葉が名高く、ミョンジ第2峰周辺は紅葉シーズンの撮影スポットとしてもよく話題に上ります。全体的に、序盤の渓谷トレッキングと後半の急傾斜の稜線登山とがくっきり対照をなすコースなので、体力配分がものを言う山行だと言えるでしょう。

コース1 — 分岐点→明智2峰から眺める明智山1峰

📏 8.43km ⛰️ 1062m 獲得標高 ⏱️ 3:53 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地: 分岐点 → 明智山承天寺 → 明智滝 国家地点番号 → 明智滝 → 明智2峰へ向かう渓谷道 → 通信塔 → 明智2峰付近の秋の紅葉 → 明智2峰から眺める明智山1峰 → 明智山山頂の風景

登山口へのアクセス: このコースの登山口である「分岐点」は、明智山承天寺・明智滝へと続く地点で、通常は明智山入口方面から徒歩で入るルートとして知られています。専用のバス停名までは確認できなかったので、加平の市街地からバスで明智山方面のバス停まで移動し、そこから歩いて向かうのが一般的なようです。

特徴・おすすめポイント: 序盤は明智山承天寺と明智滝を通る渓谷区間が見どころで、通信塔を過ぎたあたりから本格的な尾根の登りが始まります。このコースのハイライトは、明智2峰から明智1峰(山頂)を正面に望む眺望で、特に秋の紅葉が美しいことで知られているので、お寺・滝・紅葉をまとめて楽しみたい方にぴったりです。ただし通信塔を過ぎると急な傾斜が続くので、それなりに体力を使うコースだと思っておいたほうがいいですね。

コース2 — 白屯里終点バス停 → 明智3峰

📏 8.97km ⛰️ 931m 獲得標高 ⏱️ 3:48 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地: 白屯里終点バス停 → 出口・白屯里バス終点 → 分岐点 → 生態保護案内板 → 明智川 → 渓流 → 雨量自動観測装置 → 明智3峰 → 野生花 → 明智2峰 → 明智川の滝 → キャンプヴィル → 白屯里バス終点トイレ

登山口へのアクセス: コース名の通り、白屯里終点バス停からそのまま山行をスタートできるので、3コースの中では公共交通への依存度がいちばん低いのが嬉しいところです。バス停付近にはトイレ（白屯里バス終点トイレ）があることを確認済みなので、山行の前後で使えます。

特徴・おすすめしたい人: バス停からそのままスタートし、明智川沿いを歩いていくと、雨量自動観測装置のあたりから本格的な登りが始まり、明智3峰・明智2峰と尾根伝いに続けて越えていくコースです。渓谷沿いには野生花がたくさん見られることで知られているので、春から秋にかけて花散策も一緒に楽しみたい方、そして延枝峰・姜氏峰方面への縦走を計画している方には、うってつけのスタート地点だと思います。

コース3 — 明智山入口 → 麝香峰

📏 11.92km ⛰️ 1026m 獲得標高 ⏱️ 4:41 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地: 明智山入口 → アンソンチプ → 公衆トイレ → 明智川 → 観光案内図 → 明智山総合案内板 → 自然学習園 → 休憩所 → 栗の木群落地 → 分岐点 → 麝香峰 → 麝香峰付近の野花 → 帳幕峰 → 明智山付近の野花 → 明智山の野花

登山口へのアクセス: 明智山の正面玄関ともいえる登山口で、観光案内図と明智山総合案内板が設置されているので、初めて訪れる人でも入口を見つけやすいです。公衆トイレも入口にあるので、登山前に済ませておけます。

特徴・おすすめの人: 3つのコースの中では距離が一番長く（片道約11.92km）、序盤は自然学習園と栗の木群落地を抜ける緩やかな森の道なので、体を徐々に慣らしながら登っていけます。麝香峰・帳幕峰を経て頂上へ向かうルートなので、いくつもの小さなピークを越えることになり単調さは感じませんが、その分トータルの所要時間が長くなるので、早めの出発と十分な体力が必要です。明智山の代表的な正規コースをじっくり味わいたい方、時間に余裕のある方におすすめです。

難易度・路面・注意点

写真: 韓国観光公社 観光写真ギャラリー（京畿道加平郡）· 公共누리

山林庁の登山路空間情報によると、明智山エリアの登山路のデータ上の最高難易度は「中級」で、路面情報については特に記載がありません。ただ、頂上まで登る3つのコースは実測GPX基準で累積標高差900m以上、距離8~12kmに及ぶため、難易度は★★★★★（上級）と計算されます。これは行政区域単位の統計には低地の緩やかなアプローチ区間も含まれている一方、実際に頂上まで登るコースは後半の傾斜が非常に急なためだと理解できます。路面は一般的に序盤の谷筋区間では土道と岩が入り混じり、稜線上部に近づくほど花崗岩の岩盤地帯が現れるとされているため、雨天時は滑りやすさに特に注意が必要です。施設面では、登山路空間情報の基準で危険地域指定地点0か所、展望地点登録0か所、水飲み場0か所となっており、登録された登山口・下山口は合計6か所です。つまり、案内表示のある避難所や展望台、水飲み施設は事実上ないと考えるべきで、冬場は凍結した岩稜区間で滑落事故のリスクが高まるため、アイゼンの着用は必須です。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（京畿道加平郡）· 公共누리

明智山管内に登録されている登山道の総延長（複数区間を合算した数値で、単一コースの距離ではありません）は22.31kmです。データ上、管内の全区間を積み上げた場合、登りが598分、下りが418分かかるとされていて、これを距離換算すると平均の登りペースはおよそ27分/kmになります。ただこれはひとつのコースにかかる時間ではなく、管内のあちこちの区間をぜんぶ歩いた場合の平均値なので、実際のコース別の所要時間は、前述のコース別表（片道でおよそ3時間48分〜4時間41分）を基準にするのが正確です。往復で計算すると7時間30分〜9時間以上かかることもあるので、早朝スタートと十分な日照時間の確保が欠かせません。明智山には避難小屋がなく、1泊を前提にしたコース設計にはなっていませんが、日帰り登山で無理なく完走できる山です。

行き方(公共交通機関・駐車場)

사진: 한국관광공사 관광사진 갤러리 (경기도 가평군) · 공공누리

明智山の近くには、白屯里終点、陽地マウル、明智山入口、ソンバウィといったバス停があるようです。ソウル・京畿方面からだと、京春線かITX青春列車で加平駅まで行き、加平市内のバスターミナルから明智山方面(白屯里・赤木里方面)行きの郡内バスに乗り換えるルートが一般的によく使われています。バスの本数はあまり多くないので、事前に時刻表をチェックしておいたほうが安心です。登山路の空間情報によると、周辺に登録されている公営駐車場は0か所とのことなので、マイカーで行く場合は路肩駐車や民間の駐車スペースを使うことになるかもしれません。この点は事前に確認しておくのがおすすめです。正確なリアルタイムのルートやバス停の位置については、KakaoMap(カカオマップ)やNaver Map(ネイバーマップ)で「明智山入口」または「白屯里バス終点」を検索して確認することを強くおすすめします。

シーズン・天気・装備

사진: 한국관광공사 관광사진 갤러리 (경기도 가평군) · 공공누리

明知山でいちばん人気があるのは、やっぱり紅葉シーズン（だいたい10月中旬〜下旬）です。特に明知2峰周辺の紅葉は一見の価値ありと言われています。夏場は明知渓谷の滝や淵が水遊びスポットとして賑わいますが、登山道自体には登録された給水所がないので、夏山に行くなら飲み水（1.5〜2リットル以上）は必ず多めに持っていってください。冬場は山頂付近の稜線や岩稜区間が凍結しやすく、アイゼン・スパッツはほぼ必須。積雪が多いとコースタイムが大きく伸びることもあるので要注意です。共通の必須装備としては、登山靴、トレッキングポール、着替え、ヘッドランプ（このコースは距離が長く下山が遅れることもあるので）、そして冬場はアイゼン・スパッツ・防風装備を揃えておくことをおすすめします。

外国人旅行者へのヒント

写真：韓国観光公社観光写真ギャラリー（京畿道加平郡）・公共누리

明智山はローマ字だと「Myeongjisan」または「Myeongji-san」と表記され、代表的な登山口も「Myeongjisan-ipgu（明智山入口）」「Baekdun-ri Bus Terminal（白屯里バス終点）」といった名前で案内すると、現地の人とのやり取りがスムーズになります。入山許可や入場料についての案内は特に見当たらないので、韓国の一般的な国公有林と同じく自由に入れる山だと考えてよさそうですが、念のため現地の案内板で最新情報を確認しておくと安心です。トイレは明智山入口の公衆トイレと白屯里バス終点のトイレが確認できていますが、登山道の途中にはトイレも水飲み場もないので、出発前に済ませておくこと、そして飲み水は必ず持参することをお勧めします。地図アプリについては、Googleマップは韓国の山間部だとルートの精度がいまひとつなことがあるので、KakaoMapかNaverMapを使って実際の登山道と公共交通機関のルートを確認しておくのが賢明です。コース自体が長く、後半は傾斜も急になるので、下山時刻をあらかじめ決めておいて、暗くなる前に下山を終えるようにしましょう。スマホのバッテリーとモバイルバッテリー、それに万一に備えたヘッドランプも持っていくと安心です。
