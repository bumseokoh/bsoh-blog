概要

写真: 韓国観光公社 観光写真ギャラリー（慶尚北道浦項市北区）· 公共ヌリ

内延山（ネヨンサン）は、慶尚北道浦項市北区松羅面一帯にある山で、最高峰の香炉峰は960mと、なかなかの高さを誇ります。山全体が慶尚北道の有形文化遺産と自然景観をあわせ持っていて、登山と渓谷トレッキングを同時に楽しめる場所として知られています。区域内に登録された登山道をすべて合わせると総延長85.75kmという広大な山域になり、公共データ上の登山道の最高難易度は「易しい」に分類されているので、全体的になだらかなコースが多めです。とはいえ山頂方面まで登る主要コースは距離6〜11km、純高低差200〜600m台なので、体力次第では半日から丸一日かかることもあります。ただ、ほとんどのコースは日帰りで十分こなせる範囲です。

山容と地形

写真: 韓国観光公社 観光写真ギャラリー（慶尚北道浦項市北区）· 公共누리

内延山（ネヨンサン）は、尖った頂上がひとつどっしり構えているタイプではなく、いくつもの峰が稜線沿いに連なる多峰型の山容をしています。公共データに登録されている主な峰だけでも、文殊峰（636m）、三枝峰（718m）、内延山仙逸台（342m）、香炉峰（960m）、笠峰（745m）、内延山三枝峰（739m）、鷹峰（835m）、牛脊峰（813m）と実にさまざま。これらの峰が稜線でつながっていて、縦走登山の舞台になっているわけです。全体としては切り立った岩峰よりも、樹林に覆われた「土の山」の性格が強めですが、仙逸台のように削り取られたような岩の展望台が随所に配置されていて、見晴らしのいいポイントでは岩盤地形ならではの開放感もしっかり味わえます。内延山はとくに、宝鏡寺から上流へと続く渓谷部に滝が次々と現れる渓谷地形としても広く知られていて、この渓谷区間は登山と沢トレッキングを兼ねられるコースとしてよく紹介されています。

山登りの感触

写真：韓国観光公社 観光写真ギャラリー（慶尚北道浦項市北区）・公共누리

内延山（ネヨンサン）の山行は、登り口からいきなり鬱蒼としたマツ林とアベマキの群落を抜けていくコースが多く、夏は濃い木陰が暑さをやわらげてくれ、秋にはカエデの群落とナラの群落が入り混じって色とりどりの紅葉道になります。稜線に出ると日本海（東海）が視界に飛び込んでくる展望ポイントが何度も現れ、内陸の山とはひと味違う開放感があります。稜線自体はゆるやかに続いていくのですが、頂上付近では標高差がじわじわ積み重なって、体感の傾斜がはっきりきつくなってきます。ツルウメモドキの群落、ヤドリギ、ミズナラの群落地など、いろいろな植生帯を通る区間が多いので、季節ごとに山道の表情がまるで変わるのが特徴。テンの痕跡が確認できるほど、自然の生態が比較的よく守られている山でもあります。

コース1 — 亭子 → 梅峰

📏 7.06km ⛰️ 328m 獲得標高 ⏱️ 2:19 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

経由: 亭子 → 分岐路 → ベンチ休憩所 → 梅峰 → 上玉 → 内延山の稜線 → 松林 → アベマキ群落地 → テンの痕跡 → ツルウメモドキ群落 → カラムラサキツツジ群落地 → 亭子休憩所 → 東海の眺望 → 東海 → 香炉峰

登山口へのアクセス: 公共交通機関の場合は、浦項の市内から松羅面方面のバスを使うのが一般的です。樹木園近くのバス停で降りて、そこから登山口まで歩くという方が多いようです。マイカーなら近くの空き地や路肩に停める形になりがちなので、事前に地図アプリで進入路の幅と駐車できそうかどうかを確かめておくと安心です。

特徴・おすすめの方: 松林とアベマキの群落を抜けて稜線に出ると、東海が広がる眺望ポイントが何度も現れます。これがこのコース最大の魅力でしょう。梅峰を経て香炉峰まで続く稜線の道は、距離のわりに純高低差がそれほど大きくないので、三つのコースの中では比較的取りつきやすい部類に入ります。山頂からの眺めと稜線散歩、その両方を味わいたい方にぴったりです。

コース2 — 公衆トイレ → 尾根頂上の休憩所

📏 6.26km ⛰️ 614m 獲得標高 ⏱️ 2:35 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由: 公衆トイレ → ハオク渓谷売店 → 上玉里(サンオンニ)展望ポイント → 尾根頂上の休憩所 → ホソバヒカゲスゲ群落地 → 大松 → 大クヌギ → サンカラノキ群落地 → モミジ群落地 → ヤドリギ → ハオク渓谷 → マツブサ群落地 → 内延山三枝峰・東大山展望ポイント → 分岐点 → ミズナラ群落地

登山口へのアクセス: ハオク渓谷方面の登山口です。公共交通の便が比較的少ないため、自家用車かタクシーを使うのが現実的でしょう。渓谷入口の売店付近に小規模な駐車スペースがある場合もありますが、公共データ上で登録された駐車場は確認できませんでした。訪れる前に地図アプリで実際に進入できるかどうかを確認しておくと安心です。

特徴・おすすめの方: 6.26kmという比較的短い距離に純標高差614mが凝縮されているため、三つのコースの中で体感勾配がもっとも急なコースです。ハオク渓谷沿いに登りながら、上玉里や内延山三枝峰、東大山まで見渡せる展望ポイントを何度も通過します。短時間で高度感のある山行と渓谷の景色を両方味わいたい方にぴったりです。大松や大クヌギといった老木級の個体が随所に残っていて、原生林に近い雰囲気を感じられます。

コース3 — 入口・乗用車駐車場 → 樹木園展望台

📏 11.03km ⛰️ 216m 獲得標高 ⏱️ 3:07 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由: 入口・乗用車駐車場 → 障害者専用駐車場 → トイレ → 樹木園トイレ → 展望台への道の入口 → 樹木園展望台 → 分岐点 → サッカッ峰（삿갓봉） → 東屋の休憩所 → 保護樹・ウェソルベギ → ツツジ群落地 → ナラ群落地 → モミジ群落地 → 大岩と眺望スポット → 尾根と野原、そして岩

登山口へのアクセス: 名前のとおり、入口には乗用車専用の駐車場と障害者専用駐車場、トイレが整っていて、3コースの中で登り出しの設備がいちばん充実した登山口です。公共交通機関なら、近くの樹木園バス停で降りて徒歩でアクセスできます。マイカー派にとっては、いちばん気楽に取りつける登山口だと思います。

特徴・おすすめの人: 距離は11.03kmで3コース中もっとも長いのですが、純高低差は216mとゆるやか。アップダウンをこなすというより、長い尾根をのんびり散歩する感覚に近いコースです。樹木園展望台とサッカッ峰を通り、ツツジ群落地、ナラ群落地、モミジ群落地といった多彩な植生の風景をひととおり楽しめます。急な傾斜よりも、長い呼吸でのトレッキングと四季の植生観察を味わいたい方にぴったりです。

難易度・路面・注意点

写真: 韓国観光公社 観光写真ギャラリー（慶尚北道浦項市北区）· 公共ヌリ

公共データ上、内延山エリアの登山道の最高難易度は「やさしい」と表記されていますが、これはエリア全体の登山道（総延長85.75km）を基準にした分類です。頂上方面へ向かう3つのコースは、実測ベースだと星3〜4個クラスの体感難易度になります。路面の詳細情報は別途提供されていませんが、稜線区間には岩場や大きな岩の展望ポイント（コース3の「大きな岩と展望」）が含まれているので、雨の日の滑りには気をつけたいところ。公共データに登録されている危険箇所・展望地点・登山口／下山口の施設POIはいずれも0件で集計されているため、コース内に安全設備や指定展望台が整備されていない前提で山行計画を立てる必要があります。水飲み場も0件なので飲み水は必ず自分で用意すること。避難小屋も0件ですから、天候が急変したときに下山できる時間の余裕をもって出発するのが安全です。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（慶尚北道浦項市北区）· 公共누리

内延山（ネヨンサン）の頂上を目指すコースは6.26kmから11.03kmほど。往復すると12〜22km前後になるので、たいていは日帰りで歩けます。ただし、市に登録されている登山道を縦走のように全部つなげて歩こうとすると総延長85.75kmに達するので、一日では到底さばけません。避難小屋もないことを考えると、何日かに分けて歩くか、宿泊を組み込んだ計画が必要になります。公共データでは市内全区間の累積所要時間が上りで1600分、下りで1114分と集計されていて、これを距離で割ると上りの平均ペースは約19分/kmです。これはひとつのコースの所要時間ではなく全区間を足し合わせたペースなので、個々のコースの実際の所要時間は、上のコース別の表にある推定値（片道で約2時間19分〜3時間7分）を目安にするのが正確です。

アクセス（公共交通機関・駐車場）

写真: 韓国観光公社 観光写真ギャラリー（慶尚北道浦項市北区）· 公共누리（KOGL）

内延山（ネヨンサン）へは、KTX浦項駅か浦項市外バスターミナルを起点にするのが一般的です。駅やターミナルから松羅面（ソンナミョン）方面のバスに乗り換えて向かいます。登山口の近くでは「樹木園」停留所が実際に運行を確認できたバス停で、ここで降りてから徒歩で各コースの登山口までアプローチできます。とはいえバスの本数が多い地域ではないので、事前に時刻表を確認しておくのが安心です。必要なら浦項市内からタクシーを使うのも現実的な選択肢でしょう。

車で行く場合は、コース3の「入口乗用車駐車場」と「障害者専用駐車場」のように実際に利用できる駐車スペースが確認できています。ただし公共データ上、この地域に登録された駐車場POIは0件という集計になっていて、ほかの登山口には公式な駐車場が整備されていない可能性があります。出かける前にKakaoMapやNaver Mapで実際の道路状況と駐車できる場所を確認してから向かうのがおすすめです。

シーズン・天候・装備

写真: 韓国観光公社 観光写真ギャラリー (慶尚北道浦項市北区) · 公共ヌリ

ネヨン山を歩くなら、やっぱり春と秋がいちばん気持ちいい季節。春は新緑にレンゲツツジやカラムラサキツツジの群落、秋はカエデの群落とナラの群落が尾根を染めてくれて、景色の良さは格別です。夏は深い木陰と渓谷が暑さをやわらげてくれますが、湿度が高くにわか雨も多いので、路面が滑りやすくなります。雨対策はお忘れなく。冬は尾根筋や岩場が凍結することがあるので、アイゼンと防寒装備は必須。避難小屋がないことも考えると、日没前に下山を終えられるよう、余裕をもった計画を立てたいところです。共通の持ち物としては、登山靴、多めの水（水飲み場がないので十分な量の飲料水は必須）、ウインドブレーカーやレインジャケット、行動食、ヘッドランプ、トレッキングポールあたりがおすすめです。

外国人旅行者向けのヒント

写真：韓国観光公社 観光写真ギャラリー（慶尚北道浦項市北区）・公共ヌリ

内延山（ネヨンサン）はローマ字で Naeyeonsan と表記します。山頂周辺のピークは Hyangnobong（香炉峰、960m）、Maebong（梅峰、835m）、Samjibong（三支峰、718m）などと併記できます。入山許可や入場料についての情報は公共データでは確認できなかったので、訪れる前に現地の案内所か管理事務所で最新情報をチェックしておくと安心です。トイレはコース3の登山口（入口の乗用車駐車場、樹木園のトイレ）で確認できましたが、水飲み場は登録されている地点がありません。飲み water は必ず自分で用意してください。地図アプリは、韓国国内ではGoogleマップよりも精度の高い KakaoMap または Naver Map をおすすめします。英語のインターフェースにも対応しているので、あらかじめ登山口と下山地点を検索しておくといいでしょう。山中には電波が届きにくい区間があるかもしれませんし、避難小屋や安全設備も少なめです。単独での山行は避けて同行者を確保し、下山時刻には余裕を持たせた計画を立てるのが安全です。
