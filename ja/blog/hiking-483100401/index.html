概要

写真：韓国観光公社 観光写真ギャラリー（忠清南道公州市鶏龍面）・公共누리

鶏龍山（ケリョンサン）は、大田広域市と忠清南道の公州市・論山市・鶏龍市にまたがる国立公園で、三仏峰（約800m）や観音峰（約785m）といった岩峰が連なって稜線をつくる山です。全体的に中級レベルのコースが多く、日帰りでも十分に歩ける手軽さがあり、東鶴寺や甲寺など、いろいろな方向から登れるのが特徴。初心者から中級者まで幅広い層に人気の山ですが、山頂周辺の稜線は岩稜帯が多いので、油断は禁物です。

山容と地形

写真：韓国観光公社 観光写真ギャラリー（忠清南道公州市鶏龍面）・公共누리（KOGL）

鶏龍山（ケリョンサン）は花崗岩の岩峰と稜線が発達した山で、いわゆる「岳山（がくさん）」に近い印象を受けます。代表的なピークは三仏峰（サンブルボン、798m〜800m前後。データによって多少の差があります）、観音峰（クァヌムボン、785m前後。資料によっては768mと表記されることもあります）、そして三仏峰と観音峰を結ぶ稜線上にある南妹塔（ナンメタプ、632m）です。三仏峰から観音峰へ続く稜線は「自然城稜（チャヨンソンヌン）」と呼ばれる区間で、奇岩と松が織りなす景観がよく知られています。鶏龍山の最高峰は一般に天皇峰（チョンファンボン、845m前後）とされていますが、この峰は軍事施設の関係で民間人の立ち入りが規制されており、実際に一般の登山者が登れる山頂エリアは観音峰・三仏峰の一帯ということになります。全体として山容はかなり険しい部類ですが、国立公園に指定されているため、登山道や道標は比較的よく整備されている山です。

登山の雰囲気

写真: 韓国観光公社 観光写真ギャラリー（忠清南道公州市鶏龍面）· 公共누리

鶏龍山（ケリョンサン）は、登り始めでは深い森の道を、稜線近くでは岩場を、どちらも味わえる山です。東鶴寺（トンハクサ）・甲寺（カプサ）方面の入口は渓谷沿いのゆるやかな森の道から始まるので歩くのが素直に楽しく、稜線に近づくにつれて傾斜がきつくなり、岩稜と階段の区間が続きます。三仏峰（サンブルボン）・観音峰（クァヌムボン）あたりの稜線からは四方が開けた眺めが広がり、国立公園らしい爽快な展望が魅力です。春は新緑とツツジ、秋は紅葉が稜線と溶け合って季節感がはっきりしており、夏は渓谷の水音と木陰が暑さを和らげてくれます。冬は岩稜の区間に雪や霜が凍りつくことも多く、山歩きの空気が一気に引き締まる山でもあります。

コース1 — 兵士谷（ピョンサゴル）入口 → 将軍峰（チャングンボン）

📏 5.63km ⛰️ 665m 獲得標高 ⏱️ 2:31 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由: 兵士谷入口 → 探訪路案内板 → 案内標識（道標） → 将軍峰への登り道 → 案内標識（道標） → 危険地域 → 将軍峰展望ポイント → 将軍峰 → 展望ポイント → 鶏龍山国立公園位置番号 → 鶏龍山国立公園位置表示 → 分岐 → カッパウィ三叉路の休憩所 → 鶏龍山国立公園位置表示 → 休憩所

登山口へのアクセス: 兵士谷入口は鶏龍山（ケリョンサン）の北東側にある登山口で、東鶴寺（トンハクサ）やパクジョンジャ方面と比べると、比較的知られていない入口です。公共交通機関で向かう場合は、近くの集落のバス停で降りてから歩くことになるかもしれません。正確な路線は事前に地図アプリで確認しておくのが無難です。大きな駐車場があるという情報は見つからなかったので、近くの路肩や集落の空き地に停めることになる可能性が高そうです。

特徴・おすすめの人: 道標に「危険地域」の表示があるくらいなので、将軍峰への登り道は傾斜のきついところや露出した区間がそれなりにあります。ある程度は山歩きの経験がある方向け、といったところでしょうか。将軍峰の山頂部と展望ポイントからは鶏龍山の稜線がぐるりと見渡せるので、写真好きにはたまらないコースだと思います。人の少ない静かな山を歩きたい方におすすめです。

コース2 — 東鶴寺（トンハクサ）入口 → 鶏龍山 三仏峰

📏 8.29km ⛰️ 599m 獲得標高 ⏱️ 3:04 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由: 鶏龍山 三仏峰 → 落石・転落・滑落注意 → 三仏峰 → 三仏峰の展望 → 展望地点 → 自然景観 → 分岐点 → フォトゾーン → 転落注意 → 自然城稜の自然景観 → 自然城稜の展望地点 → 自然城稜のフォトスポット → 岩壁 → 落石注意 → 隠仙滝上部の安全休憩所

登山口へのアクセス: 東鶴寺入口は鶏龍山でもっともよく知られた登山口で、大田（テジョン）儒城（ユソン）方面、または鶏龍市方面のバスで行けます。近くの朴亭子（パクチョンジャ）三叉路のバス停（「朴亭子〈東鶴寺／忠南大方面〉」）で乗り換えるルートが一般的に使われていて、東鶴寺のすぐ近くにもバス停があるのでアクセスはなかなか良好です。観光地としての色が濃いため券売所のあたりに駐車スペースが用意されていますが、ハイシーズンの週末は混み合うこともあります。

特徴・おすすめの方: このコースは鶏龍山でもっとも象徴的な区間である「自然城稜」を通り、三仏峰の展望、自然城稜の展望地点、フォトスポットと、見晴らしのいいポイントが次々に現れるのが持ち味です。ただ、落石・転落注意の標識が何度も出てくるくらい岩稜帯の露出があるので、岩場歩きに慣れた中級以上の登山者向きでしょう。鶏龍山の代表的な景観をしっかり味わいたい方に、まず最初におすすめしたいコースです。

コース3 — 登山口 → 山頂

📏 3.87km ⛰️ 631m 獲得標高 ⏱️ 2:01 ➡️ 片道 難易度 ★★★☆☆ ⤓ GPX

登山口へのアクセス: このコースは具体的な登山口名のデータがなく、正確な位置を特定するのが難しい状況です。鶏龍山国立公園内の探訪路のひとつと推測されますが、実際に訪れる前には国立公園の探訪路案内、あるいは地図アプリで正確な進入路を必ず確認しておくことをおすすめします。

特徴・おすすめの方: 純標高差のわりに距離が短めなので、比較的傾斜のきつい区間が含まれている可能性があります。短時間で山頂付近の高度を稼ぎたい方には向いているかもしれませんが、登山口の情報がはっきりしない以上、初めて訪れるなら東鶴寺・甲寺など道標のはっきりしたコースを優先して検討したほうが無難です。

登山口へのアクセス: 甲寺入口は鶏龍山（ケリョンサン）西側の代表的な登山口で、公州（コンジュ）方面のバス、もしくはパクチョンジャ三叉路バス停（パクチョンジャ〈甲寺／新元寺方面〉）での乗り換えでアクセスするのが一般的です。甲寺のすぐ近くにもバス停があるので公共交通機関でも問題なく行けますし、寺の参道という土地柄、チケット売り場のあたりに駐車スペースが用意されているそうです。

特徴・おすすめの方: 甲寺という由緒あるお寺を通り抜けるコースで、一柱門や四天王門といった寺の文化財もあわせて見学できるのが大きな魅力です。経由地に龍水台の湧き水と九龍庵の湧き水が記されているので、他のコースに比べれば水の補給ができる余地はある方。ただし実際に使えるかどうかは季節や管理状況で変わってくるので、現地での確認は必要です。トイレ（甲寺トイレ）も経由地に含まれていて、序盤の設備は比較的しっかりしている印象。自然と文化遺産をいっしょに楽しみたいご家族連れにおすすめのコースです。

特徴・おすすめの方: 5つのコースのなかで距離も純標高差もいちばん短く、比較的負担の軽いコースです。天井探訪支援センターを過ぎてから渓谷沿いに登っていく区間があるので、序盤はゆるやかな森の道歩きを楽しめます。短時間で鶏龍山の山歩きを味わってみたい初級〜中級者にぴったりのコースです。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（忠清南道公州市鶏龍面）· 公共ヌリ

鶏龍山（ケリョンサン）管内の登山路の所要時間は、データ上では上り530分・下り368分と集計されています。ただしこれは管内の全区間を足し合わせた累計値で、単一コースの所要時間ではありません。距離に換算すると上りの平均ペースは約27分/kmほど。鶏龍山が、なだらかな平地よりも登り主体で体力を使う山だということがうかがえます。実測GPXをもとにしたコース別の所要時間は、短いものだと約1時間33分（天井探訪路）、長いものだと約3時間4分（東鶴寺〜三仏峰）と、片道基準でもかなり幅があります。往復での山行を考えるなら、この所要時間の約2倍に休憩時間を足して予定を組むのが無難です。鶏龍山のコースはほとんどが日帰りで十分に歩き切れる範囲なので、あえて縦走コースを組まないかぎり、1泊を要する山ではありません。

アクセス（公共交通機関・駐車場）

写真: 韓国観光公社 観光写真ギャラリー（忠清南道 公州市 鶏龍面）· 公共누리（KOGL）

鶏龍山のあたりには、パクチョンジャ三叉路（박정자삼거리）を中心に、東鶴寺方面と甲寺・新元寺方面へ分かれるバス停があります。確認できたのはパクチョンジャ（東鶴寺／忠南大方面）、パクチョンジャ（甲寺／新元寺方面）、甲寺、東鶴寺などで、大田の儒城（ユソン）や公州市外バスターミナルあたりから各方面のバスに乗り換えて向かうのが一般的なルートとされています。ただしバスの路線や運行間隔は時期によって変わることがあるので、出かける前にKakaoMapかNaver Mapでリアルタイムのルートと本数を必ず確認しておいてください。車で行く場合は東鶴寺・甲寺の入場券売り場のあたりに駐車スペースがあるようですが、公共データ上で個別に集計された駐車場は確認できませんでした。ハイシーズンの週末は混雑が予想されるので、公共交通機関との併用も頭に入れておくとよさそうです。

シーズン・天候・装備

写真: 韓国観光公社 観光写真ギャラリー (忠清南道 公州市 鶏龍面) · 公共ヌリ

鶏龍山（ケリョンサン）は、春の新緑とツツジ、秋の紅葉が美しい山として広く知られていて、この時期はとくに登山者が多くなります。夏は渓谷沿いのコースが多いので暑さをある程度しのげますが、雨の日は岩稜帯が滑りやすくなるので注意が必要です。冬は稜線の岩場が凍結していることが多く、アイゼンやスパッツといった冬装備は必携。基本の装備としては登山靴、着替え、十分な飲み水（給水所が実質的に足りないので、各自で持参するのが大事です）、防寒・防水ジャケット、トレッキングポールあたりを用意しておくと安心です。岩稜区間が多い山ですから、滑りにくいソールの登山靴を選ぶことをおすすめします。

写真: 韓国観光公社 観光写真ギャラリー（忠清南道 公州市 鶏龍面）· 公共ヌリ

鶏龍山（ケリョンサン）のローマ字表記は Gyeryongsan で、主な峰は Sambulbong（三仏峰）、Gwaneumbong（観音峰）、代表的な寺院の登山口は Donghaksa（東鶴寺）と Gapsa（甲寺）と表記されます。鶏龍山国立公園は入園料が無料で、特別な入山許可なしに登山道を利用できますが、一部の規制区域（天皇峰など軍事施設に隣接するエリア）は立ち入りが制限されているので、案内板の指示に従ってください。トイレは甲寺コースの経由地に確認されており、東鶴寺・甲寺の券売所付近にも設置されているようです。給水所はデータ上で集計されている場所がないため、水は必ず十分に持参してください。道案内については、韓国ではGoogleマップの精度が落ちるので、KakaoMap か Naver Map のアプリを事前に入れておいて実際のルートを確認しておくのが安心です。岩稜区間では標識にある落石・転落注意の表示を必ず守り、とくに冬場は凍結箇所で滑らないよう十分に気をつけてください。
