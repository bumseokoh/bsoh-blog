概要

写真: 韓国観光公社 観光写真ギャラリー（全北特別自治道 全州市 徳津区）· 公共누리（KOGL）

蓮花山（ヨンファサン）は慶尚南道固城郡にある山で、山頂部の峰々が標高500m台後半のゆるやかな稜線を描く道立公園級の山です。管内に登録されている登山道の路面はほとんどが土砂で、データ上どの区間も難易度は「易しい」に分類されているため、全体としてはあまり気負わずに入れる山として紹介されています。ただ、山頂一帯（シルボン・蓮花1峰）まで往復するコースは距離も標高差もそれなりにあるので、実際の体感としては中級者以上に向いた山かなという印象です。麓には千年の古刹・玉泉寺（オクチョンサ）があり、お寺めぐりと登山をセットで楽しみたいという人がよく訪れます。往復で歩いても日帰りで十分こなせる規模です。

山の姿と地形

写真: 韓国観光公社 観光写真ギャラリー (全北特別自治道 全州市 徳津区) · 公共ヌリ

蓮華山（ヨナサン）は、尖った頂上がひとつそびえているタイプではなく、いくつもの峰が稜線でつながっているのが特徴の山です。公共データに登録されている峰を挙げると、蓮華1峰（518m）、蓮華1峰（505m、別表記点）、蓮華山524m（補正標高539m）、南山427m（補正標高443m）、仙遊峰（405m）、玉女峰（404m）、シル峰（576m）、蓮華山（561m）など。実測GPXベースでは、頂上一帯の最高標高は574mとなっています。峰ごとに表記標高が少しずつ違うのは、地図資料と実測（GPS/DEM）の値のズレによるものでしょう。全体としての山容は、切り立った岩峰というより土が厚く積もった土の山（육산）に近く、稜線に沿ってゆるやかな上り下りが続きます。ただし頂上付近と展望台のあたりには岩場が部分的に混じっているので、完全な土の山というよりは、土の山と岩稜が入り混じった地形と考えていただくとよいかと思います。

山歩きの感触

写真: 韓国観光公社 観光写真ギャラリー（全北特別自治道 全州市 徳津区）・公共ヌリ

コース全体の雰囲気としては、序盤の渓谷・寺林エリアから始まり、尾根に近づくにつれて視界が開けていく流れです。玉泉寺（オクチョンサ）周辺の渓谷区間では、深い森と沢の音を一緒に味わえますし、尾根に上がれば固城（コソン）一帯の低地や近くの峰々が目に入ってくる展望ポイントが何度も現れます。路面は土が主体なので足運びは比較的ラクなほうですが、山頂往復のコースは距離が長く、後半になるほど疲労がじわじわ溜まってくるのを実感します。春は新緑と寺の周りに咲く花、秋は紅葉が尾根道によく似合うと言われていて、夏は渓谷区間の湿気と生い茂った草木、冬は尾根の日陰に張る氷が、体感的な難易度を押し上げる要素になります。

コース1 — 蓮花山道立公園駐車場 → シルボン（甑峰）

📏 7.98km ⛰️ 444m 獲得標高 ⏱️ 2:44 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由: 蓮花山道立公園駐車場 → 駐車場内トイレ → 玉泉寺渓谷の恐竜足跡 → 鷹峰への道 → 蓮花1峰への道 → ベンチ1基 → シルボン → シルボン展望台 → 寂滅宝宮 → 将軍峰 → 分岐26

登山口へのアクセス: 蓮花山道立公園の駐車場は、固城郡介川面の玉泉寺近くにあるとされています。地下鉄でのアクセスは難しく、固城の市街地や近隣の市外バスターミナルからタクシーか地元のバスを使うのが一般的なルートです。駐車場内のトイレが道標にも記載されているので、登山の前後に利用できます。公共交通の便数がそれほど多い地域ではないため、事前に地図アプリで実際の運行本数とルートを確認しておくことをおすすめします。

特徴・おすすめの方: このコースは玉泉寺渓谷沿いに登り始め、恐竜足跡の化石地といった見どころを通りながら、鷹峰・蓮花1峰方面の分岐を経てシルボン山頂まで続く流れになっています。シルボン展望台と寂滅宝宮をあわせて巡れるので、眺望と仏教文化遺産の両方を楽しみたい方にぴったりです。寺の参道を含んでいる分、序盤のアクセスは比較的よいのですが、往復するとなかなかの距離になるので、体力に余裕のある中級以上の登山者向きのコースだと言えます。

コース2 — 沃川小溜池（オクチョンソリュジ）駐車場 → 蓮花1峰

📏 8.4km ⛰️ 408m 獲得標高 ⏱️ 2:47 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由: 沃川小溜池駐車場 → 蓮花山道立公園 登山案内図 → 沃川小溜池 → 駐車場 → 蓮花1峰への道 → 分岐6 → 蓮花1峰 → 分岐8 → 分岐9 → ベンチ1つ → 蓮花2峰への道 → 蓮花2峰 → 烽火台 → 分岐14 → 分岐15

登山口へのアクセス: 沃川小溜池駐車場は、ため池（小溜池）のすぐそばにある登山口です。登山案内図が設置されているので、初めての人でもコースの確認は比較的しやすいと思います。公共交通機関よりマイカーでのアクセスが一般的で、固城（コソン）の街中から車で移動して駐車する、というのが定番のようです。

特徴・おすすめの人: ため池の景色から歩き始め、蓮花1峰・蓮花2峰を越えて烽火台まで続く縦走型の稜線コースです。いくつもの分岐を通りながらピークを次々と踏んでいく楽しさがあります。烽火台という歴史的な見どころがあるので、ただ登るだけでは物足りない方や、複数のピークを連続して踏む稜線縦走が好きな方におすすめです。コース1より分岐が多いので、標識をこまめに確認しながら歩くと安心です。

難易度・路面・注意点

写真：韓国観光公社 観光写真ギャラリー（全北特別自治道 全州市 徳津区）· 公共ヌリ（KOGL）

ただし山頂周辺のコース（シルボン・蓮花1峰方面）は実測ベースで難易度★★★★☆、市内の平均よりも体感的にはきつめです。路面が土砂中心なので晴れた日は滑る心配はあまりありませんが、雨の日はぬかるんで滑りやすくなりますし、冬場の日陰区間は凍結に注意が必要です。コース内の施設としては眺望ポイントが5か所、駐車場が1か所登録されていて、景色を楽しめる場所はいくつも用意されています。一方で危険地域も2か所登録されており、それぞれ「危険地」「渓谷危険」と表記されているので、この区間では特に気をつけたいところ。逆に給水所は登録されている地点がゼロなので、山行中に飲み水を補給できる場所は事実上ないと考えておくのが安全です。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（全北特別自治道 全州市 徳津区）· 公共누리（KOGL）

山頂まで往復する場合、片道およそ2時間40〜50分ほどのコースが2本あるので、往復5〜6時間前後。日帰りでも十分いけます。管内の登山道全体（総延長21.94km）で見ると、上りの累計が440分、下りの累計が305分と集計されていますが、これは管内の全区間を足し合わせた累計値です。特定のコース1本の所要時間と勘違いしないようご注意ください。この累計から割り出した平均の上りペースは1kmあたり約20分で、山頂コースの実際の片道所要時間の見積もり（距離に対する時間）とだいたい近い感じになります。避難小屋は登録されていないので、1泊以上を前提にした計画ではなく、日帰りの往復で組むのがおすすめです。

アクセス方法（公共交通・駐車場）

写真: 韓国観光公社 観光写真ギャラリー（全北特別自治道 全州市 徳津区）· 公共누리(KOGL)

蓮花山（ヨンファサン）は慶尚南道の固城郡にあります。ソウルや釜山、晋州あたりから固城の高速バスターミナルまで出て、そこから路線バスかタクシーで玉泉寺（オクチョンサ）・蓮花山道立公園方面へ向かう、というのが一般的なルートとして知られています。ただ、周辺に登録されているバス停が見当たらないので、公共交通だけで登山口まで辿り着くのはちょっと骨が折れるかもしれません。固城の中心部からタクシーを拾うか、素直にマイカーで行くのが現実的だと思います。駐車場は蓮花山道立公園駐車場が1か所登録されているので、車の方はここを起点に歩き始めれば大丈夫です。バスの正確な運行間隔やリアルタイムの経路は、KakaoMapかNaver Mapで確認するのが確実です（Googleマップは韓国国内の公共交通・徒歩ルート情報が当てにならないことがあります）。

シーズン・天候・装備

写真：韓国観光公社 観光写真ギャラリー（全羅北道特別自治道 全州市 徳津区）・公共누리（KOGL）

新緑と紅葉の両方を楽しめるベストシーズンは、春（4〜5月）と秋（10〜11月）だと言われています。夏は渓谷区間の湿度が高く、草木も生い茂るので体感的な難易度がやや上がりますし、雨が降ると土の路面が滑りやすくなるので気をつけたいところ。冬は日陰になる稜線区間が凍結することもあるため、アイゼンなどの防寒・防氷装備を用意しておくと安心です。必携品としては、登山靴、多めの水（給水所がないので飲み水は十分に持参してください）、雨具、冬場ならアイゼンやスパッツあたりをおすすめします。

外国人旅行者へのヒント

写真: 韓国観光公社 観光写真ギャラリー（全北特別自治道 全州市 徳津区）· 公共누리（KOGL）

蓮華山（ヨンファサン）はローマ字で Yeonhwasan（または Mt. Yeonhwa）と表記され、山頂周辺のピークは Sirubong（シルボン／甑峰）、Yeonhwa-1bong（蓮華1峰）などと併記できます。山の麓にあるお寺は Okcheonsa Temple（玉泉寺）です。道立公園の区域なので入山許可は特に必要ないとされていますが、寺の境内を拝観する際には文化財拝観料が別途かかる場合があるので、現地の案内表示を確認してください。トイレは蓮華山道立公園の駐車場内に登録されていますが、登山道の途中に給水所はないため、出発前に水をたっぷり用意しておきましょう。地図アプリは、Googleマップよりも KakaoMap か Naver Map のほうが韓国国内の登山道や公共交通の情報がはるかに正確なので、ぜひ併用をおすすめします。標識が多く分岐の入り組んだ区間（コース2）では道を間違えないよう地図アプリのGPSトラック機能を活用し、日が短い季節には下山時刻に余裕をもたせて出発してください。
