概要

写真：韓国観光公社観光写真ギャラリー（忠清北道堤川）・公共누리

錦繡山（クムスサン、錦繡山）は、忠清北道堤川市水山面と丹陽郡赤城面の境界、忠州湖の西側のふもとにそびえる山です。山頂部は標高1,040m前後の峰がいくつも連なる形をしていて、稜線沿いには望徳峰のような険しいピークも控えています。山全体としての難易度は中級クラスとされていますが、山頂まで一気に登るコースは距離も標高差もそれなりにあるので、体力の消耗はけっこう大きめです。短めの展望台コースから山頂縦走コースまで幅があるので、訪れる人の体力やスケジュールに合わせてコースを選べば、日帰り登山でも十分楽しめる山だと思います。

山容と地形

写真提供：韓国観光公社 観光写真ギャラリー（忠清北道堤川）・公共누리

錦繡山は花崗岩と石灰岩が入り混じった、いわゆる「骨山」タイプの山で、稜線のあちこちに岩峰や奇岩が目立ちます。頂上付近は「錦繡山頂上」と呼ばれる地点が複数表記されているほど(1044m・1040m・1037m)、狭い区間に峰が密集していて、頂上から西に伸びる稜線にはワシに似た姿の独수리岩ならぬ「トックスリバウィ」のような奇岩や、望徳峰という名の付いた峻峰が控えています。谷筋では凌江渓谷が代表格で、九つの絶景をまとめて「凌江九曲」と呼ぶ伝統が今に伝わっており、コース途中にある吹笛潭・吹笛台といった地名もこの九曲文化に由来するとされています。渓谷の上流には真夏でも氷が残ると言われる、いわゆる「氷谷(コース上の『氷谷臥仏』地点)」の地形があり、錦繡山ならではのひんやりとした渓谷らしさをよく表しています。山名自体も「錦に刺繍を施したように美しい山」という意味に由来すると伝えられ、とりわけ秋の紅葉シーズンの山容の華やかさで広く知られています。

登山の感触

写真：韓国観光公社観光写真ギャラリー（忠清北道堤川）・公共누리

登山口から稜線に出るまでは、広葉樹林が生い茂る土の山らしい雰囲気の森道がずっと続くんですが、山頂が近づくにつれて岩場や落石注意区間が現れて、体感的な難易度が一気に跳ね上がるのが錦繡山コースに共通する特徴です。渓谷沿いの区間(能江渓谷、龍潭滝の近く)では水音とひんやりした湿気が肌に伝わってくる一方、稜線や展望台(雪錦展望台など)の区間では忠州湖と周囲の山並みを見渡せて、対照的な山歩きの趣を味わえます。春には渓谷の入り口の新緑や王ツリガネニンジンなど珍しい野草が、秋には稜線の紅葉が見事だと言われていて、冬になると岩場が凍結してさらに険しい山容に感じられるようです。

コース1 — 登り口入口駐車場（無料）→ クムスサン(錦繡山)頂上

📏 14.02km ⛰️ 875m 獲得標高 ⏱️ 4:58 🔁 周回 難易度 ★★★★★ ⤓ GPX

経由地:トイレ → 無料駐車場 → バス停(チョンバンサ) → 山と水と → 登り口入口駐車場(無料) → ヌンガン橋コース登り口 → 分岐点 → 石塔 → マンダンアム → 氷谷の臥仏 → 渓谷 → 休憩所 → 火田民跡 → チュィジョクダム → チュィジョクデ(ヌンガン九曲)

登り口へのアクセス:ヌンガン渓谷方面の登り口には無料駐車場が用意されているので、マイカーでも比較的スムーズに入れます。近くにチョンバンサ行きのバスが停まる停留所もあるので公共交通機関でも行けますが、本数が少なめなので事前にリアルタイムの運行状況を確認しておくのがおすすめです。

特徴・おすすめの人:ヌンガン九曲の渓谷美と氷谷、マンダンアムのような寺院・奇岩の見どころを一通り巡る長丁場のコースで、距離は14kmを超え、3つのコースの中でも最長・最難関にあたります。渓谷の景色をじっくり味わいながら体力づくりを兼ねて頂上まで縦走したいという方向けで、初心者よりはある程度山歩きに慣れた方におすすめです。

コース2 — 登山口 → ソルグム展望台

📏 5.03km ⛰️ 615m 獲得標高 ⏱️ 2:17 ➡️ 片道 難易度 ★★★★☆ ⤓ GPX

経由地：錦繡山サンハク駐車場バス停 → サンハク駐車場 → トイレ → デチュナムチプ（大棗の木の家） → 登山口 → 分岐点 → 大悲寺 → 休憩所 → 男根石公園 → 옹달샘（湧き水） → オウレン（王提비꽃）自生地 → ソルグム展望台 → 落石注意地点 → 落石注意区間 → 展望台

登山口へのアクセス：サンハク駐車場が起点になっていて、駐車場のすぐそばにバス停も併設されているので、公共交通機関でもマイカーでも動線はわりとシンプルです。とはいえ正確なバスの本数や停留所の位置は、地図アプリで一度確認しておいたほうが安心です。

特徴・おすすめの人：男根石公園、湧き水、オウレン自生地といった見どころがコースの序盤から中盤にかけて集中しているので、自然観察をじっくり楽しみたい人向き。後半にソルグム展望台と落石注意区間を抜けると視界がぱっと開けるのも印象的です。3コースの中では距離が一番短いので、半日だけの山歩きにしたい人や、頂上まではちょっとキツいという人が、展望メインで軽く歩きたいときにちょうどいいと思います。ただ後半に「落石注意区間」の表記が2回出てくるので、油断せず気をつけて進んでください。

コース3 — 錦繡山 上川コース登山口 → 望徳峰

📏 7.14km ⛰️ 831m 獲得標高 ⏱️ 3:10 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：上川休憩所駐車場 → 錦繡山おぼろ豆腐 → お手洗い → 売店 → 上川駐車場バス停 → 錦繡山上川コース登山口 → 分岐点 → 谷 → 展望ポイント → 龍潭滝 → 展望地点 → 独鷲岩 → 望徳峰 → 錦繡山山頂 → 落石注意地点

登山口へのアクセス：上川里の行政区域内にある上川休憩所・上川駐車場を起点としていて、近くに売店とバス停もそろっているので、3つのコースの中では一番設備が充実している登山口です。バスでも車でもアクセスしやすいと言われています。

特徴・おすすめポイント：龍潭滝や独鷲岩など見応えのあるスポットがはっきりしていて、望徳峰を経て山頂まで続く、錦繡山でいちばん知られている定番コースです。山頂手前に落石注意地点があるので最後の区間は気を引き締めて歩く必要がありますが、滝と奇岩を両方楽しみながら山頂を目指したい人には一番おすすめできるコースです。

※上記の総延長（6.85km）は管内の複数区間を合算した数値であり、単一コースの距離ではありません。一方で山頂圏まで登る個々のコースは、実測GPXベースで5〜14kmに達し、体感の難易度ははるかに高くなります。短い行政区間の数字だけを見て山行を甘く見積もらないよう注意してください。

公共データ上では危険地域と展望ポイントはそれぞれ0件と集計されていますが、実測コースデータにはコース2とコース3にそれぞれ「落石注意地点」「落石注意区間」が明記されており、実際には岩の斜面で落石の危険がある区間が存在します。山頂圏の路面は岩が多く、雨天時や落ち葉が積もる秋には滑りやすいので注意が必要で、冬場は凍結によって体感難易度が大きく上がります。取り付き・下山口はデータ上2地点と把握されており、避難所は0件、展望ポイントも別途登録がないため、各自で安全装備を整えて行動することをおすすめします。

距離と所要時間

写真：韓国観光公社観光写真ギャラリー（忠清北道堤川）・公共누리

錦繡山には避難小屋がなく、管内の登山道を全部足しても6.85kmほどなので、どのコースを選んでも日帰りで十分こなせます。ただ、コース1（登山口駐車場→頂上、14.02km、片道約4時間58分）やコース3（上川コース→望徳峰、7.14km、片道約3時間10分）のように頂上まで登るコースは、往復だと8~10時間前後かかることもあるので、朝早めに出発して下山の時間もしっかり見込んでおく必要があります。コース2（雪金展望台、5.03km、片道約2時間17分）は半日コースとして無難な選択です。管内の登山道全区間を合計した所要時間は上り156分・下り109分と記録されていますが、これは個別コースの所要時間ではなく管内の全区間を合算した数値なので、特定コースの所要時間と勘違いしないよう注意してください。この合計値から換算した平均上りペースは1kmあたり約23分で、上の実測コース表の片道所要時間とあわせて、自分の体力に合わせてスケジュールを組む際の参考値として使えます。

금수산 자체には最寄り駅がなく、堤川(チェチョン)または丹陽(タニャン)市外バスターミナルから村バスや農漁村バスに乗り継いで、上川里(サンチョンニ)・陵江里(ヌンガンニ)方面の登山口へ向かうのが一般的なアクセス方法として知られています。コース1の登山口近くには正方寺(チョンバンサ)というバス停が実際にあるので、ここを基準に乗り継ぎを計画するとよいでしょう。ただ、農漁村地域ならではの事情で運行間隔がかなり空いていたり、路線がちょくちょく変わったりすることもあるので、出発前にKakaoMapやNaver Mapでリアルタイムの経路とバス停の場所を必ず確認しておいてください。車で行く場合、コース1の登山口には無料駐車場があるものの、公共データ上では管内登録駐車場が0件となっていて、正式な駐車スペースはあまり多くないかもしれません。週末やハイシーズン(特に秋の紅葉シーズン)は路肩駐車や混雑が起きがちなので、公共交通機関の利用もあわせて検討することをおすすめします。

このシーズンにいちばん歩きやすいのは、やっぱり春と秋です。新緑や紅葉が楽しめるうえ、路面のコンディションも比較的安定しています。夏場は谷筋の湿気がこもりやすく、雨上がりは落石や滑落のリスクがぐっと上がるので、雨のすぐ後の山行はできれば避けたいところ。梅雨時は谷の水量が増えることにも気を配ってください。冬は山頂付近の岩稜帯や落石注意区間の凍結がきついので、アイゼンやスパッツといった冬山装備は必須です。共通で持っていきたいのは登山靴、着替え、そして十分な飲み水（管内に登録されている水飲み場は0カ所とのことで、山中で水を調達するのはまず期待できません）、非常食、ヘッドランプ、トレッキングポール。コース1やコース3のような長丁場を選ぶ場合は、最低でも4〜5時間以上の体力を見込んで、時間に余裕を持った出発時刻を組んでおくと安心です。

外国人旅行者向けのヒント

写真:韓国観光公社観光写真ギャラリー(忠清北道堤川市水山面玉筍峰路10キル2)・公共ヌリ

錦繍山はローマ字表記だと”Geumsusan”または”Mt. Geumsusan”、代表コースの目的地である望徳峰は”Mangdeokbong”、展望台は”Seolgeum Observatory(ソルグム展望台)“と案内すると、現地の人とのコミュニケーションがスムーズになります。入山許可や入場料といったものは特に確認されておらず、国立・道立公園ではない一般の登山道なので自由に立ち入れるようですが、寺院(正方寺・大悲寺)の境内では別途マナーを守る必要があります。トイレはコース1・2・3の登山口付近(駐車場、上鶴駐車場、上川休憩所付近)に設置されているのが確認できますが、山の中腹より上の区間にはトイレがないため、出発前に必ず済ませておきましょう。水飲み場は公共データ上登録がなく(0カ所)、個人の水筒を十分に用意していく必要があります。道案内はGoogleマップが韓国国内では不正確なことが多いので、事前にKakaoMapやNaver Mapのアプリをインストールして、登山口の位置や公共交通機関のルートを確認しておくと安心です。登山中は通信がうまくつながらない区間もあり得るので、地図のオフライン保存や同行者との事前の連絡計画をおすすめします。特にコース2・3の落石注意区間では、案内標識に必ず従うようにしてください。
