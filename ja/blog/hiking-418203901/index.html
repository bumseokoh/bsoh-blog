概要

写真:韓国観光公社観光写真ギャラリー(全南光州統合特別市長城郡)・公共ヌリ

鷲嶺山（チュギョンサン）は、京畿道南楊州市と加平郡の境界にまたがる山で、頂上部の標高は登山道の実測データによると886〜891m前後です。ヒマラヤスギの植林地として知られる鷲嶺山自然休養林を抱えていて、森林浴と山林浴を兼ねた登山が楽しめる場所です。登録区間ベースの全体的な難易度は「易しい」とされていますが、実際に頂上まで登るコースは純粋な標高差500〜600m台の本格的な山行コースなので、初心者にとっては決して軽く見られません。公共交通機関・マイカーどちらでも日帰りアクセスが可能で、一日で往復登山を終えられる山です。

山勢と地形

写真：韓国観光公社観光写真ギャラリー（全南光州統合特別市長城郡）・公共누리

祝霊山は、切り立った岩峰というよりも、なだらかな稜線と鬱蒼とした森が織りなす、いわゆる「土山」に近い山容を見せています。とはいえ頂上部や稜線のあちこちには岩場も混じっていて、視界が開ける区間もちゃんとあります。代表的なところでは、ナミ岩、ファチェ峰といった岩場がコース上に続いています。祝霊山は単独の登山先として知られることが多いのですが、実際にはソリ山・チュグム山と稜線でつながる縦走コースとしてもよく利用されています。稜線上の主な峰としては、チュグム山（約830〜831m）、チュグム山頂上（約766m）、トクバウィ（約813m）、ソリ山（約847m）とソリ山頂上（約860m）が確認でき、これらの峰が祝霊山と一つの山脈を成しながら、南楊州と加平の境界に沿って連なっています。祝霊山の頂上部には頂上石（約891m）が立っていて、登山客の記念撮影スポットとしての役割を果たしています。

登山の雰囲気

사진: 한국관광공사 관광사진 갤러리 (전남광주통합특별시 장성군) · 공공누리

祝霊山の登山道は、入口から山頂まで基本的にずっと森の中を歩く感じで続いていて、特にジャーノキ(잣나무)やモミの木がびっしり茂っているエリアではフィトンチッドの香りと日陰がぐっと濃くなります。夏場はこの鬱蒼とした木々のおかげで直射日光をかなり避けられるので、思ったより涼しく歩けますし、秋になると紅葉と一緒に歩ける尾根道が広がってくれます。山頂付近や尾根の一部の展望ポイントからは南揚州(ナミャンジュ)・加平(カピョン)一帯の山並みがすっきり見渡せて、ナミ岩(남이바위)やファチェ峰(화채봉)の近くでは岩稜特有の開けた眺望も楽しめます。全体としては緩やかな土の道と森の道がずっと続いて、山頂の直前で急に傾斜が出てくる、典型的な「土山」タイプのコースという印象です。

コース1 — 市内バス 祝霊山自然休養林 → 頂上三叉路の分岐点

📏 6.15km ⛰️ 620m 獲得標高 ⏱️ 2:34 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由地: 市内バス 祝霊山自然休養林 → スーパー → 祝霊山谷ガーデン → 祝霊山自然休養林 → 木製ベンチ → 頂上三叉路の分岐点 → 祝霊山頂上886.2m → ヘリポート → 展望ポイント → 分岐点 → ナミ岩 → 第1キャンプ場 → トイレ

登山口へのアクセス: このコースは、バス停からそのまま登山がスタートできる公共交通機関フレンドリーな登山口です。南楊州・加平方面の市内バスが祝霊山自然休養林付近のバス停に停車するので、車がなくてもアクセスはそう難しくありません。ただ、バスの本数がやや少なめなので、事前に時刻表を確認しておくのがおすすめです。

特徴・おすすめの人: 入口付近のスーパーや谷ガーデンを通り過ぎる集落っぽい雰囲気からスタートし、徐々に森の道へと入っていく構成で、序盤が緩やかなので体を慣らしながら登るのにちょうどいいです。頂上直前の三叉路の分岐点からは傾斜が出てきて、頂上を過ぎた下山路ではヘリポートや展望ポイント、ナミ岩を経由しながら視界が開ける区間が続きます。公共交通機関だけで登山を完結させたい人にぴったりのコースです。

コース2 — 祝霊山休養林 → 頂上

📏 6.87km ⛰️ 483m 獲得標高 ⏱️ 2:31 🔁 周回 難易度 ★★★★☆ ⤓ GPX

経由地: 祝霊山休養林 → 休養林駐車場 → 山林休養館 → 分岐点 → モミの木の森 → ソリ山ヘリポート待避所 → モミの木群落地 → 休養林管理事務所 → 休養林第2駐車場 → 第2駐車場トイレ → バス専用操車場 → 祝霊山休養林検問所 → 休養林「森の中の家」

登山口へのアクセス: 自然休養林の正門からスタートするコースで、休養林自体に駐車場とバス専用操車場が整っているので、マイカーでも貸切バスの団体登山でも便利です。入場（チケット購入）の手続きを経て入っていく構造なので、休養林の運営時間を事前に確認してから訪れるのがおすすめです。

特徴・おすすめの人: 山林休養館、モミの木の森、モミの木群落地といった休養林の施設と植林された森を通り抜ける区間が長く続くので、家族連れや森林浴も兼ねたい登山者に特に向いています。距離は3つのコースの中で一番長いのですが、累積高度差は一番緩やかで、体感的な傾斜は比較的きつくありません。ソリ山ヘリポート待避所を通る区間は尾根らしい雰囲気を味わえるので、森の道と尾根道の両方を歩きたい人にぴったりです。

コース3 — 分岐7 → ファチェボン

📏 8.82km ⛰️ 601m 獲得標高 ⏱️ 3:12 ➡️ 片道 難易度 ★★★★★ ⤓ GPX

経由地：分岐7 → 蛍生息地 → 分岐9 → 自然休憩所 → 分岐11 → 分岐12 → 分岐13 → 稜線 → 稜線路 → チュンニョンサン → ファチェボン → 分岐19 → ツツジの丘 → 分岐21 → ツツジ尾根

登山口へのアクセス：3つのコースの中では距離が一番長く、いくつもの分岐を経由していく構造なので、単独の登山口というより「稜線縦走の入り口」といった性格が強いルートです。公共交通機関よりはマイカーで近くまで行ってから歩き始めるほうが楽で、初めて行く方は事前に地図アプリで各分岐の番号を確認しておくと安心です。

特徴・おすすめの人：蛍の生息地や自然休憩所を過ぎ、いくつもの分岐をたどって稜線に上がったあと、チュンニョンサンの山頂を経てファチェボン、ツツジの丘まで続く長距離の稜線コースです。ツツジの丘の区間は開花時期には特に見事で、3コースの中では難易度も距離も一番のボリュームがあるので、体力に自信のある方や稜線縦走を目指す方に向いています。

難易度・路面・注意点

写真：韓国観光公社観光写真ギャラリー（全羅南道光州統合特別市長城郡）・公共ヌリ

祝霊山の登録区間だけを見ると最高難易度は「やさしい」なんですが、実際に頂上まで登るコースの難易度は、純粋な高低差と距離で見ると★★★★☆〜★★★★★くらいまで跳ね上がるので、登録区間の表記だけを鵜呑みにしてコースを甘く見ないほうがいいです。コース上には展望ポイントが8箇所確認できて、その中でも「展望ポイント・やや危険」と表記されている箇所は足元に気をつけたい区間なので、通過するときは焦らずゆっくり進むのが安全です。もう一つの展望ポイントであるツツジの丘展望所は、比較的安全に眺めを楽しめる場所です。危険地域として別途登録されている箇所はありませんが、ナミバウィ（南怡岩）やファチェボン（花蕊峰）といった岩場の区間では、雨天時や冬場の路面凍結時に滑りやすいので特に注意が必要です。森の道が多い分、落ち葉が積もる晩秋から初冬にかけては路面が滑りやすくなることもあるので気をつけてください。

距離と所要時間

写真: 韓国観光公社 観光写真ギャラリー（全羅南道光州統合特別市長城郡）· 公共누리

鷲嶺山（チュリョンサン）は管内の登山道総延長（複数コースを合算した数値）が7.85kmと集計されていて、これは単一コースの距離ではなく、行政区域内の複数の登山道区間を合わせた数字です。登録されている区間は2ヶ所で、名前が明示されていない区間が4.67km、外方里（ウェバンニ）区間が3.18kmとなっています。実測の頂上コース基準では片道6~9km台の距離で、往復でも日帰り登山として十分こなせる範囲です。管内全区間の累計データでは上り187分・下り130分となっていて、そこから平均上りペースは約24分/kmと算出されますが、これは特定コースの所要時間ではなくあくまでペースの参考値なので、実際のコース別所要時間は上の表にある片道の推定値（約2時間30分~3時間12分）を目安にするのが正確です。避難小屋は別途登録されておらず総延長も短めなので、鷲嶺山は宿泊なしで日帰り往復できる山と言えます。

行き方(公共交通・駐車)

사진: 한국관광공사 관광사진 갤러리 (전남광주통합특별시 장성군) · 공공누리

公共交通を使う場合、祝霊山の近くには祝霊山自然休養林、ウィンマル、祝霊山バス停があって、南楊州・加平方面の市内バスでアクセスできます。ソウル方面からだと、地下鉄で清凉里・上鳳あたりの京春線・中央線エリアまで行って、そこから市外・市内バスに乗り換えるのが一般的なルートです。ただ、乗り換え路線や運行間隔は日によって変わることもあるので、出発前にKakaoMapやNaver Mapでリアルタイムに確認しておくのが確実です。

マイカーで行くなら、祝霊山自然休養林方面にバス駐車場と第2駐車場があるので、駐車スペースに困ることはあまりないと思います。とはいえ週末やハイシーズンは混み合うこともあるので、できるだけ早めの時間に到着するのがおすすめです。

季節・天気・装備

写真：韓国観光公社観光写真ギャラリー(全南光州統合特別市長城郡)・公共ヌリ

チュンリョンサンは一年中いつ登っても楽しめる山ですが、森が深く生い茂っている分、夏場は湿度が上がって思った以上に体力を使うことになりますし、冬場は日陰の区間や岩場が凍結しやすく、アイゼンなしだと滑って危険な思いをすることになります。逆に春は新芽やツツジ・レンゲツツジ、秋は紅葉がコース全体を彩ってくれるので、個人的にはこの時期が一番おすすめです。装備としては登山靴に加えて、水を多めに(このコースはほぼ給水施設がないので、水の持参は本当に大事です)、あと防水・防寒のアウターも欲しいところです。冬に登るなら念のためアイゼンとスパッツも持っておくと安心です。夏は虫除けと、汗をかいても蒸れにくい服装を用意しておくといいと思います。

外国人旅行者向けの豆知識

写真：韓国観光公社 観光写真ギャラリー（全羅南道光州統合特別市長城郡）・公共누리

祝霊山(チュンニョンサン)はローマ字表記だとChukryeongsanとなり、頂上の山頂標識はJeongsangseok（Summit Marker）と案内されていることが多いです。登山口の一つである祝霊山自然休養林は地図検索の際にはChukryeongsan Natural Recreation Forestという表記になるので、探すときの参考にしてください。山そのものへの入山許可は特に必要ありませんが、祝霊山自然休養林を通るコースだと休養林への入場（チケット窓口）手続きや営業時間があったりするので、事前に確認しておいたほうがいいです。トイレは第1キャンプ場付近と休養林の第2駐車場付近にあることを確認していますが、給水施設は登録がないので、登る前に飲み水はしっかり用意しておいてください。あと個人的な感覚も込みで言うと、Googleマップは韓国の山岳地形だと登山道情報がわりと不正確なことが多いので、KakaoMapかNaver Mapのアプリを使って実際の登山道ルートや公共交通機関の乗り継ぎ情報を確認することをおすすめします。稜線区間や岩場では道標がはっきりしていないこともあるので、一人で登るときはルートを外れないよう気をつけて、天候が崩れてきたら無理に山頂を目指すよりも下山を優先するほうが安全です。
