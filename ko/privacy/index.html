개인정보처리방침

본 방침은 ohwalker.com(이하 "사이트")의 개인정보 처리 기준을 설명합니다. 시행일: 2026-06-21

1. 수집하는 정보

사이트는 회원가입 기능이 없어 계정 정보를 수집하지 않습니다. 다만 방문 시 다음이 자동 수집될 수 있습니다: 쿠키, 브라우저·기기 정보, 접속 로그, 페이지 조회 기록. 이메일로 문의하시면 회신을 위해 해당 이메일 주소가 사용됩니다. 댓글을 작성하실 경우 아래 2항의 정보가 추가로 수집됩니다.

2. 댓글

사이트는 로그인 없이 이용할 수 있는 댓글 기능을 제공합니다. 댓글을 등록하면 다음 정보가 수집·저장됩니다.

  • 이름(닉네임)과 댓글 본문: 입력하신 내용이 사이트에 그대로 공개되며 Cloudflare D1 데이터베이스에 저장됩니다. 실명이나 개인 식별 정보를 입력하지 않으셔도 됩니다.
  • 작성 시각: 댓글과 함께 저장·표시됩니다.
  • IP 주소 해시: 도배·스팸 방지를 위해 접속 IP에 비밀값을 더해 해시(SHA-256)한 값만 저장합니다. 원본 IP 주소는 저장하지 않으며, 해시값은 외부에 공개되지 않고 게시 빈도 제한에만 사용됩니다.
  • 봇 차단(Cloudflare Turnstile): 자동 등록을 막기 위해 Cloudflare Turnstile을 사용합니다. 검증 시 Turnstile 토큰과 접속 IP가 Cloudflare로 전송되며, 해당 처리는 Cloudflare의 개인정보 정책을 따릅니다.

댓글 삭제·정정을 원하시면 아래 문의 이메일로 해당 글 주소와 댓글 내용을 알려주시면 처리해 드립니다.

3. 쿠키 및 광고

본 사이트는 쿠키를 사용합니다.

  • Google 애널리틱스: 방문 통계 분석을 위해 쿠키를 사용합니다.
  • Google 애드센스: 제3자 공급업체(Google 포함)가 쿠키를 사용해 사용자의 본 사이트 및 다른 사이트 방문 기록에 기반한 맞춤형 광고를 게재합니다. Google의 광고 쿠키 사용으로 사용자에게 광고가 표시됩니다.

조회수 카운터: 글별 조회수는 Cloudflare를 통해 쿠키 없이 익명 집계 수치만 기록하며, 개인을 식별하지 않습니다.

맞춤형 광고는 Google 광고 설정에서 비활성화할 수 있으며, aboutads.info 에서 제3자 쿠키를 거부할 수 있습니다. 브라우저 설정에서 쿠키를 차단·삭제할 수도 있습니다.

4. 제3자 서비스

사이트는 Google Analytics, Google AdSense, GitHub Pages(호스팅), Cloudflare(DNS·조회수 집계·댓글 저장(D1)·봇 차단(Turnstile))를 이용합니다. 각 서비스는 자체 개인정보 정책을 따릅니다.

5. 데이터 보관·제3자 제공

사이트 운영자는 수집된 통계 데이터를 분석 목적 외로 제3자에게 판매·제공하지 않습니다. 댓글은 삭제 요청이 있거나 사이트 운영자가 부적절하다고 판단해 삭제하기 전까지 보관됩니다.

6. 아동

본 사이트는 만 14세 미만 아동을 대상으로 하지 않으며 의도적으로 해당 정보를 수집하지 않습니다.
