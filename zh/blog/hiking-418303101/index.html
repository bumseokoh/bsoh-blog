千年银杏与岩石嶙峋山脊的京畿龙门山

概述

照片：韩国观光公社观光照片图库（京畿道杨平）· 公共누리

龙门山（龍門山，Yongmunsan）位于京畿道杨平郡，主峰海拔约1,176米，是京畿东部地区数一数二的高山。通往山顶的几条主要路线单程大多在8~11公里上下，累计爬升超过800米，按实测数据来看，绝大多数登顶路线都属于最高难度级别，体力消耗不小。不过官方登记的登山道区段本身在公共数据里标注的难度是”简单”，所以对只想走一小段的游客来说，这座山其实也算好接近。从登山口一路走到山顶，一天之内完全可以来回，不是那种非得住一晚才能搞定的规模。

山势与地形

사진: 한국관광공사 관광사진 갤러리 (경기도 양평) · 공공누리

龙门山是那种土石相间的山，既有厚实的土坡，也不乏裸露的岩脊。整座山沿着一条粗壮的主脊延展，串起好几座山峰：主峰龙门山（1,161米），附近另有一处也标注为”龙门山顶”（1,152米）；再加上将军峰（有1,025米和1,113米两种标注）、白云峰（940米）、中元山上峰（782米）、龙门山神仙峰（645米）、龙门山龙鸟峰（612米）等等。越靠近主峰区域，不同资料给出的海拔数值差异越明显，这大概是GPS测量点位或调查时间不同造成的，属于常见现象——按实测GPX数据看，主峰一带的最高点应为1,176米。山顶一带岩石与山脊交错，视野开阔的地方不少；往下则是茂密的森林，土山的味道更浓一些。龙门山脚下坐落着有千年历史的古刹龙门寺，寺里那棵银杏树是韩国现存最古老、最高大的银杏树之一，颇负盛名，顺路去看看也很值得。

登山感受

照片：韩国观光公社观光照片库（京畿道杨平）· 公共누리

龙门山的登山路线，走的是那种典型的节奏：从入口平缓的林间路开始,越往上坡度越明显。下段是阔叶林和针叶林混杂的林道，树荫浓密，就算夏天走起来也算舒服；到了上段，岩脊和岩石路段开始交替出现，体感难度会陡然上升。快到顶峰的一带，沿着山脊会有几处视野开阔的地方，能把京畿东部的群山尽收眼底。这里的季节感很分明——春天新绿和溪水相映成趣，秋天则以枫叶沿山脊层层染红著称。整体来说这是一条长距离、大高差的路线，不太适合当短途散步来走，更适合把它当成值得投入一整天的正式登山来安排。

路线1 — 龙门峰登山口 → 龙门峰

📏 8.92km ⛰️ 953m 爬升 ⏱️ 3:49 🔁 环线 难度 ★★★★★ ⤓ GPX

途经：龙门峰登山口 → 龙门峰 → 岔路口 → 场岩（마당바위）

入口交通：龙门峰登山口跟龙门山主登山路不是一个方向，是另开的一个入口，坐大众交通不太方便，一般自驾或打车过去更省事。具体进山口位置建议提前用Kakao地图或Naver地图查一下再出发。

特点·适合人群：这条路线是经龙门峰再接上主峰方向的脊线型路线，一上来就是持续爬升的路段，没什么缓冲。走到场岩附近视野忽然开阔，能好好欣赏一番岩脊景观。喜欢安静脊线徒步、对岩石地形感兴趣的老手会比较对胃口，新手走起来压力会不小。

路线2 — 岔路口 → 龙门山主峰

📏 8.2km ⛰️ 903m 爬升 ⏱️ 3:33 ➡️ 单程 难度 ★★★★★ ⤓ GPX

经过点：岔路口 → 平床（休息平台）→ 龙门山主峰

登山口接近方式：这条路线是从半山腰的岔路口直接接到主峰的一段，大多是和其他路线搭配着走。如果要从下方登山口进入，一般是走龙门山旅游区、龙门寺方向，通常在中央线电铁龙门站（Yongmun Station）下车后再转乘公交或出租车前往。

特点·推荐对象：路线经过一个叫”平床”的休息点后直上主峰，走向比较直，是想以登顶为目标的登山者的高效选择。快到主峰附近会有一段视野开阔、能看到山脊景色的路段，推荐给体力比较好的登山者。

路线 3 — 岔路口 → 山顶

📏 9.54km ⛰️ 838m 爬升 ⏱️ 3:47 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经：岔路口 → 休息处 → 百年药水泉

登山口交通：这段路线与从龙门寺方向上来的主登山道相接，一般是先坐公交或出租车到龙门山旅游区入口，再徒步进入。旅游区附近建有大型停车场，所以自驾前往的人也不少。

特点·推荐对象：经过百年药水泉的这条路线，是龙门山使用率最高的传统登顶路线。整体走势很典型——先是一段很长的林间小路，到上半段才出现岩脊和岩石地带，因此对大多数以登顶为目标的游客来说，这是首选推荐路线。

路线4 — 龙门寺入口 → 将军峰

📏 11.54km ⛰️ 845m 爬升 ⏱️ 4:18 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经：龙门山旅游区 → 售票处 → 家庭卫生间 → 生态农业博物馆 → 韩国民族独立运动发祥地 → 龙门寺入口 → 龙游亭 → 龙门寺四天王门 → 龙门寺寺庙寄宿 → 龙门寺银杏树 → 龙门寺 → 岔路口 → 长椅

登山口交通：龙门寺入口就在龙门山旅游区的门户位置，得先经过售票处才能进去。坐公交的话，一般是先坐中央线电铁到龙门站，再换乘公交车过去。这里毕竟是旅游景区，配套停车场也修得挺齐全，整体可达性不错。

特点及适合人群：这条路线最大的亮点是沿途会经过龙门寺银杏树、四天王门这些文化古迹和游览设施，不只是单纯爬山，还能顺便逛逛寺庙。不过它是五条路线里全程最长的一条，体力消耗不小，所以比较适合那些想把文化探访和登顶计划一起安排、且能留出充裕时间的山友。

路线5 — 京畿杨平站 → 里克达松树植林地带

📏 8.83km ⛰️ 902m 爬升 ⏱️ 3:43 ➡️ 单程 难度 ★★★★★ ⤓ GPX

沿途经过：京畿杨平站 → 岔路口3 → 岔路口4 → 休息处 → 松树群落地 → 岔路口7 → 观景点 → 岔路口10 → 栗树植林地 → 里克达松树植林区域 → 里克达松树植林地带 → 带运动设施的休息处 → 岔路口16 → 岔路口24 → 兄弟井药水泉

登山口交通：这条路线可以从京畿杨平站（Yangpyeong Station）直接步行进入，是五条路线中大众交通便利性最好的一条。搭乘中央线电铁在杨平站下车后，不用换乘公交车就能直接开始爬山。

特色与推荐对象：这条路线会经过松树群落地、栗树植林地、里克达松树植林地带等多处人工林，能欣赏到人工林与天然林交织而成的独特森林景观。因为市区交通便利，特别适合只靠大众交通规划登山行程的游客；路线后段的兄弟井药水泉，据说是解渴的好去处。

上表中的区间是按辖区内行政洞划分的登山道区段，并非实际的登山路线名称，这一点需要留意。相比之下，正如前面所述，真正登顶主峰的实际路线大多是净爬升超过800米的高难度路线。路面情况是：下段的林间小路以泥土路和落叶混合路段为主，而上段的山脊和接近山顶处则会出现裸露的岩石与石块地段，雨天或冬季结冰时尤其要小心防滑。路线中确认有3处观景点，沿山脊攀登途中会遇到视野开阔的地方；此外未发现有另外划定的危险地带或避难所。

距离与所需时间

사진: 한국관광공사 관광사진 갤러리 (경기도 양평) · 공공누리

攀登龙门山主峰，当天往返完全够用，不需要另外安排住宿。辖区内所有登山路线合计的上山时间约为370分钟，下山约257分钟，但这是把区域内多条路段全部加总的数字，可别误以为是某一条具体路线的耗时。把这个累计值换算成距离来看，平均上山配速大概是每公里22分钟左右——套用到实际的主峰路线上，跟”8~11公里路线大约需要3小时30分到4小时20分”这个基于GPX的估算大体吻合。不过这终究只是平均配速，实际花费的时间还是要看个人体力和休息时长而定。如果打算走一个来回，建议把往返时间预留得比单程的两倍还宽裕一些，出发时间也尽量早一点，免得下山时天色已晚。

交通方式（大众交通·停车）

照片：韩国观光公社观光照片库（京畿道杨平）· 公共누리

龙门山附近，中央线电铁的龙门站和杨平站算是主要的门户站。前往龙门山观光地、龙门寺方向的路线，一般得在龙门站换乘公交或出租车才能到；不过也有像赤松林种植地路线这种，从杨平站下车直接步行就能进山的。目前确认过的、离入山口比较近的公交站有龙门山、安息馆入口、杨平站、杨平市场入口等，按自己要走的路线挑合适的站下车就行。不过公交路线和班次间隔会随时期调整，出发前最好用KakaoMap或Naver地图确认一下实时路线和站点位置，这个还是建议做一下的。自驾的话，观光地方向是有停车场的，但登山道本身好像没有专门登记的停车场，所以现实一点，还是停在观光地停车场比较稳妥。

季节·天气·装备

照片：韩国观光公社观光照片库（京畿道杨平）· 公共누리

龙门山最推荐的季节是新绿渐浓的春天和红叶绚烂的秋天。夏季山谷水量增大、湿度也高，实际爬起来会更累，所以一定要早点出发并随时补水。冬季山顶一带的稜线和岩壁路段容易结冰，需要带上冰爪、雪套之类的防寒防滑装备。不管哪个季节都少不了的基本装备包括登山鞋、足量的水（山上几乎没有取水点，一定要多备一些）、防水防风外套、登山杖和备用衣物，另外建议无论季节都随身带头灯，以防下山时间比预计晚。

外国游客小贴士

照片：韩国观光公社观光图片库（京畿道杨平）· 公共누리

龙门山的罗马字拼写为Yongmunsan，山顶标注为Yongmunsan Summit，主要寺庙龙门寺则写作Yongmun Temple。因为它不是国立公园而是普通山岳，所以不需要另外申请入山许可，不过龙门山观光地和龙门寺区域可能会收取门票，出发前最好确认一下。洗手间设在龙门山观光地入口和售票处附近，但登山道沿途几乎没有专门的饮水点，所以上山前一定要自备足够的饮用水。地图软件方面，谷歌地图上的登山路线信息经常不太准确，建议安装韩国本地常用的KakaoMap或Naver Map，查看实际路线和公共交通信息。为了安全起见，最好把行程安排在天黑前下山，同时记得给手机充好电、备好紧急联系方式。
