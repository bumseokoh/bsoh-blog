概览

照片：韩国观光公社观光照片图库（庆尚北道庆州市）· 公共누리(KOGL)

庆州历史探访自行车道（Gyeongju Yeoksa Tambang Bicycle Path / Gyeongju History Exploration Bike Route），顾名思义，就是骑着自行车把新罗千年古都庆州一带兜个遍的路线。韩国大多数自行车道都沿着河流从上游往下游走，重心是”移动”；而这条路更像是在一处处古迹之间穿针引线的”朝圣”。踩踏板的时间有多久，从车上下来的时间就有多长——所以它不适合较劲刷成绩，而是最好整天留白，慢慢消化。

地形以庆州盆地特有的平缓平地为主，河边路段视野开阔得很舒服。不过一旦驶出市区往外围走，比如去普门方向或佛国寺方向，就会掺进一些坡度不陡但持续的上坡，体感难度比想象中要高。倒不是新手骑不了，但若想一天吃下全程，还是把它当作需要一定耐力的中级路线来看比较稳妥。

玩法大致可以分成以下几种。

第一，一日历史骑行。 清早从市区出发，先绕古坟群和王宫遗址一带，下午再跑一趟郊外的寺庙方向。这是这条路线最标准的玩法，不用住宿，当天就能收工。

第二，两天一夜分段纵走。 把全程对半切开，第一天走市区古迹和河边，第二天走外围的寺庙与湖区。庆州的住宿选择挺多，中间插一晚很方便，而且每处古迹都能留出充裕的停留时间——如果重点是观光，这种走法要充实得多。

第三，小轮车、折叠车配公共交通。 把 Brompton 或 Dahon 之类的折叠车搬上火车到庆州，落地展开就骑，回程再折起来带走，这个组合尤其合适。这条路线上需要停好车、改成步行游览的地段很多，能折起来拎着走的小车优势明显。

第四，家庭、新手的部分路段骑行。 不必非得走全程，只挑市区的平地段，剪成 20~30 公里左右的短程，带孩子的家庭骑行也完全应付得来。古迹密集的区域大体平坦、路面也经过整修，负担不大。

线路信息

照片：韩国观光公社观光照片图库（庆尚北道庆州市）· 公共누리（KOGL）

这条线路从庆州市区遗迹密集的区域出发，沿河边自行车道一路向郊外延伸。起点一带会经过大陵苑周边的古坟群、瞻星台、东宫与月池、月城地区——也就是所谓”庆州历史遗迹地区”的核心地带。这一段有与马路并行的自行车道，以及公园内部的通行路，在一座座圆润隆起的古坟之间穿行的视野，是整条线路上最令人难忘的画面之一。

出了市区，就进入兄山江水系的河边道路。这一段基本属于沿江自行车专用道，等红灯的次数少了，配速也容易保持稳定。因为是在堤坝上行进，风的影响会毫无遮挡地扑面而来；但反过来说，视野开阔，是最适合提速的路段。

再往后，线路通向普门湖一带和佛国寺、吐含山方向，性质又变了。环湖路段旅游氛围浓厚，行人往来频繁，自行车与行人共用的道路也会不时出现。佛国寺方向是整条线路上坡度最明显的一段，前面最好留点体力。如果加上绕行南山山脚的选项，还能顺带收获散落着古寺遗址和摩崖佛的乡间小路风景。

路面整体状况不错，但并不均一。河边接近铺装平整的专用道，而遗迹周边和景区进出路段则混杂着共用道路或与普通道路共享的部分。也就是说，如果你带着”沿江一路都是专用道”的四大江系列线路的印象过来，预期会落空。规划行程时，请把市区红绿灯和游客的步行动线一并考虑进去。

这条线路不属于国土纵走认证制度的对象路线，因此途中没有需要打卡的认证中心。不过遗迹本身实际上就充当了检查点，所以事先把想去的遗迹按顺序列出来，做成自己的一份途经点清单，找路会轻松许多。

周边美食

照片：韩国观光公社 观光照片图库（庆尚北道庆州市）· 公共누리（KOGL）

庆州是旅游城市，吃的选择自然不少。这里就不点名具体店家了，只说说当地普遍有名的几样。

名气最大的当属庆州饼、皇南饼这类豆沙馅的小饼，还有糯麦饼。都是单个独立包装，塞进骑行服后袋或包里随身带着，骑行途中补糖正合适，市区古迹密集的区域一带基本都不难买到。作为长距离骑行的补给品，实用性相当高。

正餐方面，包饭套餐是最能代表庆州的一桌菜。小菜种类多、米饭量足，作为下午还要继续骑之前的午饭很合适。此外豆浆汤、解酒汤、韩牛烤肉、各类面食也都是本地常见的选择；像普门湖一带这种游客集中的区域，咖啡馆和餐厅分布得比较密。

从补给角度要留意的是分布不均。市区古迹区和旅游据点周边便利店、餐厅扎堆，但**河堤路和外围农道路段，可能连着相当长一段距离一家店都没有，属于彻底的无补给区间。**尤其清晨和傍晚，外围的店铺有时干脆不开门，所以请养成一个习惯：出市区之前，先在便利店把水和能量补给品补足。「到下个村子再买就行了」——这种判断最危险。

补给与便利设施

这条线路上，登记为自行车道专用的认证中心、卫生间、饮水台、打气筒，全都是 0 处。也就是说，**任何指望自行车道自身提供后勤支持的计划，都行不通。**补给与便利这一项之所以只给了★☆☆☆☆，原因就在这里。

不过也别以为是在无人区里骑车。庆州是旅游基础设施相当完善的城市，所以策略上要把城市基础设施当成替代资源来用，而不是依赖自行车道设施。具体来说：

  • 卫生间：主要遗址的参观区、公营停车场、旅游咨询处、公园里一般都设有卫生间。每次去遗址的时候先解决好再出发，最稳妥。
  • 饮水：既然没有饮水台，就默认在便利店买瓶装水。至少准备两个水壶，离开市区之前一定要全部灌满。
  • 打气与维修：自行车道上没有打气筒，所以便携气筒或 CO2 气瓶不是可选项，而是必需品。市区里或许有自行车销售、维修店，但最好事先确认好营业时间和位置。

另外，这条线路不属于国土纵贯自行车道认证制的范围，所以沿途没有可以在认证手册上盖章的印章亭。如果你的目标是收集认证章，那就得把洛东江、东海岸（庆北）等另外的认证制线路一并规划进去。认证制的整体使用方法，我在下面的”外国旅行者提示”里另作了整理。

返程计划

照片：韩国观光公社观光照片图库（庆尚北道庆州市）· 公共누리（KOGL）

这条路线是单程 77.9km 的单向型线路。骑完不会自动回到出发地，所以返程方式必须在出发前就定好。选项大致有三种。

第一，坐火车。 庆州有 KTX 和普通列车都停靠的庆州站，附近城市还有浦项站、蔚山站等。韩国铁路对携带自行车乘车，一般遵循以下原则：无穷花号、ITX 系列的普通列车上，折叠车折好后装入专用袋或车套，可以作为行李带上车；部分列车、部分区间还会挂设有自行车支架的自行车专用车厢。而 KTX 座位之间空间局促，不折叠的整车基本带不上去，所以稳妥的想法是只按”折叠车折好装套”这一种形态来规划。规定和车辆编组都可能变动，请以韩国铁路公社（KORAIL）官方指引或车站窗口当天的说明为准。如果是公路车这类不能折叠的车，通常做法是拆下前轮装进专用收纳袋（轮行袋）。

第二，坐大巴。 长途客车和高速客车一般是把自行车放进车底行李舱，多数要求拆前轮并用车套包好。不过能不能上车很大程度上取决于司机和公司的自行裁量，所以上车前一定要先问清楚。市内公交则基本可以认为带不了自行车。线路周边虽然分布着市内公交站点，但现实点看，那更适合当作”把车寄放在某处再移动”或”只让同伴移动”时的辅助手段。

第三，原路骑回（往返骑行）。 来路照原样返回的话总计 155.8km，一天内消化这个距离相当吃力。选这个方案就得凌晨出发、下午早些时候折返，还要备好夜骑车灯、备用电池和充足的补给。如果对体力没把握，建议一开始就把路线截短到往返 60~80km 的规模，重组成原点折返型。

推荐组合是折叠车 + 火车。庆州铁路可达性好，把车折起来坐火车进城、骑一整天，再坐火车离开，这种安排压力最小。另一个很实用的替代方案是：把住处订在庆州市区，行李寄放好，每天以住处为起点朝不同方向骑环线。这样就从结构上消掉了单向型线路的返程难题。

安全与注意事项

照片：韩国观光公社观光照片库（庆尚北道庆州市）· 公共누리

  • 人车共用道路段：景区周边和古迹入口路段混杂着自行车与行人共用道。庆州游客步行量很大，在古迹密集区一定要减速，把优先权让给行人。提前按铃或出声示意会更安全。
  • 汇入普通道路：河边专用道会中断，有些地方要汇入普通车道。汇入前务必确认后方，不要停留在右转车辆的视线盲区里。
  • 旅游大巴与停车拥堵：主要寺庙和古迹入口附近，大型客车通行和车辆进出停车位都很频繁。当心开门（dooring）事故和突然倒车。
  • 结冰：冬季河边堤岸路和背阴的寺庙入口路，霜与结冰会残留到很晚。桥面和背阴弯道路面温度更低，尤其危险。
  • 夜间灯光：河边路段有几处没有路灯。前灯和尾灯无论什么时段都要常备安装，行程安排上以天黑前返回市区为基本原则。
  • 注意脱水：这条线路上饮水点为 0 处。等到口渴才喝就已经晚了。每隔 20~30 分钟有意识地补水，夏季还要一并备好电解质补充剂。
  • 古迹区内骑行限制：文物保护区或参观步道内可能禁止自行车通行。请遵守指示牌，在限行区域推车步行。

季节·天气·装备

照片：韩国观光公社旅游照片库（庆尚北道庆州市校洞）· 公共누리(KOGL)

推荐季节是春季（4~5月）和秋季（10~11月）。 庆州以樱花和红叶闻名，这两个时段的风景回报最丰厚。不过也正因为如此，游客会大量涌入，所以穿越遗址区域时，工作日胜过周末，清晨胜过午后，体验会舒服得多。

夏天是这条路线最难熬的季节。庆州盆地夏季气温相当高，河边堤坝路几乎没有遮阴。再加上沿途没有饮水点，脱水风险实实在在地升高。如果非要在夏天骑，建议日出后立刻出发，上午把主要路段跑完，正午则安排室内参观或休息，把行程拆成两段。梅雨季节河边自行车道可能被淹或封闭，出发前务必确认。

冬天人少，可以安安静静地骑，但结冰和强劲的河风是变数。尤其沿河路线特有的顶风，会把体感难度拉高一大截。风大的日子别逞强，缩短路线为宜。

必备装备如下。

分类物品
安全头盔、前灯、尾灯、手套
维修便携打气筒或 CO2、备用内胎、撬胎棒、多功能工具、补胎片
补给两个水壶、能量补给（能量棒·面包类）、夏季电解质补充剂
其他防晒霜、薄款防风衣、充电宝、少量现金

之所以特别强调维修装备，是因为这条路线上的打气点是 0 处。一次爆胎就可能让整个行程泡汤，所以出发前务必检查轮胎状态和胎压。

外国游客小贴士

① 路线名罗马字标记

  • 韩文：경주 역사탐방 자전거길
  • 罗马字：Gyeongju Yeoksa Tambang Jajeongeo-gil
  • 英文含义：Gyeongju History Exploration Bicycle Route
  • 城市名：庆州 = Gyeongju（请用这个词在 GPS 和地图 App 里搜索）

② 认证制实战指南 —— 本路线不属于认证制范围

首先要说明的一点是，庆州历史探访自行车道并不在国土纵贯自行车道认证制的路线范围内。因此这条线路上认证中心为 0 处，也没有可以盖章的岗亭。如果你的目标是集章认证，那得另行规划属于认证制范围的路线。

不过为方便参考，这里还是把韩国自行车道认证制的一般情况整理如下。

  • 认证手册（Bike Passport）：想拿到国土纵贯认证，需要专用手册。官方网上销售渠道只有韩文界面，加上海外发行的信用卡和韩国本人身份验证（手机号、身份证号）这两道坎，在海外提前购买基本不现实。所以最稳妥的办法是抵达韩国后，在有人值守的认证中心（设有管理事务所的据点）现场购买。价格不高，建议带点现金比较保险。
  • 无人认证中心：绝大多数认证中心是没人值守的无人岗亭。找那种长得像红色公用电话亭的小亭子就对了。里面有一枚用链子拴着的印章，自己盖在手册对应的格子里即可。印泥干掉或印章丢失的情况时有发生，所以拍一张把亭子和自行车都拍进去的照片，日后可以当作凭证。
  • 完骑之后：走完一个路段，有人值守的认证中心会把该路段的认证贴纸贴到手册上；满足条件的话，还能领到完骑证书和纪念奖章。奖章和证书的发放通常需要另外付费并办理申请手续。

③ 如果你没带自行车

  • Ttareungi（따릉이）：首尔市的公共自行车，有英文 App，也支持海外发行的银行卡付款，外国人用起来很方便。但这是首尔地区专属服务，在庆州用不了，这一点务必记牢。
  • 当地租赁：庆州是旅游城市，主要遗址周边和市区住宿附近一般都有自行车租赁点。不过租来的车大多是市内观光用的普通通勤车，未必扛得住 77.9km 全程。如果打算跑长距离，建议提前通过住宿方确认可租的车型、还车条件和营业时间。
  • 自带自行车：最靠谱的办法，是把折叠车装上火车带过来。首尔、釜山这样的大城市里，有些自行车店提供长期租赁，如果整趟旅行都以骑行为主，这个方案值得考虑。

④ 地图 App

在韩国，谷歌地图的自行车路线导航基本不能用。受国内地图数据出境管制影响，步行和自行车路线要么不准确，要么干脆没有——只信谷歌地图的话，你会迷路。

  • KakaoMap（카카오맵）—— 支持自行车模式，自行车道标注很详细，有英文界面。
  • Naver Map（네이버 지도）—— 支持英文、日文、中文界面，公共交通换乘查询能力很强。

这两个 App 建议入境韩国前就装好，条件允许的话，出发前一晚在住处的 Wi-Fi 上把路线先搜一遍。另外，如果你用 GPS 码表，最稳妥的做法是提前下载好 GPX 文件导进去——哪怕数据漫游断了，也不会丢失路线。

⑤ 其他值得知道的事

  • 韩国的便利店（CU、GS25、7-Eleven、Emart24）一般 24 小时营业，刷卡也很方便，是骑行途中最可靠的补给点。
  • 紧急情况请拨打 119（急救·消防）、112（警察）。旅游翻译咨询由 1330 提供多语种服务。
  • 遗址区域为保护文物会有通行限制和参观礼仪要求，有些路段必须推车通过，请遵照现场指示牌。
  • 强烈建议佩戴头盔。

庆州是一座特别适合骑车的城市。在千年前王都的棋盘格局上原样穿行，这种感觉在别的任何路线上都很难获得。只是这条线路本身几乎没有任何配套支援设施，所以出发前请务必把三件事定好：水、维修工具，以及返程计划。只要准备到位，这会是一条让整个白天变得漫长而丰盈的路线。
