藏着玉泉寺山谷的山脊路，固城莲花山

概览

照片：韩国观光公社观光照片馆（全北特别自治道全州市德津区）· 公共누리 KOGL

莲花山（蓮花山，Yeonhwasan）位于庆尚南道固城郡，山顶一带的几座峰构成了海拔500多米的平缓山脊，属道立公园级别的山。登记在册的登山路段路面大多为土质，数据上各路段的难度都归为”容易”，因此整体上是一座亲和度不错、走起来不太吃力的山。不过通往主峰一带（甑峰·莲花1峰）的往返路线距离和落差都不小，实际体感难度更适合中级以上的人。山脚下坐落着千年古刹玉泉寺，因此不少人是为了把参访寺庙和爬山一并安排才来这里的。即便按往返计算，规模也完全够一天走完。

山势与地形

照片：韩国观光公社旅游照片图库（全北特别自治道全州市德津区）· 公共누리(KOGL)

莲花山的特点在于它并非只有一座尖锐的主峰，而是由多座山峰以山脊相连而成。公共数据中登记的山峰包括莲花1峰（518米）、莲花1峰（505米，另一处标记点）、莲花山524米（修正高程539米）、南山427米（修正高程443米）、仙游峰（405米）、玉女峰（404米）、甑峰（576米）、莲花山（561米）等；按实测GPX来看，主峰一带的最高海拔为574米。各山峰标注的高程略有出入，应该是地图资料与实测（GPS/DEM）数值之间的差异所致。整体来看，这里的山势并非陡峭的岩峰型，而更接近覆土深厚的土山，沿着山脊起伏平缓的路段接连不断。不过主峰附近和观景台一带也夹杂着局部的岩石地带，所以与其说是纯粹的土山，不如理解为土山与岩脊混合的地形。

登山体验

照片：韩国观光公社观光照片图库（全罗北道特别自治道全州市德津区）· 公共누리(Public Nuri)

整条路线的氛围，是从入口的溪谷与寺院林地起步，越往山脊走视野越开阔。玉泉寺附近的溪谷段，浓密的林子和潺潺水声可以一并享受；登上山脊后，固城一带的低地和邻近山峰便映入眼帘，这样的观景点会接连出现好几处。路面以土质为主，走起来相对轻松，不过登顶往返的距离偏长，越到后半段越能感觉到体力的消耗在累积。据说春天的新绿与寺院周边的花、秋天的红叶都和山脊小径相得益彰；而夏天溪谷段的湿气与茂密草木、冬天山脊背阴处的结冰，则是让实际难度往上走的因素。

路线 1 — 莲花山道立公园停车场 → 甑峰

📏 7.98km ⛰️ 444m 爬升 ⏱️ 2:44 🔁 环线 难度 ★★★★☆ ⤓ GPX

途经：莲花山道立公园停车场 → 停车场公共卫生间 → 玉泉寺溪谷恐龙足迹 → 鹰峰方向路 → 莲花1峰方向路 → 长椅1处 → 甑峰 → 甑峰观景台 → 寂灭宝宫 → 将军峰 → 岔路口26

登山口交通：莲花山道立公园停车场据说位于固城郡开川面玉泉寺附近，没有地铁可达，通常要从固城邑区或附近的长途汽车客运站打车或乘坐当地公交前往。停车场内的卫生间已登记在路标系统里，登山前后都能使用。这一带公共交通班次不多，建议出发前用地图 app 确认实际的发车时刻和路线。

特色与推荐人群：这条路线从玉泉寺溪谷起步向上，途中会经过恐龙足迹化石地等看点，再经鹰峰、莲花1峰方向的岔路口一直通到甑峰顶。甑峰观景台和寂灭宝宫可以一并逛到，适合想把风景和佛教文化遗产一起收进行程的朋友。因为包含了寺庙进山道路，前半段走起来相对轻松，但往返距离不短，更适合体力有余裕的中级以上登山者。

路线 2 — 玉川小水库停车场 → 莲花1峰

📏 8.4km ⛰️ 408m 爬升 ⏱️ 2:47 🔁 环线 难度 ★★★★☆ ⤓ GPX

途经点: 玉川小水库停车场 → 莲花山道立公园登山导览图 → 玉川小水库 → 停车场 → 通往莲花1峰的路 → 岔路6 → 莲花1峰 → 岔路8 → 岔路9 → 长凳1处 → 通往莲花2峰的路 → 莲花2峰 → 烽火台 → 岔路14 → 岔路15

登山口交通: 玉川小水库停车场就在水库旁边，是个登山起点，现场立着登山导览图，第一次来的人对照着看也能比较顺利地弄清路线。这里一般是自驾前往，公共交通不太方便；通常的做法是从固城邑内开车过来停好车再出发。

特色与推荐人群: 从水库风光起步，翻过莲花1峰、莲花2峰，一路走到烽火台，是条纵走型的山脊路线。途中要过好几个岔路口，连着翻越一座座山头，走起来别有一番乐趣。烽火台这处历史遗迹让行程不只是单纯的爬山，想看点风景之外的东西的人，或是偏爱连续踏过多个山头的山脊纵走的人，都很适合走这一条。岔路比路线 1 多，建议边走边仔细核对指示牌，这样更稳妥。

不过通往主峰一带的路线（甑峰·莲花1峰方向）实测难度为 ★★★★☆，体感难度高于辖区平均水平。路面以土砂为主，晴天打滑风险不大，但下雨时会变成泥路、容易滑倒，冬季背阴路段还要留意结冰。路线内登记的设施包括观景点 5 处、停车场 1 处，可供停下来欣赏风景的地方不少；同时也登记了 2 处危险区域，分别标注为”危险地”和”溪谷危险”，经过这些路段时尤其要小心。相反，饮水台一处都没有登记，所以最好当作途中基本无处补水来准备。

距离与所需时间

照片：韩国观光公社旅游图片库（全北特别自治道全州市德津区）· 公共누리

以登顶往返计算，有两条单程约 2 小时 40~50 分钟的路线，往返 5~6 小时左右，当天来回完全没问题。若按辖区内全部登山道（总长 21.94km）统计，上行累计 440 分钟、下行累计 305 分钟——这是把辖区内所有路段加在一起的累计值，可别误当成某一条路线的耗时。由这个累计值算出的平均上行配速约为 20 分钟/km，与登顶路线按距离推算的实际单程耗时大体吻合。辖区内没有登记在册的避难小屋，因此比起过夜的登山计划，建议还是安排成当天往返。

交通指南（公共交通·停车）

照片：韩国观光公社观光照片图库（全罗北道特别自治道全州市德津区）· 公共누리(KOGL) 开放许可

莲花山位于庆尚南道固城郡，一般的走法是：先从首尔、釜山或晋州坐长途客车到固城客运站，再换当地公交或出租车前往玉泉寺、莲花山道立公园方向。查下来附近没有登记在册的公交站点，光靠公共交通到登山口会有点折腾，所以比较现实的选择是在固城镇上打车，或者干脆自己开车。停车场登记有一处，就是莲花山道立公园停车场，自驾的话以这里为起点开始登山就行。准确的公交发车间隔和实时路线，建议用 KakaoMap 或 Naver Map 查（谷歌地图在韩国境内的公共交通和步行路线信息可能不太准）。

季节·天气·装备

照片：韩国观光公社旅游照片图库（全北特别自治道全州市德津区）· 公共누리(KOGL)

一般来说，春季（4～5月）和秋季（10～11月）最适合，能同时欣赏新绿与红叶。夏天溪谷段湿度高、草木茂密，体感难度会略微上升；遇上下雨，泥沙路面容易打滑，需多加留意。冬季背阴的山脊路段可能结冰，带上冰爪等防寒防滑装备会更安全。必备装备建议：登山鞋、足量的饮水（沿途没有饮水处，务必自备充足水量）、防雨的雨衣，以及冬季用的冰爪和雪套。

外国游客提示

照片：韩国观光公社旅游照片图库（全北特别自治道全州市德津区）· 公共누리（Korea Open Government License）

莲花山的罗马字拼写为 Yeonhwasan（或 Mt. Yeonhwa），山顶一带的几座山峰可以并列标注为 Sirubong（甑峰）、Yeonhwa-1bong（莲花一峰）等。山脚下的寺庙是 Okcheonsa Temple（玉泉寺）。这里属于道立公园范围，据了解无需另行申请入山许可，但参观寺庙院内时可能会收取少额的文物观览费，请以现场公告为准。厕所登记在莲花山道立公园停车场内，山路上没有饮水处，出发前请备足饮用水。地图应用方面，KakaoMap 或 Naver Map 在韩国境内的登山路线和公共交通信息上远比 Google Maps 准确，强烈建议一并使用。路标较多、岔路密集的路段（路线 2）请打开地图应用的 GPS 轨迹功能以免走错，昼短的季节里则要把下山时间算得宽裕些再出发。
