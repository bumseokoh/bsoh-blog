西海浪路90号线 安山海岸跑步路线

这是一条沿安山西海岸铺开的单程海岸跑步路线，一路只有平缓的起伏，从清晨慢跑到马拉松LSD训练都能广泛胜任。

跑步配速与分段策略

照片：韩国观光公社观光照片图库（京畿道安山市檀园区大阜南洞）· 公共许可（공공누리）

这条路线的性格，可以概括为”靠长度取胜的平地长距离跑”。最高海拔只有101米，累计爬升也仅为每公里8.7米，所以真正拖垮双腿的不是坡度，而是累积的距离和风。因此，配速策略的核心就是前段克制。

分段配速（推荐）

区间目标体感强度
0~4km比目标配速慢20~30秒/km可以聊天
4~10km进入目标配速，保持稳定轻松但需专注
10km~终点保持步频，缩小步幅最后2km如有余力再提速

完赛目标时间

水平配速预计用时
初级（跑走结合）8:00~9:00/km2小时~2小时20分
中级（慢跑）6:30/km左右1小时40分左右
高级（节奏跑）5:00~5:30/km1小时15~25分

对初级跑者，我推荐”跑10分钟+走2分钟”循环的跑走结合。路面平坦，走路时心率恢复得很快，全程跑下来不会太吃力。

折返点与补水时机

这是一条单程路线，基本方案是到终点后乘公共交通返回。如果是开车过来的，或者想把长距离跑量拉满，可以选择往返30.6km的方案。这种情况下，与其把中间点当折返点，不如跑到终点再原路返回，心理上会轻松得多。若打算跑往返，前半程建议比目标配速慢30~40秒/km，以防后半程崩盘。

补水要在感到口渴之前进行，建议每隔20~25分钟分两三口小口补充。夏天把间隔缩短到15~20分钟；如果要挑战往返，请一并准备电解质饮料或盐丸。

补水·便利设施·洗手间

照片：韩国观光公社旅游照片图库（京畿道安山市檀园区布谷山路107（大阜北洞）· 公共著作权 Kogl）

在海岸和围垦地路段绵延不断的路线上，最好不要假设沿途的便利设施是均匀分布的。我建议遵循以下几条原则：

  • 出发前把水灌满：在进入登山口之前，先在公交站附近或市区路段把水装满、上好洗手间。建议带两个 500ml 软水壶，或在跑步背心里装 1L。
  • 提前查好点位：在地图 App 上沿着路线预先搜索”便利店""洗手间""公园”，并至少保存两处以上作为补水候选点。关键在于留好备选方案，以防实际到了发现没开门。
  • 善用村庄路段：海岸路之间穿插的村庄、停车场、休息点路段，实际上就是补给点。经过这些路段之前，先检查一下剩余的水量。
  • 往返路线可设补给缓存：如果是开车前往，最稳妥的办法是在车里放些备用饮料，往返中途折回来补充。
  • 随身带现金和交通卡：为了小额消费和回程车费，身上务必常备一张交通卡。

概览

图片：韩国观光公社观光图片库（京畿道安山市檀园区富兴路232-68（大阜南洞）· 公共Nuri（KOGL）

西海浪之路90号线（Seohaerang-gil Course 90）是一条沿着安山（Ansan）西海海岸延伸的滨海跑步路线。它不是山地越野路线，而是由海岸公路、步行道、木栈道和村间小路串联起来的平地路线，所以不用担心碎石路对脚踝的考验，取而代之的是视野开阔的直线节奏感。大海、滩涂和天空构成的辽阔景观让跑步不那么容易乏味，也很适合稳定地保持配速。

推荐用法

  1. 周末长距离跑 / 马拉松LSD训练：红绿灯少、陡坡少，适合把心率压在低位进行长距离训练。往返拉长到30.6公里，正好是备战全马的30公里训练。
  2. 晨跑：在日出时分看着大海奔跑的路线，也可以只截取一部分，当作5~8公里的环线来用。
  3. 旅行跑（Runcation）：从首都圈当天即可往返，很适合把周末出游和跑步合二为一。
  4. 新手走跑结合·跑步初体验：几乎没有起伏负担，适合用走跑交替的方式完成人生第一次长距离。
  5. 节奏跑·配速感训练：在平坦的路面上练习把每公里分段计时跑得均匀，再合适不过。

路线信息

照片：韩国观光公社 观光照片图库（京畿道安山市檀园区大船路466（大阜南洞）· 公共文化信息开放许可（공공누리））

起点建议选在高莱嘴入口（Goraetburi-ipgu）公交站附近，路线沿海岸线呈南北向延伸，一直到与下一段路线衔接的地方结束。中途会经过大南小学（Daenam Elementary School）公交站附近，把这两个点分别作为起点和中间参照点来划分区段，规划起来会轻松许多。

路面大致有四种类型交替出现。

路面类型特点跑步注意事项
海岸公路·防潮堤视野开阔，直线路段长顶风路段可能较长
木栈道脚感柔软，冲击小遇雨、露水、霜冻时非常滑
村道·人行道与居民日常动线重叠注意行人及车辆进出
土路·碎石混合脚感舒适但有凹凸小心崴脚，保持步频

沿途风景由海景、滩涂、防潮堤线条和海边村落循环构成。路线略有起伏，算不上完全的平地，但从最高海拔101米这个数字就能看出，不会有打断跑步节奏的陡坡。

前往方式（交通指南）

照片：韩国观光公社 观光照片图库（京畿道安山市檀园区Dongju-gil 41（大阜洞洞）· KOGL公共许可

乘坐公共交通完全可以到达，但需要换乘，所以便利程度算是中等水平。

  • 铁路：搭乘首都圈电铁4号线或水仁·盆唐线，先到安山市区的车站（中央站、汉大前站、常绿树站等）。从首尔市中心出发，大约需要1小时到1小时20分钟。
  • 换乘公交：在安山市区车站前的公交站换乘开往海岸方向的市内公交。下车站点以Goraetburi入口或大南小学为路线起点的参照站。
  • 务必确认发车间隔：海岸方向的线路发车间隔比市区线路要长得多。出发前请查好实时公交信息，并且**提前把终点站返程末班车的时间截图存好。**在单程型路线上，最常见的翻车原因就是回程交通没着落。
  • 自驾：可以利用海岸公路沿线的公营停车场和村级停车场。周末和旺季往往上午就停满了，建议尽早出发。开车前往的话，采用往返30.6公里、或者到中点折返的方式，就能干净利落地解决回程问题。
  • 出租车：有时下了公交站离路线起点还有一段距离，提前装好叫车App会方便不少。

安全·注意事项

照片：韩国观光公社观光照片图库（京畿道安山市檀园区富兴路359-43（大阜南洞）· 公共Nuri版权）

  • 人车混行路段：村道和人行道路段车辆进出频繁。建议调低耳机音量、只戴单耳，或者使用骨传导耳机。
  • 夜间视野：海岸路段有些地方路灯稀少。日落之后请务必佩戴头灯和反光装备，条件允许的话，尽量避免夜间独自跑步。
  • 海岸风：会出现长距离朝同一方向顶风的路段。逆风时别硬撑着维持配速，改按体感强度来跑。
  • 炎热·脱水：一路都是缺少遮荫的开阔路段。夏季请把时间挪到上午9点前或日落前后，一旦出现头晕、发冷、停止出汗等信号，立即停止。
  • 路面湿滑：木栈道和防潮堤顶部被雨水、露水、霜或海雾打湿后非常滑。在湿滑的栈道上请缩小步幅、延长触地时间。
  • 潮位·天气：海岸路段遇上强风、海雾时体感危险会明显增大。如有气象预警，最好推迟行程。
  • 紧急联络：报警112、急救119。有些路段很难描述所在位置，请提前熟悉地图App的坐标分享功能。

季节·天气·着装

图片：韩国观光公社旅游图片库（京畿道安山市檀园区富兴路376）· 公共Nuri许可（KOGL）

推荐季节是4~5月和9~11月。气温宜人、视野通透，能把海岸风光尽收眼底。

季节特点应对
春最佳。但风依然可能很大薄款风衣
夏缺少遮阴，湿度高清晨或傍晚跑，补充电解质，多带水
秋最佳。空气清爽，配速容易上来天黑得早，带头灯
冬海风让体感温度骤降，木栈道易结冰防风夹克、手套、脖套，抓地力好的鞋

着装·装备清单

  • 有缓震的公路跑鞋（不需要越野鞋）
  • 500ml~1L的水（软水壶或跑步背心）
  • 帽子或空顶帽、防晒霜、太阳镜
  • 防风夹克（应对海岸大风，无论哪个季节都建议带上）
  • 能量胶或能量棒1~2个（跑10km以上或往返时必备）
  • 充电宝、交通卡、身份证件
  • 膝盖或脚踝有旧伤的话，带上压缩护套

外国跑者小贴士

照片：韩国观光公社旅游图片库（京畿道安山市檀园区Jalpuri-gil 107（大阜南洞）· 公共努里授权）

Course name：西海浪路90号线 — Seohaerang-gil Course 90，位于京畿道（Gyeonggi-do）安山市（Ansan-si）。起点公交站是 Goraetburi-ipgu（고랫부리입구），中途参照点是 Daenam小学（대남초등학교，Daenam Elementary School）。建议把韩文原文名称直接截图保存，这样确认公交站和叫出租车都会容易得多。

地图应用：在韩国，谷歌地图的步行、跑步路线导航常常不准确，甚至根本不提供。请安装 KakaoMap 或 Naver Map。这两款应用都支持英文界面，步行路线、公交站、洗手间、便利店的搜索结果与实际地形吻合度很高。最准确的用法是把上面的韩文名称直接粘贴到搜索框里。为防途中信号中断，请提前保存路线区间的离线地图或截图。

公共交通与交通卡：换乘查询用 Naver Map 或 Kakao Metro / Kakao Bus 应用最准确。支付方面，在便利店购买并充值 T-money 或 Cashbee 交通卡，公交、地铁和部分出租车都能通用。海外发行的非接触式银行卡在某些线路上可能受限，所以备一张交通卡更稳妥。打车推荐用 Kakao T 应用。

补水与便利店：韩国的便利店以 GS25、CU、7-Eleven、emart24 为主，矿泉水、电解质饮料（宝矿力水特、佳得乐之类）、香蕉、能量棒都能买到。不过这条路线的海岸段便利店间隔可能很大，**请把”出发前灌满水”当作铁律。**洗手间可以在地图应用里搜索”화장실（hwajangsil，洗手间）“，公园、停车场、公交站周边一般都有。

其他：自来水不建议直接饮用，请购买瓶装水。紧急电话是119（急救·消防）和112（警察），旅游翻译咨询热线1330提供24小时英语服务。这是一条单程路线，务必先确认返程末班车时间；如果是独自跑步，出发前请把预计结束时间告知住处或熟人。
