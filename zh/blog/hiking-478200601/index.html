藏着千年摩崖佛的花岗岩山脊——庆州南山

概览

照片：韩国观光公社观光照片图库（首尔特别市）· 公共누리

庆州南山（Gyeongju Namsan）位于庆尚北道庆州市南部，是一座海拔不高的山，最高峰高位峰（高位峰）约539米。整座山被称为新罗时代佛教遗迹的露天博物馆，摩崖佛、石佛、塔材、寺址散落各处，因此与韩国其他山不同，在这里登山与文化探访是同时进行的。虽然本身海拔不高，但山脊绵延很长，辖区内登山道总长（多条路线合计）达30.01公里，步道网络铺展得相当开阔。数据上的难度最高只归为”中等”级，无需专业攀登技术即可走，不过按路线不同也有单程6~9公里、耗时3小时左右的路段，作为一日行程仍足够有挑战性。这是一座适合串联三陵、鲍石亭、萝井、瞻星台等新罗历史遗迹一起走的山，大多数路线当天来回都能轻松走完。

山势与地形

照片：韩国观光公社观光照片图库（首尔特别市）· 公共누리

庆州南山是典型的花岗岩土山与岩山混杂的地形。沿着山脊，随处都能看到裸露的花岗岩岩壁，以及刻有摩崖佛的巨石，因此柔软的土路与岩脊路段会交替出现。代表性的山峰是南侧的高位峰（约539米）和北侧的金鳌峰，沿着连接两座山峰的山脊，三陵溪、茸长溪、佛谷、塔谷等多条溪谷呈放射状延伸开去，所以无论从哪个方向上山，最终都会汇入顶峰一带的主脊。溪谷地带松林茂密，登上山脊后则是花岗岩裸露的开阔视野路段接连出现，可以把庆州市区和辽阔的原野一并收入眼底——这正是它在地形上的独特之处。

登山感受

照片：韩国观光公社观光照片图库（首尔特别市城东区圣水洞1街）· 公共누리

入口的溪谷路段大多是平缓的土路和松林小径，走起来负担不大，一路上还能遇见摩崖佛、石佛坐像等，颇有趣味。越靠近山脊，裸露花岗岩的路段就越多，出现需要留意落脚点的岩脊地形；到了顶部的高位峰附近，视野豁然开阔。春天有杜鹃和新绿，秋天有红叶，与古迹相映成趣，季节感格外分明；夏天山脊段少有遮荫，暑热感受会比较强烈。整体来说，这条路线「一半是轻度登山，一半是历史寻访」，很适合想把爬山和文化遗产探访一并享受的人。

路线 1 — 三陵谷第一寺址塔身与佛像 → 高位峰

📏 9.39km ⛰️ 445m 爬升 ⏱️ 3:05 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

途经：三陵谷第一寺址塔身与佛像 → 岔路口 → 途经点 35 → 栈道顶端 → 途经点 37 → 途经点 38 → 途经点 39 → 高位峰 → 途经点 46 → 观景台 → 岩脊路段 → 途经点 49 → 途经点 50 → 途经点 51 → 途经点 52

登山口交通：前往三陵方向，一般是从庆州市区乘公交车过来，也有游客选择利用三陵的停车场。具体的公交站点和停车信息，建议出发前用地图 App 再确认一遍。

特色与适合人群：这条路线穿过新罗王陵与佛像、塔身密集的三陵溪谷，一路登上高位峰顶，在五条路线中距离和海拔落差都属于最大的一档。前段的遗迹参观路段走完之后，接着就是木栈道台阶和岩脊路段，越往后体力消耗越大；靠近山顶的观景台上，可以把南山一带的风景尽收眼底。适合那些既想看历史遗迹、又想认真爬一趟山的人。

路线 2 —— 19 号航点 → 山顶

📏 6.82km ⛰️ 418m 爬升 ⏱️ 2:24 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

途经：19 号航点 → 停车场 → 25 号航点 → 26 号航点 → 27 号航点

登山口交通：登山口附近能找到停车位，但没有标注确切地名，出发前最好用地图 App 确认一下实际的进山路。

特点与适合人群：路标沿途的经过点比较单纯，坡度也平缓，是五条路线里相对好走的一段。入口处就有停车位，自驾前来的人很方便；沿途遗迹点较少，适合那些只想专心走山脊的人。

路线 3 — 巴士 → 高位峰

📏 6.99km ⛰️ 418m 爬升 ⏱️ 2:27 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

途经：巴士 → 南山遗址导览所 → 西南山停车场 → 三佛寺 → 三佛寺停车场 → 卫生间 → 庆州拜洞石造如来三尊立像 → 拜里石佛立像 → 禅房谷石佛立像 → 岔路口 → 枫树 → 望月寺 → 公共墓地 → 庆州拜洞三陵 → 三陵林

登山口交通：可乘坐开往西南山方向的巴士抵达；途经点里有西南山停车场和三佛寺停车场，自驾同样方便。南山遗址导览所可以先了解相关信息。

特色与推荐人群：这是一条遗迹密集的路线，沿途会经过拜洞石造如来三尊立像、拜里石佛立像等多尊国家级文物佛像，再经望月寺一路延伸到三陵林。途经点中有卫生间，便利设施相对好找。如果你更想把重心放在历史寻访而不是爬山上，这条路线尤其值得一试。

路线 4 — 罗井入口 → 山顶

📏 6.31km ⛰️ 414m 爬升 ⏱️ 2:16 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

途经：公交 → 罗井入口 → 庆州罗井 → 停车场 → 六部殿 → 月岩岭 → 休息处 → 庆州南涧寺址幢竿支柱 → 鲍石亭卫生间 → 售票处 2,000 韩元 → 庆州鲍石亭址 → 红叶 → 鲍石亭小卖部 → 家庭休息区营地 → 咨询处

登山口交通：可乘公交直达罗井入口，附近有停车场。途中经过售票处（门票 2,000 韩元），参观鲍石亭址时会产生少量门票支出。

特色与推荐人群：这是一条把承载新罗始祖传说的罗井与鲍石亭址串在一起的文化路线，沿途小卖部、卫生间、家庭休息区营地等设施齐全，在五条路线中便利性最高。这里也是有名的赏枫地，适合全家出游，或是把散步和登山合在一起的轻松行程。

路线 5 — 公交 → 庆州瞻星台

📏 8.84km ⛰️ 400m 爬升 ⏱️ 2:53 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

途经：公交 → 校洞本家雪浓汤 → 二代庆州手工刀削面 → 粉黛乱子草 → 庆州瞻星台 → 大陵苑 → 庆州鸡林 → 月井街超市 → 庆州乡校 → 月精桥 → 红叶 → 庆州月城 → 庆州石冰库 → 庆州月城发掘调查区 → 休息区

登山口交通：可乘庆州市区公交抵达，路线经过餐饮街和市区商圈，是五条路线中公共交通最便利的一条。

特色与推荐人群：这是一条城区型路线，依次经过瞻星台、大陵苑、鸡林、月精桥、月城、石冰库等庆州核心古迹。相比其他四条路线，山路少，平地和遗址间的移动占了大头。它不太算纯粹的登山，更适合想用双脚把庆州历史遗迹逛个遍的旅行者，而且吃饭、买零食都很方便。

※ 路段名称按行政区划划分，并非登山道的正式名称，而是统计辖区内登山道总长度（30.01km）的单位。

数据中登记的最高难度是”中等”，整体来说算是比较平缓的一类，但山顶一带和高位峰附近确实有花岗岩岩脊路段，实际走起来的体感难度可能比标注的更高。尤其是路线 1 和路线 5 的 GPX 难度被评为 ★★★★☆，也正是这些岩脊和高差路段的缘故。路面方面没有单独登记的细项，不过花岗岩岩石路段一下雨就格外湿滑，冬天还有结冰的风险，需要特别小心。公共数据中也查不到观景点、饮水台、避难所、危险区域等设施点位（POI）的登记数量，所以别指望山里有什么便利设施，出发前把该带的水和装备准备齐全，才是最保险的做法。

距离与所需时间

照片：韩国观光公社观光照片图库（首尔特别市中区）· 公共信息开放许可（KOGL）

庆州南山的主要路线大多是单程 6~9km、耗时 3 小时左右，就算按往返算，也是一天之内能轻松走完的当日登山地。不过，山内登山道总长度达 30.01km，如果想把多个路段串起来纵走整个南山，一天是吃不下来的，建议考虑在庆州市区住上一晚，分成 2~3 天来走。顺便说一句，有个数据是山内全路段累计上行 559 分钟、下行 387 分钟——这是把南山所有登山道加总后的累计时间，并不是单条路线的耗时。用这个累计值除以距离，算出平均上行配速约为 19 分钟/km，可以作为参考，大致感受一下南山这种缓坡土路与岩脊路段混杂的整体步行速度。至于每条路线实际要走多久，还是按上面路线表里的数字（约 2 小时 16 分~3 小时 5 分，单程）来规划更准确。

交通指南（公共交通·停车）

照片：韩国观光公社观光照片库（首尔特别市中区）· 公共版权

前往庆州南山，一般是先坐 KTX 到新庆州站或庆州站，再换乘市内公交。不同登山口对应的目的地不一样——三陵、萝井、鲍石亭、瞻星台等等，所以出发前建议在 KakaoMap 或 Naver Map 上搜一下你想去的登山口名称，确认实际的公交线路和站点。目前能查到的登山口附近公交站有：三陵、南山温泉、萝井入口、五陵十字路口、月城洞行政福利中心、瞻星台，可以根据自己走的路线挑最近的一站。公共数据里没有登记专用停车场，所以自驾的话，最好提前用地图 App 搜好三佛寺停车场、西南山停车场这类路线途经点的停车位，或者附近的公营停车场。谷歌地图在韩国的公交和步行路线指引经常不准，到了当地强烈建议用 KakaoMap 或 Naver Map。

季节·天气·装备

照片：韩国观光公社观光照片图库（首尔特别市中区）· 公共누리

爬庆州南山，最舒服的时节是春天（4～5 月）和秋天（9～11 月）。春天有满山的杜鹃和新绿，秋天则是红叶与古迹交织的景致。夏天山脊路段几乎没有遮阴，体感温度偏高，虫子也多，所以最好赶早出发，并备足饮用水。冬天积雪量本身不大，但花岗岩岩脊路段容易结冰，带一副轻便冰爪会更安心。不分季节都该带的东西：登山鞋（徒步鞋）、充足的饮用水（山里基本没有饮水处，全程得自己背）、防晒帽和防晒霜、登山杖等。这条路线本身也是一趟古迹探访，所以穿轻便些的衣服、带上相机也很值得。

外国旅行者小贴士

照片：韩国观光公社旅游图片库（首尔特别市中区）· 公共누리

庆州南山的罗马字拼写为 Gyeongju Namsan，顶峰高位峰写作 Gowibong；主要登山口三陵为 Samneung，罗井为 Najeong，鲍石亭为 Poseokjeong，瞻星台为 Cheomseongdae。进入登山道本身不需要入山许可，也不收门票，但线路 4（罗井入口 → 山顶）会经过鲍石亭遗址，参观时可能需要 2,000 韩元门票。山内的厕所和饮水处因线路而异，差别很大：仅在线路 3 的三佛寺停车场附近、线路 4 的鲍石亭附近确认有厕所可用，其余路段基本别指望有配套设施，所以出发前先上厕所、带足饮用水才稳妥。找路方面，KakaoMap 或 Naver Map 比 Google 地图准确得多，建议出发前务必装好这两款中的一款。山中有些路段信号不佳，最好提前保存离线地图；白昼较短的季节则要把下山时间安排得宽裕些，务必在日落前下到山下。
