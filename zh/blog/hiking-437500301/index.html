溪谷之美与岩脊之美交融的江原头陀山

概述

照片：韩国观光公社观光照片库（江原特别自治道东海市三和洞）· 公共누리

头陀山（Dutasan）横跨江原道东海市和三尺市的交界处，主峰一带海拔约1,380米左右，根据实测GPX数据，通往山顶的最高点可达1,428米。这里毗邻武陵溪谷（Mureung Valley），是当地颇具代表性的名山，兼具溪谷之美与岩石山脊之险，在江原东海岸一带算得上首屈一指的登山胜地。通往主峰一带的路线距离和高差都不小，体力消耗较大，但只要凌晨或清晨早早出发，当天往返完全不成问题。不过公共交通不太方便，山路上也没什么地方能补给饮用水，所以事先做好准备格外重要。

山势与地形

照片：韩国观光公社观光照片库（江原特别自治道东海市三和洞）· 公共누리

头陀山是一座典型的”土山”与”石山”特征兼具的山。山体下部覆盖着茂密的森林，山脊线平缓延展，属于典型的土山地貌；而到了主峰一带和部分山脊路段，则露出岩脊与峭壁，呈现出截然不同的一面。据公共数据登记，主要山峰包括햇댓等（988米）、头陀山主峰区域（1382米与1371米，分别单独登记为两个点位）以及쉰음산（689米），这些山峰沿山脊相连，构成了整座山的骨架。头陀山一带广为人知的地形还包括武陵溪谷，以及베틀바위（织机岩）、头陀山城等岩壁与峡谷交织的景观，溪谷下游一带更以宽阔的盘石和深潭闻名。越往主峰靠近，陡坡与峭壁路段就越多，地形变化对体力和注意力都提出了不小的考验。

登山的感觉

照片：韩国观光公社观光照片图库（江原特别自治道东海市三和洞）· 公共누리

头陀山的山路变化相当明显：从入口处的溪谷路和林间小道起步，越往上走，岩石棱线和陡坡就越多。前半段一直走在阔叶树与松树混生的林荫下，就算是夏天也感觉比较凉爽，一路听着溪水声前行，据说给人的感觉相当舒心。到了中段以后海拔渐高,视野开阔的地段开始出现，越接近顶峰，陡坡和悬崖地形就越密集，体感难度也随之骤增。这座山春天新绿与野花齐放，秋天红叶映衬溪谷，四季变化十分鲜明；到了冬天，背阴的陡坡路段很容易结冰，整个登山氛围也会随之变得肃穆起来。

路线1 — 国家地点编号 → 山顶

📏 13.74km ⛰️ 1267m 爬升 ⏱️ 5:33 ➡️ 单程 难度 ★★★★★ ⤓ GPX

沿途经过：国家地点编号 → 岔路口 → 观景点 → 直升机停机坪 → 河流泛滥路段 → 保护树木 → 拍照点 → 悬崖 → 简易休息处 → 武陵溪谷名胜导览图 → 将军岩 → 山慈姑（얼레지）休息地

登山口路线：这条路线的登山口似乎是从武陵溪谷名胜区附近开始的，一般都是从东海市或三陟方向坐巴士或出租车过去。目前没查到专用停车场的资料，所以直接停在武陵溪谷景区的停车区域应该是最省心的办法。

特点·推荐对象：在三条路线里，这条无论是距离还是耗时都是最长的，累计爬升也最大，据说比较适合体力有底子的人。前段会经过河流泛滥路段和保护树木区域，能把溪谷的氛围充分感受一遍；到了后半段的悬崖、简易休息处、将军岩一带，据说岩壁景观会一路延续。由于登山口不太好靠大众交通精准抵达，对开车或打车的人来说这条路线走起来会顺手不少。

路线2 —— 大岘停车场→大岘展望台

📏 6.24km ⛰️ 538m 爬升 ⏱️ 2:27 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

经由路线：大岘停车场 → 大岘展望台 → 大岘造型物 → 大岘休息所 → 大岘公共厕所 → 岔路口 → 简易休息处 → 太阳岘岭（햇댓등） → 陡坡段 → 观景点 → 三角点

登山口交通：大岘据说位于连接三陟和太白的白头大干山道上，路边配有停车场和休息设施，是三条路线里自驾最方便的登山口。公共交通线路有限，比较现实的办法是从三陟市区打车过去。

特点·推荐人群：这条路线在三条路线里距离和爬升都最小，相对来说负担较轻。入口处集中了大岘造型物、休息所、厕所等基本便利设施，出发前准备很方便，据说过了太阳岘岭之后会有一段视野开阔的路段。只要留意陡坡段，这条路线很适合只想用半天时间感受一下白头大干山脊氛围的人。

课程3 —— 天恩寺停车场厕所 → 山顶

📏 9.17km ⛰️ 1151m 爬升 ⏱️ 4:13 ➡️ 单程 难度 ★★★★★ ⤓ GPX

经过地点：天恩寺停车场厕所 → 天恩寺停车场 → 东安寺 → 保护树 → 简易停车场 → 小型厕所 → 天恩寺 → 岔路口 → 拍照点 → 观景点 → 陡坡地段 → 五十音山 → 五十井

入口交通：天恩寺（Cheoneunsa）是三陟地区一座颇有名气的寺庙，从三陟市区开车或打车过去都很方便。入口处配有停车场和厕所，三条路线里，这条的起步便利性算是最好的。

特点·适合人群：路线前段要穿过天恩寺、东安寺等寺庙内部，能一路感受些许禅意氛围，算是这条线的一大特色。翻过五十音山，经五十井药水附近再往山顶去，这段距离和爬升都不小，得留着体力慢慢分配。比较适合既想逛寺庙又想登顶的人，也适合想从武陵溪谷对面进山的朋友。

按公共数据统计，危险地带、观景点、饮水处（山泉）、避难所、登山口/下山口等登记点数量均为0，也就是说这座山不太能指望沿途设施，必须自备好装备和饮用水才能上山。实际路线上有多段（1号路线的悬崖、2、3号路线的陡坡）会出现悬崖、陡坡等岩脊地形，雨天、落叶堆积的秋季，以及结冰的冬季尤其要小心防滑摔倒。据说越往山顶走，裸露的岩石越多，所以登山杖和登山鞋的抓地力就显得格外重要。

距离与耗时

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 동해시 삼화동) · 공공누리

두타산 관내 등산로 총연장은 22.26km인데, 이건 여러 구간을 다 합친 수치라 하나의 코스 거리로 착각하면 안 된다. 이 산은 관내 등산로 총연长为22.26公里，这是把多段路线加总后的数字，千万别误当成单条路线的距离。按实测GPX数据，通往山顶一带的路线单程距离从6.24公里（댓재路线）到13.74公里（国家地点编号路线）不等，单程预估耗时也从约2小时27分到5小时33分不等，跨度不小。官方给出的是全区间累计数据：上山508分钟、下山353分钟，换算下来平均上山配速约为每公里23分钟。不过这个配速是把辖区内所有路线加总后算出来的平均值，并不代表某条具体路线的实际耗时，真正规划行程时还是得参考上面按路线分列的表格。若考虑往返登山，即便是最短的댓재路线也得花上大半天，最长的路线甚至要耗上一整天，所以最好一早出发，行程安排也要留有余裕。由于沿线没有登记在册的庇护所，比起过夜山行，更常见的做法是当天往返。

交通方式（大众交通・停车）

照片：韩国观光公社观光图片库（江原特别自治道东海市三和洞）· 公共누리

头陀山位于江原道东海市与三陟市交界处，从首尔等首都圈出发，一般是先坐KTX或市外巴士到东海站或三陟巴士客运站，再转乘市内巴士或出租车到各个登山口。据说前往武陵溪谷方向的登山口有地区巴士线路可到东海、三陟市区，但去大岾(댓재)或天恩寺方向的话，公共交通班次有限，很多时候打车反而更现实。公共数据显示附近登记在册的公交站和停车场数量都是0，所以建议出发前用KakaoMap或Naver Map再确认一下实际的车站位置和停车情况。自驾的话可以用武陵溪谷景区停车场、大岾路边停车位等，但旺季和周末容易拥堵，最好留出充裕的时间早点出发。

时节·天气·装备

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 동해시 삼화동) · 공공누리

据说头陀山最受欢迎的季节是春天（4~5月）和秋天（9月末~11月初），这两个时候能同时看到新绿或红叶，风景最好。夏天走山谷段会比较凉快，这是优点，但下雨时陡坡和岩棱路段容易打滑，得多留心；梅雨季节谷水暴涨，像河川泛滥路线这类区段更是要格外小心。冬天背阴处和山顶附近的陡坡经常结冰，难度一下子拔高不少，冰爪、绑腿这些冬季装备是必备品。不管哪个季节，登山鞋、登山杖、充足的饮用水（山上没有山泉，建议至少备1.5~2升以上）、防风防水外套、头灯（应对长距离路线）、应急食物和急救用品，这些都最好准备齐全。

外国游客小贴士

照片：韩国观光公社观光图片库（江原特别自治道东海市三和洞）· 公共누리

두타산的英文标注为”Duta Mountain”或”Dutasan”，主要地名的罗马字拼写分别是：武陵溪谷（Mureung Valley）、天恩寺（Cheoneunsa Temple）、댓재垭口（Daetjae Pass）、쉰음산（Ssaeneumsan）等。据了解，进山本身通常不需要另外申请许可证或购买门票，但武陵溪谷等部分景区可能设有自己的门票，建议以当地告示牌信息为准。洗手间方面，第3号路线的天恩寺停车场洗手间、小型洗手间，以及第2号路线的댓재洗手间等在登山口附近可以找到几处，但据了解登山途中没有洗手间或饮水点，所以出发前务必先解决，并携带足够的饮用水。Google地图在韩国境内标注的登山路线常常不准确，强烈建议提前安装KakaoMap或Naver Map，确认实际登山路线及公共交通路线。通信信号在山脊地带大体畅通，但在接近山顶的岩石地段，出于安全考虑更建议结伴同行而非独自登山；下山时间也要留有余裕，尽量在日落前完成下山，这样比较安全。
