概述

照片：韩国观光公社观光照片资料库（江原特别自治道旌善郡旌善邑）· 公共누리

加里王山（Gariwangsan，迦利王山）坐落在江原道旌善郡与平昌郡的交界处，主峰最高处约海拔1,597米。作为太白山脉深处的一座高山，因2018平昌冬奥会滑降比赛场地——加里王山高山滑雪赛场就设在附近——而广为人知。登山步道大体以平缓的土路为主，路面本身的难度不算高，但到山顶的距离长、总爬升大，体力消耗上绝不是一座轻松的山。由于交通不算方便、路线又长，虽然当天往返也可以走完，但如果想走全程纵走或安排得从容一些，很多人会选择在山上留宿一晚。

山势与地形

照片：韩国观光公社观光照片图库（江原特别自治道旌善郡旌善邑）· 公共누리

加里王山不是那种以尖峰怪石取胜的山，而是典型的”肉山”型高山——厚实的山脊配上幽深的山谷，浑然一体。山顶一带比较特别，加里王山主峰（1,556米）、主峰路标附近（1,569米），还有比这两处都高一些的加里王寺峰（1,593米）彼此相邻，整片山势显得宽阔而平缓，没有陡然拔起的感觉。半程的山脊上有座泉水峰（1,252米），顾名思义，那一带正是出水的地方。整座山几乎被原始森林般的植被覆盖，尤其是被称为”苔藓谷”的那段溪谷，历经岁月堆积的青苔、瀑布和深潭交织在一起,那种江原道山林特有的原始气息，扑面而来。

登山的感受

照片：韩国旅游发展局旅游图片库（江原特别自治道旌善郡旌善邑）· 公共누리

加里旺山的登山路线从起点到接近山顶的绝大部分路段，都在郁郁葱葱的针阔叶混交林下延伸，走的是泥土路，脚感柔软，林荫浓密，即使夏天爬起来也相对凉快。不过沿溪谷而上的路段，长满青苔的岩石和湿滑的地面会让人时不时得打起精神防滑。越接近山顶，坡度陡增，呼吸也随之急促起来，而到了山顶附近，视野豁然开朗，江原道层层叠叠的群山一览无余。秋天这里是橡树与枫树交织成的红叶盛景巅峰期，冬天则因高山地带的特性积雪深厚,能让人真切感受到雪山行走的那份意境。

路线 1 —— 长鼓项 → 山顶指路牌

📏 9.79km ⛰️ 1161m 爬升 ⏱️ 4:23 ➡️ 单程 难度 ★★★★★ ⤓ GPX

经过点：长鼓项入口 → 苔藓谷1瀑 → 指路牌 → 苔藓谷6瀑 → 苔藓谷9瀑 → 简易休息处 → 岔路口 → 苔藓岩 → 红豆杉 → 山顶指路牌 → 山顶 → 渔隐谷 → 渔隐谷瀑布 → 渔隐谷瀑布水脉 → 千日窟一景

入口交通：长鼓项位于旌善郡的山区地带，公共交通十分有限。一般得从旌善市外巴士客运站搭乘开往山村的慢车，或干脆打车，班次间隔很长，出发前最好先查好时刻表。这一带没有专门的公共停车场，自驾的话大多只能停在路边或村子附近的空地上。

特色·适合人群：这条路线沿着苔藓谷一路走过好几处瀑布（1瀑、6瀑、9瀑），溪水声和满壁浓密的苔藓是最打动人的地方。累计爬升达1161米，坡度相当大，后半段的上坡会让人明显感到吃力，比较适合体力好、既想体验溪谷徒步、又想感受原始林氛围的登山爱好者。

路线2 — 发心寺入口 → 山顶

📏 10.84km ⛰️ 690m 爬升 ⏱️ 3:52 ➡️ 单程 难度 ★★★★★ ⤓ GPX

沿途：发心寺入口 → 苔藓谷 → 蕨类群落 → 岔路口 → 橡树林 → 倒木 → 直升机停机坪 → 枫树地带 → 简易休息处 → 红松林 → 有洞的枯木 → 旌善江陵府三山峰标

登山口交通：发心寺入口同样位于旌善郡花岩面附近的山区，一般是从旌善市区搭村巴或出租车过去。开车的话，很多人会把车停在发心寺进山路附近的空地上，但目前没有确认是否设有正规停车场，建议早点到，留出找车位的余地。

特点与推荐人群：这条路线距离偏长，但累计爬升只有690米，坡度相对平缓，体力消耗分摊得比较均匀。沿途会经过直升机停机坪，还有标示旌善与江陵府分界的古老三山峰标等历史遗迹，也是这条路线的一个看点。整体上不是那种拼陡坡的路线，更考验长距离的耐力，适合喜欢长时间徒步的登山爱好者。

难度·路面·注意事项

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 정선군 정선읍) · 공공누리

加里旺山辖区内的登山道，按行政区划登记的5个区段在数据上都标注为难度”简单”，但这只是各区段坡度的评估标准，实际上通往山顶的纵走型路线（长龟木耳·发心寺路线）由于总爬升落差大，体感难度要高得多。路面大多是土路，但苔藓谷路段容易因潮湿和苔藓而打滑，雨后或结冰季节需要格外小心。冬季山顶部分积雪、结冰严重，没有冰爪的话通行会有危险。公共数据中确认登记的设施只有饮水处1处（泉水），没有标注专门的观景点、避难所或危险区域，因此建议自备饮用水和应急装备再上山比较稳妥。登山口和下山口共有6处，路线选择余地还算不小。

距离与耗时

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 정선군 정선읍) · 공공누리

加里旺山境内登山道全长（各路段合计）达29.3公里，数据显示上行累计576分钟、下行累计404分钟，平均上行配速约为每公里20分钟（这是境内全部路段合并统计的累计值，切勿误以为是单一路线的耗时）。实际登顶路线中，长久木耳路线（9.79公里，约4小时23分钟）或发心寺路线（10.84公里，约3小时52分钟），仅单程就要耗时4小时左右，往返下来是8~9小时左右的长时间登山。体力充沛的话当天往返也没问题，但如果想避开拖得太长的纵走或夜间登山，建议在附近住一晚，凌晨出发比较稳妥。

交通方式（大众交通·停车）

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 정선군 정선읍) · 공공누리

从首尔等首都圈出发去加里王山，坐大众交通的话，一般是先搭KTX江陵线到珍富站，或者坐开往旌善的市外巴士到旌善市外巴士客运站，再从那里换乘开往山间村落的普通巴士或出租车。这条线路班次间隔比较长，路线也可能说变就变，出发前最好先查一下实时公交信息，免得白等。开车去的话也别太乐观——各个登山口附近目前没有正规的大型停车场，大多数人只能把车停在村里的空地或路边，所以最好留出充裕的时间提前到达，慢慢找地方停车。实际路线和最新交通信息，建议一定要用高德地图（KakaoMap）或Naver地图再三确认一遍。

季节·天气·装备

照片：韩国旅游发展局旅游照片图库（江原特别自治道旌善郡旌善邑）· 公共누리

加里旺山最适合登山的季节，是新绿正盛的暮春到初夏，以及枫叶漂亮的秋季。夏天要留意溪谷路段又湿又滑，冬天则因高山特有的积雪和结冰，难度会明显上升，冰爪、绑腿、防寒装备缺一不可。基本装备建议准备登山鞋、充足饮用水（山上只有一处饮水点，务必多带一些）、防水外套、头灯和登山杖；这条路线较长，且不少路段人烟稀少，手机备用电池和应急食物也最好带上。

外国游客小贴士

照片：韩国观光公社观光照片库（江原特别自治道旌善郡旌善邑）· 公共누리

峰顶英文可标注为 Gariwangsan Summit，主要登山口则分别是 Janggumogi Trailhead 和 Balsimsa Temple Entrance。目前没查到需要另外办理登山许可或买门票，不过路过发心寺（Balsimsa）附近时，礼貌一点总是没错。步道沿线几乎没有厕所和饮水设施（只确认有一处饮水点），建议出发前先在村子里解决好。Google 地图在韩国的登山道信息经常不准，用卡카오맵（KakaoMap）或 Naver 地图查实际路线和公交会靠谱得多——啊不好意思，是”카카오맵”，中文写就是 KakaoMap。由于山区地处偏僻，部分路段信号不太好，建议结伴同行，下山时间也要留得宽裕一些。
