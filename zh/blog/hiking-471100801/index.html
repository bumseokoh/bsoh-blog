东海尽收眼底的山脊，藏着瀑布溪谷的浦项内延山

概览

照片：韩国观光公社观光照片图库（庆尚北道浦项市北区）· 公共누리

内延山（Naeyeonsan）位于庆尚北道浦项市北区松罗面一带，主峰香炉峰海拔960米，山势相对高峻。整座山既有庆尚北道有形文化遗产，也有秀美的自然景观，因此以既能登山又能溯溪徒步而广为人知。辖区内登记在册的登山道全部加起来，总长度达85.75公里，构成了一片颇为辽阔的山域；按公共数据的分类，这里登山道的最高难度为”轻松”，整体上平缓的路线偏多。不过，通往主峰一带的主要路线距离在6~11公里、净高差在200~600米之间，视体力不同，可能耗上半天到一整天；绝大多数路线都可以当天往返，不会太吃力。

山势与地形

照片：韩国观光公社观光照片库（庆尚北道浦项市北区）· 公共누리(KOGL)

内延山不是那种只有一座尖峰的山，而是多座山峰沿着山脊连绵相接的多峰型山势。仅公共数据中登记的主要山峰就有文殊峰（636m）、三枝峰（718m）、内延山仙逸台（342m）、香炉峰（960m）、斗笠峰（745m）、内延山三枝峰（739m）、鹰峰（835m）、牛脊峰（813m）等，这些山峰通过山脊彼此相连，构成了纵走登山的舞台。整体上看，它更像林木茂密的土山，而非陡峭的岩峰，但像仙逸台这样峭壁般的岩石观景台散布在各处，站在这些观景点上，也能一并体会到岩盘地形那种开阔畅快的感觉。内延山尤其以从宝镜寺出发、一路向上游延伸的溪谷地形闻名，沿途瀑布一座接一座；这段溪谷路线也常被介绍为可以把登山与溪谷徒步合在一起走的路段。

登山的感觉

照片：韩国观光公社观光照片图库（庆尚北道浦项市北区）· 公共누리

内延山的登山路，往往从入口处就穿行在茂密的松林和栓皮栎群落之间。夏天，浓密的树荫把暑气挡在外面；到了秋天，枫树群落与栎树群落交错，铺成一条色彩斑斓的红叶小径。登上山脊，东海的海面几次闯入视野，那种开阔感是内陆山所没有的。山脊本身走得平缓，但接近顶峰时高差一点点累积起来，脚下的坡度就明显吃力了。沿途要经过雷公藤群落、槲寄生、蒙古栎群落等各种植被带，所以每换一个季节，这条山路的表情就大变一次——这是它最有意思的地方。这里的自然生态保存得相当不错，连貂的踪迹都能找到。

路线 1 — 亭子 → 梅峰

📏 7.06km ⛰️ 328m 爬升 ⏱️ 2:19 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

途经：亭子 → 岔路口 → 长椅休息处 → 梅峰 → 上玉 → 内延山山脊 → 松林 → 栓皮栎群落地 → 貂类痕迹 → 南蛇藤群落 → 山踟躅群落地 → 亭子休息处 → 东海远眺 → 东海 → 香炉峰

登山口交通：坐公共交通的话，一般是从浦项市区乘往松罗面方向的公交车，在树木园附近的站下车后步行前往登山口，这条路线用的人最多。开车来的话，多半只能停在附近的空地或路肩上，所以建议提前用地图 App 确认一下进入道路的宽度和有没有地方停车。

特点与推荐人群：穿过松林和栓皮栎群落登上山脊后，眼前的东海一次次铺展开来——这样反复出现的远眺路段是这条路线最大的魅力。从梅峰一直延伸到香炉峰的山脊路，相对于距离而言净高差并不大，在三条路线中算是比较容易上手的一条。既想登顶看景、又想享受山脊漫步乐趣的人，走这条最合适。

路线 2 — 公共厕所 → 山脊顶休息处

📏 6.26km ⛰️ 614m 爬升 ⏱️ 2:35 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

途经：公共厕所 → 下玉溪谷小卖部 → 上玉里观景处 → 山脊顶休息处 → 细叶苔草群落地 → 大松树 → 大栓皮栎 → 蒙古栎群落地 → 枫树群落地 → 槲寄生 → 下玉溪谷 → 藤五加群落地 → 内延山三枝峰、东大山观景处 → 岔路口 → 蒙古栎群落地

登山口交通：这是通往下玉溪谷方向的登山口，公共交通班次相对稀少，实际上还是自驾或打车更靠得住。溪谷入口的小卖部附近有时会有小规模的停车空地，但公共数据中查不到正式登记的停车场，所以出发前最好用地图 App 确认一下究竟能不能开进去。

特点·推荐人群：6.26km 的距离算是比较短，却集中了 614m 的净海拔差，体感坡度在三条路线中最陡。一路沿着下玉溪谷向上攀，途中数次经过可以远眺上玉里、内延山三枝峰乃至东大山的观景点，因此很适合想在短时间内既获得高度感、又能顺带看溪谷风光的登山者。大松树、大栓皮栎这类堪称古树的个体散落各处，走在其间能感受到接近原始林的氛围。

路线 3 — 入口小车停车场 → 树木园观景台

📏 11.03km ⛰️ 216m 爬升 ⏱️ 3:07 🔁 环线 难度 ★★★★☆ ⤓ GPX

途经：入口小车停车场 → 无障碍专用停车场 → 卫生间 → 树木园卫生间 → 观景台步道入口 → 树木园观景台 → 岔路口 → 笠峰（삿갓봉） → 凉亭休息处 → 保护树·独松坡（외솔배기） → 杜鹃花群落 → 栎树群落 → 枫树群落 → 巨石与观景点 → 山脊、原野与岩石

登山口交通：正如其名，入口处配有小车专用停车场、无障碍专用停车场和卫生间，是三条路线中入口配套设施最完善的一个。乘公共交通的话，可以在附近的树木园站下车步行前往；开车来的人负担也相对较小。

特点与适合人群：全程 11.03 公里，是三条路线中最长的，但净海拔差只有 216 米，坡度平缓，与其说是爬上爬下，不如说更接近一段长距离的山脊漫步。沿途经过树木园观景台和笠峰，杜鹃花群落、栎树群落、枫树群落等各类植被景观一路看下来相当丰富。比起陡坡，如果你更想要慢慢走、长时间徒步，顺便观察四季植被的变化，这条路线正合适。

难度·路况·注意事项

照片：韩国观光公社观光照片图库（庆尚北道浦项市北区）· 公共何如

公共数据中，内延山辖区内登山路的最高难度标记为”简单”，但这是以辖区全部登山路（总长 85.75km）为基准的分类；实际走一遍就知道，通往主峰一带的三条路线体感难度大约在三到四星。路况方面没有单独的详细说明，不过山脊段包含岩石地带和大岩石观景段（路线 3 的”大岩石与观景处”），下雨天要格外小心打滑。公共数据里登记的危险区域、观景点、登山口／下山口设施 POI 全部为 0 处，也就是说路线上并没有专门整修过的安全设施或指定观景台，做行程计划时得把这一点考虑进去。饮水台同样是 0 处，水必须自己带足；避难所也是 0 处，所以出发时要留出足够的时间余量，万一天气突变能及时下山才安全。

距离与所需时间

照片：韩国旅游发展局旅游照片图库（庆尚北道浦项市北区）· 公共누리

内延山的登顶路线长度在 6.26km 到 11.03km 之间，往返约 12～22km，多数人都能当日往返走完。不过如果想像纵走一样把辖区内登记的全部登山路径都走遍，总长可达 85.75km，一天肯定吃不下来；再加上山里没有避难所，就得分成几天走，或者安排住宿。公共数据里辖区全路段的累计所需时间为上行 1600 分钟、下行 1114 分钟，换算成距离，上行平均配速约为 19 分/km。这个数字不是某一条路线的耗时，而是辖区全路段合计出来的配速，所以要估算单条路线的实际用时，还是以上面各路线表格中的推算值（单程约 2 小时 19 分～3 小时 7 分）为准更准确。

交通指南（公共交通·停车）

照片：韩国观光公社观光照片库（庆尚北道浦项市北区）· 公共누리

去内延山，通常以 KTX 浦项站或浦项长途汽车客运站为起点。从浦项站或客运站换乘开往松罗面方向的巴士，靠近登山口的”树木园”站是实际确认有班次运行的站点，在这里下车后步行即可抵达各条线路的登山口。这一带班次不算多，出发前最好先查好时刻表；有需要的话，从浦项市区直接打车也是挺实际的选择。自驾的话，3 号线路的”入口小客车停车场”和”残疾人专用停车场”已确认可以使用，不过公共数据里该辖区登记的停车场 POI 记录为 0 个，也就是说其他登山口未必配有正式停车场。建议出发前用 KakaoMap 或 Naver Map 确认一下实际路况和可停车的位置再动身。

季节·天气·装备

照片：韩国观光公社观光照片图库（庆尚北道浦项市北区）· 公共누리

内延山最适合徒步的季节是春秋两季。春天有新绿以及成片的映山红和济州杜鹃，秋天则是枫树林与橡树林把山脊染上颜色，景致格外好。夏天有浓密的林荫和溪谷帮着降温，但湿度高、阵雨频繁，路面容易变滑，得做好防雨准备。冬天山脊和岩石路段可能结冰，冰爪和保暖装备必不可少；这里没有避难所，行程要留足余量，确保日落前完成下山。共通的装备清单包括：登山鞋、备用饮水（山上没有饮水处，务必带足）、防风防水外套、零食、头灯、登山杖等。

外国游客提示

照片：韩国观光公社观光照片图库（庆尚北道浦项市北区）· 公共누리

内延山的罗马字拼写为 Naeyeonsan（내연산），主峰一带的山峰可标注为 Hyangnobong（향로봉，960m）、Maebong（매봉，835m）、Samjibong（삼지봉，718m）。公共数据中没有关于入山许可或门票的信息，出发前最好通过当地的游客中心或管理处确认最新情况，这样更稳妥。厕所在路线三的登山口（入口小车停车场、树木园厕所）有记录，饮水点则没有登记，所以水一定要自己带足。地图应用推荐用 KakaoMap 或 Naver Map，它们在韩国本地的准确度比 Google Maps 高，也都有英文界面，建议提前把登山口和下山点搜好存下来。山中有些路段信号不佳，避难所和安全设施也偏少，因此最好别独自上山，找个同伴一起走，下山时间也留出充裕余地，这样更安全。
