环仙洞抱怀的喀斯特岩脊，三陟德项山

概述

图片：韩国观光公社观光照片库（江原特别自治道三陟市新基面幻仙路800）· 公共누리

德项山（德項山，Deokhangsan）位于江原特别自治道三陟市，主峰海拔1059米，与相邻的地藏山幻仙峰（1056米）以山脊相连。它是白头大干山脉的一段支脉，山顶附近发育有岩石嶙峋的岩脊和喀斯特（石灰岩）地貌，山脚下则是被指定为天然纪念物的幻仙窟、大金窟等石灰岩溶洞所在的大耳里洞窟地带。整体山势偏向平缓的土山，但通往山顶的路段落差较大，比较考验体力，而且不同路线之间的难度差异也很明显。大部分路线当天往返即可轻松搞定。

山势与地形

照片：韩国观光公社观光照片图库（江原特别自治道三陟市新基面大基里）· 公共누리

德项山整体上属于坡度平缓的土山，但山顶及周边地带受喀斯特地形影响，到处露出奇岩和石灰岩绝壁，这是它最大的特点。代表性山峰有德项山主峰（1059米）和相邻的芝角山幻仙峰（1056米），两峰之间有山脊相连，也可以走纵走路线一次登两峰。山脚下的大耳里一带是国内石灰洞窟最密集的地区之一，幻仙窟等溶洞正好体现了这座山的地质特征。根据实测路线数据，登山路径能到达的最高海拔为1111米，这个数值应该是在德项山主峰附近展望点或通往幻仙峰方向的路段测出来的。

登山的感觉

照片：韩国观光公社观光照片图库（江原特别自治道三陟市新基面幻仙路800号）· 公共누리

德项山的登山路线通常是从入口处的溪谷路开始，逐渐过渡到陡峭的山路。沿大耳溪谷向上攀登的这段，水声潺潺配上茂密的树林，让人觉得格外凉爽；但海拔越高，棱线路和岩棱路段交替出现，爬起来也就越吃力。快到山顶时，视野豁然开阔，能看到俯瞰四周棱线和山势的观景点。从季节感来说，夏天溪谷的凉意和郁郁葱葱的绿意、秋天棱线上的红叶、冬天山顶的雾凇和树挂，都是这座山让人印象深刻的看点。不过山顶一带的路线净爬升较大，还包含不少陡坡路段，体力消耗相当可观，这一点需要提前有心理准备。

路线1 — 登山口洗手间 → 观景台

📏 6.21km ⛰️ 749m 爬升 ⏱️ 2:48 🔁 环线 难度 ★★★★★ ⤓ GPX

途经：溪谷餐馆聚集区 → 1号路标点 → 大耳溪谷 → 幻仙窟乘降台 → 小空地 → 4张长椅 → 登山道前洗手间 → 仙女瀑布 → 保护树 → 幻仙窟前休息处 → 谷末（골말） → 单轨列车乘降站旁洗手间 → 幻仙窟 → 岔路口 → 观景台

登山口交通：这条路线的登山口位于大耳里幻仙窟景区附近，一般从三陟市区乘坐开往大耳里方向的市内公交或自驾前往。作为知名景区，进山道路整备得相当完善，不过附近公交站在数据里查不到具体信息，如果打算坐公交，最好提前把车次时间确认清楚，免得白等。停车场景区内确认有1处，游览幻仙窟的游客和登山客共用同一片车位，旺季的时候估计得抢位置。

路线特点与适合人群：前半段串起了大耳溪谷、仙女瀑布、幻仙窟这些景点，与其说是纯粹的登山路，不如说更像观光兼徒步的混合型路线，可以边逛景点边爬山。不过从幻仙窟往观景台爬升这一段，净爬升高度达到749米，体力消耗相当可观，加上整条路线的难度也被评为最高等级，所以比较适合平时就有一定登山经验的人。如果你想把溪谷、洞穴和展望一次体验个够，这条路线值得一试。

路线2 — 德项山登山口、外木谷 → 德项山山顶

📏 5.15km ⛰️ 366m 爬升 ⏱️ 1:54 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

沿途：耶稣院站 → 德项山登山口、外木谷 → 岔路口 → 路标点10 → 路标点13 → 观景台 → 德项山山顶 → 休息处前 → 悬崖 → 倒木处 → 木桥中段 → 洗手间

起点交通：外木谷登山口附近能看到”耶稣院站”这样的路牌，说明周边应该有个小型停靠点，但这一带的班车班次估计不会太密，还是自驾更省心。如果打算从三陟市区出发，建议出门前用KakaoMap或Naver Map查一下实时路况和最新的公交信息，心里更有数。

路线特点·推荐人群：这条路线累计爬升366米，比路线1要平缓不少，基本是沿着一条山脊一路直上德项山山顶，路线相对干脆。不过沿途会经过”悬崖""观景台”这类地名，说明途中也有需要小心通过的岩壁和峭壁地形。登顶之后视野很开阔，很适合看风景。总体来说，这条路线比较对得起那些就是想登顶、或者单纯想专心爬山的人的胃口。

难度·路面·注意事项

以辖区内登记的登山道区间为准，公共数据显示的最高难度为”简单”，但这个数字涵盖了辖区内所有区间（包括环山步道、探访路性质的路段），实际的登顶路线难度差异很大——从上表可以看到，最高能到★★★★★级别。路面情况数据里没有单独标注，但考虑到山顶一带的喀斯特地形和岩脊特征，露出岩石的路段应该不会少，尤其下雨天要特别当心打滑。从设施POI统计看，危险区域和观景点均为0处，也就是说没有专门标示的危险路段或观景设施记录在案，但实际路线沿途是有”风景好的地方""悬崖”这类提示地形特征的路标的，所以走的时候还是要留心看路标。饮水点确认有3处，详细名称都是”药水泉”，在路程较长的路线1上可以当作补水点用。停车场只有1处，登山口/下山口登记了6处，选路线的空间不小，但接驳设施本身并不算多。

距离与所需时间

德项山境内登山道总长15.09公里（多条路线合计），无论选哪条路线，当天往返都绰绰有余。最具代表性的登顶路线中，路线1（登山口洗手间→观景台）单程约需2小时48分钟，路线2（外那木谷→德项山山顶）单程约需1小时54分钟，若是原路来回，时间还是留得宽松些比较好。顺带一提，把境内全部路段累加起来的数据显示，上山269分钟、下山186分钟，由此算出的平均上山配速约为18分钟/公里。不过这个数字并非某一条具体路线的耗时，而是境内所有登山道的累计平均值，实际按路线规划行程时，还是应该以上表列出的单程时间为准。

出行方式（大众交通·停车）

德项山位于江原特别自治道三陟市，从首尔等首都圈出发的话，一般路线是先坐KTX或市外巴士到三陟或东海，再从三陟综合巴士客运站换乘开往大耳里（대이리）、道溪方向的市内巴士。不过从公共数据来看，登山路线附近并没有登记在册的公交站点，光靠大众交通到登山口可能会比较不方便，所以还是建议自驾前往。辖区内确认有1处停车场，环仙窟旅游区附近的停车场是登山客和洞窟游客共用的设施，比较为人所知。想查准确的实时路线和最新交通信息，用KakaoMap或Naver Map最靠谱；谷歌地图在国内山区的步行路线信息经常不准，不太推荐。

季节·天气·装备

德项山最适合的季节是春秋两季，气温宜人，视野也开阔。夏天沿着大耳溪谷走这条路线倒是凉快，但雨天要多留神——溪水容易暴涨，岩棱路段也会变得湿滑。冬天山顶结冰积雪，难度陡增，防滑冰爪和保暖装备缺一不可。不管哪个季节，登山鞋、登山杖、充足的饮用水（沿途虽有山泉，但为保险起见还是自备为好）、雨衣或防水外套都是标配；如果走的是长线路线（路线1），头灯也建议带上。

外国游客小贴士

德项山的罗马字拼写是”Deokhangsan”，附近的著名景点幻仙窟则写作”Hwanseon Cave”。登山路线本身不需要另外申请入山许可或购票，但如果1号线路中途要顺路参观幻仙窟，那是要另外买票的，出发前最好在当地确认一下价格和时间。厕所倒是不用太担心，路线沿途设有好几处，比如”登山口前的厕所”、“单轨列车上下站旁边的厕所”，还有2号线路上的”厕所”，基本够用了。饮用水的话，区域内有3处药水泉可以取用，不过具体位置最好还是用地图App再确认一遍，以防万一。这边推荐用KakaoMap或Naver Map，在韩国山区，这两款比谷歌地图靠谱得多。安全方面，建议出发前查一下当天天气和这个季节路面是否结冰；如果选的是1号线路这种爬升幅度大、耗时长的路线，一定要把下山时间算得宽松一些，别卡着点走。
