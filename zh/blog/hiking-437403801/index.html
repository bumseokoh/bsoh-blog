概览

照片：韩国观光公社观光照片图库（庆尚北道金泉市大项面）· 公共누리

黄岳山（Hwangaksan）横跨庆尚北道金泉市与忠清北道永同郡交界处，是白头大干山脊的一部分。据登山路线资料记载，主峰海拔在1,132米至1,142米之间。山脚下坐落着新罗时代的古刹直指寺，因此这里向来以”登山+访寺”两不误而闻名。整体上属于土山，山势较为平缓，登山路线空间信息中标注的最高难度也只是”简单”，但实际通往山顶的登山路线大多距离较长、爬升幅度也不小，走下来颇为耗费体力，属于长线路线居多的类型。选择短程路线的话，当天往返绰绰有余；但如果选的是沿白头大干山脊纵走的长线路线，一天之内走完可能会比较紧张，选路线时要多加留意。

山势与地形

照片：韩国观光公社观光照片图库（庆尚北道金泉市牙浦面）· 公共누리

黄岳山不以陡峭的岩峰见长，而是绵延的缓坡与柔和的山脊构成典型的土山地形。周边的黄岳山（1132米）、黄岳山兄弟峰（记录为1082米、1065米两个点）、余靖峰（1055米）、昆天山（1058米）、云水峰（674米）、黄岳山望峰（596米）等多座山峰沿着白头大干的山脊线接连而立，与其说是单一山峰，不如说是整条山脊共同勾勒出这片山势。各类资料对山顶海拔的记录在1125米到1142米之间略有出入，这大概是测量地点或调查时间不同所致，也从侧面说明了山顶本身就是山脊上一处平缓的隆起，而非尖锐的独立峰顶。翻看各条路线的详细路标会看到白莲庵、云水庵、明寂庵等附属庵堂，以及防砂坝、国有林界石等地物，这正是典型的白头大干支脉山路——沿途穿行山谷与寺院林地的特征。

登山感受

照片：韩国观光公社观光照片图库（庆尚北道金泉市大项面）· 公共누리

低海拔路段沿着直指寺一带茂密的林间小路和溪谷延伸，是一段平缓好走的土路；随着海拔升高，会逐渐出现棱线路特有的开阔视野。从多条路线路标反复出现的”眺望点""黄岳山眺望台""三圣山眺望点”等字样来看，登上棱线后，沿途应该有不少能欣赏白头大干山脉绵延景色的观景点。春天是新绿与山樱，夏天是溪谷里的阴凉，秋天是与红叶相映的棱线小路，冬天则能感受白雪覆盖的白头大干棱线之美，四季各有不同韵味。不过部分路段路标上也标注了陡坡及注意落石、落叶的提示，越到后半程，上坡的强度会明显增加，这点得有心理准备。

课程1 — 岔路口4 → 山顶附近观景点

📏 10.88km ⛰️ 950m 爬升 ⏱️ 4:18 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经点：岔路口4 → 岔路口5 → 休息处 → 亭子 → 岔路口17 → 岔路口19 → 岔路口20 → 岔路口21 → 岔路口23 → 山顶附近观景点 → 一对黑山羊 → 岔路口33 → 观景点 → 岔路口51 → 岔路口56

登山口交通：登山口本身是个岔路口，附近没有查到专门的公交站名，可能得先坐附近的乡镇巴士或打车，再步行一段才能到。开车去的话，通常是找附近的空地或路边停一下。

特点·适合人群：这一段要连续经过好几个岔路口、休息处和亭子，路线感觉会有点绕；途中还有个”一对黑山羊”这种很特别的路标提示，说明这是条清静的稜线路，走着走着说不定真会撞见野生动物。虽说路标密集，但也正因为如此得频繁确认，建议边走边对着地图App核实方向，比较适合喜欢安静山路的资深登山爱好者。

코스 2 — 극락전 주차장 → 정상부조망점

경유: 극락전 주차장 → 안내도 → 입산통제소 → 이정표 → 갈림길 → 백련암 해우소 → 백련암 → 운수암주차장 → 운수암 해우소 → 운수암,황악산갈림길 → 쉼터 → 황악산이정표 → 국가지점번호 → 출입금지지역 → 출입금지구역

登山口交通：极乐殿停车场与寺院进山路相连，一般是先坐市内巴士到直指寺方向，再步行进入。开车的话这里也有停车场，通行条件算是比较方便的。

特点·推荐对象：这条路线是传统的寺院巡礼型登山道，会依次经过白莲庵、云水庵等附属庵堂。入口处就有入山管制所和导览图，所以就算是第一次来的人找路也不算难。后半段有禁止出入区域的标示，一定要老老实实沿着规定的登山道走，别乱闯。如果想把寺院文化和爬山体验一起收入囊中，这条路线会很合你的胃口。

课程 3 — 玉勒村（海坪）→ 昆天山山顶休息处

📏 12.4km ⛰️ 851m 爬升 ⏱️ 4:31 🔁 环线 难度 ★★★★★ ⤓ GPX

经由：玉勒村（海坪）→ 多用途仓库空地 → 过溪 → 岔路口 → 陡坡上坡路 → 路标 → 陆军标志石 → 军用铁丝网和哨所 → 陡峭斜坡 → 观景台 → 路标 → 标记带 → 松树 → 黄岳山观景台 → 落叶注意

入口路线：从玉勒村（海坪）出发的入口，公共交通不太方便，开车或叫代驾出租车会更实际。因为没有专门标注的正式停车场，可能需要借用村道边的空间来停车。

特点·适合人群：这是六条课程里距离最长的一条（12.4公里），沿途要过溪、爬陡坡，还会经过军用铁丝网和哨所，算是紧邻军事设施的一条山路。从最后标注的”落叶注意”来看，秋末到初冬时节路面可能会被落叶覆盖，变得滑溜又不好辨认，所以这条路线更适合体力和经验都比较到位的登山者。

课程 4 — 停车场 → 三城山山顶休息处

📏 7.2km ⛰️ 376m 爬升 ⏱️ 2:26 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

沿途经过：停车场 → 牛头岭 → 牛头岭指示牌 → 路标 → 山脊休息处 → 三城山山顶休息处 → 三城山 → 余情峰 → 白头大干受损地恢复项目区 → 天然石阶 → 休息处 → 国家地点编号

登山口交通：起点是牛头岭附近的停车场。由于牛头岭是白头大干主脊线经过的一处山口，一般都是自驾前往，当地也设有停车位。若想搭乘大众交通，得先查一下附近小城市开往牛头岭方向的班车信息。

路线特点·推荐对象：在六条课程里，这条路线距离最短（7.2公里）、累计爬升最小（376米），坡度也最平缓，是初中级玩家最容易上手的一条。沿途会经过白头大干受损地恢复项目区、天然石阶等整修过的设施，还能沿着山脊一路走到余情峰，很适合想在短时间内感受一下白头大干主脊线氛围的登山爱好者。

路线5 — 风峙休憩处（入口）→ 山顶

📏 10.5km ⛰️ 690m 爬升 ⏱️ 3:47 🔁 环线 难度 ★★★★★ ⤓ GPX

沿途：风峙休憩处 → 风峙休憩处（入口）→ 风峙入口 → 岔路口 → 导览岗亭 → 三圣山观景点 → 停车及掉头空间 → 停车及掉头空间 → 观景点 → 停车空间及掉头点 → 注意落石 → 停车空间及掉头点 → 国有林出租地界石 → 山体滑坡易发区提示牌 → 防砂坝

入口交通：入口附近有”风峙”公交站，在六条路线里算是搭大众交通比较方便的一条。路边也标了好几处停车和掉头空间，自己开车过来也没问题。

特点及推荐对象：沿途导览岗亭和观景点接连出现，视野开阔的路段不少，不过也有防砂坝和山体滑坡易发区提示牌，下雨天要特别留意溪谷地带的安全。路上还立着注意落石的标牌，雨季、融雪期尤其要小心通行，比较适合打算搭大众交通当天往返的登山者。

课程 6 — 极乐殿停车场 → 望月峰

📏 6.92km ⛰️ 735m 爬升 ⏱️ 2:57 🔁 环线 难度 ★★★★★ ⤓ GPX

沿途经过：极乐殿停车场 → 入山管制所 → 黄岳山指路牌 → 望月峰 → 望月峰休息处 → 岔路口 → 国家地点编号 → 岔路口休息处 → 休息处 → 神仙峰 → 指路牌 → 内院溪谷与登山路会合处 → 内院溪谷瀑布 → 明寂庵停车场 → 白头大干路线导览图及黄岳山登山导览牌

登山口交通：出发点和课程2一样，都是极乐殿停车场，只不过这条线走到半路会拐向望月峰、神仙峰方向，公共交通和停车条件跟课程2完全一样，照搬即可。

特点·推荐对象：这条路线大体呈环形，翻过望月峰、神仙峰后经内院溪谷瀑布下到明寂庵停车场，一路能同时看到瀑布和溪谷的风光，算是它的一大特色。全程6.92公里不算长，但累计爬升落差高达735米，短短距离里上上下下特别密集，比较适合那种既想欣赏溪谷美景、又想找条稍微费体力的路线来练练腿脚的登山爱好者。

从辖区内登山路空间信息来看，最高难度被归类为”简单”，但实际通往山顶、基于GPX数据的百大名山路线，大多净爬升超过700米、距离在10公里上下，实际体感难度要高得多。这大概是因为辖区内登山路数据主要登记的是低海拔区段，而通往山顶的路线则沿白头大干山脊线绵延较长所致。危险区域登记点数为0，但各路线的路标牌上实际能看到陡坡、落石注意、落叶注意、山体滑坡易发区等标识，因此雨后或结冰期在这些路段要格外小心。观景点官方登记数字为0，但路线详情中却能找到”山顶附近观景点”、“山顶部观景点”、“黄岳山观景台”、“三圣山观景点”等实实在在的观景点，所以在稜线路段还是可以期待一下风景的。饮水处（药水泉）没有登记在案，山中很难取得饮用水，务必提前备足水；同时也没有登记的避难所，遇到天气突变时缺乏可供躲避的设施，这点也要留意。登山口、下山口共登记了3处，可见比起原路折返，这座山更常见的是走登山口和下山口不同的纵走路线。

距离与所需时间

사진: 한국관광공사 관광사진 갤러리 (경상북도 김천시 대항면) · 공공누리

以辖区内登山道全长5.34公里区间的上行96分钟、下行66分钟数据来计算，平均上行配速约为每公里18分钟。这个数字是辖区内多段路径累加得出的通行耗时，不能误认为是某条单一路线的往返所需时间。真正对登顶行程有参考价值的耗时，是基于”100大名山”GPX数据得出的各路线单程估算值，短则2号路线(停车场→三圣山山顶休息处，单程约2小时26分)，长则3号路线(玉勒村(海坪)→昆天山山顶休息处，单程约4小时31分)，跨度相当大。若计划往返登山，通常按单程耗时的1.8~2倍来预估，照此推算，短路线当天上午到下午之间往返绰绰有余，但若打算往返走完长路线(1、2、3、5号路线)，则可能需要8~9小时左右，最好一大早出发，并留出充裕的时间余量。总体来看，黄岳山辖区内登山道全长不过5公里出头，又没有避难所，因此比起过夜登山，一般更适合规划为当天往返；只有打算串联多条路线挑战白头大干区间纵走时，才需要考虑入住山庄或附近住宿设施安排过夜行程。

가는 길(大众交通·停车)

照片：韩国观光公社观光照片图库（庆尚北道金泉市牙浦面）· 公共누리

黄岳山登山口附近有바람재、화곡两个公交站，其中通往바람재休息区（登山口）的5号路线，靠바람재站坐公交还算方便。一般做法是先从金泉市区坐开往直指寺方向或牛头岭方向的市内公交，到站下车后再步行到登山口。如果坐KTX或普通列车过去，得先到金泉龟尾站或金泉站，再换乘市内公交，具体路线和发车时间可能会有变动，建议出发前用KakaoMap或Naver Map搜”직지사（直指寺）“或”우두령（牛头岭）“，实时查一下公交路线比较保险。登山道数据里没有登记在册的正式停车场，不过看路线详细路标的话，极乐殿停车场、云水庵停车场、明寂庵停车场，还有牛头岭附近的停车场等实际能用的停车空间倒是不少，自驾的话把这些地方设成目的地会比较现实。不过车位不一定宽裕，旺季周末最好还是趁早到。

季节·天气·装备

사진: 한국관광공사 관광사진 갤러리 (경상북도 김천시 대항면) · 공공누리

黄岳山最适合登山的季节是春天（4~5月）和秋天（10~11月），气温宜人，还能同时欣赏枫叶或新绿。夏天山谷路段凉爽是个优点，但下雨时经过防砂坝、山体滑坡易发区标识路段要格外留意天气，暴雨可能带来急流或落石风险。冬天棱线路段和陡坡容易结冰，冰爪、绑腿这类冬季装备必须带上，季节性难度体感也是冬天最高。不管哪个季节，都建议备好这些基本装备：保护脚踝的登山鞋、足量饮用水（山上没有取水处，视路线不同建议带1.5~2升以上）、登山杖、防风防水外套、零食和应急干粮、头灯（应对长距离路线下山延误的情况），以及装有地图App的智能手机。

外国游客小贴士

照片：韩国观光公社观光照片图库（庆尚北道金泉市大项面）· 公共누리

黄岳山的英文标注是”Hwangaksan”，代表性寺庙直指寺则标为”Jikjisa Temple”。山顶标注为”Hwangaksan Summit”，主要登山口之一牛头岭在指示牌上多并注为”Udu-ryeong Pass”。一般来说，登山本身不需要另外申请许可或买门票，不过如果走的是穿过直指寺境内的路线，可能会额外收取寺庙文化财参观费，建议到现场再确认一下。厕所可以在极乐殿停车场、云水庵停车场等寺庙附近的设施使用，但半山腰以上路段没有厕所，建议出发前先解决。沿途没有登记在册的饮水点（药水泉），出发前务必买好足量的瓶装水随身携带。地图软件方面，Google Maps在韩国国内步行、公共交通路线指引上常常不准，建议提前装好Kakao Map或Naver Map，实际确认登山路线和交通班次会更保险。安全方面要注意，山中没有登记的避难所和危险地段标识，但实际上确实存在陡坡、落石、积叶打滑等路段，所以比起独自登山，更推荐结伴而行，下山时间也要预留充裕，尽量安排在天黑前下山完毕。
