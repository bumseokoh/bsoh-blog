火旺山城环抱的银色芒草原野——昌宁火旺山

概览

照片：韩国观光公社旅游照片馆（全南光州统合特别市）· 公共누리(KOGL)

火旺山（화왕산，Hwawangsan）位于韩国庆尚南道昌宁郡昌宁邑一带，山顶海拔通常记作 785 米，而按登山路径实测数据，顶峰一带的最高点为 783 米。山顶盆地上铺开一大片芒草群落，又有火旺山城（史迹）相映成趣，因此作为秋日赏芒草的徒步胜地格外有名。从多个登山口出发到山顶，路线长度大约在 6 至 11 公里之间；难度按数据分类为“中等”，初中级爱好者也能当天来回。不过通往山顶芒草地的上坡一路不停歇，体力消耗其实不小。

山势与地形

照片：韩国观光公社观光照片库 · 公共누리（KOGL）

火旺山最独特的地方，是顶部铺开一片辽阔的芒草平原，而这片平原正落在昔日火旺山城的城墙以内。山顶周边散布着屏风岩、大石人脸、奇岩怪石、海豚岩等岩脊地貌，处处裸露，土山与岩山两种性格在这里同时呈现。主要山峰以火旺山顶（785 米）为中心，火旺支脈（745 米）、拜峰顶以及相邻的观龙山顶由山脊一线相连；朝观龙山方向走，还能一并望见名刹观龙寺与龙船台附近的奇岩。山脚一带则广泛分布着昌宁校洞·松岘洞古坟群、牧马山城等新罗至伽倻时期的遗迹，因此登山路本身就有不少路段与历史遗迹的踏查线路重叠，这也是此山的一大特色。

登山感受

照片：韩国观光公社旅游照片库（庆尚南道昌宁郡昌宁邑火旺山观龙寺路 171）· 公共누리(KOGL)

登山口一带大体上是穿过松林与寺庙（昌华寺、道成庵等）的平缓林道，从山腰起，花岗岩质的岩脊和观景点交替出现，脚步也一点点变沉。越接近山顶，视野越开阔，火旺山城的城墙和一大片芒草原尽收眼底；这里是风可以毫无阻挡地直接吹上来的开阔地形，所以季节感格外分明。春天，成片的金达莱把山脊染成一片红；秋天，银白色的芒草随风起伏，与城墙相映，构成昌宁地区最具代表性的秋景。反过来说，夏天山脊少有遮阴，得在烈日下熬上好一阵；冬天芒草原和岩脊风都很大，体感温度会降得厉害。

路线 1 — 校洞古坟群（登山口）→ 山顶

📏 6.75km ⛰️ 651m 爬升 ⏱️ 2:46 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

途经：昌华寺 → 校洞古坟群（登山口）→ 昌宁博物馆停车场 → 昌宁校洞古坟群 → 牧马山城 → 观景点 → 石塔 → 岔路口 → 火旺山城 → 休息处 → 兼作体育公园的休息处 → 洗手间 → 昌宁松岘洞古坟群

登山口交通：这是离昌宁邑市区最近的登山口，从昌宁公共汽车站步行或坐一小段市内公交就能到。加上可以停在昌宁博物馆停车场，自驾的便利程度也比其他登山口要好。

特色与推荐人群：一开始就与经过校洞、松岘洞古坟群的遗迹踏访路线重合，很适合想把登山和历史探访一起打包的旅行者。途中会经过牧马山城的旧城址，在观景点可以俯瞰昌宁邑市区；交通方便，作为一天往返的路线推荐起来毫无压力。

路线 2 — 上月村会馆 → 火旺山顶

📏 7.75km ⛰️ 656m 爬升 ⏱️ 3:02 🔁 环线 难度 ★★★★★ ⤓ GPX

途经：上月村会馆 → 休息亭 → 盘谷古宅 → 简易停车场 → 岔路口 → 火旺山故事路导览图 → 松树林 → 火旺山 → 观景点 → 火旺山顶 → 火旺山城及芒草原 → 保护树

登山口交通：上月村附近有公交站可用，但这里属于班次不多的乡村进村路，因此自驾或打车相对更方便。简易停车场规模不大，周末拥挤时需留意。

特点·推荐人群：这是数据上难度最高的一条路线，经盘谷古宅和松树林，沿火旺山故事路上行，人相对少。适合想避开人多的热门路线、安静爬山的人；不过距离和高差在五条路线中最大，得把体力负担考虑进去。

路线 3 — （起点、终点）玉泉售票处停车场 → 观龙山顶

📏 11.07km ⛰️ 572m 爬升 ⏱️ 3:43 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经：停车场卫生间 → 休息区、健身设施 → 玉泉售票处停车场 → 昌宁郡旅游咨询处 → 公交站 → （起点、终点）玉泉售票处停车场 → 人工瀑布 → 停车场 → 登山导览图 → 卫生间 → 火旺山故事之路导览图 → 玉泉溪谷 → 巨石人面 → 有登山道，但松茸采集期禁止入内 → 登山道禁止通行

起点交通：昌宁郡旅游咨询处和公交站就在起点附近，公共交通的便利程度在几条路线中数一数二；玉泉售票处停车场也能用，开车来同样方便。起点和终点是同一处，很容易安排原路返回的环线行程。

特点·推荐人群：这是一条溪谷型路线，沿途经过玉泉溪谷、人工瀑布和巨石人面，前半段林间小路格外凉爽。五条路线里它距离最长，一路通到观龙山顶，适合对体力有信心的人；秋季松茸采集期部分路段可能封闭，出发前务必确认。

路线 4 — 紫霞谷售票处 → 火旺山顶

📏 9.13km ⛰️ 625m 爬升 ⏱️ 3:19 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经：紫霞谷售票处 → 体育公园兼休息处 → 卫生间 → 昌宁郡旅游咨询中心 → 停车场 → 火旺山导览图 → 山与云之下 → 岔路口 → 道成庵 → 休息处 → 观景点 → 火旺山顶 → 拜峰顶 → 屏风岩 → 火旺支脉

登山口交通：这里是昌宁郡旅游咨询中心和停车场都在的一处，也是最具代表性的登山口。火旺山导览图之类的指示设施相当完备，第一次来的人也不难找到路。从昌宁市区过来交通方便，据说是所有火旺山登山路线中使用频率最高的登山口。

特色与推荐人群：途中经过道成庵，登顶之后还能继续走到拜峰顶、屏风岩，一直延伸到火旺支脉。所以这条路线不只适合单纯登顶往返，也很适合想走山脊纵走的人。指示设施齐全，是最适合推荐给第一次来火旺山的旅行者的一条路线。

路线 5 — 山与云下 → 拜峰顶

📏 3.55km ⛰️ 615m 爬升 ⏱️ 1:55 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

途经：山与云下 → 智雄山庄 → 观景点 → 岔路口 → 拜峰顶 → 无岔路 → 奇岩怪石 → 海豚岩 → 休息处 → 洗手间 → 兼作休息处的体育公园 → 泉水处

登山口交通：入口是一条经过智雄山庄这处私人据点的短进山路，一般不靠公共交通，而是从紫霞谷方向步行接入，或者自驾前往。

特点与推荐人群：五条路线里距离最短、耗时也最少，时间不太宽裕时只上到拜峰顶再折返正合适。整条路线的看点集中在奇岩怪石、海豚岩这类岩石地貌上，适合想来一趟短而有料的登山的人。

路面材质没有按路段单独统计，不过从路线路标数据里反复出现的屏风岩、大石人脸、奇岩怪石、海豚岩等名称来看，山顶一带和山脊段应该混有岩脊路。路线内共统计到 6 处观景点，沿山脊行走时视野会在好几个地方豁然开朗；被单独登记为危险区域的地点则是 0 处。不过雨后或冬季结冰时，岩脊段容易打滑，得多加小心；另外玉泉售票处一线的部分路段在松茸采集期禁止进入，秋天去之前务必先确认。

距离与耗时

把辖区内所有登山路线加总的上行 664 分钟、下行 463 分钟除以总距离（35.82 公里），平均上行配速约为每公里 19 分钟，可以拿来粗略估算各条路线的单程耗时（要注意这是累计数值，并非某一条具体路线的耗时）。实测的单程耗时差别不小，短的约 1 小时 55 分钟（拜峰山顶路线），长的约 3 小时 43 分钟（冠龙山山顶路线）。多数路线往返在 4 到 7 小时上下，当天来回完全没问题；但如果打算把几座山峰连起来纵走，考虑到辖区内总长达 35.82 公里、又没有查到设有避难小屋，建议安排至少一晚的住宿，把行程留得宽松一些。

交通与停车

照片：韩国观光公社观光照片图库（庆尚南道昌宁郡火旺山路170）· 公共누리(KOGL)

火旺山登山口附近可以查到桃园公寓、Solter Line公寓、松岘十字路口、上月村、玉泉、昌宁女子中高等学校、昌宁女子中学等公交站点，一般的走法是从昌宁长途汽车客运站换乘市内公交前往。昌宁没有KTX和地铁站，所以推荐先从釜山、大邱、马山等邻近城市坐长途汽车到昌宁客运站，再换公交或出租车抵达登山口。官方统计里登山口附近的停车场数量并不多，但紫霞谷售票处和玉泉售票处两条路线的路标数据中，除了游客服务中心之外还包含了停车空间，所以这两处登山口自驾前往相对方便一些。具体的公交时刻表、发车间隔，以及实时步行和驾车路线，建议用KakaoMap或Naver Map确认。

季节·天气·装备

照片：韩国观光公社旅游照片图库（庆尚南道昌宁郡昌宁邑紫霞谷路147）· 公共누리

火旺山以春天的杜鹃和秋天的芒草闻名，游客也大多集中在这两个季节。尤其是正月十五前后的烧芒草活动，更是名声在外。也正因如此，登山路是否封闭、活动是否照常举行，都会随时节而变，出发前最好先确认一下。夏天山顶的芒草平原和山脊几乎没有遮阴，人就这么暴露在烈日底下，沿途也基本看不到饮水点，水一定要带够。冬天则是岩脊路段和山顶芒草地上大风与结冰叠加，体感难度直线上升，冰爪和防风装备不能少。基本装备建议备齐：登山鞋、替换衣物、保暖防风外套（深秋至冬季）、充足饮用水、防晒用品（夏季）、冰爪和雪套（冬季）。

外国游客小贴士

照片：韩国观光公社旅游照片库（庆尚南道昌宁郡昌宁邑校里159）· 公共누리(KOGL)

火旺山的罗马字写作 Hwawangsan（Mt. Hwawang），主要登山口紫霞谷售票处标为 Jahagok，玉泉售票处标为 Okcheon。相邻的冠龙山、冠龙寺可并注为 Gwallyongsan、Gwallyongsa Temple。虽然有些地点名称里带着”售票处”，但实际是否收取门票、金额多少会随时期变动，出发前最好确认一下；一般来说不需要另外申请入山许可。紫霞谷售票处、玉泉售票处停车场、校洞古坟群附近等多个登山口都有洗手间，但登山道上几乎找不到饮水点，个人饮用水一定要自己带足。导航方面，Google 地图在韩国境内的步行和公共交通路线指引常常不准，建议使用 KakaoMap 或 Naver Map。安全方面，此处没有登记在册的危险区域，但要留意岩脊路段容易打滑，以及秋季部分路段会因松蘑采集期而封闭；下山时间也请留出充裕余量，尽量在日落前走完。
