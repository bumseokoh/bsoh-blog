越过枯木与芒草山脊登上天王峰，庆南智异山纵走

概览

照片：韩国观光公社旅游照片图库（庆尚南道泗川市昆明面）· 公共누리(KOGL)

智异山（지리산，Jirisan）横跨庆尚南道、全罗南道和全罗北道，是韩国代表性的国立公园名山。最高峰天王峰（Cheonwangbong）的海拔因资料测点不同，记录在 1,938m 到 1,945m 之间。它山体庞大，山脊绵长，一座接一座的山峰连成一片，所以路线的难度落差很大——既有散步式的短程小段，也有直冲主峰的长距离纵走。园区内登记在册的登山路总长（多段路线累加，并非单条路线的距离）为 13.93km，数据中标注的最高难度为”中等”。不过实际冲顶的路线单程 7~15km，净爬升超过 1,300m，体力消耗相当大；与其毫无准备地想一日往返登顶，不如留足时间、把身体状态调整好再出发。

山势与地形

照片：韩国观光公社观光照片库（全南光州统合特别市求礼郡土旨面）· 公共누리(KOGL)

智异山以花岗岩和片麻岩混杂的”肉山”（土山）特征为主，但主峰一带的山脊上又零星夹杂着岩石地带，柔缓的山脊与粗砺的岩脊在这里并存。代表性山峰是最高峰天王峰，以及往西相连的中峰（1,889米），这两座峰之间的山脊，是智异山纵走中最具标志性的一段。实测路线上还会经过一座名叫帝释峰的山峰，自古就以枯木林闻名。整条山脊绵延极长，很难一眼看尽全貌；峡谷部分则深邃、水量充沛。

登山体感

照片：韩国旅游发展局旅游图片库（全南光州统合特别市求礼郡土旨面）· 公共누리

入口的溪谷段是一路茂密的林荫小径，随着海拔升高，树木逐渐变矮，视野也随之开阔，转为亚高山带地貌——这正是爬智异山最有代表性的体感。靠近山顶的帝释峰一带以枯木与芒草交织的独特景致闻名，被认为是那种让人觉得头顶忽然打开了一片天的地段。这是一座季节感格外鲜明的山：春天有新绿与野花，秋天是红叶配芒草，冬天山顶一带积起雾凇与白雪，据说雪景之美足以让人以为换了一座山。整体走势前半段较为平缓，后半段临近山顶处坡度陡然变急——这一点在实测高程数据里也得到了印证。

路线 1 — 智异山（中山里）→ 帝释峰

📏 15.13km ⛰️ 1304m 爬升 ⏱️ 5:57 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经：智异山（登山口）→ 卫生间 → 中山里探访中心 → 岔路口 → 刀刃岩 → 石阶 → 木栈道阶梯 → 里程木 → 望岩 → 观景点 → 避难所 → 法界寺 → 观景台 → 休息处 → 凯旋门

登山口交通：路标里出现了”中山里探访中心”，看得出这是一条以智异山国立公园中山里区域为起点的路线。中山里区域位于庆尚南道山清郡矢川面，一般的走法是从晋州长途汽车客运站或附近城市搭开往中山里的长途或农渔村巴士，这条路子流传得比较广。自驾的话，通常停在中山里探访支援中心附近的公营停车场。不过按这次公共数据的地点统计，辖区内的公交站和停车场都记为 0 处，所以实际出发前，务必再通过当地政府和国立公园的官方公告确认最新的交通和停车信息。

特点与适合人群：起步沿着溪谷边的林间小路上行，之后刀刃岩、石阶、木栈道阶梯等人工设施接连出现，属于整修得比较完善的路段；过了法界寺，海拔急剧攀升，视野也开始开阔起来。帝释峰附近的枯木地带是只有这条路线才能看到的独特景观。考虑到里程和高差都相当可观，这是一条适合体力有自信的登山者、或是计划纵走智异山的人的长距离路线。

路线 2 — 参泉（참샘）→ 山顶

📏 7.18km ⛰️ 1410m 爬升 ⏱️ 4:09 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经：参泉（除登山口附近的这一处外，没有其他路标数据）

登山口交通：“参泉”这个地名在智异山一带的泉眼、溪谷附近很常见，这次的资料并没有明确它具体属于哪个行政区、公共交通条件如何。看上去它是智异山南坡与西坡一侧的溪谷登山口之一，出发前最好在 KakaoMap 或 Naver Map 上搜一下“참샘”这个地名，务必提前确认实际的进入道路以及附近的公共交通、停车条件。

特点与适合人群：全程 7.18km，比路线 1 短，但净爬升反而更大，达到 1,410m——也就是说，这是一条在短距离内迅速拉升高度的陡坡型路线。从一开始上坡就连绵不断，体感相当明显，所以它不适合当作悠闲散步，更适合想认真爬一场的登山者，或是希望在短时间内体验一次接近山顶高度的资深玩家。除参泉一处之外没有查到其他路标数据，实际走的时候，最好同时参考国立公园的官方地图和现场路标，这样更稳妥。

难度·路面·注意事项

照片：韩国观光公社观光照片图库（全北特别自治道南原市周川面）· 公共누리(KOGL)

数据显示，辖区内登山路的最高难度被归类为”中等”，但通往顶峰一带的两条实测路线均被评定为难度最高级（★★★★★），可见体力消耗相当大，这一点需要留意。路面材质在本次资料中没有单独记录，不过从路线1的路标上出现”石阶·木栈道台阶·刀刃岩”来看，应该是修整过的台阶路段与岩盘、碎石坡混杂的地形。这类路段遇雨会变得非常滑，冬季结冰也很常见，务必格外小心。从设施相关的公共数据来看，本次资料中危险区域、观景点、饮水台统计均为0处，说明路线内几乎没有正式登记的便利设施。不过现场实际存在法界寺、避难所等路标上提到的地点，因此补水和休息最好提前充分规划好再上山。

距离与所需时间

照片：韩国观光公社观光照片库（全北特别自治道南原市周川面）· 公共누리 KOGL

按辖区内全部路段的累计数据，上行记录为 293 分钟、下行为 202 分钟。把这个数字放到总长 13.93km 上换算，上行的平均配速约为 21 分钟/km。不过这是把辖区内多个路段加总得出的累计值，别误当成某一条具体路线的耗时。若以主峰一带的实测路线为准，智异山（中山里）→帝释峰这一段单程约 5 小时 57 分，参泉→山顶单程约 4 小时 9 分；来回则分别可能要 12 小时和 8 小时左右，作为一天的行程实在太长了。数据里避难小屋统计为 0 座，形式上归类为可以当日往返，但实际上必须凌晨早早出发，并给下山留足余量。体力或时间不够的话，与其硬撑着走完全程往返，不如只走其中一段，或者干脆另做住宿、露营的计划。

交通指南（公共交通·停车）

照片：韩国观光公社旅游图片库（全北特别自治道南原市周川面）· 公共누리(KOGL)

以智异山中山里地区为起点的话，一般的走法是先到晋州等邻近的中心城市，再换乘开往中山里的班车。从首尔等首都圈出发，通常先坐KTX或高速大巴到晋州，然后换当地公交。至于参샘（Chamsaem）登山口，这次查到的资料里没有确切的公交线路信息，所以出发前请务必用KakaoMap或Naver Map核对实际道路和公交班次。Google Maps在韩国境内的步行和公共交通导航常常不太准，人在当地还是建议用KakaoMap或Naver Map的手机应用。自驾的话，一般是停在国立公园的官方停车场或附近村子的公营停车场；旺季和周末车位很容易满，建议改乘公共交通，或者干脆早点到。

季节·天气·装备

照片：韩国观光公社 观光照片图库（全北特别自治道南原市朱川面）· 公共获取授权（KOGL）

智异山的登山季，一般公认春天（4~5月）和秋天（10~11月）在气温和视野上最省心。夏天赶上雨季和梅雨，加上气温上升，体力消耗大，还有雷击和短时强降雨的风险，出发前查好天气很重要。冬天山顶一带结冰、大风、体感温度骤降都是常事，冰爪、雪套、防风衣这类冬季装备缺一不可；对新手来说，冬季登顶尤其吃力。不分季节，登山鞋、备用衣物、充足的饮水和路餐、头灯、防风防水外套都属于基本配置。另外，数据里这条线路的饮水点统计为 0 处，所以水一定要提前备足。

外国旅行者小贴士

照片：韩国观光公社旅游照片图库（全罗北道特别自治道南原市朱川面）· 公共누리(KOGL)

智异山的罗马字拼写是 Jirisan，最高峰天王峰是 Cheonwangbong，中峰是 Jungbong，帝释峰是 Jeseokbong。一般来说，在国立公园区域内走登山道本身不额外收门票，但可能会有探访预约制之类的分时段管控，所以出发前最好去韩国国立公园管理局官网确认最新公告。厕所方面，1号线路的路标上写着”厕所”，看来位置在登山口附近，其余路段则没有查到可靠的饮水点和厕所信息，饮用水和个人卫生用品请务必提前备好。找路方面，KakaoMap 或 Naver Map 比谷歌地图准确得多，而且都有英文界面。智异山山脊很长，天气变化剧烈，比起单独出行，最好和同伴一起走，下山时间也要留足余量，避免走到天黑。
