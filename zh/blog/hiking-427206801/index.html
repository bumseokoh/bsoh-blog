概览

照片：韩国观光公社观光照片图库（江原特别自治道平昌郡龙坪面云头岭路1243）· 公共누리

桂芳山（Gyebangsan）坐落在江原道平昌郡与洪川郡的交界处，山顶海拔各类资料记载略有出入，大约在1,572米到1,601米之间，是南韩数得着的高峰之一。它算是一座典型的”肉山”——山势平缓、稜线圆润，虽说海拔不低，爬起来却没那么吃力，走主流路线的话，一天之内轻松就能来回登顶。按公共数据的分级，当地登山路线的最高难度也不过是”简单”，也就是说，只要装备准备到位，新手挑战这座山也完全没问题。

山势与地形

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 평창군 용평면 이승복생가길 160) · 공공누리

桂芳山不属于那种以尖峭岩峰取胜的山，而是标标准准的”土山”性格——山脊宽厚绵长，一路铺展开来。据说山顶一带地势相当平缓，几乎像片草原，视野四面开阔，毫无遮挡。公共数据里登记的主要山峰有”桂芳山顶”（1580米）和”桂芳山”（1572米）两个，这也说明山顶并非单一的尖峰，而是被认作几处平缓相连的地点。整座山总体上少有陡峭的岩脊路段，据说以土路、草地为主，再夹杂着栎树、冷杉、紫杉等针叶与阔叶树混生的林间小道。

登山的感受

照片：韩国观光公社观光照片图库（江原特别自治道平昌郡龙坪面云头岭路728-3）· 公共누리

桂芳山从登山口到山顶，大部分路段都要在茂密的树林里走上很长一段路。夏天林荫浓密、遮天蔽日，走起来阴凉又舒服；到了秋天，满山红叶配上脚下沙沙作响的落叶，是这条路线最让人印象深刻的地方。越接近山顶，树木越矮，视野渐渐开阔起来，登顶后更是四面群山连绵、天际线尽收眼底，那种豁然开朗的感觉正是它的特色所在。比起攀爬陡峭岩壁的惊险刺激，这里更像是一段考验体力、闷头一路向上的登山路，四季分明——新绿、浓荫、红叶、雪景轮番登场，形成鲜明对比，也是它的魅力所在。

路线1 — 简易休息处 → 山顶

📏 4.71km ⛰️ 819m 爬升 ⏱️ 2:33 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

途经：简易休息处 → 野猪出没痕迹 → 山踯躅（映山红）→ 龟大监岩 → 岔路口 → 休息处 → 登山路指示牌

登山口交通：简易休息处登山口位于桂芳山西南坡一侧，据了解比起大众交通，自驾前往会更方便一些。一般都是从附近村落（平昌郡龙坪面一带）进山，如果要搭公共交通，通常得先到平昌市外巴士客运站或珍富站，再换乘乡村巴士或出租车过去。公共数据里查不到辖区内登记的公交站、停车场数量，所以出发前建议先用地图App确认一下实际路况和是否有地方停车。

特点及推荐对象：这条路线净爬升高达819米，在辖区两条路线里算是坡度更陡、上升也更持续的一条，比较适合体力有把握的登山爱好者。沿着山脊往上走，会经过一片山踯躅群落和岩石地形（龟大监岩），林间小路和岩石地貌交替出现，变化感十足，适合那些就是奔着登顶去的山友。

路线 2 — 入口导览 → 观景台

📏 4.06km ⛰️ 460m 爬升 ⏱️ 1:47 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

沿途经过：桂芳山云头岭 → 洗手间 → 云头岭林特产宣传馆 → 云头岭休息处 → 入口导览 → 休息处 → 白蜡树 → 岔路口 → 禁止通行 → 导览牌 → 禁止通行导览牌 → 矮生灌木林 → 禁止行为告示 → 禁止告示 → 观景台

登山口交通：这条路线的起点云头岭（雲頭嶺），是国内铺装公路中海拔最高的路段之一，也算是小有名气。它就在6号国道上，开车过去相对方便。附近已经配套了洗手间、林产品宣传馆、休息处等设施，所以比起大众交通，大家更习惯自驾或包车前往。要是非坐大众交通不可，比较现实的办法是从珍富站或附近客运站打车过去。

特点与推荐人群：净爬升460米，比路线1平缓不少。沿途经过白蜡树群落，还有好几处导览牌和禁止通行区段，看起来这条路线里为了保护自然生态而设的管制区间不少。它不通向山顶，而是在观景台收尾，所以比较适合想在短时间内看看风景的游客、带孩子的家庭访客，或者对野花、植被观察感兴趣的人。

难度・路面・注意事项

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 평창군 용평면 운두령로 714-52) · 공공누리

根据山林厅公共数据，桂芳山境内登山道的最高难度等级登记为”简单”，路面信息则没有单独记录（登山道总长13.93公里）。不过按照”100大名山”GPX实测数据来看，从简易休息处到山顶这段，垂直高差达到819米，难度评级为★★★★☆——所以抛开公共数据里”简单”这个标注不谈，实际走到顶的这段路，体力消耗其实相当可观，这点得心里有数。沿途设施方面，确认有观景点1处、饮水处（泉水）1处，可以作为补水点参考。公共数据里没有单独标注危险区域，但山顶草地和棱线一带很容易受强风和大雾影响，下雨天或冬季结冰路段务必格外小心。尤其是冬天，积雪结冰会让实际难度大幅上升，据说没有冰爪之类的辅助装备，下山时很容易打滑。

距离与所需时间

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 평창군 진부면 방아다리로 1011-26) · 공공누리

计方山境内登记在册的登山路线共两段——路东里段9.99公里、紫云里段3.94公里——合计总长13.93公里，且没有单独登记的避难所，属于当天往返就能轻松搞定的山。以实测GPX为准，代表性路线简易休息处→山顶单程约需2小时33分，入口向导处→观景台单程约1小时47分，往返的话通常分别按5小时、3小时30分左右来安排。公共数据里还记录了境内全部路线累计的上山414分钟、下山289分钟，不过这只是境内所有登山路线加总后的参考值，并非某条具体路线的耗时，换算下来平均上山配速约为每公里30分钟。以这个配速为基准，再结合自己的体力状况来估算各段路线的大致耗时，会比较实用。

交通方式（大众交通·停车）

照片：韩国观光公社观光照片库（江原特别自治道平昌郡龙坪面云头岭路 601-4）· 公共누리

去桂芳山附近，一般是先坐KTX到珍富（五台山）站，再换乘出租车或村镇巴士；从首尔等首都圈出发的话，也可以先搭市外巴士到平昌、珍富方向的客运站，再转乘当地交通工具。云头岭方向（入口指示牌→观景台路线）就在6号国道边上，自驾比较方便；但如果是从简易休息处起步的1号路线，得走村子里面的道路，出发前最好先把路线确认清楚。公共数据里查不到这一带登记在册的公交站和停车场信息，所以实际的大众交通时刻表和是否能停车，建议一定要在KakaoMap（卡카오地图）或Naver Map（네이버地图）上实时再确认一遍，再定行程。

시즌·날씨·装备

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 평창군 용평면 운두령로 767-17) · 공공누리

桂芳山以春天的新绿和秋天的红叶闻名，夏天则因为树荫浓密，走起来相对凉快，算是一条比较友好的路线。不过到了冬天，积雪量大，山顶稜线上的风也刮得特别猛，难度一下子就上去了，所以冰爪、绑腿、防风夹克这类防寒防滑装备是必备的，千万别省。基本上不管哪个季节，登山鞋、备用衣物、充足的饮用水、头灯、应急食物这些都建议常备；山顶昼夜温差大，就算是夏天，也建议带件薄款防风外套以防万一。

外国游客小贴士

照片：韩国观光公社观光照片图库（江原特别自治道平昌郡龙坪面云头岭路767-17）· 公共누리

桂芳山山顶的罗马字标注为”Gyebangsan(-jeongsang)“，主要登山口云头岭则标为”Undureong”。目前未确认需要另行办理入山许可或缴纳门票，不过由于紧邻国家公园区域，出发前务必留意当地的指示牌和管制路段说明（2号路线上有不少”禁止通行”的标识）。洗手间确认设在云头岭附近（2号路线登山口一带），沿途虽有一处饮水点（泉水）可供参考，但比起指望现场取水，还是提前备足饮用水更保险。地图软件方面，Google Maps 在韩国境内的登山路线信息常有不准确之处，建议一定要用 KakaoMap 或 Naver Map 来确认实际路线和公共交通信息。为了安全起见，冬季最好结伴同行而非独自登山，并预留充裕时间，把下山时间安排在日落之前。
