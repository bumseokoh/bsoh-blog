概览

照片：韩国观光公社观光照片图库（全罗南道长城郡北下面白羊寺一带）· 公共누리

白岩山（Baegamsan）横跨全罗南道长城郡与全罗北道淳昌郡、井邑市交界，是内藏山国立公园北侧片区的主峰所在。山顶名为上王峰，登山路径空间信息里登记的高度有769米和772米两个数值并存，本文统一采用772米作为山顶海拔。整座山都在国立公园范围内，还坐落着千年古刹白羊寺，因此这里一直以能同时享受古刹巡礼与登山之乐而闻名。虽然登山路径空间信息中登记路段的最高难度标注为”简单”，但实际串联山顶一带的路线往返距离达8~10公里，累计爬升480~620米，体力消耗其实不小，当日往返完全可行，不过还是建议尽早出发。

山势与地形

照片：韩国旅游公社旅游照片图库（全罗南道光州特别市长城郡北下面，白羊寺）· 公共누리

白岩山的山势颇有意思，缓坡为主的土山和陡峭的岩脊在这里揉在了一起。从主峰上王峰（769~772米）向南延伸的稜线上，坐落着白鹤峰（记录中有669米和678米两个点位），据说因形似仙鹤展翅而得名，这一段岩峰像屏风一样护在白羊寺后方。稜线的另一端还有狮子峰（748米）撑场，南边的笠岩区间则立着一块外形酷似斗笠的笠岩峰顶石（668米），是白岩山最具代表性的岩石景观之一。整体来看，山顶和稜线一带岩脊、观景岩石密布，而山谷和坡面则多是阔叶林覆盖的土山地形，两种风貌各有各的味道。

登山的感觉

照片：韩国观光公社观光图片库（全南光州统合特别市长城郡北下面）· 公共누리

山路的起点大多是林间小道。从白羊寺方向出发的话，先是穿过榧树、栓皮栎等阔叶林的平缓步道，气氛悠闲，随着海拔渐渐爬升，视野也慢慢打开，能望见白鹤峰岩脊的景色。走南仓溪谷方向则更像是一场溯溪式的登山，一路多是沿着몽계瀑布听水声前行的路段；而从杉树林入口爬向갓岩的路线，后半程要穿过有坠落风险的地带，一直走到山顶观景台才算松口气，全程都带着几分紧张感。季节感受上，春天有新绿和溪水，夏天林荫浓密适合溯溪，而秋天的红叶才是这座山最招牌的风景；到了冬天，山脊岩壁覆上冰雪，又是完全不同的一番登山体验。

路线1 — 佳人民宿村入口 → 白鹤峰

📏 10.09km ⛰️ 617m 爬升 ⏱️ 3:33 🔁 环线 难度 ★★★★★ ⤓ GPX

沿途经过：白羊探访支援中心 → 指引路标 → 一柱门厕所 → 岔路口 → 休息处 → 佳人民宿村入口 → 佳人厕所 → 白羊水边路 → 博物馆厕所 → 白羊寺博物馆 → 白羊寺停车场 → 白岩谷自然观察路 → 救援箱 → 自然观察路拍照点 → 自然观察路休息处

登山口交通：白羊寺方向是这座山最具代表性的正门，一般是从长城方向坐市内公交，再利用白羊寺停车场进山。白羊寺本身就是热门景点，所以进山路线相对修得比较清楚。

特点·适合人群：从白羊探访支援中心出发，依次经过白羊寺寺院、博物馆和自然观察路，前半段是可以顺道逛寺庙的平缓林间小路，越往后走则逐渐朝白鹤峰的岩脊爬升，变成正儿八经的登山路。这条路线在三条线路里距离和爬升都是最大的，比较适合体力有底气的驴友，或者想把白羊寺的寺院风光和山顶展望一并收入囊中的人。

路线 2 — 清凉园入口 → 山顶

📏 8.16km ⛰️ 504m 爬升 ⏱️ 2:53 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

沿途经过：南昌国立公园停车场 → 山谷民宿 → 小憩咖啡&民宿 → 四季民宿 → 南京山祈祷院 → 南昌探访支援中心 → 梦溪瀑布探访路指引牌 → 岔路口 → 位置编号白岩13-13 → 路标指引 → 位置编号白岩13-12 → 注意落石 → 梦溪瀑布 → 危险地段 → 位置编号白岩13-10

登山口交通：这是南昌溪谷方向的登山口，一般从淳昌方向进入，多数人会把南昌国立公园停车场当作起点。附近民宿不少，看来也很适合安排一趟带住宿的行程。

特点·推荐人群：这条路线的特色是前段沿溪谷而行、经过梦溪瀑布的区间比较长，路标上在瀑布附近标出了”注意落石”和”危险地段”的提示，雨后尤其要多加小心。喜欢一边听着水声一边走溪谷路线的朋友，应该会很中意这条路。

路线三 — 杉树林 → 甲岩顶峰

📏 8.35km ⛰️ 481m 爬升 ⏱️ 2:53 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

经由：杉树林 → 公园自然保护区 → 岔路口 → 杉树生长监测点 → 北美短叶松 → 简易休息处 → 急救箱 → 坠落危险区 → 甲岩前观景点 → 坠落警示区 → 甲岩 → 甲岩顶峰 → 甲岩观景台眺望点 → 龟岩 → 野花丛

入口路线：入口穿过一片杉树林，起点划为公园自然保护区，得先走过这段自然保护地带。相比另外两条路线，这条的入口信息知道的人不算多，建议出发前先用地图App确认好路线。

特点·适合人群：路线先穿过杉树和北美短叶松林，后半段一路爬升到甲岩顶峰，指示牌上”坠落危险""坠落警示”的标识出现了两次，可见顶部岩脊路段的紧张感不低。不过甲岩前观景点、甲岩观景台眺望点、龟岩这些看点也集中在这一段，所以对喜欢岩石风光和拍照的登山者来说，这条路线还是很值得推荐的。

难度·路况·注意事项

照片：韩国观光公社观光照片图库（全罗南道光州通合特别市长城郡北下面）· 公共누리

| （无区段名） | 14.71km | 简单 | - | | 瓦也里区段 | 4.95km | 简单 | - |

※ 上表以行政洞（区段）为单位统计登山道空间信息，把辖区登山道总长19.66km汇总为两个区段。请注意，这是按行政区划划分的区段，并非登山路线名称。

虽然按行政区划登记的区段最高难度只标为”简单”，但实测连接峰顶一带的3条路线，累计高差达480~620米，难度相当于★★★★☆~★★★★★，和实际体感有不小落差。路况信息表里没有单独标注（-），不过在GPX实测路线的路标名称中，分别出现了”注意落石”（第2号路线，梦溪瀑布附近）、“危险地带”（第2号路线，梦溪瀑布附近）、“坠落危险”和”坠落注意”（第3号路线，笠岩附近）等提示，说明瀑布周边的落石区段和笠岩附近的岩脊区段实际上都需要格外小心。眺望点方面，实测路线上确认第3号路线有笠岩前眺望、笠岩展望台眺望共两处。雨后刚放晴时的落石区段，以及结冰季节的岩脊区段，尤其建议放慢脚步、谨慎通过。

距离与所需时间

照片：韩国观光公社观光图片库（全罗南道长城郡北下面）· 公共누리

区内登山道总长为19.66公里，这是几条路线累加起来的数字，并非单一路线的距离。上行375分钟、下行264分钟这组数据同样是全区间的累计值，千万别误以为是单条路线的所需时间——用它换算下来，平均上行配速约为每公里19分钟。以这个配速来推算，三条主打登顶路线各自的距离都在8~10公里区间，单程大概需要2小时53分到3小时33分。往返的话，算上休息时间，一般预估在6~8小时左右，三条路线都完全可以当天往返，不是那种非得住一晚才能爬完的山。不过其中单程超过3小时的1号路线（佳仁民宿村入口→白鹤峰），往返时建议一大早就出发。

交通方式（大众交通·停车）

사진: 한국관광공사 관광사진 갤러리 (전남광주통합특별시 장성군 북하면) · 공공누리

白羊寺方向的登山口，一般以停靠KTX、无穷花号的长城站为起点，从长城市外巴士客运站或长城站换乘开往白羊寺的市内公交车抵达。从光州广域市搭乘市外巴士过去也是常见的方式。南昌溪谷、梦溪瀑布方向的登山口通常从淳昌郡方向进入，杉木林登山口也是要经过附近村庄才能到达。不过登山路径的空间信息里，并没有查到这片山区已登记的公交站、停车场坐标，所以出发前务必自己在KakaoMap或Naver Map上搜一下”白羊寺""南昌国立公园停车场""梦溪瀑布”之类的关键词，确认实际路线和有没有地方停车。

季节·天气·装备

사진: 한국관광공사 관광사진 갤러리 (전남광주통합특별시 장성군 북하면) · 공공누리

秋天（大概10月底到11月初）是白羊寺红叶最出名的时候，那阵子游客会扎堆过来；春天（4月前后）新绿正好，加上水量变大的梦溪瀑布也很值得一看。夏天走溪谷线路凉快是凉快，但梅雨季暴雨刚过那几天，梦溪瀑布附近容易有落石，属于危险地段，得多留个心眼。冬天山顶稜线和甲岩附近的岩稜段很容易结冰，体感难度会一下子拔高不少，冰爪、绑腿这类防寒防滑装备一定要备好。通用的必备装备包括登山鞋、登山杖、充足的饮用水（登山道空间信息上没查到饮水点，所以全程都得自己带水）、应急口粮、雨衣，这些都建议带齐。

外国游客小贴士

照片：韩国观光公社观光图片库（全罗南道光州都市圈长城郡北下面）· 公共版权

主要地名的罗马字标记如下：白岩山 Baegamsan、上王峰 Sangwangbong、白鹤峰 Baekhakbong、甲岩 Gatbawi、白羊寺 Baekyangsa Temple、梦溪瀑布 Monggyepokpo Falls。这座山属于国立公园（内藏山国立公园）范围，韩国从2023年5月起全面取消了国立公园门票，所以一般不需要额外支付登山门票，不过关于寺院（白羊寺）内部参观的具体事项，最好还是以当地告示牌为准。厕所可在白羊游客服务中心、一柱门、佳人、博物馆附近找到；饮水点在登山道的空间信息数据中并无登记记录，出发前最好自备足够的水，比较稳妥。地图软件方面，谷歌地图在韩国境内的步行路线导航上常有不准确的情况，建议使用 KakaoMap 或 Naver Map。安全方面，实测路线显示梦溪瀑布附近有落石区段，甲岩附近也有坠落危险、需注意坠落的区段，雨后初期或结冰季节经过这些路段时务必放慢脚步，并尽量结伴同行，而不要独自登山。
