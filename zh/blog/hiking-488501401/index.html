概述

照片：韩国观光公社观光照片图库（江原特别自治道麟蹄郡）· 公共资源开放许可（KOGL）

黄场山（Hwangjangsan，荒場山）位于庆尚北道闻庆市东鲁面与忠清北道丹阳郡的交界处，是白头大干山脊上的一座山峰。官方登记的山顶海拔约为1,076米，而根据实测GPX数据，顶峰最高点可达1,085米。它坐落在闻庆鸟岭以南，与道乐山、黄庭山、修理峰一脉相连的白头大干余脉之上，以岩脊与奇石交错、骨山（骨山）特征鲜明而闻名。官方登山路线数据将其难度归为”简单”，但实际通往山顶的主要路线，若把距离和高差算进去，体力上绝非轻松的一趟，不过作为当日往返的行程完全应付得来。

山势与地形

照片：韩国观光公社旅游照片图库（庆尚北道闻庆市东鲁面安生达路 279）· 公共누리（KOGL）

黄杨山是典型的岩峰型山体，山顶一带和山脊各处都发育着近乎垂直的岩壁与狭窄的岩脊路段。这里的山势核心，是沿白头大干主脊线延伸的那道山脊——临近山顶处岩石地形陡峭到需要架设木栈梯和观景台。代表性山峰是黄杨山（1,076 米）主峰，山顶附近还有被称作”甘投峰”的岩峰，以及卧瀑（누운폭포）周边的岩盘地带，都是颇具特色的地形。顶部山脊上有一段被称为”天国的阶梯”的陡坡木栈道，岩脊与人工设施在此并存，构成了独特的地形景观。整体上，这里岩石与峭壁多于土壤，属于骨山型山势；溪谷段（卧瀑一带）虽有水流形成，但看来并非常年水量充沛的溪涧。

登山感受

照片：韩国观光公社观光照片图库（庆尚北道闻庆市东鲁面狐狸岭路 2371-5）· 公共著作权（KOGL）

从登山口开始，前半段基本都是林间小路，过了中段的岔路口之后，岩石和岩脊会逐渐显露出来——这是这趟山行的典型节奏。过了卧瀑（누운폭포）进入接近山顶的区域，岩盘、绳索和栈道路段接连出现，体感难度陡然上升。经过山顶附近的树荫休息处和山顶休息处，站上黄壁山顶时，从道乐山观景点和栈道观景台望去，白头大干的山脊线与周边群山尽收眼底，视野格外开阔。这座山四季分明的感觉很鲜明：春天有新绿和野花，秋天则是红叶与山脊交相辉映；夏天林间路段的树荫能稍稍消解暑气，但岩脊路段基本就暴露在烈日之下。冬天岩脊和栈道台阶一结冰，整趟山行的气氛就彻底变了——不再是安静清幽的雪景，而是需要相当紧张感的路段。

途经点：月岳山黄肠山生达公营停车场 → 生达2里村民会馆卫生间 → 岔路口 → 黄肠山公园守护站 → 卧瀑布 → 山顶附近树荫休息处 → 山顶休息处 → 黄肠山顶 → 道乐山观景点 → 木栈观景台 → 山顶木栈道 → 天国的阶梯 → 安生达观景点 → 航点 22 → 航点 23

登山口交通：生达公营停车场位于闻庆市东路面生达里一带，属山区地带，没有铁路或地铁可直达。附近的公共交通一般是搭乘往返安生达桥、生达2里站点的地方巴士，但班次间隔较长，建议提前查好时刻表。虽名为”公营停车场”，但在公共数据中查不到已登记的停车场设施，实际能否停车、有多大规模，最好到现场确认。

特点与推荐人群：起步先经过村道和林间小路，穿过公园守护站后正式进入山径；从卧瀑布一段开始，能感受到岩石与流水交织的溪谷氛围。此后越接近山顶，岩脊和木栈台阶接连出现，体力消耗明显加大，因此这条路线更适合白头大干纵走者，或是习惯了岩脊登山的人。山顶附近的道乐山观景点和木栈观景台视野开阔，可以饱览山脊全景，重视风景的登山者满意度也相当高。不过陡坡木栈道和岩脊路段对新手来说会有些吃力，建议具备一定登山经验后再来。

难度·路面·注意事项

照片：韩国旅游发展局旅游照片库（庆尚北道闻庆市东鲁面生达里）· 公共版权许可（KOGL）

辖区登山道空间信息中登记的最高难度为”容易”，但这一分级是以辖区内登山道总长（3.1km）为基准的，而实际登顶的代表性路线（5.65km，净高差 582m）按百大名山 GPX 实测标准被评为 ★★★★☆，是一趟不容小觑的行程。路面相关的详细属性在公共数据中并未单独登记，不过从山势特征来看，越接近山顶，岩盘与岩石路段的比重就越大。观景点、危险区域、避难所、登山口与下山口等设施，在公共数据的地点统计中全部为 0 处，也就是说这一带很难指望有单独的指示设施或避难空间。这种岩脊地形的特性意味着：雨天岩石会变滑，尤其冬季结冰时，木栈道台阶和岩脊路段的坠落风险会明显升高，务必格外小心。

距离与所需时间

以辖区内全部登山路段累计的公共数据为准，上行需 55 分钟、下行需 38 分钟，由此推算的平均上行配速约为 18 分钟/km。不过这个数字是辖区内全部路段的累计值，不能误当成实际登顶的代表性路线（生达公营停车场 → 接近顶峰的树荫休息处，5.65km）所需的时间；该路线基于实测的估算用时为单程约 2 小时 23 分。加上下山，往返 4~5 小时左右算是常见范围，因此完全可以当作一日登山来安排。由于没有登记在册的避难小屋，专门计划过夜登山的理由并不多；但如果打算和附近的道乐山、黄井山等连起来纵走，行程就可能延伸为一夜的登山了。

交通与停车

黄裳山生达登山口附近的公共交通，可查到安生达桥、生达2里两处站点，一般是从闻庆或丹阳方向搭乘地方巴士前往。不过山区的班次间隔往往很长，路线也常有变动，出发前一定要在 KakaoMap 或 Naver Map 上确认实时公交线路和发车时间。自驾的话可以搜索”生达公营停车场”作为目的地，但公共数据中并未登记到该处停车设施，所以最好同时把路边临时停车之类的备选方案也考虑进去。谷歌地图在韩国山区的登山道和小路信息经常不准确，建议改用 KakaoMap 或 Naver Map。

季节·天气·装备

适合登山的季节是春季（4~5月）和秋季（9~11月），这两段时间既能看新绿，也能赏红叶。夏天林间路段有树荫遮蔽，但走到岩脊路段就完全暴露在烈日和暑热之下，所以要备足饮水、多做休息。冬天顶峰一带的木栈台阶和岩脊路段常常结冰，冰爪、雪套等冬季装备基本属于必备品；如果是新手，冬季登山本身就该慎重考虑。四季通用的装备包括：能保护脚踝的登山鞋、登山杖、备用衣物、头灯（应急用），以及足量的饮用水。公共数据中查不到山内有饮水台，因此出发前多带些个人饮水就显得格外重要。

外国旅行者提示

黄肠山的罗马字写法为 Hwangjangsan（山顶海拔 1,076～1,085 米），主要登山口在 Saengdal Public Parking Lot（生达公营停车场）附近。目前没有查到需要单独申请入山许可或缴纳门票的信息，看来不必像国立公园那样提前预约就能进入，不过到了现场最好再看一眼公告板上的最新信息，比较稳妥。厕所可以利用登山口附近生达二里村民会馆的厕所（Saengdal 2-ri Village Hall Restroom），但数据中查不到登山途中另有厕所或饮水点，所以出发前请先解决内急，并带足饮用水。地图 App 方面，就韩国山区登山路线信息而言，KakaoMap（카카오맵）或 Naver Map 比谷歌地图准确得多，强烈建议一并使用。这里山势以岩脊为主，也没有配备避难所和安全设施，所以尽量不要独自上山，最好有人同行；遇到天气恶劣（尤其冬季结冰）时，推迟行程才是明智之举。
