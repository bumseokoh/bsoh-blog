奇岩与松树的自然城陵，大田·公州鸡龙山

概览

照片：韩国观光公社旅游图片库（忠清南道公州市鸡龙面）· 公共누리（KOGL）

鸡龙山（Gyeryongsan）是横跨大田广域市与忠清南道公州市、论山市、鸡龙市的一座国立公园，三佛峰（约800米）、观音峰（约785米）等多座岩峰连成山脊。整体来看，难度中等的路线不少，安排一天的行程完全走得下来；而且从东鹤寺、甲寺等多个方向都能上山，这也是它的一个特点。从新手到中级登山者都爱来这儿，但主峰一带的山脊岩石路段很多，千万不能掉以轻心。

山势与地形

照片：韩国观光公社观光照片库（忠清南道公州市鸡龙面）· 公共누리(KOGL)

鸡龙山是一座花岗岩峰岩与山脊十分发育的山，给人的印象更接近人们常说的”岳山”。代表性的山峰有三佛峰（798米至800米上下，不同数据略有出入）、观音峰（785米上下，也有资料记作768米），以及位于三佛峰与观音峰之间山脊上的男妹塔（632米）。从三佛峰延伸到观音峰的这段山脊被称为”自然城陵”，奇岩与松树相映成趣的风景广为人知。鸡龙山的最高峰一般认为是天皇峰（845米上下），但这座山峰因军事设施的关系禁止民间人士进入，因此普通登山者实际上能够登顶的”峰顶区域”是观音峰、三佛峰一带。整体来看，这里山势较为险峻，不过由于被指定为国立公园，登山步道和指示牌都维护得相当完善。

登山体验

照片：韩国观光公社旅游照片库（忠清南道公州市鸡龙面）· 公共努力(KOGL)

鸡龙山是一座在入口段能走葱郁林道、接近山脊时又能遇上岩石地带的山。东鹤寺、甲寺方向的入口段沿着溪谷起步，是一段坡度平缓的林间小路，走起来颇有趣味；越靠近山脊坡度越陡，岩脊和台阶路段接连出现。在三佛峰、观音峰附近的山脊上，四面视野开阔，可以饱览国立公园特有的那种畅快远景。春天有新绿与金达莱，秋天有红叶映衬山脊，季节感相当鲜明；夏天则有溪谷的水声和林荫替人消暑。冬天岩脊路段常有积雪与霜冻结冰，登山的气氛也随之变得严肃许多。

路线 1 — 兵士谷入口 → 将军峰

📏 5.63km ⛰️ 665m 爬升 ⏱️ 2:31 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

途经：兵士谷入口 → 步道导览牌 → 指示标（路标） → 将军峰上山路 → 指示标（路标） → 危险区域 → 将军峰观景点 → 将军峰 → 观景点 → 鸡龙山国立公园位置编号 → 鸡龙山国立公园位置标示 → 岔路口 → 笠岩三岔路休息处 → 鸡龙山国立公园位置标示 → 休息处

登山口交通：兵士谷入口位于鸡龙山东北侧，比起东鹤寺、朴亭子方向，算是相对小众的进山口。乘公共交通的话，可能要在附近村里的公交站下车后步行一段，具体线路建议提前用地图App查清楚。这里没有查到大型停车场的信息，多半只能停在附近路边或村里的空地上。

特点与推荐人群：路标上标有“危险区域”，说明通往将军峰的上山路有一定坡度，也有暴露路段，比较适合有些登山经验的人。将军峰顶和观景点能把鸡龙山的山脊一览无余，喜欢拍照的人会觉得很值。也推荐给想清清静静走一走的登山者。

路线 2 — 东鹤寺入口 → 鸡龙山三佛峰

📏 8.29km ⛰️ 599m 爬升 ⏱️ 3:04 🔁 环线 难度 ★★★★☆ ⤓ GPX

途经：鸡龙山三佛峰 → 注意落石、坠落与湿滑 → 三佛峰 → 三佛峰观景 → 观景点 → 自然景观 → 岔路口 → 拍照区 → 注意坠落 → 自然城陵自然景观 → 自然城陵观景点 → 自然城陵拍照点 → 岩壁 → 注意落石 → 隐仙瀑布上段安全休息处

登山口交通：东鹤寺入口是鸡龙山最知名的登山口，从大田儒城方向或鸡龙市方向都有公交可达。一般走法是在附近的朴亭子三岔路口站（朴亭子〈东鹤寺/忠大方向〉）换乘，东鹤寺附近另设有公交站，交通算是相当方便。这里旅游气息浓厚，售票处附近备有停车场，不过旺季周末可能会很挤。

特点·适合人群：这条路线会经过鸡龙山最具标志性的一段——“自然城陵”，沿途三佛峰观景、自然城陵观景点、拍照点等眺望点接连出现，是它最大的看头。不过路上”注意落石""注意坠落”的警示牌出现了好几次，说明岩脊路段的暴露感不小，比较适合走惯岩脊的中级以上登山者。想要好好领略鸡龙山代表性景观的人，这条路线会是首推。

路线 3 — 登山口 → 山顶

📏 3.87km ⛰️ 631m 爬升 ⏱️ 2:01 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

登山口接近方式：这条路线没有具体的登山口名称数据，很难确定准确位置。推测是鸡龙山国立公园内的某条步道，实地前往之前，建议务必通过国立公园步道指南或地图应用再次确认准确的入口。

特点与推荐人群：相对净高差而言距离偏短，因此可能包含坡度较陡的路段。想在短时间内爬升到接近山顶的高度的登山者或许会喜欢，但由于登山口信息不明确，初次前往的话，建议优先考虑东鹤寺、甲寺等路标清晰的路线。

路线 4 — 甲寺入口拍照点 → 龙门瀑布观景台

📏 8.01km ⛰️ 615m 爬升 ⏱️ 3:02 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

途经：石碑 → 甲寺入口拍照点 → 甲寺售票处 → 甲寺一柱门 → 甲寺探访支援中心 → 甲寺探访支援中心休息处 → 登山口 → 龙水台山泉 → 岔路口 → 自然观察路旁长椅 → 甲寺自然观察路 → 九龙庵山泉 → 四天王门 → 甲寺卫生间 → 佛教用品茶室

登山口交通：甲寺入口是鸡龙山西侧的代表性登山口，一般乘坐开往公州方向的公交车前往，或在朴亭子三岔路口站（朴亭子〈甲寺／新元寺方向〉）换乘。甲寺附近也设有公交站，可以坐公共交通抵达；因为是通往寺院的进山路，据说售票处一带备有停车位。

特色与推荐人群：这条路线会经过甲寺这座历史悠久的古寺，能顺道参观一柱门、四天王门等寺院文物，这是它最大的亮点。途经点里标注了龙水台山泉和九龙庵山泉，比其他路线更有补水的余地；不过是否正常出水会随季节和管理情况变化，还是到了现场再确认为好。卫生间（甲寺卫生间）也在途经点之列，起步段的配套设施相对完善。推荐给想把自然风光和文化遗产一次看遍的家庭出游者。

路线 5 — 天井步道入口 → 山顶

📏 3.12km ⛰️ 458m 爬升 ⏱️ 1:33 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

途经：岔路 9 → 顺 Mart → 天井步道入口 → 天井步道服务中心 → 天井步道服务中心入口 → 天井步道服务中心路段 → 天井步道服务中心溪谷 → 注意落石 → 岔路 19 → 登山道

登山口交通：天井步道推测位于鸡龙山南侧（邻近论山市、鸡龙市一带）的登山口，从途经点中出现”顺 Mart”这样的店名来看，应该是从村落附近进山的路线。乘公共交通前往的话，建议先用地图 App 查一下附近的公交线路再出发。

特点与适合人群：五条路线中距离和净爬升都最短，负担相对较小。经过天井步道服务中心后有一段沿溪谷上行的路段，前半程可以享受坡度平缓的林间徒步。适合想在较短时间内体验一次鸡龙山登山的初、中级登山者。

距离与所需时间

照片：韩国观光公社观光照片库（忠清南道公州市鸡龙面）· 公共版权（KOGL）

数据显示，鸡龙山辖区内登山路的上行所需时间为 530 分钟、下行为 368 分钟。不过这是辖区内所有路段的累计值，并非单条线路的用时。换算成距离来看，平均上行配速约为 27 分钟/公里——可见鸡龙山不是那种平缓的散步型山头，爬升为主，还是挺费体力的。按实测 GPX 数据，各条线路的单程用时短则约 1 小时 33 分（天井探访路），长则约 3 小时 4 分（东鹤寺～三佛峰）。如果打算往返，建议以上面这些时间的大约两倍为基准，再加上休息时间来安排行程。鸡龙山的大部分线路当天往返完全够用，除非你特意计划纵走，否则不需要在山上住一晚。

交通指南（公共交通·停车）

照片：韩国观光公社观光照片图库（忠清南道公州市鸡龙面）· 公共누리(KOGL)

鸡龙山附近以朴亭子三岔路为中心，有分别通往东鹤寺方向和甲寺·新元寺方向的公交站。已确认的站点有朴亭子（东鹤寺／忠大方向）、朴亭子（甲寺／新元寺方向）、甲寺、东鹤寺等，一般路线是从大田儒城或公州长途汽车客运站换乘各方向的公交车前往。不过公交线路和发车间隔会随季节调整，出发前请务必用 KakaoMap 或 Naver Map 再确认一次实时路线和班次。自驾的话，东鹤寺、甲寺售票处附近据说有停车位，但公共数据里并没有单独统计的停车场记录，旺季周末预计会比较拥挤，建议一并考虑公共交通。

季节·天气·装备

照片：韩国观光公社旅游照片馆（忠清南道公州市鸡龙面）· 公共私用

鸡龙山以春季的新绿与杜鹃、秋季的红叶闻名，因此这两个时节的访客格外多。夏天有不少沿溪谷而行的路线，多少能避一避暑气，但下雨时岩脊路段会变滑，需要格外小心。冬季山脊的岩石地带常有结冰，冰爪、雪套等冬季装备是必备的。基本装备建议准备登山鞋、备用衣物、充足的饮用水（山上饮水点其实不太够，自己带水很重要）、防寒防水外套和登山杖；由于这座山岩脊路段较多，推荐穿防滑性能好的登山鞋。

外国旅行者贴士

照片：韩国观光公社旅游照片图库（忠清南道公州市鸡龙面）· 公共누리(KOGL)

鸡龙山的罗马字拼写是 Gyeryongsan，主要山峰分别写作 Sambulbong（三佛峰）、Gwaneumbong（观音峰），代表性寺庙登山口则是 Donghaksa（东鹤寺）和 Gapsa（甲寺）。鸡龙山国立公园免收门票，也不需要另外申请入山许可就能使用各条登山道，但部分管制区域（天皇峰等靠近军事设施的地带）禁止进入，请务必遵照现场指示牌。厕所在甲寺路线的途经点可以找到，东鹤寺、甲寺售票处附近据说也设有厕所。饮水处在数据中没有任何记录，所以一定要自备足够的饮用水。至于导航，谷歌地图在韩国的精确度不高，建议事先装好 KakaoMap 或 Naver Map，用它们确认实际路线更稳妥。走岩脊路段时，一定要遵守指示牌上关于落石和坠落的警示；尤其冬季，务必格外小心结冰路段，别滑倒。
