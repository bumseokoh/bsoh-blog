惊险刺激的天桥，十二岩峰的奉化清凉山

登山 · 发布日期 2026/7/25 ·

概述

사진: 한국관광공사 관광사진 갤러리 (경상북도 봉화군) · 공공누리

清凉山（청량산，Cheongnyangsan）坐落在庆尚北道奉化郡，主峰丈人峰海拔869米，不过按公共数据登山路线GPX记录，最高海拔为882米。它紧邻洛东江上游而立，岩峰如屏风般层层排开，虽说规模不算大，山势却格外分明，如今被指定为道立公园加以管理。整体难度归为”中等”，通往主峰一带的主要路线单程约2小时左右，大多数人当天来回绰绰有余。不过山中多处陡峭岩棱路段，比起新手，更适合有一定登山经验的人前来挑战。

山势与地形

사진: 한국관광공사 관광사진 갤러리 (경북) · 공공누리

清凉山不是那种土山，而是以岩峰为主的骨山地形，这一点非常鲜明。除了主峰丈人峰（869米）之外，祝融峰（标注845.2米，数据上为875米）、紫霄峰（又名菩萨峰，标注840米，数据为850米）、砚滴峰（标注846米，数据为852米）、卓笔峰（836米）等五座以上知名山峰沿着山脊一字排开。像笔尖（卓笔峰）、砚台（砚滴峰）、菩萨（紫霄峰）这类命名的山峰之所以这么多，是因为自古以来这座山就以儒生们潜心苦读的地方著称，因此也常被人称作”清凉山十二峰”。山脊各处多为陡峭岩壁，视野开阔的路段不少，山腰处的清凉寺、应真殿等寺庙建筑与岩石地形相映成趣，构成独特景观。谷地相对平缓，但越往山顶走，岩石山脊和陡坡就越明显，是典型的岩山地形。

登山的感觉

사진: 한국관광공사 관광사진 갤러리 (경상북도 봉화군) · 공공누리

清凉山的登山路线通常是从入口处茂密的林间小径出发，慢慢过渡到岩石渐多、视野渐开的稜线。前半段沿着溪谷和寺庙周边的树林走，走到中段之后开始出现岩稜和拉绳、阶梯路段，难度感明显上升。尤其是”天空之桥”这一段——横跨峡谷的吊桥——走起来颇有高度感，上下时既刺激，又能俯瞰脚下的溪谷,视野格外开阔。据说春天新绿初绽时，寺庙周边那种静谧的气息尤其动人；秋天则是岩峰与红叶交相辉映的景色最为出彩。整体来看，林间小径、溪谷路和岩稜观景路交替出现，走起来不会单调乏味，是一条评价很不错的路线。

코스 1 — 하늘다리 입구 → 장인봉

📏 4.94km ⛰️ 647m 爬升 ⏱️ 2:19 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

경유: 청량사 경관 → 솟대와 시인 → 봉화 청량정사 → 벤치 → 해우소 → 약수터(청량사 해우소) → 청량사 → 갈림길 → 청량사 약수터 → 청량사 정원 → 청량사 5층석탑 → 봉우리 조망 → 하늘다리 입구 → 청량산 하늘다리 → 하늘다리 경관

入口交通：天空桥入口一般从清凉山道立公园入口一侧进入。这一带地铁到不了，通常得先从奉化或安东市区坐市外·市内巴士，再步行或打车过去。自驾的话大多停在道立公园附近的停车场，不过旺季和周末车位比较紧张，建议提早出发，别卡点到。

特点·适合人群：这条路线要经过清凉寺，走天空桥，一路爬到丈人峰顶，算是清凉山最有代表性的一段。先在寺院里逛逛，感受一下人文氛围，接着在横跨峡谷的天空桥上体验一把惊险刺激的高空视野，最后沿岩石棱线登顶——徒步和观光两不误，很适合既想爬山又想顺便看看风景的人。不过天空桥之后到山顶这一段高度差比较大，岩石路段也不短，没点基础体力还真吃不消。

路线 2 — 山城入口 → 北门址观景台

📏 6.72km ⛰️ 458m 爬升 ⏱️ 2:27 🔁 环线 难度 ★★★★☆ ⤓ GPX

途经点：山城入口 → 山城入口洗手间 → 起点山城入口 → 山城入口休息区 → 岔路口 → 密城台观景点 → 清凉寺·应真殿眺望点 → 北门址观景台 → 位置信息 → 祝融峰海拔845.2米 → 终点山城入口 → 金汤峰·莲花峰 → 立石休息区 → 清凉山休息站·小卖部

如何到达起点：山城入口这个起点同样以自驾前往为主，公共交通不算方便。附近有休息站和小卖部，爬山前后垫垫肚子、打听点信息都很方便，洗手间也设在起点入口处。具体的公交路线会因当地班次调整而有变化，出发前最好用地图App确认一下最新信息。

特点·推荐人群：这条路线在三条路线里距离最长，会经过密城台、北门址观景台等好几个观景点，走起来更像是沿着山脊一路纵走到祝融峰。途中有一处能从山脊俯瞰清凉寺和应真殿的观景点，很适合把清凉山整体的山势尽收眼底。比起只登顶一次就下山，更推荐给那些想体验纵走乐趣的人。不过路程较长,体力分配得提前规划好。

路线3 — 紫霄峰入口定位点 → 应真殿登山道观景台

📏 4.68km ⛰️ 564m 爬升 ⏱️ 2:07 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

途经：坠落注意 → 岔路口 → 应真殿登山道观景台 → 坠落危险 → 应真殿 → 经由台（应真殿法堂前）→ 风穴台 → 登山道观景台 → 风穴台观景台 → 聪明水 → 御风台 → 坠落危险禁止靠近 → 金生窟 → 金生瀑布 → 莲花峰全景

入口路线：紫霄峰方向的入口同样是从清凉山道立公园园区内进入，据说相比另外两条路线要相对清静一些。这里比起公共交通，大家更习惯开车或打车过去。

特点·推荐人群：这条路线最大的亮点是沿途经过应真殿、风穴台、金生窟、金生瀑布等一众有名的景点，在三条路线里，人文和自然景观是最丰富的。不过路标上反复出现”坠落注意""坠落危险禁止靠近”这样的提示,说明沿途有不少贴近悬崖的路段，得多留神——尤其是顾着拍照的时候，千万别一个不留神踩空。这条路线比较适合既想看风景又想爬山的朋友，也适合喜欢相对平缓、高差不那么大的路线的人。

路面情况没有单独登记，但由于顶峰一带多为岩脊地形，实际体感难度可能比标注的”中等”更高一些。尤其是雨天或冬季结冰时，岩石表面会变得很滑，需要格外小心。各路段的路标上多次出现”坠落注意""坠落危险""坠落危险禁止靠近”的提示，这些主要出现在应真殿、风穴台、御风台附近的悬崖地段。公共数据显示，这里没有单独统计的危险区域、观景点、避难所或饮水点（各项均为0个），所以饮水和休息计划最好自己提前准备好。

距离与所需时间

사진: 한국관광공사 관광사진 갤러리 (경상북도 봉화군) · 공공누리

以清凉山辖区内登山道总长（17.17公里，5段合计）为基准，数据显示上行大约需要400分钟，下行大约需要168分钟。这是把辖区内所有路段加总后的累计数字，千万别误以为是某一条específica路线的耗时——换算成距离的话，平均上行配速大概是每公里23分钟左右。具体到各条路线的单程耗时：天空栈道入口→丈人峰约2小时19分，山城入口→北门址观景台约2小时27分，紫霄峰入口→应真殿登山道观景台约2小时7分，每条路线往返大概4~5小时就能走完。由于沿途没有单独的避难所，总长也就17公里左右，清凉山完全是一座不用过夜、当天来回就够的山。不过要是打算把几条路线连起来纵走，或者想从从容容逛逛寺庙和景点，最好把移动时间预留得宽松一些。

交通指南（大众交通·停车）

图片：韩国观光公社观光照片图库（庆尚北道奉化郡）· 公共누리

清凉山地处地铁完全够不着的地方，从首尔等首都圈过来，一般得先坐KTX或市外巴士到安东或奉化，再换乘当地的市内·农渔村巴士才能摸到清凉山入口。开车的话，走中央高速公路一类的路线进入道立公园的进山路，是比较常规的走法。公共数据里并没有单独统计附近的公交站点或停车场信息，所以实际的站点位置、能不能停车，还是强烈建议用高德地图……不对，是用KakaoMap或Naver Map查一下最新的路线和设施情况比较保险。Google地图在国内的道路和交通信息上经常不太准，最好还是搭配国内地图App一起用。

季节·天气·装备

照片：韩国观光公社观光照片库（庆尚北道奉化郡）· 公共누리

清凉山最推荐的季节是春天（新绿）和秋天（红叶）。夏季酷热难耐，加上山上几乎没什么补水点，要特别当心脱水；冬季则因岩石棱线路段结冰，实际难度会飙升不少，冰爪、绑腿这类冬装是必备的。基本装备方面，建议准备一双能护住脚踝的登山鞋、至少1~1.5升以上的饮用水（园区内实际上没有像样的取水处，这个真的不能省）、防雨的雨衣、登山杖，以及防晒用品。经过天空桥、应真殿这类紧贴悬崖的路段时，穿双防滑的鞋子、戴上手套，会让人安心不少。

外国游客小贴士

照片：韩国观光公社观光照片图库（庆尚北道奉化郡）· 公共누리

清凉山的罗马字标记为Cheongnyangsan，主峰将军峰标为Jangingbong，代表性景点天桥标为Cheongnyangsan Sky Bridge，清凉寺则标为Cheongnyangsa Temple。这次的数据里没有单独的入山许可或门票信息，建议出发前先通过清凉山道立公园管理事务所或官方渠道确认最新的费用和开放时间。洗手间确认设在山城入口登山口附近，饮水点（山泉）根据公共数据显示并没有单独设置，所以爬山前最好自备充足的水。地图软件强烈建议用KakaoMap或Naver Map，而不是谷歌地图；这一带公共交通不算密集，最好再备一个叫车软件（比如KakaoT），出行会方便不少。安全方面，靠近悬崖的路段务必留意”坠落危险”的警示牌，日照较短的季节要预留充裕的下山时间，避免摸黑走夜路。
