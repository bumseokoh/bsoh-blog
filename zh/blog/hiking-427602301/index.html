泥土路尽头遇上的岩脊，江原白德山

概述

照片：韩国观光公社观光照片库（江原特别自治道宁越郡武陵桃源面百年溪谷路158）· 公共누리

白德山（Baekdeoksan）横跨江原道宁越郡水周面与平昌郡防林面的交界处，山顶海拔按不同地理资料略有出入，介于1,327米到1,345米之间，而按登山道实测数据，最高点可攀升到1,364米。它与相邻的狮子山（1,183米）之间有山脊相连，因此把两座山峰连在一起走的纵走路线也颇为知名。整体来说白德山偏土山性质，但接近山顶的区域夹杂着不少岩石地段，所以越往后段走，体感难度就越高。区内登记在册的登山道总长（各区间累加）为16.42公里，不算太长，主要路线单程在4~11公里左右，当天往返完全可行。不过通往山顶一带的路线累计高差达700~860米，相对距离而言体力消耗不小，因此被归类为比看起来更费体力的一座山。

山势与地形

照片：韩国观光公社观光照片图库（江原特别自治道旌善郡舞陵桃源面百年溪谷路142）· 公共누리

白德山很能代表江原岭西一带山脉的典型特征：整体上以土路为主，属于典型的土山，但快到山顶的那段路，会突然冒出岩棱和碎石坡混杂的地形。翻查公共数据里登记的山峰信息可以看到，狮子山山顶（1,183米）、白德山山顶（各调查点标高不一，有1,327米、1,337米、1,345米等说法）、九峰台山（907米）和九峰台山山顶（922米）其实都串在同一条山脊线上——也就是说，从白德山经狮子山到九峰台山这整条山脉，规模足以撑起一次纵走。实测路线上还会经过雪桶岩、骆驼岩、龙岩这些有名有姓的岩块，可见白德山山顶一带并非单纯的土峰，而是夹杂着大大小小的岩石地形。山顶附近有个叫骆驼岩展望台的观景点，据了解可以同时眺望山脊与溪谷。往溪谷方向走会遇到一个叫比内所谷的地名，这一段被标为山体滑坡脆弱地区，可以说是带有溪谷地形特有的边坡不稳定性的地方。

登山的感受

照片：韩国观光公社观光图片库（江原特别自治道宁越郡武陵桃源面百年溪谷路88-3号）· 公共누리

白德山的山行体验有一种鲜明的反差感：前段是平缓的林间小路,越往山顶走坡度和岩棱地带就越陡峭。从兴元寺方向进山,一开始便是寺院丛林般幽静的氛围,山路的看点也随着路段和季节不断变化——有的地方是古树倒地形成的天然隧道（먹골线路),有的地方立着杜鹃花群落的指示牌。快到山顶时会经过骆驼岩瞭望台、龙岩等岩石地带,沿途还能看到”小心坠落”的警示牌,这一段需要手脚并用地攀爬岩棱,颇有几分紧张刺激的味道。相反,从文岾入口爬狮子山的那条路线,途经直升机停机坪,是一条相对平缓的稜线路,可见同一座山,选哪个入口，山行的性格能差出一大截。秋天有满山红叶,初夏有成片杜鹃,四季分明，是这座山颇值得一走的理由。

路线1 — 兴元寺 → 观景台

📏 7.72km ⛰️ 691m 爬升 ⏱️ 3:05 ➡️ 单程 难度 ★★★★★ ⤓ GPX

沿途：宁越公营幸福巴士站 → 简易厕所 → 兴元寺 → 白德山登山口，兴元寺 → 雪桶岩 → 岔路口 → 祭坛遗址 → 观景台 → 骆驼岩观景台 → 坠落注意路段 → 龙岩 → 白德山顶前岩石

登山口交通：从兴元寺方向进山，走的是宁越郡水周面这一侧，登山口附近据说有地区公营巴士（幸福巴士）站点，不过农村公交这种车次稀少的特点，出发前一定要先查好时刻表。自驾的话，一般都停在兴元寺附近的空地，没看到有正式的登山口停车场。

特点·推荐人群：这条路线先从寺庙的林间小路走起，后半段接连经过雪桶岩、骆驼岩、龙岩等几处颇有名气的岩石地带，可以说是最能体会到白德山山顶一带岩棱魅力的代表路线。骆驼岩观景台的视野极佳，但沿途明确标注了坠落注意路段，所以更适合有岩棱徒步经验的登山者。

路线 2 — 墨谷 → 山顶

📏 4.51km ⛰️ 427m 爬升 ⏱️ 1:50 ➡️ 单程 难度 ★★★☆☆ ⤓ GPX

沿途经过：白德山停车场卫生间 → 白德山登山口 → 墨谷 → 枯木倒伏形成的隧道状路段 → 岔路口 → 路标旁的小憩息处 → 杜鹃花群落指示牌 → 登山道封闭路段 → 路边小空地 → 小空地圆凳 → 枯木倒伏地点 → 坡陡且为土路，需注意脚下 → 白德山登山口 → 云桥站 → 云桥一里村会馆前卫生间

登山口交通：墨谷登山口位于平昌郡芳林面云桥里一带，附近有云桥站，看起来可以搭乘市外车或农渔村巴士前往，但班次不多，建议出发前先查好时刻表。村会馆前设有卫生间，登山前后都能用上。

特点与推荐人群：这是四条路线里最长的一段，全长11.19公里，途经枯木倒伏形成的隧道路段和杜鹃花群落，森林原始气息很浓。不过沿途好几处能看到登山道封闭的标识，还有坡陡土路需要小心，比较适合体力和时间都比较充裕的登山者，出发前最好先确认一下最新的封闭情况。

路线3 —— 白德山方向 → 登顶前的小空地

途经：白德山方向 → 岔路口 → 登顶前的小空地 → 登顶前 → 登顶前的树 → 白德山山顶 → 门岾·白德山·非内所谷岔路口 → 下往非内所谷的路 → 注意事项告示牌 → 溪谷 → 山体滑坡易发区 → 非内所谷

登山口交通：这条路线没有单独明确的村落登山口名称，标注上直接写着”白德山方向”，实际使用中更多是和其他路线在稜线上相连、当作纵走区间来走的情况居多。比起搭乘大众交通，开车到附近再徒步进入会更现实一些。

特点·推荐对象：这条路线会直接经过白德山山顶，再往非内所谷方向下山，特点是过了山顶之后可以在门岾·白德山·非内所谷岔路口自行选择前进方向。下山路上明确标示了山体滑坡易发区，下雨天或梅雨季节最好避免走这条路，比较适合想顺便体验溪谷地形的登山爱好者。

路线4 — 文岾登山口 → 狮子山山顶

沿途：文岾休息处 → 文岾登山口 → 登山道封闭区间 → 岔路口 → 直升机停机坪 → 倒木地带 → 横倒在路上的枯木 → 登山道封闭 → 枯木倒伏处 → 狮子山山顶 → 陡坡旁小路 → 白德山前2公里处

登山口交通：文岾是连接宁越和平昌的一条山间公路，岭顶就有文岾休息处，开车过去相对方便。没查到专门的公交路线，一般都是自驾或打车上来。

特点与推荐人群：在这四条路线里，它是距离最短、累计爬升也最小的一条，走起来相对轻松。虽然大部分是经过直升机停机坪的平缓稜线路，但沿途有几处登山道封闭区间和倒伏的枯木，出发前最好先确认一下最新路况。如果你想花不多的时间就登顶狮子山，或者打算把这里当作白德山纵走的起点或终点，这条路线会比较合适。

难度・路面・注意事项

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 영월군 무릉도원면 백년계곡길 15-5) · 공공누리

区内登记在案的登山路数据显示最高难度为”简单”，不过这只是行政洞层级的登山路区间数据，实际的顶峰路线（兴元寺·墨谷·白德山方向）按GPX实测应属最高难度（★★★★★），体感上落差相当大，这一点要留意。路面情况没有单独登记，但从路标名称就能看出，这一带是土路和岩石地混杂的地形。尤其在雪桶岩、骆驼岩、龙岩一带，岩脊特有的湿滑感明显，墨谷路线和文岾路线也各自立有”坡陡且为土路，需注意”的告示牌，下雨天要特别当心打滑。公共数据里没有另外标注危险区域（数量为0），但实测GPX上却能看到”注意坠落”（1号路线）、“滑坡脆弱地带”（3号路线，往飞衣所谷方向）的标记，这些区段务必格外小心。观景点确认有1处（骆驼岩观景台），可以说是白德山登山途中最具代表性的观景处。另外，墨谷、文岾两条路线上都多处出现”登山路封闭”的告示，建议出发前先查一下地方政府或国立公园相关的最新通告，确认是否仍在管制中。

距离与所需时间

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 평창군 평창읍 원당리 261) · 공공누리

白德山把辖区内所有登山路线加总起来，上山共需419分钟，下山共需293分钟——不过这是把好几段路合并计算出来的累计数字，可别误以为是某一条具体路线的耗时。以这份累计数据推算，平均上山配速大约是每公里26分钟，比其他山头要慢一些，这也和白德山山路上不少陡坡、岩石地带的实际情况相符。具体到各条路线：兴源寺路线约3小时29分钟，墨谷路线约4小时10分钟，“白德山之路”路线约3小时5分钟，文岾-狮子山路线约1小时50分钟（均为单程数据）——这些都是按距离和高度算出来的估算值，实际所需时间还是会因个人体力和休息时间长短而有出入。如果走兴源寺或墨谷路线来回一趟，一天下来总共可能要花7到8个小时以上，建议一大早就出发；另外，不管选哪条路线，目前都没查到沿途设有避难所，所以一般还是按当天往返来安排，不建议留宿一晚。

徒步路线（大众交通·停车）

照片：韩国旅游发展局观光照片图库（江原特别自治道平昌郡芳林面德谟古开路47-1）· 公共누리

白德山位于江原道宁越郡与平昌郡交界处，属于大众交通不太方便抵达的山。从首尔等首都圈出发，一般是先坐KTX或市外巴士到平昌（芳林）或宁越市区，再转乘农渔村巴士或出租车到各个登山入口。먹골路线附近有云桥站，可以搭乘班次巴士；兴元寺路线附近确认有宁越公营幸福巴士站，但发车间隔较长，出发前务必先查好时刻表。文岾入口本身就在山道上，比起等公交，开车或叫出租车更现实一些。公共数据里没有查到登记在册的停车场，实际上大家多半是把车停在入口附近的空地或村口进村路的路边，这时候要格外留意别误入私人用地或农田。建议出发前务必用Kakao地图或Naver地图确认最新路况和路线，Google地图在韩国境内的步行、大众交通导航支持有限，不太适合用来查这条登山路线。

季节·天气·装备

照片：韩国观光公社观光照片图库（江原特别自治道宁越郡无陵桃源面百年溪谷路66-16）· 公共누리

白德山素以春天杜鹃、映山红绽放时节和秋天红叶时节最适合登山而闻名。夏季由于溪谷方向（碧内所谷）属于山体滑坡易发区，暴雨集中时段最好避免登山，加上湿度大，体力消耗也会随之增加。冬季山顶一带的岩脊路段（雪桶岩、骆驼岩、龙岩）以及陡坡土路段容易结冰，冰爪、绑腿等冬季装备必不可少。通用的必备装备包括登山鞋、备用衣物、防风防水外套、充足的饮用水（沿途没有确认到饮水点，建议至少携带1.5~2升），头灯（应对长距离路线），登山杖（应对陡坡路段）等。洗手间方面，兴元寺附近的简易厕所、白德山停车场厕所、云桥1里村会馆前厕所都可以在登山前后使用。

外国游客小贴士

白德山的罗马字标注是”Baekdeoksan”，山顶写作”Baekdeoksan Summit”，旁边相邻的狮子山（사자산）则标为”Sajasan”。这座山没有查到固定的封山时段或门票信息，不像国立公园那样需要提前预约或买票，随时可以去，不过登山道上有好几处路段确认是封闭的，一定要留意当地的告示牌。厕所资源比较有限，目前确认能用的只有兴元寺的简易厕所、白德山停车场厕所，以及云桥1里村会馆厕所，建议上山前先解决好，别指望半路找地方。登山道中途没有确认设有饮水处，所以水一定要自己带够（Bring your own drinking water — no water fountains are confirmed along the trail）。地图软件比起Google地图，更推荐用KakaoMap或Naver地图，两款都支持英文界面，外国游客用来查登山路线和公交换乘都没问题。这一带大众交通比较受限，建议顺手准备好叫车软件（比如Kakao T）。另外山里有些路段手机信号会变弱，最好提前把离线地图下载好；比起独自上山，更安全的做法是找人同行，并提前把行程和预计下山时间告诉别人。
