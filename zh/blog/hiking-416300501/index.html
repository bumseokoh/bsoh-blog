概述

照片：韩国观光公社观光照片资料库（全南光州统合特别市莞岛）· 公共누리

道乐山（道樂山，Doraksan）位于忠清北道丹阳郡，山顶最高海拔在985米左右（公共数据登记的正式海拔为987米，但通常也有介绍为964米左右，说法略有出入），因可以俯瞰丹阳八景以及仙岩溪谷（上仙岩、中仙岩、下仙岩）一带的景致而广为人知。整体来看，这座山岩石嶙峋、山势险峻，不过公共数据将其登山路线难度归为最低的”简单”级别，接近山体的路段本身相对平缓。只是实际的登顶路段净爬升较大，体感难度并不算低，属于可以搭乘大众交通、当天往返完成的山。

山势与地形

照片：韩国观光公社观光照片图库（全南光州统合特别市 莞岛）· 公共누리

道乐山是一座典型的骨山，大大小小的岩峰沿着山脊连绵不断。目前收录在公共数据中的山峰有兄峰（911米）、道乐山（987米）、神仙峰（938米）、彩云峰（892米）、剑峰（848米）、道乐山964峰（932米）、上仙岩峰（659米）、帝峰（843米），这些山峰依次排列在同一条山脊线上，因而可以走一趟纵走式的岩脊路线。越往顶部走，花岗岩、石灰岩一类的岩石地带越是明显，而山下的溪谷则有仙岩溪谷清澈的溪流与水潭点缀其间——上部的岩峰地形与下部的溪谷地形形成鲜明对比，正是这座山的一大特色。

登山的感觉

照片：韩国旅游公社旅游照片图库（全南光州统合特别市莞岛）· 公共누리

登山口从上仙岩溪谷沿线的缓坡林道开始，一路听着溪水声往上走。过了半山腰，岩石地带渐渐多了起来，到上仙岩峰附近，视野豁然开朗，丹阳一带的山脊尽收眼底。连接兄峰和弟峰的一段是典型的岩脊路，紧张感十足，有些地方得手脚并用地爬，难度瞬间上一个台阶。登上道乐山顶峰，四面山脊尽展眼前，视野极为开阔，秋天枫叶和岩峰相映成趣，是这条路线公认的最佳观景段。

途经：佳山2里公交站 → 上仙岩停车场 → 岔路口 → 上仙岩 → 仙岩园餐厅 → 观景点 → 上仙岩峰 → 观景处 → 岩石区 → 帝峰 → 兄峰 → 拍照点 → 道乐山 → 落雷危险区域 → 神仙峰

登山口交通：佳山2里公交站离登山口不远，一般都是从丹阳邑市区坐市内公交过去。发车时间和路线时不时会调整，建议出发前用KakaoMap或Naver Map查一下最新信息。公共数据里没查到这一带有登记在册的停车场，所以要是打算自驾的话，得靠上仙岩溪谷入口附近的空地或指示牌自己现场确认能不能停车了。

特点·适合人群：沿上仙岩溪谷往上走的前半段，树林和溪流相映成趣，坡度平缓，算是热身路段。过了上仙岩峰之后，岩棱地带和观景地带便交替出现，兄峰到帝峰这段的岩石区对新手来说可能有点吃力，比较适合有一定岩棱行走经验的驴友。整条线走到山顶道乐山后还会继续延伸到神仙峰方向，是纵走型路线，想同时享受观景和攀岩乐趣的人，这条路线值得一试。

难度·路况·注意事项

사진: 한국관광공사 관광사진 갤러리 (충청북도 단양군 대강면 선암계곡로 148) · 공공누리

公共数据里道乐山辖区登山道的最高难度被标为”简单”，但这是按整个辖区登记路段（以行政洞为单位）统计出来的分类，若考虑通往主峰路线（加山2里→上仙岩峰）的实际爬升高度差和岩石地形，体感难度恐怕比这个数字要高不少。路况细节没有单独登记，但正如前面地形介绍里提到的，越往主峰走岩盘、岩石地带越多，下雨天或清晨露水未干时岩石会变滑，需要格外小心。冬季岩石结冰路段滑倒风险更高，建议带上冰爪之类的辅助装备。

从公共数据的登山道设施POI清单来看，观景点、饮水处、避难所、危险区域全都是0笔，也就是说地图上并没有另外登记的指示设施。不过实际GPX轨迹记录里，上仙岩峰附近有个观景点，道乐山至神仙峰路段之间也标出了一处落雷危险区，作为途经点出现——就算没有相应的实体设施，这段路上还是要留意天气变化（尤其是夏季雷雨）。

按辖区行政洞统计的登记路段共有7段，需要注意这里统计的是以行政区划为单位的登山道总长度，而不是各条登山路线的名称。

距离与所需时间

照片：韩国观光公社观光照片图库（忠清北道丹阳郡仙岩溪谷路790 上仙岩）· 公共누리

通往顶峰区域的路线（加山2里公交站→上仙岩峰）单程6.62公里，垂直高度差692米，预估单程耗时约2小时49分钟。往返合计大概需要5个小时左右，这条路线本身当天来回完全没问题。不过道乐山园区内登记在册的登山道总长加起来有7段共32.53公里，这是把好几段路线全部合计的数字，并不是单一路线的距离。公共数据里园区全线累计所需时间为上行585分钟、下行401分钟，这同样不是单一路线的耗时，而是园区全部路段的累计值，千万别混为一谈。把这个累计数值换算成距离的话，平均上行配速大约是每公里18分钟，可以作为道乐山整体登山道坡度偏缓的一个参考指标。如果打算把好几段路线连起来纵走，一天之内恐怕难以走完，建议考虑安排一晚以上的行程。

交通与停车

照片：韩国观光公社观光照片图库（忠清北道丹阳郡丹城面佳山里）· 公共누리

登顶路线的登山口附近有佳山2里公交车站，从丹阳市区出发的市内公交可以直接抵达。一般走法是先从首尔东首尔综合客运站或清凉里等地乘坐市外·高速客运，或者搭乘KTX、无穷花号等火车到丹阳站、丹阳客运站，再换乘市内公交进山。公交路线和班次会随时节调整,建议出发前务必用KakaoMap或Naver Map查一下实时的公交路线。开车去的话，公共数据里查不到登记在册的停车场，最好提前用地图App确认一下上仙岩溪谷入口附近能停车的地方，或者按当地餐馆、设施的指引找地方停车。

季节·天气·装备

照片：韩国观光公社观光照片美术馆（忠清北道丹阳郡大江面寺人岩2街42）· 公共누리

道乐山最适合在春秋两季登山，尤其是秋天，岩峰与红叶相映成景,观景效果堪称一绝，是最推荐的季节。夏天酷热难耐，午后还常有雷雨，尤其是走到前面提到的道乐山至神仙峰之间那段落雷危险区时,一定要格外留意天气变化。冬天岩石路段容易结冰打滑，建议备好冰爪、绑腿等冬季装备。不论哪个季节都要准备的基本装备包括支撑脚踝的登山鞋、登山杖、备用衣物，以及充足的饮用水。山里目前没有发现药水泉或饮水点，所以出发前一定要多备些水。

外国游客小贴士

照片：韩国观光公社观光照片图库 · 公共누리

道落山山顶的罗马字拼音标注为”Doraksan”，主峰路线起点的Gasan 2-ri（가산2리）也可写作”Gasan 2-ri”。途经的上仙岩可标注为”Sangseonam”，道落山附近的几座山峰——神仙峰、兄峰、弟峰——分别可拼作”Sinseonbong”、“Hyeongbong”、“Jebong”。目前没有查到需要另行申请入山许可或缴纳门票的信息，不过还是建议到了现场留意一下当地的指示牌，确认最新情况比较稳妥。公共数据里并没有单独登记这条登山路线沿途的厕所和饮水设施，所以最好在起点Gasan 2-ri或附近上仙岩停车场一带的餐馆、商店解决，或者提前备足饮用水。谷歌地图在韩国的登山路线信息常常不太准确，强烈建议装上KakaoMap或Naver Map，提前查好实际的登山路径和公交换乘信息。这条路线包含岩石山脊路段，下雨或结冰时滑倒的风险会比较高，出发前最好先看看天气，别勉强上山。
