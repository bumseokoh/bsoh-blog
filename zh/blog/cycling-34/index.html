概述

照片：韩国观光公社 观光照片图库（文俊经路188）· 公共努里（KOGL）

新安郡（曾岛）自行车道（Sinan-gun Jeungdo Bicycle Path）以全罗南道新安郡的曾岛（Jeungdo）为舞台。在国内的自行车道里，它属于风格极为独特的一类。不同于沿江贯穿内陆的纵贯线路，这条路穿行于大海、滩涂和一望无际的盐田之间。几乎没有遮挡视线的建筑物，近乎与地平线重合的海平线一路绵延，所以蹬车途中风景变化不大，但那份风景的密度却相当惊人。

坡度总体平缓。受岛屿地形影响，会有一些短促起伏反复出现的路段，但可以说基本不存在长距离爬坡。因此，真正决定这条线路难度的，不是体力负担，而是风、日晒和补给计划。

具体的玩法建议如下。

第一，作为悠闲的一日骑行路线。 上午出发，中午前后到达折返点，下午返程，这样的安排最为自然。与其追求速度，不如在盐田、滩涂、海滩边频频停下来，这才更符合这条路的气质。

第二，作为两天一夜海岛之旅的交通工具。 曾岛是被认定的国际慢城（Cittaslow），比起汽车，自行车的速度和这里要合拍得多。把行李放在住处，只骑自行车环岛一圈，观光和骑行就能一举两得。

第三，与小轮车、折叠车（Brompton 等）联动的旅行方式。 带着折好的自行车乘公共交通抵达新安，再在当地展开骑行，这种玩法很实用。路面总体维护良好，小轮径车骑起来也没有明显吃亏。

第四，作为家庭出游、新手骑友的分段骑行路线。 不必骑完全程，只在盐田一带或海滩路段来回骑一段，满足感也已足够。

路线信息

照片：韩国观光公社 观光照片图库（大草里）· 公共努里授权

路线从曾岛入口处的大桥一带出发，穿过岛屿内部，再沿海岸线延伸。曾岛经由曾岛大桥（Jeungdo Bridge）和沙玉岛与陆地相连，虽是海岛，却不用坐船就能进入。这一点对骑行者来说是相当大的优势。

主要途经点包括太平盐田（Taepyeong Salt Farm）一带、盐博物馆周边、弹涂鱼桥（Jjangttungeo Bridge）附近的滩涂，以及羽田海滩（Ujeon Beach）和其后方绵延的海松林路段。太平盐田作为韩国规模最大的单体日晒盐田而广为人知，制盐结晶池呈格子状一望无际地铺开的景象，堪称这条路线的标志性画面。在弹涂鱼桥周边，退潮后可以观察到在滩涂上蹦跳的弹涂鱼和螃蟹。

路面状况因路段而异。它并不是像江边自行车专用道那样长距离与机动车完全隔离的形式，更稳妥的理解是：与岛内公路共用的混行路段和专用路段交替出现。交通量本身远比城市地区少得多，但旅游旺季时小汽车和观光巴士会增多，切不可掉以轻心。

风景最大的特点是开阔感。由于防风林和建筑物很少，风会直接扑面而来。顺风时车速自然而然就上去了，逆风时即使是平路也感觉像在爬坡。如果是往返骑行，去程和回程的体感难度可能相差很大，建议提前把这一点算进计划里。

这条路线不属于国土纵走自行车道认证制的对象路线，因此沿途没有设置认证中心。与其说是收集印章的乐趣，不如把它理解为一条以欣赏风景和体验当地文化为主的路线更为贴切。

周边美食

图片：韩国观光公社旅游图片库（文俊卿路459-2）· 公共文化开放许可（KOGL）

新安郡是一个以大海和滩涂为生活根基的地方，饮食自然也带着这份印记。这里不点名推荐具体某家餐馆，只介绍当地普遍出名的几样吃食。

最具代表性的当属**天日盐（Cheonilyeom，日晒海盐）**及其衍生食品。盐本身就是当地特产，用盐角草（Salicornia，海蓬子）制作的食品，以及用盐田海盐腌制的各类鱼虾酱，在这一带都很容易见到。

海鲜方面，**章鱼（nakji，韩式小章鱼）**料理最为出名。当地一般把滩涂里捕到的章鱼做成软泡汤（章鱼清汤）、辣炒章鱼或章鱼生拌。此外，鮸鱼、鲳鱼、鲈鱼等西南海域的鱼种也会随季节上桌；放眼整个新安郡，黑山岛的洪鱼（hongeo，发酵斑鳐）堪称头号特产。洪鱼带有发酵特有的浓烈气味，对外国游客来说可能是个不小的挑战，第一次尝试的话，建议先来一小份试试。

**补给方面务必多加小心。**这条路线不是城市型路线，便利店并不密集。在盐田与海岸之间的开阔路段，可能要骑上相当长一段距离，途中既没有商店也没有自动售货机。另外，当地餐馆的营业时间比城市里短，淡季或工作日还有些干脆不开门。所以出发前请备足饮水和行动干粮，并提前把用餐时间安排在路线中段，这样才稳妥。“骑着骑着总会碰到吃的”——这种想法在这条路线上是行不通的。

补给·便利设施

照片：韩国观光公社观光照片图库（智岛曾岛路 1053-11）· 公共努里（Kogl）授权

根据韩国行政安全部自行车道数据库的登记信息，这条线路的设施现状是：认证中心 0 处、卫生间 0 处、饮水台 0 处、打气筒 0 处。也就是说，这是一条没有把自行车道专用便利设施纳入线路信息管理的路线。

实际的应对办法如下。

水请全部自行准备。线路沿途没有饮水台，出发前装满两个水壶或一个水袋会更稳妥。盐田地带几乎没有遮荫，水分消耗很快。

卫生间没有登记为线路设施。不过一般来说，主要景点或公共停车场周边往往设有公用卫生间，所以比较高效的做法是：每到一个观光点，就先提前解决。

打气筒同样没有登记，因此便携式打气筒或 CO₂ 气瓶加备用内胎是必须随身携带的。在海岛地区很难马上找到自行车修理店，所以补胎这件事，请按照全靠自己解决的前提来准备。

至于认证制度，这条线路不属于国土纵贯认证制的范围，沿途没有可以在认证手册上盖章的打卡亭。如果你骑行的目的是收集认证贴纸，那需要提前知道这条路线不在其列。不过换个角度看，沿途的各个景点本身就足以充当目的地了。

返程

照片：韩国观光公社观光照片图库（甑洞里）· 公共著作权（KOGL）

虽然这是一条单程型路线，返程的负担却不算大。单程 37.8km，原路返回也就是 75.6km 的往返距离，一天之内完全消化得了。不必专门安排长途返程交通，如果车或住处就放在出发地，原路骑回去就是最简单、最稳妥的选择。

不过，如果打算原路往返，到了折返点请务必检查一下体力和剩余的水量。去程如果是顺风，回程多半就是逆风，所以最好给返程留出更充裕的时间。要是体力所剩无几，不必硬撑到折返点，中途掉头折返也是个灵活的好选择。

安全与注意事项

照片：韩国观光公社旅游图片库（羽田里 山37-6）· 公共信息开放许可（KOGL）

沿途存在机非混行路段，请默认自己会与机动车共用同一路面来骑行。靠右行驶，随时留意身后驶来的车辆声音。不建议两只耳朵都戴着耳机。

在人车混行路段请放慢速度。景点周边、海滨步道、桥梁附近，随时可能有没料到会有自行车经过的游客突然走进你的行进路线。养成提前用车铃或喊话告知对方自己存在的习惯，能有效减少事故。

风是这条线路上最现实的危险因素。在开阔的盐田和海岸路段，侧风一起，车子可能被吹得横向偏移。轻握车把、压低上身以稳住抓地的骑行姿势会很有帮助。

路面结冰是冬季需要注意的事项。海岸地区湿度大，背阴路面或桥面上可能残留薄冰。在这类路段，原则是刹车和转向都不要有急动作。

夜骑尤其要小心。海岛地区的道路路灯稀少，太阳一落山天色会迅速暗下来。务必备好前灯和后闪灯，如果可以，把行程安排在日落前结束才是最稳妥的。

补水与脱水是值得反复强调的问题。盐田地带的反射光加上毫无遮荫的暴晒，会让体感温度大幅升高。建议不要等到口渴才喝水，而是每隔 20~30 分钟少量多次地补充。

季节·天气·装备

照片：韩国观光公社旅游照片图库 · 公共努里（Kogl）授权

最推荐的时节是春季（4~5月）和秋季（9~10月）。气温温和、湿度低，非常适合长距离骑行，也是盐田和滩涂色彩最鲜明的季节。

夏季难度会大幅上升。开阔路段几乎没有树荫，一路暴露在直射阳光下，热负荷相当大。如果非要在这个季节骑，我强烈建议一大早就出发。梅雨季和台风期会同时出现强风和能见度下降的情况，这时候需要果断调整行程本身。

冬季的问题不在气温，而在海风。如果只看气温来选衣服，体感温度会算错一大截。最好备上防风外套、脖套和防风手套。

外国游客小贴士

照片：韩国观光公社观光照片图库（防筑里 山318-1）· 公共Nuri授权

① 路线名称的罗马字标记 这条路线的官方名称是新安郡（曾岛）自行车道，罗马字写作 Sinan-gun (Jeungdo) Bicycle Path。行政区名为 Sinan-gun（新安郡），岛名为 Jeungdo（曾岛）。在当地问路时，说”증도 자전거길（Jeungdo jajeongeo-gil，曾岛自行车道）“基本都能听懂。主要地点的英文标记为 Taepyeong Salt Farm（太平盐田）、Ujeon Beach（羽田海滩）、Jeungdo Bridge（曾岛大桥）。

② 骑行认证制实战指南——本路线不在认证范围内 首先需要了解的是，这条路线并不属于韩国国土纵贯自行车道认证制（Korea Cross-Country Cycling Certification）的对象。也就是说，骑完这条路线拿不到认证印章，沿途也没有认证中心。

不过，了解一下韩国的认证制本身，对以后把骑行版图扩展到其他路线会很有帮助，所以这里把一般的运作方式整理如下。

  • 认证手册（Bike Passport）：这是纵贯认证的基本工具。通常最稳妥的方式是在有人值守的认证中心现场购买。官方网站基本只有韩语版，而且往往要求韩国本人认证（韩国手机号·身份证明）或不支持海外发行的银行卡付款，所以在国外提前购买一般比较困难。因此，更实际的计划是抵达韩国后，在认证制路线上的有人值守中心直接购买。
  • 无人认证中心的使用方法：无人认证点是红色公用电话亭造型的盖章亭，远远就能认出来。亭子里的印章用链条固定着，翻开手册对应的格子直接干盖（无需印泥）即可。没有工作人员，也没有付款环节，24小时随时可用。
  • 完骑奖励：每骑完一个区间，会在手册上贴认证贴纸；骑完全部区间或特定纵贯路线后，还可以获得完骑证书和奖牌。当然，这些只适用于认证制范围内的路线，请把它和曾岛路线区分开来理解。

③ 不带自行车前来的情况 对于不打算自带自行车的游客，有以下几个选择。

  • 当地租车：曾岛是一个以旅游为主的岛屿，住宿设施或旅游服务点通常都提供自行车租赁。不过，租赁数量和车况可能不像大城市那样有保障，建议出发前通过住宿方确认是否可租以及规格（成人车·儿童车·是否含头盔）。岛屿地区的租赁点在旺季和淡季的运营差别很大。
  • 叮铃铃（Ttareungi, Seoul Bike）：这是首尔地区的公共共享单车服务。App 有英文界面，支持海外发行的银行卡付款，对外国游客非常友好。但它是首尔专属服务，在曾岛用不了。如果你的行程是先在首尔热身骑一圈，再前往地方路线，用它正合适。

④ 地图应用 在韩国，谷歌地图（Google Maps）的自行车导航准确度较低，经常不能正确反映自行车专用道。因此推荐使用以下应用。

  • KakaoMap（Kakao地图）：支持自行车模式，自行车道的标示很详细，并支持英文显示。
  • Naver Map（Naver地图）：提供自行车路线导航和多语言（英语·日语·中文）界面。

这两款应用最好提前安装并注册好账号。另外，岛屿地区部分路段的数据信号可能较弱，出发前预先加载好当地地图或截图保存，会实实在在派上用场。紧急情况请记住 119（急救·救援）；韩国观光公社的旅游咨询热线 1330 提供包括英语在内的多语言服务，存进手机里会很有用。
