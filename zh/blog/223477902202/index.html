카멜백 러닝벨트 실리콘 물병 실사용기입니다——以下是把这段正文翻译成自然流畅的简体中文（保留 markdown 与图片路径）：

这是我骑车通勤时用了好多次的 CamelBak 跑步腰包硅胶水壶的真实使用体验。材质是硅胶，越往末端越扁的设计，塞进腰带里骑车或跑步时能很好地固定住。上班时装 500 毫升水出门，下班也一样。单程差不多 22 公里，最近天气热了，路上会拿出来喝几口，不过更多的还是那种”身上带着水”的心理安慰。当然，出发前我在两头都会先把水喝足再上路。

因为壶里只装纯净水，不装别的饮料，所以内部我也不用洗涤剂特意清洗。取而代之的是好好晾干——像上面照片里那样有个挂孔，挂在墙上的挂钩上，到下班时就已经彻底干透了，细菌滋生的风险看起来也就相对安全了。大概一周会用洗涤剂清洗一次。

Previous image Next image

上面这张照片是用嘴咬着喝的部位。用门牙一咬，水就能流出来。平时是闭合的，咬住才会打开。它其实还能拧一下重新锁死，就算不小心盖子松了，也能多加一道锁防止水哗哗流出来。硅胶水壶有的带双重锁，有的只有一种锁法，作为跑步腰包用的水壶，最好是带双重锁以上的。因为收进腰包的硅胶水壶会被腰部或腹压挤压，还会反复上下晃动。

Previous image Next image

壶嘴用一天后就带回家清洗。当然在办公室时也会尽量晾干。只要不装含糖饮料之类的，用一天是完全没问题的。

这个跑步腰包用来跑近距离的越野跑，或者去附近爬山也都没问题。如果再多加一个硅胶水壶，感觉爬 15—20 公里的山也能轻装上阵、没什么负担。我这辆车本来就不是什么空气动力学车，是以 Brompton T Line 为基础拆掉了挡泥板等部件，在不想再加装受风阻的额外物件的前提下，为了能随身带水壶、手机、卡包，才买了这个 CamelBak 跑步腰包来用。不过用着用着，用途越来越多，心情真的很不错。这就是一次慢跑、跑步、爬山、骑行都能通用的 CamelBak 跑步腰包硅胶水壶的真实使用体验。

谢谢大家。
