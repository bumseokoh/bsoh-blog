概述

照片：韩国观光公社观光照片图库（庆尚北道龟尾市南通洞，药师庵）· 公共누리

金乌山（金烏山，Geumosan / Mt. Geumo）是位于庆尚北道龟尾市的一座道立公园级名山。主峰玄月峰（玄月峰）按峰顶资料记载海拔约为984米左右（同一批资料中也出现981米的标注，说明高度会因测量时点不同而略有出入，仅供参考），沿着山脊分布着陡峭的岩壁与奇石，自古以来就以景色秀丽著称。通往顶峰的实测路线短则6公里出头，长则达11公里，单程大约需要3小时左右，大多数情况下当天往返即可完成。不过累计爬升落差高达750～860米，相当可观，与其说是轻松散步，不如说是需要一定体力和事前准备的中高难度登山路线，更为贴切。

按行政区划（龟尾市）登记的辖区内登山道共有4段，这些区间合计总长为3.43公里。需要提前说明的是，这并非登顶单一路线的距离，而是按行政洞划分的多段登山道加总所得的数值，因此与下文”主要路线”中列出的实测路线距离（6～11公里级别）性质并不相同，请留意区分。

山势与地形

照片：韩国观光公社观光照片图库（庆尚北道龟尾市金乌山）· 公共누리

金乌山不像那种浑圆敦厚的土山，而是以岩峰岩脊见长。以主峰岘月峰为中心，城安全危峰（855米）、刀达峰（734米）、孝子峰（515米）、喘气峰（538米）等诸峰沿山脊依次排开，山脚下则散落着甘隐山（241米）、虎岭峰（268米）等低矮山头，勾勒出整座山的轮廓。尤其是接近山顶以及往西峰、南峰方向的路段，眺望岩、岩块、观景台形态的岩盘地带频繁出现，其中不乏需要借助绳索或扶手才能通过的陡峭岩脊路段。沿山脊留存至今的金乌山城，也是这座山的一大特色，城墙与岩脊相映成景的画面，在各处登山道的路标上也常能看到。金乌山整体被指定为道立公园，大慧瀑布、道诜窟等广为人知的名胜就位于登山入口附近，所以除了登顶之外，很多人也会专程来走一段短程步道，随便逛逛。

登山的感觉

照片：韩国观光公社观光照片图库（庆尚北道龟尾市）· 公共누리

从登山口出发到爬上稜线之前，沿途要穿过松树林和溪谷，这一段树荫浓密、空气偏湿润，夏天还能一路听着溪水声往上走，颇有几分惬意。过了半山腰，岩石地带和观景岩渐渐多了起来，快到山顶时得攀着岩稜往上爬，视野也随之豁然开朗，四面八方尽收眼底。好几条路线上都能看到”注意坠落、湿滑路段”的警示牌，这也说明山顶附近的岩稜地带不少地方确实得留神脚下，马虎不得。秋天的时候，稜线上的红叶和岩稜的开阔视野相映成趣，是最受欢迎的季节；春天则适合在入口处的溪谷和林间小路欣赏新绿。不过要提醒一句，冬天岩稜路段常常结冰，实际难度会陡增不少，这一点务必牢记在心。

路线1 — 富上里登山口 → 山顶

📏 10.93km ⛰️ 754m 爬升 ⏱️ 3:59 🔁 环线 难度 ★★★★★ ⤓ GPX

途经点：岔路口 → 富上里登山口 → 山顶路标 → 观景岩 → 木椅休息处 → 石塔 → 岩上松树 → 岩上拍照点 → 观景台岩壁 → 第1观景台 → 第1观景台木栈道 → 岩块群 → 观景岩之上 → 第2观景台 → 葛项寺

登山口交通：前往富上里方向，一般乘龟尾市内公交比较方便，附近有富上1里、富上等站点，坐公交也能到达登山口附近。目前没查到专门的停车场，如果自驾的话，多半只能停在路边或村子附近的空地上。

特点·适合人群：这是8条路线里最长的一条，第1、第2观景台等观景点一路接连不断。沿着山脊走很长一段路，体力消耗不小，不过换来的是可以边走边看风景、自己调节节奏的余裕，比较适合体力好、走得动的登山爱好者。

课程二 — 于将岭入口 → 金乌山山顶

📏 7.4km ⛰️ 763m 爬升 ⏱️ 3:07 🔁 环线 难度 ★★★★★ ⤓ GPX

沿途经过：于将岭入口 → 木椅休息处 → 山顶指示牌 → 岔路口 → 坠落、防滑注意区段 → 国家坐标点 → 观景岩 → 眺望岩 → 金乌山西峰 → 松树林 → 岩石休息处 → 平台休息处 → 金乌山山顶指示牌

登山口交通：于将岭位于龟尾市区外围，很多时候得转乘市内公交才能到达，建议出发前先用地图App确认好站点位置，免得临时抓瞎。

路线特点·推荐人群：这是一条经西峰再登顶的稜线型路线，途中设有”坠落、防滑注意”警示牌，雨天或冬季尤其要打起精神。如果想顺路欣赏西峰的view，这条路线会很对胃口。

코스 3 — 위쪽공영주차장 → 칼다봉

📏 9.25km ⛰️ 863m 爬升 ⏱️ 3:45 🔁 环线 难度 ★★★★★ ⤓ GPX

경유: 위쪽공영주차장 → 탐방안내소 → 케이블카 아래 → 화장실 → 갈림길 → 해운사 → 대혜폭포 → 쉼터 → 금오산(성안전위봉) → 칼다봉

登山口交通：这是金乌山道立公园的正门,上侧公营停车场和游客服务中心、缆车站都在一起,是所有登山口里最好找、最方便到达的一个。自己开车的话,停这个停车场基本不会出错。

特点·适合人群：一路会经过大惠瀑布、海云寺这些公园里数得着的名胜,入口处又有游客服务中心和洗手间，第一次来的人或者带着家人一起爬的，规划行程都很省心。不过越往后走,到金乌山主峰(城岸战危峰)一带的爬升会越来越猛，后半段得留着点体力才行。

课线5 — 灵梅寺入口 → 金乌山南峰

📏 10.26km ⛰️ 814m 爬升 ⏱️ 3:55 ➡️ 单程 难度 ★★★★★ ⤓ GPX

沿途：空地停车场 → 长山堤水库 → 灵梅寺 → 观景岩 → 岔路口 → 岩壁 → 金乌山南峰 → 山神堂 → 奇岩 → 慎防滑落路段 → 祈祷处 → 少林寺 → 石岩寺

登山口交通：这条路线起点很安静，途经长山堤水库和灵梅寺，虽有空地可以停车，但并非正式铺装的停车场，建议留出充裕时间从容前往。

特色·推荐人群：这条路线的一大特色是沿途会经过灵梅寺、少林寺、石岩寺等多座寺庙，在幽静的山路氛围中，还能顺道看到山神堂、奇岩这类民间信仰的痕迹。推荐给想避开喧闹人群的登山爱好者。

路线6 — 金鸟山酒店入口 → 通往山顶方向指示牌

📏 6.49km ⛰️ 845m 爬升 ⏱️ 3:02 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经点：岔路口 → 溪谷 → 岩石 → 岩脊观景点 → 通往山顶方向指示牌 → 观景岩 → 急救箱 → 观景岩与松树 → 岩壁 → 木椅休息处 → 金鸟山城 → 石塔 → 四季食堂 → 金鸟山酒店入口

登山口交通：起点在金鸟山酒店附近，离道立公园入口很近，交通算是比较方便的一条线路；起点一带还有一片餐馆街，登山前后想随便吃点什么都不用发愁。

特点及推荐人群：途经点里专门标出了急救箱的位置，这点挺让人安心。整条路线会多次经过岩脊上的观景点，能反复饱览风景。如果想一趟解决登山和饭后聚餐，这条路线很适合你。

难度·路面·注意事项

照片：韩国观光公社观光照片图库（庆尚北道龟尾市）· 公共누리

按行政洞登记的辖内登山路区间（总长3.43km），具体情况如下。

区间距离难度路面
（无区间名）1.95km简单-
香川里区间0.7km简单-
禮山里区间0.48km简单/中等/困难-
山城里区间0.3km中等-

上表按行政洞划分成较短的登山路区间，像禮山里区间这样在同一区间内混杂着从简单到困难各种难度的情况也存在，所以实际体感难度即便在同一区间内也可能有落差。就辖内整体登山路而言，出现过的最高难度是”困难”，路面材质则没有另外记录。

设施方面，登山路POI数据库中登记的危险地带、观景点、饮水台、避难所、正式登山口/下山口全部统计为0件。不过前面介绍的实测路线GPX路标上，“注意坠落、湿滑区段""落石危险地带""瞭望台""观景岩”等标识在各条路线上多次出现。也就是说，官方设施登记统计与实地地形、安全标识之间可能存在差异，登山途中务必留意当地设置的指示牌和标识，尤其是在岩壁区段，雨后或冬季结冰时通行更要格外小心。

距离和所需时间

照片：韩国观光公社观光照片图库（庆尚北道龟尾市）· 公共누리

金乌山各条路线大约在6~11公里之间，单程耗时多在3小时上下，就算按往返计算，一天之内也能轻松走完全程。不过要提醒一句：按辖区登山道数据来看，上行60分钟、下行43分钟这个数字，其实是前面提到的行政洞区间（全长3.43公里）的累计值，千万别误以为这就是登上山顶某一条实际路线的所需时间。把这个累计数值换算成配速的话，平均上行速度大约是每公里17分钟左右，可以拿来当作规划行程时估算自己节奏的参考。但实际登顶路线的净爬升有750~860米之多，走起来往往比这个平均配速更费时间，所以往返登山时最好预留出6~8小时的富余时间，并提前定好下山时间点。总体来说，一天之内就能往返登顶，不算是需要过夜的山，只是在日照较短的晚秋到冬季，最好尽早出发。

前往方式（公共交通·停车）

照片：韩国观光公社观光照片图库（庆尚北道龟尾市）· 公共누리

金烏山位于庆尚北道龟尾市，从首尔等首都圈出发，一般是先坐KTX到金泉龟尾站或龟尾站，再换乘市内公交前往。最常见的路线是开往道立公园售票处·缆车方向（也就是路线3上方的公营停车场附近）的公交；如果是走扶桑里方向的登山口（路线1），可以在扶桑1里或扶桑站下车后步行前往。不过龟尾市内公交的路线和班次时常会有变动，出发前务必用KakaoMap或Naver Map查一下实时的公交路线。Google Maps在韩国国内的公共交通和步行路线信息比较有限，很多时候并不准确，这点要留意。停车的话，建议直接停到道立公园售票处附近的上方公营停车场最省心；其他几个登山口（牛场岘、灵梅寺、金乌山酒店等）目前都没有确认过正规的大型停车场，所以还是优先考虑坐公交比较稳妥。

季节·天气·装备

照片：韩国旅游发展局旅游照片图库（庆尚北道龟尾市）· 公共누리

登山最舒适的季节是春季（4~5月）和秋季（9~11月）。春天可以同时享受入口溪谷和林间小路的新绿，秋天则能一并领略稜线红叶与岩稜远眺的风光。夏季溪谷湿气重、暑热难耐，体力消耗会明显加大，遇到局部暴雨时更要留意溪谷路段的通行安全。冬季岩稜和观景岩石区域很容易结冰，实际体感难度会大幅提高，一定要备好冰爪、绑腿和防寒装备。整座山没有确认设有饮水点，因此不论季节，都请务必自备充足的饮用水（体感上建议每人1~1.5升以上），并配齐登山鞋、登山杖、头灯（备用）、应急干粮等基本装备后再出发。

外国游客小贴士

照片：韩国观光公社观光图片库（庆尚北道龟尾市）· 公共누리

金乌山的罗马字标记为Geumosan（山顶弦月峰为Hyeonwolbong）。因为是道立公园，通常不像国立公园那样要求单独申报入山或收取高额门票，但公园区域可能会收取入场费或停车费，建议到现场问询处确认一下比较稳妥。洗手间主要集中在上方公营停车场·探访咨询所附近（3号线路），其他登山口目前没有确认到单独的洗手间信息，建议在换乘大众交通的地点，或出发前在市区先解决。前面也提到过，这座山没有专门的饮水点，所以矿泉水一定要提前买好带上。地图软件比起谷歌地图，用KakaoMap或Naver Map会更准确地显示登山路线和大众交通信息。山顶一带的稜线上多次出现岩壁及”注意坠落、湿滑”路段，登山经验较少的游客不妨只走一走路况较好、设施齐全的3号线路（上方公营停车场→刀达峰）的前半段（探访咨询所~大惠瀑布），也是不错的选择。手机信号总体上还算稳定，但为以防万一，建议提前把预计下山时间告知同行者或住宿处。

周边其他山峰
