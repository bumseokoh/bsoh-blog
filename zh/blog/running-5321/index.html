西海浪路47号线 扶安格浦海岸跑步路线

跑步 · 发布日期 2026/8/19 ·

러닝 코스 트랙 (공공데이터: 한국관광공사 두루누비) · 지도 © OpenStreetMap ⤓ GPX 다운로드

这条路线，跑步新手能去吗？从首尔当天能往返吗？

图片：韩国观光公社旅游图片库（全北特别自治道扶安郡边山面格浦里）· 公共努哩（KOGL）

先说结论：两个问题的答案都是”能”。西海浪路47号路线沿着扶安格浦一带的西海海岸延伸，几乎没有起伏，跑步经验不多的朋友也可以走跑结合完成全程。当天往返同样可行。不过前往扶安的路上单程就要将近半天时间，稳妥起见，建议以凌晨出发为前提来安排行程。

用星级来打分的话，交通便利度是★★★★☆。市外巴士和乡村公交能直达路线入口跟前，没有私家车也不会有太大困难；但从首尔、釜山这样的大城市出发需要换乘至少一次，所以给不了满分。难度是★★☆☆☆，偏低。最高海拔只有41米，累计爬升也不过每公里0.8米的水平，这不是坡道训练，而是一场纯粹考验配速稳定性的跑步。路面平整度是★★★★★，可以说是这条路线最大的优点。

分季节来看，春季★★★★★、秋季★★★★★，是最好的时节。海风凉爽、湿度低，非常适合长距离慢跑。夏季是★★☆☆☆。海岸路段几乎没有遮荫，正午体感温度会大幅飙升，必须把时间挪到清晨或傍晚。冬季是★★★☆☆，气温本身还能忍受，但从西海迎面吹来的风会让体感温度大打折扣。

来源：韩国观光公社”Durunubi”GPX实测 · 季节评分仅供参考

跑步配速与分段策略

照片：韩国观光公社观光照片图库（全北特别自治道扶安郡边山面边山海边路29-14）· 公共努里（KOGL）

这条路线几乎没有起伏，所以全程保持同一配速的匀速跑（even pace）是最高效的选择。开头要是被海景吸引忍不住提速，到了后半段的海岸直线路段，很容易在风和单调感的双重夹击下迅速掉电。

水平配速预计完赛时间策略
初级7分30秒~8分/km约1小时47分~1小时54分跑9分钟+走1分钟循环
中级6分30秒/km约1小时33分全程匀速
高级5分30秒/km约1小时19分最后5km渐进加速

我建议把全程大致分成三段来跑。前4公里是热身段，比目标配速慢20~30秒进入状态。4~10公里是主体段，等呼吸稳定下来后就锁定目标配速。10公里之后的最后一段，体感难度会随风向变化很大——如果顶着逆风，就别死守配速，稍微压低上身、保住步频反而更划算。

补水方面，出发前喝一次，之后每4~5公里分次小口补充比较好。夏天则要缩短到每3公里一次。

这是一条单程型路线，跑到终点再折返的话，往返正好28.6公里。对正在备战马拉松的朋友来说，这是一条绝佳的LSD（长距离慢跑）路线。这种跑法建议把配速降到7分/km上下，按3小时20分左右规划，并且在折返点务必补足水和零食再出发。如果没把握跑完全程折返，也可以在半程处掉头，用往返的方式自行调节距离。

补水·便利店·卫生间

照片：韩国观光公社旅游图片库（全北特别自治道扶安郡边山面道清里）· 公共努里（Kogl）授权

由于是海岸型路线，中途会有商店稀少的路段。建议不要把计划建立在”某处一定有补给点”的前提上，而是遵循以下原则。

  • 出发前备齐：作为起点的港口周边有村庄和客运站，属于生活区，出发前请备好水、电解质饮料和几支能量胶。
  • 随身至少带 500ml：春秋季建议 500ml，夏季建议 1L 以上，或在跑步背心里装两个软水壶。
  • 卫生间：海水浴场、港口和主要景点停车场大多设有公共卫生间。请以出发前和抵达终点后为基准来安排，中途不抱期待反而心里更踏实。
  • 现金·银行卡：小村庄的商店可能刷不了卡，请备些小额现金。

路线概览

照片：韩国观光公社旅游图片库（全北特别自治道扶安郡边山面参桑路434-20）· 公共努里（Kogl）版权

西海浪路47号线（Seohaerang-gil Course 47）是一条沿全罗北道扶安郡（Buan-gun）西海岸延伸的单程路线。西海浪路是一条纵贯朝鲜半岛西海岸的长距离徒步旅行线路，其中47号线属于最贴近扶安格浦（Gyeokpo）一带海景与渔村风光的区段。得益于平坦无起伏的路面和一望无际的海景，跑起来的感觉更接近路跑，而非越野跑。

这条路线的玩法相当多样：

  • 周末长距离跑：在平坦的路面上不打乱配速地刷够两位数的里程，再合适不过。
  • 马拉松LSD训练：跑个来回凑成28.6公里，就是一次备战全马的长距离训练。
  • 旅行跑：在扶安的行程里加上一天，早晨沿海岸跑步、下午观光，这个组合非常搭。
  • 新手走跑结合：跑走交替、活动两个多小时，是很适合入门者的长距离体验。
  • 晨间慢跑：如果住在附近，日出时分往返前后5公里，就已经足够让人心满意足。

路线信息

图片：韩国观光公社旅游照片图库（全北特别自治道扶安郡边山面防波堤路11）· 公共努力（KOGL）

起点位于格浦港（Gyeokpohang）周边的生活区。港口、客运站和商铺聚集在一起，很适合在这里做好出发前的准备；附近还有以层层堆叠的沉积岩峭壁闻名的彩石江一带海岸地貌。一出发大海就映入眼帘，从最初几步起你就能直接感受到这条路线的气质。

之后的路线由沿海岸线的道路旁人行道、连接村与村之间的铺装路，以及可以眺望大海的木栈道区段交替组成。途中会经过渔村、小渔港和海水浴场，滩涂、沙滩和防风松林轮番登场。路面大多是铺装路或木栈道，跑鞋抓地稳定，即便偶有土路，也是修整良好的步道水准。

整条路线沿着蜿蜒的海岸线不断划出平缓的曲线，视野不会一次性打开好几公里。但这一点反而减少了枯燥感，对长距离跑步来说是个优势。终点同样位于海岸村落一带，抵达后可以做整理放松，也方便接驳公共交通。

交通方式

照片：韩国观光公社旅游图片库（全北特别自治道扶安郡边山面边山路3210-16）· 公共努哩（KOGL）授权

公共交通：从首都圈出发，最简单的方式是在首尔Central City客运站乘坐高速/市外巴士直达扶安公用客运站。如果想坐火车，可以先乘KTX到井邑站，再换乘开往扶安方向的市外巴士。从扶安市区到格浦，有开往格浦的市外巴士或农渔村巴士可以接驳。

登山口附近的公交站是格下2、格浦、格浦港客运站这三处。其中格浦港客运站是最容易辨认的参照点，如果是第一次去，建议就把它设为目的地。

农渔村巴士班次间隔长，末班车也收得早。出发前一晚务必查好时刻表，先确定从终点返程的末班车时间，再倒推自己开跑的时间。

自驾：从西海岸高速公路扶安IC下来，往格浦方向走即可。港口和海水浴场周边设有公营及路边停车位，但旺季周末会相当拥挤。由于路线是单程型，需要提前想好怎么回到停车的地方（往返跑一遍，或者坐巴士回来）。

安全·注意事项

照片：韩国观光公社旅游图片库（全北特别自治道扶安郡边山面赤壁江路54）· 公共许可（KOGL）

  • 人车混行路段：沿海公路旁的人行道路段离车辆很近。尽量在面向来车方向的一侧跑，耳机只戴一只，或开启能听到环境音的模式。
  • 礼让行人：木栈道和海边步道是与游客共用的空间。从后面超越时要减速，留出充足距离再绕行。
  • 海边的风：西海岸大风天很常见。逆风路段配速慢上30秒以上都不奇怪，别太执着于成绩。
  • 夜间视野：渔村路段有些地方路灯稀少。日落之后头灯和反光装备是必需品，也不建议单独夜跑。
  • 防滑：木栈道被雨水或露水打湿后相当滑。滩涂、海滩入口处湿滑的石头和青苔也要当心。
  • 高温与脱水：缺少树荫的路段会持续很长。如果感到头晕或突然不再出汗，请立即停下来转移到阴凉处。
  • 潮汐：直接经过海滩的路段可能因潮位而难以通行，建议提前查好满潮时间。

季节·天气·着装

照片：韩国观光公社观光照片图库（全北特别自治道扶安郡边山面参梦路434-20）· 公共许可（KOGL）

最好的时段是4~6月和9~11月。这两段时间气温宜人，又正赶上西海独有的晚霞，傍晚出发、伴着日落收尾的安排格外令人难忘。夏天建议把时间挪到早上6~8点或晚上6点以后，冬天则以风较小的上午过半时段为佳。冬季的木栈道和背阴的铺装路面可能结冰，落地时步幅记得放短。

季节建议着装额外装备
春·秋短袖或薄长袖 + 跑步短裤防风外套、防晒霜
夏透气短袖 + 短裤帽子·太阳镜、1L以上饮水、盐分补给
冬功能性内层 + 防风夹克 + 紧身裤手套、脖套、护耳

路面以坚硬的铺装路为主，一双缓震充足的公路跑鞋就很合适，越野跑鞋完全用不上。如果计划跑长距离，建议带上能装水和补给的跑步背心或腰包。海边的风会让体温掉得很快，除了夏天，其他季节最好都折一件薄防风夹克随身带着。

给外国跑者的小贴士

照片：韩国观光公社旅游图片库（全北特别自治道扶安郡边山面竹幕路20-4）· 公共努里（Kogl）授权

路线名称的罗马字标记：Seohaerang-gil Course 47（西海浪路47号线），所在地区为 Buan-gun, Jeollabuk-do（全北扶安郡），起点是 Gyeokpo Port / Gyeokpohang（格浦港）。在当地问路时，说 “Gyeokpo-hang” 大多数人都能听懂。

地图 App：由于法律限制，Google Maps 在韩国的步行和跑步路线导航往往不准确，甚至根本不显示。请安装 KakaoMap 或 Naver Map，两款 App 都支持英文，并提供步行路线和公交时刻表。徒步路线本身可以参考”两路旅”（Durunubi）的官方资料。部分海岸路段信号不稳定，请提前保存离线地图。

公共交通与交通卡：预订市外巴士请使用 Bustago 或 TmoneyGO App。乘坐市内及农渔村巴士需要 T-money 或 Cashbee 交通卡，可在便利店购买和充值。部分农渔村巴士只收现金，准备几张1,000韩元纸币会更安心。

补水与便利店：韩国的便利店品牌有 GS25、CU、7-Eleven、Emart24，大多24小时营业，矿泉水、电解质饮料、能量棒、香蕉乃至防晒霜都能买到。不过海岸村落路段可能没有便利店，出发前请务必在格浦一带补充完毕再上路。

其他：韩国的自来水可以直接饮用，但跑步途中还是建议购买瓶装水。遇到紧急情况请拨打 119（急救·消防）、112（警察）；旅游相关咨询可拨打 1330 旅游翻译咨询热线，提供英语、日语、中文等语言服务。
