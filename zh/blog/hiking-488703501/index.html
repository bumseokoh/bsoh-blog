刀刃般的岩脊高高耸起——庆南居昌黄石山纵走路线

概览

照片：韩国观光公社旅游照片图库（庆尚南道居昌郡渭川面上川里）· 公共누리 KOGL

黄石山（Hwangseoksan）位于庆尚南道居昌郡，主峰在数据记录中为 1202 米，附近几个测点也给出 1192 至 1216 米之间的不同数值。北边耸立着北峰（1215 米），西侧则与金猿山、箕白山、居望山以山脊相连，构成一片完整的山群。因此这里不仅可以单独攀登黄石山，与邻近诸峰串联的纵走路线也颇有名气。整体地形是岩脊与土山交杂，难度偏高；单登主峰往返一天足够，但金猿山—箕白山—居望山的山脊纵走，考虑到距离和耗时，计划住上一晚会更稳妥。

山势与地形

照片：韩国观光公社观光照片图库 · 公共누리（KOGL）

黄石山山群的岩峰与山脊格外分明，顶峰一带接连出现锐利的岩脊路段，是居昌地区极具代表性的”骨山”型山势。查看公共数据登记的峰顶信息，除了黄石山主峰（1202m）之外，附近测点还有 1192m、1210m、1216m 等略有差异的海拔值一并被记录在册。这大概是因为顶峰的岩峰本身由好几个峰组成，测量位置一变，数值也就跟着微妙地变化。往北延伸的北峰以 1215m 单独登记，可见主峰岩峰与北峰共同构成了同一条山脊主轴。把目光转向西侧，是金猿山与箕白山连成的山脊线——数据中箕白山顶部记录为 1357～1369m，比黄石山明显更高一截。实测路线数据里顶峰一带最高海拔达到 1419m，也正与这整条山脊的地形特征相吻合。总体来看，谷地部分是较为平缓的”肉山”形态，越靠近顶峰则急转为岩脊与岩石地带——这就是这一带山群的地形特色。

登山的感受

照片：韩国观光公社旅游照片图库（庆尚南道居昌郡渭川面金猿山路471-27）· 公共版权（Korea Open Government License）

登山口一带大多是沿着茂密林道和溪谷延伸的平缓土路，走起来相当轻松。从金猿山自然休养林方向上山，会经过门岩、幼安厅瀑布这类溪谷地形，夏天有溪水声和树荫消暑，是有名的纳凉路段。可越接近山顶，气氛就完全变了：裸露的岩脊和陡坡接连出现，还有需要手脚并用往上攀的地方。登顶之后视野四面通透，金猿山、箕白山、巨望山连成的山脊尽收眼底，因此在韩国的岩脊登山爱好者当中，这里被公认为观景极佳的路线。秋天是山脊红叶与岩峰交织的景色，冬天则是覆着冰雪的岩脊格外震撼——但危险系数也随之上升，这正是这座山的特点。

途经：水望岭 → 龙湫溪谷登山路线导览图 → 岔路 3 → 通往金猿山顶之路 → 岔路 14 → 水望岭凉亭

登山口交通：水望岭是连接居昌与咸阳的山岭，据了解，比起公共交通，自驾或打车通常更为方便。岭顶似有一小块空地可供停车，但并无正式停车设施的登记数据，建议出行前确认实际路线。

特点与推荐人群：与其他路线相比，这条路线的净高差相对较小，走山脊的负担较轻；加上起点本身已有一定海拔，因此在较短的路段内就能饱览山脊景色。适合想在减轻体力负担的同时体验山脊徒步的登山者。

路线 2 — 金猿山管理事务所 → 山顶

登山口交通：金猿山自然休养林入口设有公交站（金猿山自然休养林站），是少数可以坐公交抵达的登山口之一。休养林管理事务所附近有车辆通行道路，据说停车也相对方便。

特点与适合人群：小卖部、卫生间、休息处等设施在路线的前中段分布均匀，初次到访的人也能比较安心地往上走，属于正规登山道。沿途经过有门岩等看点的溪谷路段，一路延伸到山顶，全程偏长；想用一天时间完整体验这一带山系代表性路线的人，会很适合走这一条。

路线 3 — 入口卫生间 → 山顶

📏 12.85km ⛰️ 918m 爬升 ⏱️ 4:45 🔁 环线 难度 ★★★★★ ⤓ GPX

登山口交通：这条路线包含途经玄城山的山脊段，一般是从附近的溪谷入口进入。相比公共交通，自驾更为稳妥，具体停车条件需要到现场确认。

特点与推荐人群：包含玄城山岩脊段，在 8 条路线中属于距离最长的一类，岩脊与山脊交替出现，行走起来颇有变化。沿途还能顺道游览仙女潭等溪谷景点，适合体力有把握、喜欢长距离徒步的有经验者。

登山口交通：正如”林中小屋停车场”这个名字所示，据了解此处备有自己的停车空间；它位于金猿山自然休养林一带，从前面提到的公交站步行即可抵达。

特点与推荐人群：这条路线的配套设施相当完善，沿途有女性安心卫生间、休养林内卫生间等，而且会经过遗安厅瀑布这处名胜，可以一边欣赏溪谷风光一边往上走。特别适合全家出游的人，以及看重配套设施是否齐全的登山者。

路线 5 — 森林文化休养馆 → 箕白山登顶路

📏 4.22km ⛰️ 858m 爬升 ⏱️ 2:29 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

途经：森林文化休养馆 → 岔路 8 → 箕白山登顶路 → 岔路 10 → 两处长椅 → 箕白山山顶

登山口交通：森林文化休养馆兼作住宿设施，据了解车辆可以顺畅抵达，周边也设有停车场。

特点与推荐人群：8 条路线里距离算是最短的，但净高差达到 858 米，属于在短距离内把海拔集中拉起来的陡坡型路线。适合想在短时间内登顶箕白山的登山者，不过陡坡路段对体力和装备都有要求。

路线 6 — 龙湫寺一柱门停车场 → 前往箕白山山顶之路

📏 11.3km ⛰️ 878m 爬升 ⏱️ 4:17 🔁 环线 难度 ★★★★★ ⤓ GPX

途经：龙湫寺一柱门停车场 → 路标木 → 岔路 3 → 龙湫溪谷登山路线图 → 两张长椅 → 前往箕白山山顶之路 → 三张长椅 → 岔路 10 → 观景台 → 麯岩（누룩덤바위）→ 山林遗传资源保护区告示 → 第二麯岩 → 观景平台 → 岔路 18 → 岔路 19

登山口交通：龙湫寺一柱门前设有停车场，是自驾前往颇为方便的一条路线。通往寺院的道路已经整修完善，整体交通状况良好。

特色与推荐人群：观景台、麯岩、第二麯岩、观景平台等赏景点位散布在路线各处，一路向上都能欣赏风景，这是它最大的优点。推荐给想顺道游览龙湫寺的登山者，以及格外看重视野与景观的登山者。

路线 7 — 通往巨望山 → 山顶

登山口交通：据了解，巨望山方向的登山口一般靠自驾抵达，公共交通不太方便；也没有查到正式停车场的相关数据，建议事先了解一下附近村庄路边的停车条件。

特点与推荐人群：在 8 条路线中属于难度最高的一档，沿山脊攀升的路段绵延很长，体力消耗相当大。适合计划纵走金猿山—箕白山山脊的资深登山者。

线路 8 — 清凉寺入口 → 北峰

登山口接近方式：清凉寺入口需经由寺庙进山路进入，一般在寺前设有供香客使用的小型停车场。公共交通看来不太方便，自驾或打车比较省心。

特点·适合人群：这是一条直通黄石山北峰的线路，穿过寺庙院落后，在相对较短的距离内快速拔升。适合以北峰视野为目标、不打算硬啃顶峰岩脊的登山者，也适合想把寺庙参访和爬山凑成一趟的人。

难度·路面·注意事项

按韩国山林厅登山路空间信息的数据来看，黄石山辖区内已登记的最高难度为「困难」；而在实测 GPX 路线数据里，8 条通往主峰一带的路线中，有一半以上被划为最高难度（★★★★★）。路面信息没有单独登记，不过从各路线详情里出现的「玄城山岩脊」「Nurukdeom 岩」「第二 Nurukdeom 岩」等地名就能看出来，主峰一带遍布裸露的岩脊与岩石路段。这类路段一旦下雨就会变得非常滑，到了冬天更会因结冰而风险陡增，务必格外小心。公共数据中单独登记为危险区域、观景点、登山口／下山口的 POI 统计为 0 处，但各路线详情里确实能找到观景台、Nurukdeom 岩、观景木台等可以赏景的地点；洗手间（含女性安心洗手间）也在锦猿山自然休养林一带的路线上确认到多处。只是以整座山为范围来看，饮水点（山泉）统计为 0 处，所以基本可以认为登山途中没有任何补充饮用水的地方。

距离与所需时间

辖区内登山道总长为多条路线相加的数值，达到 62.3 公里。需要注意的是，这不是单条路线的距离，而是黄石山区域整个登山道网络的总和。已登记的 7 个路段（按行政洞划分）中，大部分标记为”轻松”难度，但这是按行政区划单位统计的结果，与实际登顶路线的难度是两回事。以实测 GPX 为准，登顶路线单程约 2 小时 20 分至最长 4 小时 45 分不等；数据显示辖区内全部路段的累计耗时为上行 1108 分钟、下行 766 分钟，据此计算平均上行配速约为 18 分钟／公里。这个累计值同样不是某一条路线的耗时，而是全部登山道相加的结果，因此实际选择路线时，还是以上面各路线表格中的单程耗时为准更准确。若只是往返某一座主峰，一天时间足够；但要走金猿山—箕白山—巨望山的纵走路线，考虑到总距离和耗时，安排一晚以上的住宿才比较稳妥。

交通指南（公共交通・停车）

黄石山山系位于庆尚南道居昌郡，地铁无法直达。一般路线是先从首尔南部客运站或大邱西部客运站搭乘开往居昌方向的长途客车或高速客车，抵达后在居昌市区换乘前往金猿山自然休养林方向的区域公交或出租车。公共数据（TAGO）中登记的登山口附近公交站为”金猿山自然休养林”，以该站为起点，步行即可抵达金猿山管理事务所、林间小屋停车场等休养林片区各条路线的登山口。不过公共数据中登记的正式停车场数量为 0 个，所以现场实际的停车条件建议出发前用 KakaoMap 或 Naver Map 确认最新信息。尤其对外国游客来说，Google Maps 上的韩国道路与公共交通信息往往不够准确，务必用 KakaoMap 或 Naver Map 应用再次核对实际路线和公交时刻表。

季节·天气·装备

照片：韩国观光公社 观光照片库（庆尚南道咸阳郡安义面龙湫溪谷路623）· 公共누리(KOGL)

黄石山一带的山行，一般公认春秋两季相对轻松，尤其秋天红叶与山脊岩峰交相辉映，景致格外出众。夏天可以享受溪谷段的荫凉与凉意，但酷热和高湿会让体力消耗明显加大，务必备足饮用水。冬天山顶一带的岩脊路段容易结冰，难度大幅上升，没有冰爪、雪套等冬季装备就不要贸然上山。必备装备建议包括：能保护脚踝的登山鞋、充足的饮用水（沿途没有饮水处，需要多少全部自带）、应对降雨和低体温的防水外套、冬季的冰爪与雪套，以及应对山脊段耗时较长的头灯和备用电池。

外国旅行者贴士

照片：韩国观光公社旅游照片图库（庆尚南道咸阳郡安义面龙湫溪谷路 494-6）· 公共누리(KOGL)

黄石山的罗马字标注为 Hwangseoksan，周边几座山峰分别写作 Geumwonsan（金猿山）、Gibaeksan（箕白山）、Geomangsan（举网山），北峰在指示牌上多标为 Bukbong（北峰）。最主要的登山口金猿山自然休养林标注为 Geumwonsan Natural Recreation Forest，另外龙湫寺（Yongchusa）、清凉寺（Cheongnyangsa）等寺庙名称也一并记下来，找路时会方便不少。入山不需要单独申请许可，但金猿山自然休养林等韩国山林厅所辖自然休养林路段可能收取少额门票，建议到现场售票处确认。厕所在金猿山自然休养林区域的路线（管理事务所、林中小屋停车场路线等）设有多处，但公共数据中饮水台数量记录为 0 处，出发前务必备足饮用水。地图应用方面，比起谷歌地图，KakaoMap 或 Naver Map 对韩国境内的登山路线和公共交通信息准确得多，建议使用这两款。顶峰一带的岩脊路段存在安全事故风险，不建议独行，最好有人同行，并且一定要带好手机电量和紧急联络手段。

附近的其他山

  • 坐拥大慧瀑布与山城岩脊的龟尾金乌山 — 直线距离约 63km
  • 藏着佛教遗迹的花岗岩山脊，大邱八公山 — 直线距离约 88km
  • 石柱如屏风般排开的光州无等山 — 直线距离约 94km
