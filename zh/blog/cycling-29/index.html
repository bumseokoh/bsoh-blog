概述

照片：韩国观光公社观光照片图库（101-1 新兴寺）· 公共努里（Kogl）授权

莞岛树木园自行车道（Wando Sumogwon Jajeongeo-gil / Wando Arboretum Bicycle Road）是一条单程线路，舞台就在朝鲜半岛最南端的岛屿地区——全罗南道莞岛。它和国土纵贯四大江线路那种沿汉江、洛东江延绵铺开的大型纵贯路线，性格完全不同。这条路的魅力不在规模，而在密度：暖温带林木葱郁的树木园一带的满眼绿意、岛屿特有的海岸风光，还有城市自行车道上难得一遇的安静地方公路的节奏，全都浓缩在同一条线路里。

玩法大致可以归纳为四种。

**第一，当日往返骑行。**单程距离不算吃力，上午出发、中午前后抵达终点，下午原路返回，行程安排毫无压力。最省心的方式是把住处订在莞岛邑内，轻装上阵、不带行李地走一趟。

**第二，作为南道跳岛游的一段。**莞岛一带有跨海大桥相连的岛屿和沿岸公路，很适合把这条线路嵌进两天一夜的南海岸骑游中，作为其中一天的行程。常见的安排是第一天骑完这条线路，在莞岛住一晚，第二天再向周边的海岸公路延伸。

**第三，小轮车、折叠车与公共交通的联运。**把 Brompton 或 Dahon 这类折叠自行车收起来，坐高速大巴或火车过去，到了当地再展开骑——这种玩法和这条线路尤其合拍。距离不长，也没有连续的陡坡，小轮径车完全应付得来。

**第四，家庭骑行和新手的分段体验。**不必骑完全程，只在树木园周边的平坦路段往返一趟，也已经是一次相当尽兴的骑行了。

路线信息

图片：韩国观光公社旅游图片库（海边公园路124街26号）· 公共努里（Kogl）授权

这条路线以莞岛树木园（Wando Arboretum）一带为起点，沿莞岛本岛的海岸与内陆公路延伸，属于单程型线路。莞岛树木园地处国内罕见的暖温带常绿阔叶林地带，所以从出发点开始，映入眼帘的植被就与其他地区的自行车道截然不同。山茶树、红楠、赤皮青冈这些冬天也不落叶的树木在道路两旁排开，即使在隆冬时节，你也能看到一片依然葱绿的风景。

路面性质与汉江、洛东江自行车道不同。它不是那种沿着江边堤路、与机动车完全分离的专用车道连绵数十公里的形态，而更接近于地方道、郡道的路肩与自行车混行道交替出现的构成。因此，做好与机动车共用路面的心理准备，骑行起来会更安全。柏油路况总体尚可，但海岸公路的特性决定了局部可能出现沙子、落叶或湿滑路面。

海拔曲线并非完全平坦。由于是海岛地形，沿海岸线骑行时翻越岬角与海湾，短促的上坡会反复出现，这是常态。不过并没有一口气爬升几百米的正经爬坡，只要齿比留足余量，初、中级骑友也完全应付得来。

风景的高光，无疑是大海与森林同时入眼的路段。左手边是多岛海层层叠叠的岛屿，右手边是常绿林投下的树荫，这样的画面一路反复上演。莞岛是鲍鱼养殖非常兴盛的地区，在海岸路段，你还能看到海面上密密麻麻的养殖场浮标织出的独特网格景观。

有一点需要明确知晓：这条路线不属于国土纵走认证制的对象路线。因此沿途没有设置认证中心，也没有盖章认证分段完骑的流程。与其当作收集认证印章的旅行，不如把它当成一场享受风景与在地风情的旅程，这才是正确的打开方式。

周边美食

照片：韩国观光公社旅游照片图库（清海镇路1380-138）· 公共努里（Kogl）授权

在韩国，说起鲍鱼（jeonbok，abalone），人们最先想到的地方就是莞岛。众所周知，全国相当大比例的鲍鱼产量都出自这一带，所以在莞岛邑内和港口周边，鲍鱼刺身、鲍鱼粥、烤鲍鱼、鲍鱼水拌生鱼片之类的菜品随处可见。骑行途中或结束后想吃点恢复餐，鲍鱼粥通常是最稳妥的选择——好消化、咸味也不重，大量出汗之后吃起来没什么负担。

海藻类也是这里的招牌美食。**海苔（gim，未调味的干海苔）、海带芽（miyeok）、昆布（dasima）养殖十分兴旺，到了冬天，加入莞岛细海苔（maesaengi）**煮的汤常被当作这个季节的时令美味来介绍。此外，作为全罗南道的海滨地区，比目鱼、许氏平鲉之类的白肉鱼刺身、章鱼料理，以及小菜种类繁多的南道式白饭套餐，也都很容易吃到。

从补给的角度，有一点必须提醒各位：**这条路线和便利店密布的首都圈江边骑行道完全是两回事。**便利店和餐馆都集中在莞岛邑内、面所在地这样的村镇里，而村镇之间的海岸和山林路段，可能连续好几公里见不到一家店铺。尤其是通往树木园方向的森林路段和人迹稀少的海岸路段，更是如此。

另外，地方小城镇的店铺**营业时间短、休息日不固定的情况很常见。**傍晚才到、想找地方吃饭，结果只看到一家家关门的店——这种事真的会发生。所以在这条路线上，每经过一个村镇就提前补足饮水和路餐，这个习惯格外重要。

补给与便利设施

照片：韩国观光公社旅游照片图库（开浦路159街55号）· 公共努里（Kogl）授权

出发前请务必对沿线设施状况有清醒的认识。这条线路登记在册的认证中心为 0 处、卫生间 0 处、饮水点 0 处、打气筒 0 处。也就是说，路线上没有任何专为自行车道配套管理的便利设施。在江边自行车道上常见的无人认证亭、饮水机、公用打气筒，在这条线路上就别指望了。

不过也并非毫无办法。实际骑行中可以按下面的方式解决：

需求现实可行的替代方案
补水村镇便利店、超市、餐馆、旅游咨询处
卫生间树木园设施、公园及停车场、面事务所（乡镇政府）、加油站、餐馆
打气必须自带便携打气筒或 CO₂ 气瓶
爆胎及机械故障以自行修理为前提，建议携带 2 条备用内胎
紧急情况提前存好当地出租车电话

建议出发时至少灌满两个水壶（合计 1.5 升以上），夏天还需要更多。自行车修理店基本只有邑内（镇上）才有，链条油、多功能工具等基础维修套装最好自己带齐，才更稳妥。

前面也提到过，这条线路不在认证制范围内，所以认证手册、盖章、完骑证书那一套流程在这里统统不适用。对国土纵走认证感兴趣的朋友，可以参考下文”外国游客小贴士”中关于认证制的说明，但请记住：那些流程要在四大江等认证制线路上进行，而不是这条线路。

返程

照片：韩国观光公社观光照片图库（张保皋大路332）· 公共许可（KOGL）

虽然这是一条单程型线路，但返程负担并不大。单程39.2公里，即便原路折返，往返也就78.4公里左右，这个距离在一天的行程里完全消化得了。不需要另行安排长途返程交通。

而且，我反而更推荐往返骑行，还有一个理由：海岸公路随行进方向不同，看到的风景会完全两样。去程大海在右手边，回程则在左手边，虽是同一条路，实际上却像在骑另一条路线。加上光线角度的变化，下午返程那段反而更令人印象深刻的情况也不少。

如果担心体力吃不消，也可以把车停在出发地，只骑单程，再搭当地出租车或市内公交返回。不过地方公交的班次间隔较长，最好提前查好时刻表。

安全·注意事项

照片：韩国观光公社旅游照片图库（张保皋大路339）· 公共许可（KOGL）

**应对人车混行路段，是这条路线安全问题的核心。**路线中存在与机动车共用路面的区段，因此对后方来车的感知能力非常重要。建议尾灯白天也开着日间行车模式。货车或渔业相关车辆随时可能经过，请保持骑行线路稳定，不要向左侧大幅偏移。

海岸路段的侧风务必放在心上。海岛地区的滨海公路，在地形豁然开阔的地方会突然刮来强劲的侧风。碟轮或高框轮组并不适合这条路线。风大的日子里，请放松握把、压低上身来保持稳定。

路面杂物同样需要留意。滨海公路上有时会散落着沙子、贝壳碎片和海藻残骸，被打湿后非常滑。请把”入弯前减速”当作铁律。

冬季路面结冰——就算莞岛气候温和，也不能掉以轻心。背阴的林间路段、桥面上、清晨时段都可能出现暗冰。

**不建议夜间骑行。**没有路灯的路段相当多，也存在野生动物突然窜出的可能。如果不得已天黑了还在路上，前灯请使用光量充足的产品（400流明以上），并穿着带反光材料的服装。

最后要强调的是补水管理。这条路线沿途没有取水点，所以原则不是”渴了才喝”，而是每20~30分钟定时喝一次。夏季最好搭配电解质饮料或盐丸一起补充。

季节·天气·装备

照片：韩国观光公社旅游图片库（竹青路94-73）· 公共努里版权

**推荐季节是春季（4~5月）和秋季（10~11月）。**这段时间的莞岛气温温和、湿度较低，骑行状态最佳。尤其是春天，山茶花等暖温带林植被生机盎然，树木园路段的体验感很高。

**夏季（7~8月）是最难熬的季节。**在南海岸地区，比起气温本身，高湿度才是加重体感负担的主因。再加上这条路线沿途没有补水点，风险就更高了。如果非要夏天骑，建议凌晨到上午9点之间出发，中午前收工。另外，6~9月可能受台风影响，出发前务必确认天气预报。

**冬季（12~2月）出乎意料地不算糟。**莞岛属于韩国冬季最温暖的地区之一，降到零下的日子不多，而且托常绿林的福，冬天也能欣赏到绿色风景。不过海风会让体感温度大幅下降，防风夹克和脖套是必需的。

必备装备整理如下。

类别项目
必备头盔、前后车灯、便携打气筒、备用内胎和撬胎棒、多功能工具、水壶2个

② 骑行认证制度（Certification System）实战指南 — 本线路不在认证范围内

先把话说清楚：**莞岛树木园自行车道并不属于国土纵贯骑行认证制度的线路。**骑完这条路线，既没有可以盖章的认证中心，也无法申领完骑证书。以下内容是为您日后单独挑战韩国认证线路（汉江、洛东江、锦江、荣山江等）时准备的指南。

认证手册（Bike Passport） — 韩国的国土纵贯认证制度采用在纸质手册上集章的方式运作。手册在有人值守的认证中心现场购买，实际上是唯一靠谱的途径。官方认证网站只有韩语版本，且经常因海外发行的银行卡无法支付、或需要韩国实名认证等问题而无法提前在线购买，所以抵达韩国后在遇到的第一个有人值守中心直接购买，最省心。

无人认证中心使用方法 — 认证中心大多是无人值守的。您只需寻找一个外形酷似红色公用电话亭的小亭子。亭子里有用链条拴着的印章，自己在手册的对应格子里盖章即可，全程自助。没有工作人员，也不收费。印章油墨干涸的情况时有发生，如果一次盖不清楚，就用力按住几秒钟。亭子的位置在地图应用里搜索”인증센터”（认证中心）大多能找到。

完骑奖励 — 一般流程是：骑完某一区段、集齐该区段的全部印章后，可在指定窗口领取区段完骑认证贴纸；完成国土纵贯全部区段后，可获颁完骑证书和奖牌。具体的发放地点和条件，还是以现场认证中心的说明为准。

③ 不带自行车前来的情况

这条路线**建议以自带自行车、或事先落实好的租赁自行车为前提来规划，这样最稳妥。**莞岛是个小规模的郡级地区，很难保证旅游型租车点常年营业，公路车、山地车这类性能车更是难寻。建议出发前先向住宿处或莞岛郡旅游咨询处确认能否租到车。

首尔公共自行车（Ttareungi，Seoul Bike） — 这是首尔市的公共自行车，也是为数不多支持英文应用、且可用海外发行银行卡支付的服务之一。不过**它仅限首尔地区使用，在莞岛用不了。**如果您在首尔停留期间想提前体验一下韩国的自行车基础设施，它倒是个很好的选择。

长途移动时携带自行车 — 折叠自行车装进车袋后，带上高速大巴和火车大体都比较顺利。普通自行车则因线路和车型不同、规定各异，购票前需要确认。从首尔前往莞岛方向，一般选择乘坐高速大巴。
