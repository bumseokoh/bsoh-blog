概述

照片：韩国观光公社观光照片图库（江原特别自治道洪川郡东面）· 公共누리

孔雀山（공작산，Gongjaksan）位于江原特别自治道洪川郡花村面一带，按老版本的山顶标石记载，海拔为886米，但根据实测GPX数据，路线上的最高点其实达到923米。整座山不算是那种险峻的岩峰型山峰，但越靠近山顶，高度差会拉得相当明显。从好几个登山口出发，单程到山顶都在8~14公里之间，所以这更像是一座得空出一整天才能好好走一趟的山，而不是随便抽半天就能搞定的那种。如果选一条方便到达、距离较短的路线，当天往返完全没问题；但要是选择那种把山顶一带几座山峰串起来走的纵走路线，行程距离和所需时间都会大幅增加，这一点最好提前有个心理准备。

山势与地形

照片：韩国观光公社观光照片图库（江原特别自治道洪川郡东面）· 公共누리

孔雀山与那种岩壁尖峭连绵的”骨山”不同，整体更接近山脊平缓延展的”肉山”，不过山顶一带却接连立着好几座山峰，山势并不单一。光看公共数据里登记的主要峰头就有一长串：药水峰主峰（557米）、药水峰558（537米）、秃鹰峰（820米）（789米）、秃鹰峰（755米）（773米）、孔雀山秃鹰峰主峰（780米）、640峰（652米）、고사리峰（466米），还有孔雀山主峰（旧山顶标石所在处，886米）——各种高度的山峰沿着山脊依次排开。峰名和海拔标得这么细密，恰恰说明孔雀山不是那种孤零零一个尖顶的山，而是好几座峰头肩并肩连成一片的”连峰”。沿途还分布着大片老松林、红松林、落叶松造林地、橡树林等针叶阔叶混交的森林，走在山脊上，能明显感觉到树种一路在变换。

登山的感觉

사진: 한국관광공사 관광사진 갤러리 (강원특별자치도 홍천군 동면) · 공공누리

孔雀山这条线路，前段是平缓好走的林间小路，走到中后段就会穿过老松群落、잣나무（红松）林之类针叶树密集的地带，树荫一下子浓了起来。有些路线还会顺路经过孔雀瀑布、屈云水库、防砂坝这些跟水沾边的地形，也能体验到一点溪谷山行的味道。快到山顶的观景点附近视野会豁然开朗，但整体来说林木茂密的路段占大头，所以哪怕是酷暑天走这条线也大多有树荫可躲。不过很多路线单程距离都不短，越到后半段越容易感觉体力被一点点耗光，尤其是走纵走型路线时，会经过标着”注意坠落""坠落危险”的路段，那几步是真不敢掉以轻心。到了秋天，落叶松、橡树群落的红叶，春天的新绿，都会让整条路线的氛围柔和不少。

路线1 — 孔雀桥 → 山顶

📏 8.19km ⛰️ 601m 爬升 ⏱️ 3:03 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

经由：孔雀桥 → 亭子休息处 → 岔路口 → 老松树群落地 → 老松树群落地尽头 → 落叶松种植区

登山口交通：孔雀桥据了解位于洪川郡花村面一带，从洪川市区开车约需20~30分钟。公共交通一般是先在洪川客运站坐开往花村面方向的郡内巴士，再步行前往；目前没有确认到正规划设的登山停车场，所以自驾的话大多只能停在路边或找块小空地将就一下。

特点·推荐人群：在6条路线里属于距离较短、相对好走的一条。从入口到亭子休息处这段是平缓的林间小路，走到老松树群落地时能感受到古松林特有的韵味。适合第一次来孔雀山的登山者，或者只想当天往返、轻松逛一圈的人。

路线2 — 孔雀山入口停车场·洗手间 → 山顶

📏 12.86km ⛰️ 714m 爬升 ⏱️ 4:24 ➡️ 单程 难度 ★★★★★ ⤓ GPX

途经：孔雀桥 → 榉树休息处 → 拍照点 → 岔路口4 → 孔雀山入口停车场·洗手间 → 落叶松林 → 小心坠落路段 → 观景点 → 山顶 → 红松林 → 橡树林 → 640峰 → 红松林 → 老松林 → 老松林

登山口交通：顾名思义，这里从带洗手间的空间出发，是6条路线里对新手最友好、最容易找到入口的一段。不过这里并不是官方登记的登山专用停车场，规模不算大，旺季去的话最好留意车位可能爆满。从洪川市区开车大约20~30分钟，坐公交的话可以搭往华村面方向的车，下车后再步行过去。

特点·适合人群：这条路线的距离和爬升高度在6条里都是最大的，难度也是最高档（★★★★★）。沿途设有榉树休息处、拍照点等好几处歇脚的地方，接近山顶的观景点视野也不错，但实地路标上特别标出了”小心坠落”路段，务必格外留神。比较适合体力有把握、或打算把一整天都留给这次登山的人。

路线3 — 掘云水库站 → 山顶

📏 12.82km ⛰️ 718m 爬升 ⏱️ 4:24 ➡️ 单程 难度 ★★★★★ ⤓ GPX

沿途：掘云水库站 → 岔路口 → 阳光度假花园（햇살팬션가든）→ 坠落危险区 → 松林群落 → 老松群落 → 红松林 → 私营孔雀山（공작산）休养林

起点交通：掘云水库站是附近登记在册的公交站之一，坐公交能直接下车开走，算是最省事的起点。开车的话，很多人也是把车停在水库周边的空地上。

特色·适合谁走：一开始沿着掘云水库绕行的那段风景很不错，经过阳光度假花园之类的住宿设施后，就进入松林和红松林区。中间有一段标着”坠落危险”的路段，下雨天或结冰季节尤其要小心，别大意。这条线还会经过私营的孔雀山休养林附近，所以想顺便体验一下自然休养林氛围的人会比较适合走这条。

路线4 — 屈云水库公交站 → 落叶松林区

📏 13.91km ⛰️ 706m 爬升 ⏱️ 4:39 ➡️ 单程 难度 ★★★★★ ⤓ GPX

沿途站点：屈云水库公交站 → 岔路口 → 落叶松林区 → 孔雀瀑布 → 那奔村站（郡业2里）

入山接近方式：与路线3一样从屈云水库公交站出发，但终点在那奔村站（郡业2里）附近，可以搭乘大众交通，实现入山口和下山口分离的行山方式。

特点·推荐对象：这是一条不一定要登顶、穿过落叶松林区和孔雀瀑布后从对面下山的纵走路线，全长13.91公里，是6条路线中最长的一条。沿途能欣赏孔雀瀑布等溪谷景观，适合喜欢瀑布、溪谷风光，或是计划安排入山口和下山口不同的纵走行程的人。

路线5 — 老岘坪 → 山顶

📏 8.54km ⛰️ 543m 爬升 ⏱️ 3:02 ➡️ 单程 难度 ★★★★☆ ⤓ GPX

沿途节点：老岘坪 → 墓地 → 岔路口10 → 老松林地 → 岔路口13 → 侧柏林地 → 落叶松植林区

登山口交通：老岘坪是村落地名，一般做法是先开车到附近，再步行走到登山口。搭大众交通工具的话，建议提前查一下洪川郡内公交的路线和站点位置。

特点·推荐人群：这条路线全长8.54公里，爬升543米，在六条路线里坡度算是比较平缓的一条，走起来没什么压力。沿途会经过墓地、侧柏林地等地方，也能顺带看看村庄周边那种质朴亲切的风景，适合想轻松快速登上孔雀山的初中级登山爱好者。

路线6 — 屈云水库 → 落叶松栖息地带

📏 10.44km ⛰️ 617m 爬升 ⏱️ 3:38 ➡️ 单程 难度 ★★★★★ ⤓ GPX

沿途经过：屈云水库 → 萤火虫栖息地 → 风景画Pension → 岔路口7 → 防砂坝 → 落叶松栖息地带 → 红松林地 → 岔路口20 → 岔路口21 → 岔路口11 → 岔路口12 → 老松树群落地 → 岔路口14 → 秀里峰(820m) → 岔路口16

登山口交通：从屈云水库附近出发。搭乘大众交通的话，在屈云水库站下车后步行即可；开车前往则可以停在水库周边的空地上。

特点及推荐对象：这是6条路线里途经指示牌最多的一条，沿途会经过萤火虫栖息地、防砂坝、秀里峰（820米）等各式各样的生态与地形要素，是一条纵走型的长距离路线。比较适合想把孔雀山各座山峰尽收眼底、深入感受山势起伏的资深登山爱好者，由于全程不短，建议预留充裕的时间再出发。

难度·路面·注意事项

照片：韩国观光公社观光图片库（江原特别自治道洪川郡东面）· 公共누리

公雀山境内的登山道按行政区（行政洞）划分，共登记了4个区段，数据显示各区段难度均为”简单”。不过要注意，这里统计的并非单条登山路线，而是把整个辖区登山道按行政洞切分后得出的总里程区段。

虽然按行政洞统计的数据里最高难度只标为”简单”，但按百大名山GPX数据来看，登顶路段的单程距离和高度落差都相当可观，实际体感难度很可能比数据标注的要高。路面信息目前没有单独登记，具体是否铺装无从确认；不过现场路标中有些区段出现了”注意坠落""坠落危险”的警示标识，雨后初晴或冬季结冰时尤其要小心防滑。观景点、饮水处、避难所、危险区域等设施类POI都没有官方登记点位，所以爬山途中很难指望能有额外的补水点或避难设施，这点务必提前做好准备。

距离与耗时

照片：韩国观光公社观光照片图库（江原特别自治道洪川郡东面）· 公共누리

把辖区内所有登山路线累加起来算，上行总共需要622分钟、下行435分钟，换算成总长29.81公里的话，平均上行配速大约是每公里21分钟。不过这只是把整个辖区步道首尾相连后的累计数字，千万别误当成走完某一条具体路线所需的时间——实际每条路线的耗时，还是要参考上表里单程约3小时到4小时40分钟这个区间才准确。像孔雀桥、老岘坪登山口这类短线,即便按往返计算，一天之内也绰绰有余；但单程12～14公里的路线，往返下来总耗时可能超过8～9个小时，建议一大早就出发。如果打算安排一趟串联多座山峰的纵走行程，考虑到辖区步道总长29.81公里、且沿途完全没有避难设施，最好从容地规划成1晚以上的行程，这样才安全。

交通方式（大众交通·停车）

照片：韩国观光公社观光照片图库（江原特别自治道洪川郡东面）· 公共누리

公雀山附近确认有公雀洞、掘云水库、瓦洞소니고개等公交站点。从首尔等首都圈出发,一般是在东首尔综合客运站或上凤客运站乘坐开往洪川的市外巴士,抵达洪川客运站后,换乘开往花村面方向的郡内公交,在公雀洞、掘云水库、瓦洞소니고개等自己想去的登山口附近站点下车。不过郡内公交发车间隔比较大，建议提前查好时刻表。开车前往的话，目前没有确认到正式登记的登山专用停车场，大家多是利用像路线2里提到的”公雀山入口停车场”这类小有名气的小型空地,或者掘云水库附近的空地停车。实际路线和最新的大众交通信息，强烈建议在KakaoMap或Naver Map上搜索”공작산”或各登山口地名（공작교、굴운저수지、노현들等）后再确认一遍。

季节·天气·装备

照片：韩国观光公社观光照片图库（江原特别自治道洪川郡东面）· 公共누리

孔雀山春秋两季爬起来最舒服，新绿和红叶都能赶上。夏天林子密，走在树荫下倒也凉快，但山上没有正儿八经的取水点，大热天很容易脱水，出发前一定要多备些水。冬天要小心的是老松林、잣树林那几段背阴路，还有标着”注意坠落""坠落危险”的地方，特别容易结冰，最好带上冰爪、绑腿之类的防滑防寒装备。基本装备准备好登山鞋、备用衣物、登山杖、头灯（走长线的话尤其需要），水和干粮也要备足。山上没有避难设施，天气一旦变坏就别硬撑着走完全程，早点下山才是正经。

外国游客小贴士

照片：韩国观光公社观光照片图库（江原特别自治道洪川郡东面）· 公共누리

公雀山的罗马字标注为Gongjaksan(Mt. Gongjak)，主要地名标注为公雀桥(Gongjak-gyo)、堀云水库(Guluun Reservoir)、老岘平原(Nohyeondeul)等。目前没有确认需要另行申请入山许可或购买门票，据了解这座山不像国立公园、道立公园那样设有售票处，可以直接进入，但保险起见，最好还是以现场指示牌上的最新信息为准。厕所只在路线2的起点（“公雀山入口停车场，厕所”）有确认记录，其余路段没有登记的厕所或饮水处，出发前请务必自行准备。谷歌地图（Google Maps）对韩国境内登山路线的信息常常不够准确，建议提前安装KakaoMap或Naver Map应用，事先查好交通方式和实际登山路线。山中部分路段手机信号可能较弱，建议提前下载离线地图，而且沿途没有避难设施，最好把日落前下山作为行程规划的目标，这样比较稳妥。
